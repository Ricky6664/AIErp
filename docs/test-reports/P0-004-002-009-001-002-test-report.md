### 2.1 selectWorkbenchStats — 核心统计

```sql
SELECT
    (SELECT COUNT(*) FROM sys_user WHERE is_deleted = 0) AS total_users,
    (SELECT COUNT(*) FROM auth_online_device WHERE status = 'online') AS online_users,
    (SELECT COUNT(*) FROM sys_user WHERE is_deleted = 0
       AND create_time >= date_trunc('month', CURRENT_TIMESTAMP)) AS new_users_this_month
```

| 检查项 | 结果 | 说明 |
|--------|:---:|------|
| 参数化防注入 | ✅ | 无用户输入参数，全为字面量 |
| 软删除过滤 | ✅ | `is_deleted = 0` |
| PostgreSQL 函数 | ✅ | `date_trunc('month', CURRENT_TIMESTAMP)` 为 PG 标准函数 |
| XML 特殊字符转义 | ✅ | `>=` 正确转义为 `&gt;=` |
| 租户隔离 | ✅ | TenantLineInnerInterceptor 自动注入 tenant_id |
| 表存在性 | ✅ | sys_user、auth_online_device 均已在 P0-003 建表 |

### 2.2 selectRoleDistribution — 角色分配统计

```sql
SELECT r.role_name, COUNT(ur.user_id) AS user_count
FROM sys_role r
LEFT JOIN sys_user_role ur ON r.id = ur.role_id AND ur.is_deleted = 0
WHERE r.is_deleted = 0
GROUP BY r.id, r.role_name
ORDER BY user_count DESC
```

| 检查项 | 结果 | 说明 |
|--------|:---:|------|
| LEFT JOIN 策略 | ✅ | 无用户的角色也能显示（COUNT=0） |
| GROUP BY 完整性 | ✅ | 包含 r.id 防止同名角色合并 |
| 排序逻辑 | ✅ | 按用户数降序，最多用户的角色排最前 |

### 2.3 selectDeptDistribution — 部门关联统计

```sql
SELECT d.dept_name, COUNT(ud.user_id) AS user_count
FROM sys_dept d
LEFT JOIN sys_user_dept ud ON d.id = ud.dept_id AND ud.is_deleted = 0
WHERE d.is_deleted = 0
GROUP BY d.id, d.dept_name
ORDER BY user_count DESC
```

| 检查项 | 结果 | 说明 |
|--------|:---:|------|
| LEFT JOIN 策略 | ✅ | 无用户的部门也能显示（COUNT=0） |
| GROUP BY 完整性 | ✅ | 包含 d.id 防止同名部门合并 |
| 排序逻辑 | ✅ | 按用户数降序 |
