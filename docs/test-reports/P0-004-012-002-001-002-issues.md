### 问题 #2：默认AES密钥为硬编码

| 属性 | 描述 |
|------|------|
| 严重程度 | 🔴 高 |
| 位置 | `OAuth2ConfigController.java:52` |
| 问题描述 | `@Value("${aes.secret-key:default-key-change-me-in-production}")` 在配置缺失时使用弱默认密钥。若运维未配置环境变量，所有ClientSecret将使用已知默认值加密，形同明文。 |

| 修复方案 | 方案A：移除默认值，启动时若未配置则抛出启动失败。方案B：启动时检测默认值并打印WARN日志提醒。建议方案A（更安全）。 |
| 状态 | 📋 待修复（P0阶段可接受，上线前必须修复） |
