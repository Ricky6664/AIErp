## 已修复问题

### 问题 #1：el-option undefined 值类型错误

- **文件**：`erp-ai-web/src/views/system/user/UserGroupList.vue:26`
- **错误**：`TS2322: Type 'undefined' is not assignable to type 'EpPropMergeType<...>'`
- **原因**：el-option 的 `:value="undefined"` 不符合 Element Plus 组件类型要求
- **修复**：移除"全部"选项，el-select 已有 `clearable` 属性支持清空筛选
- **状态**：✅ 已修复

### 问题 #2：el-table 行类型不匹配

- **文件**：`erp-ai-web/src/views/system/user/UserGroupList.vue:80,92,102`
- **错误**：`TS2345: Argument of type 'DefaultRow' is not assignable to parameter of type 'UserGroupListItem'`
- **原因**：Element Plus el-table 列模板的 `row` 默认类型为 `DefaultRow`，不是泛型用户类型
- **修复**：在模板回调中添加 `as` 类型断言：`handleEdit(row as { id: number })` 等
- **状态**：✅ 已修复

### 问题 #3：el-switch change 事件类型不匹配

- **文件**：`erp-ai-web/src/views/system/user/UserGroupList.vue:80`
- **错误**：`TS2322: Type '(val: boolean) => Promise<void>' is not assignable to type '(val: string | number | boolean) => any'`
- **原因**：Element Plus el-switch 的 @change 事件参数类型为 `string | number | boolean`，不是 `boolean`
- **修复**：回调签名改为 `(val: string | number | boolean)`，内部用 `val as boolean` 断言
- **状态**：✅ 已修复

### 问题 #4：操作列缺少"成员管理"按钮

- **文件**：`erp-ai-web/src/views/system/user/UserGroupList.vue:84-107`
- **规格要求**：Section 5.1 第5点：操作列需包含"成员管理(跳转组成员管理)"按钮
- **修复**：添加 UserFilled 图标按钮，权限 `system:user-group:member`，路由跳转到 `/system/user-group/:id/members`
- **状态**：✅ 已修复
