## 错误处理与边界条件

| 场景 | 分析 | 结论 |
|------|------|:--:|
| 菜单树为空（后端返回 []） | allTreeData = []，menuTreeData = []，表格显示空数据 | PASS |
| API 调用失败（网络异常） | catch 块清空数据 + ElMessage 提示（通过拦截器） | PASS |
| 加载详情失败 | ElMessage.error('加载菜单详情失败') | PASS |
| 更新排序失败 | ElMessage.error('更新排序失败') | PASS |
| 表单校验未通过 | validate() 返回 false，不提交 | PASS |
| 提交中重复点击 | submitLoading 禁用按钮 | PASS |
| parentId 为 0（根节点） | loadDetail 中将 parentId===0 映射为 undefined | PASS |
| permissionCode 空字符串 | 提交时转为 undefined（不发送空字符串） | PASS |
| 图标字段为空 | 显示 '-' 占位文本 | PASS |
| 子菜单全部过滤掉 | 仅匹配父节点时 children 保留原值，未匹配父但子匹配时仅保留匹配子节点 | PASS |
