## 五、发现的问题

### 问题 1: MsgMessageController 缺失
- **严重程度**：高
- **描述**：前端消息相关页面调用 `/api/message/message` 等端点，但后端无对应的 MsgMessageController
- **影响**：消息页面无法与后端通信
- **建议**：新增 MsgMessageController，映射 IMsgMessageService 的 CRUD 方法到 REST 端点

### 问题 2: DTO 缺少字段长度校验
- **严重程度**：低
- **描述**：`MsgMessageCreateDTO.messageTitle` 仅有空值校验，无 `@Size` 长度限制
- **影响**：超长标题可能导致数据库列溢出
- **建议**：添加 `@Size(max=200)` 注解

## 六、结论

全局消息通知弹窗的 Service 层 CRUD 功能验证通过（44/44 测试通过）。前端 GlobalNotification.vue 组件编译无错误，WebSocket/心跳/重连/轮询兜底机制实现正确。主要阻塞项为 MsgMessageController 缺失，需后续补充。
