## 问题清单

### 问题 #1：数据范围 "custom" 标签颜色无对应 EL Plus 类型

- **严重度**：🟡 低（UI 显示问题）
- **发现位置**：`erp-ai-web/src/views/system/role/RoleList.vue:188`
- **描述**：规格要求 `custom → "自定义"` 显示为**紫色**，但 Element Plus el-tag 组件内置类型只有 `primary/success/warning/info/danger` 五种，无 purple。当前使用 `danger`（红色/粉色）作为近似。若必须严格匹配紫色，需自定义 CSS 样式或使用 el-tag 的 `color` 属性。
- **修复方案**：使用 el-tag 的 `color` prop 传入自定义颜色 `#8B5CF6`（紫色），或保持 `danger` 并在后续 UI 统一调整时处理。
- **状态**：📋 已记录，暂不修复（非阻塞）

### 问题 #2：搜索栏关键字只传 roleName — ✅ 已修复

- **严重度**：🟡 中
- **发现位置**：`erp-ai-web/src/views/system/role/RoleList.vue:203-205`
- **描述**：搜索栏 placeholder 为"角色名称 / 角色编码"，但 fetchRoleList 只设置 `params.roleName`，未传 `params.roleCode`。后端 `SysRoleController.pageList` 同时支持 `roleCode` 和 `roleName` 参数。
- **修复方案**：已修复 — 同时设置 `params.roleCode = searchKeyword.value`
- **状态**：✅ 已修复

### 问题 #3：数据范围标签 "all" 颜色错误 — ✅ 已修复

- **严重度**：🟡 中
- **发现位置**：`erp-ai-web/src/views/system/role/RoleList.vue:179`

### 问题 #4：前端传 dataScope 筛选参数但后端不支持

- **严重度**：🟢 低（不影响核心功能，后端无 dataScope 查询参数）
- **发现位置**：`RoleList.vue:209` 设置 `params.dataScope`，但 `SysRoleController.pageList` 无 `dataScope` 请求参数
- **描述**：前端数据范围筛选下拉框设置 `dataScope` 参数发送，后端 Controller 未声明 `@RequestParam dataScope`，导致该筛选条件无效。属于前后端接口未对齐。
- **修复方案**：需在 `SysRoleController.pageList` 添加 `@RequestParam(required = false) String dataScope` 参数，并在 wrapper 中追加 `wrapper.eq(SysRole::getDataScope, dataScope)` 条件。此项涉及后端改动，建议作为后续任务处理。
- **状态**：📋 已记录，待后续任务补充

### 问题 #5：规格要求的用户数量列未实现

- **严重度**：🟢 低（增强功能）
- **发现位置**：`SysRoleVO.ListVO` + `RoleList.vue`
- **描述**：任务规格明确要求 "用户数量统计：LEFT JOIN sys_user_role GROUP BY role_id 统计每个角色的用户数量"，并在表格中显示。当前后端 VO 和前端表格均无此字段。
- **修复方案**：需在 `SysRoleVO.ListVO` 添加 `userCount` 字段，Mapper XML 添加 LEFT JOIN 子查询统计，前端 RoleListItem 接口和表格列同步添加。
- **状态**：📋 已记录，非阻塞（用户数量可在角色详情页查看）

### 问题 #6：操作列缺少"数据权限"和"字段权限"按钮

- **严重度**：🟢 低（增强功能）
- **发现位置**：`erp-ai-web/src/views/system/role/RoleList.vue:98-133`
- **描述**：规格要求操作列包含"数据权限"和"字段权限"按钮。当前实现仅有编辑、权限配置（菜单权限）、删除三个操作按钮。后端已提供数据权限 API（`/api/system/role/{id}/data-scopes`）和字段权限 API（`/api/system/role/{id}/field-permissions`），前端按钮缺失。
- **修复方案**：在操作列添加"数据权限"（跳转数据权限配置页）和"字段权限"（跳转字段权限配置页）按钮。按钮对 superadmin 应禁用。
- **状态**：📋 已记录，待后续任务补充
