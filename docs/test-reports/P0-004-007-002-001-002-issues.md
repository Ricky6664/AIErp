## 问题 #1: 测试文件 `vi` 全局未导入导致编译失败（已修复）

| 属性 | 值 |
|------|-----|
| 严重程度 | 中等 |
| 影响范围 | `erp-ai-web/src/composables/__tests__/usePermission.test.ts` |
| 发现方式 | `pnpm build` (vue-tsc -b) |
| 修复状态 | ✅ 已修复 |

**现象**: 执行 `pnpm build` 时 `vue-tsc -b` 报错 `error TS2304: Cannot find name 'vi'`，构建失败。

**根因**: 测试文件中使用了 vitest 的 `vi.mock()` 但未显式导入 `vi`，且 tsconfig 中未配置 vitest 全局类型。

**修复**: 在 import 语句中添加 `vi`:
```typescript
import { describe, it, expect, beforeEach, vi } from 'vitest'
```

**验证**: 修复后 `pnpm build` 成功，12 个 vitest 测试全部通过。
