## 一、问题清单

### 问题 #1: 后端API端点缺失 [严重] [阻塞]

| 属性 | 值 |
|------|-----|
| 严重级别 | 🔴 严重 (阻塞前后端联调) |
| 发现方式 | 代码审查 |
| 负责修复 | 后续后端任务 |

**问题描述**:
前端定义了3个API调用 (getLoginLogPageApi / clearLoginLogApi / exportLoginLogApi)，对应3个后端端点:
- `GET /api/system/login-log` — 分页查询登录日志
- `DELETE /api/system/login-log` — 清空所有登录日志
- `GET /api/system/login-log/export` — 导出登录日志

但后端没有任何Controller处理这些端点。当前LoginLogService仅负责异步写入日志，不提供查询功能。

**修复方案**:
创建 `LoginLogController.java`，实现:
1. `GET /api/system/login-log` → 调用 SysLoginLogMapper.selectPage 分页查询，LEFT JOIN sys_user 获取用户名
2. `DELETE /api/system/login-log` → 调用 SysLoginLogMapper.deleteAll (需超管权限)
3. `GET /api/system/login-log/export` → 调用 SysLoginLogMapper.selectList 全量导出

### 问题 #2: 前后端字段名不匹配 [中等] [后续任务]

| 属性 | 值 |
|------|-----|
| 严重级别 | 🟡 中等 (后端API实现时需注意) |
| 发现方式 | 代码审查 |
| 负责修复 | 后续后端任务 |

**问题描述**:
前端 `LoginLogItem` 类型与后端 `SysLoginLog` 实体存在两处不一致:

| 前端字段 | 后端字段 | 差异 |
|---------|---------|------|
| `username` | **不存在** (仅userId) | 前端需要username展示, 后端无此字段 |
| `logoutTime` | `logoutAt` | 命名不一致 |

**修复方案**:
1. username: 后端查询时 LEFT JOIN sys_user 获取用户名，在VO/Mapper XML中映射
2. logoutTime: 后端返回时在VO中命名为 logoutTime（或MyBatis-Plus @TableField 映射）

### 问题 #3: 导出格式与规格不一致 [轻微] [已知偏差]

| 属性 | 值 |
|------|-----|
| 严重级别 | 🟢 轻微 |
| 发现方式 | 代码审查 |
| 负责修复 | 无需修复 (可接受偏差) |

**问题描述**:
规格要求使用 `xlsx` 库导出Excel格式，文件名 `登录日志_YYYYMMDD.xlsx`。实际实现为CSV格式导出，文件名 `登录日志_YYYYMMDD.csv`。

**修复方案**:
CSV格式功能等效且无额外依赖，属于合理的实现选择。如需严格遵循规格，可安装 `xlsx` 依赖并切换为Excel导出。

### 问题 #4: isSuperAdmin 非响应式 [轻微] [代码改进]

| 属性 | 值 |
|------|-----|
| 严重级别 | 🟢 轻微 |
| 发现方式 | 代码审查 |
| 负责修复 | 前端开发 |

**问题描述**:
```typescript
const isSuperAdmin = ref(userStore.roles?.includes('superadmin') ?? false)
```
此值在组件初始化时计算一次，如果用户角色在会话中变化（如管理员修改角色），不会响应式更新。

**修复方案**:
改用 computed:
```typescript
const isSuperAdmin = computed(() => userStore.roles?.includes('superadmin') ?? false)
```

### 问题 #5: 登录时间为空时在线时长格式化可能异常 [轻微] [边界条件]

| 属性 | 值 |
|------|-----|
| 严重级别 | 🟢 轻微 |
| 发现方式 | 代码审查 |
| 负责修复 | 前端开发 |

**问题描述**:
`formatOnlineDuration(loginTime, logoutTime)` 中 `new Date(loginTime)` 如果 loginTime 为 null/undefined 会返回 Invalid Date，`getTime()` 返回 NaN，后续计算产生异常结果。

**修复方案**:
函数开头增加空值校验:
```typescript
if (!loginTime || !logoutTime) return '-'
```
