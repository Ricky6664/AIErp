## 问题清单

### Issue #1: valueTypeTag 返回值类型不兼容

| 属性 | 值 |
|------|-----|
| **严重程度** | 🟡 中等 - 编译阻断 |
| **文件** | `erp-ai-web/src/views/system/params/index.vue` |
| **行号** | 177-185 |
| **问题描述** | `valueTypeTag` 函数默认返回空字符串 `''`，但 ElTag 组件的 `type` prop 类型为 `'primary' \| 'success' \| 'warning' \| 'info' \| 'danger' \| undefined`，不接受空字符串 |
| **复现步骤** | 运行 `pnpm build` |

**当前代码**:
```typescript
function valueTypeTag(type: number): '' | 'success' | 'warning' | 'info' | 'danger' {
  const map: Record<number, '' | 'success' | 'warning' | 'info' | 'danger'> = {
    1: '',
    2: 'warning',
    3: 'info',
    4: 'danger',
    5: 'success'
  }
  return map[type] ?? ''
}
```

**修复方案**:
```typescript
function valueTypeTag(type: number): 'primary' | 'success' | 'warning' | 'info' | 'danger' {
  const map: Record<number, 'primary' | 'success' | 'warning' | 'info' | 'danger'> = {
    1: 'primary',
    2: 'warning',
    3: 'info',
    4: 'danger',
    5: 'success'
  }
  return map[type] ?? 'info'
}
```

### Issue #2: openEditDialog 参数类型不兼容

| 属性 | 值 |
|------|-----|
| **严重程度** | 🟡 中等 - 编译阻断 |
| **文件** | `erp-ai-web/src/views/system/params/index.vue` |
| **行号** | 71 |
| **问题描述** | `<el-table-column>` 的 `#default` slot 参数类型为 `DefaultRow`，但 `openEditDialog` 期望 `SysParamItem` |
| **复现步骤** | 运行 `pnpm build` |

**当前代码**:
```typescript
@click="openEditDialog(row)"
```

**修复方案**:
```typescript
@click="openEditDialog(row as unknown as SysParamItem)"
```
或使用类型断言:
```typescript
@click="openEditDialog((row as SysParamItem))"
```

### Issue #3: useAppInit 组合式函数未被集成

| 属性 | 值 |
|------|-----|
| **严重程度** | 🔵 低 - 功能缺失 |
| **文件** | `erp-ai-web/src/composables/useAppInit.ts` + `erp-ai-web/src/App.vue` |
| **问题描述** | `useAppInit` 定义了 `initialize()`、`setupWatermark()`、`applyThemeColor()` 及相关的 watch 监听器，但未在 `App.vue` 中调用。导致以下功能未激活：<br>1. 水印渲染（watermarkEnabled 变化时）<br>2. 主题色动态切换监听（themeColor 变化时 CSS 变量同步）<br>3. 初始化错误状态追踪（initError） |

**修复方案**:
在 `App.vue` 中集成:
```typescript
import { useAppInit } from '@/composables/useAppInit'

const { initialize, setupWatermark } = useAppInit()

onMounted(async () => {
  await initialize()
  setupWatermark()
})
```
