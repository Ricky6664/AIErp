## 发现清单

### 建议 #1：loadReferenceData 静默失败

- **严重程度**：建议（非阻塞）
- **位置**：UserGroupForm.vue:182-184
- **描述**：加载用户列表和角色列表失败时，catch 块静默忽略。用户可能在参考数据为空的情况下提交表单，不知道数据加载失败。
- **建议方案**：可在开发环境 console.warn 输出错误信息，生产环境保持静默降级。
- **状态**：已知悉，当前降级策略可接受

### 建议 #2：handleSubmit 错误无用户反馈

- **严重程度**：建议（非阻塞）
- **位置**：UserGroupForm.vue:259-261
- **描述**：提交保存失败时，catch 块为空（注释写明由 interceptor 统一处理）。如果 interceptor 未正确处理特定错误码，用户可能看不到失败反馈。
- **建议方案**：确认 axios interceptor 对 4xx/5xx 错误均有 toast 提示。
- **状态**：已知悉，依赖 interceptor 全局处理

### 建议 #3：shuttle 数据搜索大小写敏感

- **严重程度**：建议（非阻塞）
- **位置**：UserGroupForm.vue:187-189
- **描述**：`filterUser` 方法虽然使用了 `toLowerCase()`，但如果用户名包含特殊 Unicode 字符，`toLowerCase()` 行为可能不符合预期。
- **建议方案**：当前实现覆盖常见中英文场景，特殊字符场景极少，暂不处理。
- **状态**：已知悉，无需修改
