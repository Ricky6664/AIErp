### 问题 1：缺少验证码图片生成接口 (继承自 P0-004-011-001-001-001 #1)

| 属性 | 值 |

| 严重程度 | 🟡 中 |
| 状态 | ⚠️ 已跟踪 — 由后续任务处理 |

| 影响范围 | 前端登录页无法获取验证码图片 |

**描述**：
`CaptchaService.generateCaptcha()` 只返回 UUID key，不生成实际的验证码图片(base64或image/png)。需要新增 Controller 端点将验证码文本渲染为图片后返回。

**当前状态**：该功能由后续任务负责：
- P0-004-011-001-002-001（前端登录页验证码组件）
- P0-004-011-001-002-002（后端登录接口改造）

**修复方案**：在 AuthController 添加 `GET /auth/captcha` 端点，使用 BufferedImage 生成图形验证码图片，返回 base64 编码或 image/png 二进制流。

### 问题 2：CaptchaService 未使用 AuthProperties 配置 (继承自 P0-004-011-001-001-001 #2)

| 属性 | 值 |
|------|-----|
| 严重程度 | 🟡 中 |
| 状态 | ⚠️ 已跟踪 |
| 来源 | P0-004-011-001-001-001-issues.md #2 |
| 影响范围 | TTL和验证码长度不可动态配置 |

**描述**：
`CaptchaService` 中硬编码了 TTL（`CAPTCHA_TTL = 5`）和验证码长度（`generateRandomCode(4)`），未注入 `AuthProperties` 使用配置项。

```java
// 当前：硬编码
private static final long CAPTCHA_TTL = 5;
// ... generateRandomCode(4);

// 应改为：注入 AuthProperties
private final AuthProperties authProperties;
// ... authProperties.getCaptcha().getTtlMinutes()
// ... authProperties.getCaptcha().getCodeLength()
```

**当前状态**：AuthProperties 已正确定义（含 `captcha.ttlMinutes` 和 `captcha.codeLength`）且测试通过，但 CaptchaService 未使用。

**修复方案**：在 CaptchaService 中注入 AuthProperties，替换硬编码值。

### 问题 4：Math.random() 非加密安全 (继承自 P0-004-011-001-001-001 #4)

| 属性 | 值 |
|------|-----|
| 严重程度 | 🟢 低 |
| 状态 | 💡 建议改进 |
| 来源 | P0-004-011-001-001-001-issues.md #4 |
| 影响范围 | 验证码可预测性略高 |

**描述**：
`generateRandomCode()` 使用 `Math.random()` 生成随机字符。

```java
// 当前
sb.append(chars.charAt((int) (Math.random() * chars.length())));

// 建议
private static final SecureRandom RANDOM = new SecureRandom();
sb.append(chars.charAt(RANDOM.nextInt(chars.length())));
```

**修复方案**：将 `Math.random()` 替换为 `java.security.SecureRandom` 实例。
