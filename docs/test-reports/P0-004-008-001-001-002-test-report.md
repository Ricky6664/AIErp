### 前端类型错误详情

**文件**: `erp-ai-web/src/views/system/user/index.vue:34`
```
error TS2353: Object literal may only specify known properties,
and 'value' does not exist in type 'TreeOptionProps'.
```
**位置**: `el-tree-select` 组件的 `:props="{ label: 'menuName', value: 'id', children: 'children' }"`
**原因**: Element Plus 2.14.x 的 `TreeOptionProps` 类型不包含 `value` 属性，节点值标识应通过 `node-key` 属性指定，而非 `props` 对象。

| `status` | `@RequestParam String status` | ✅ |
| `deptId` | `@RequestParam Long deptId` | ✅ |

### 6.2 响应结构匹配

| 层级 | 后端 | 前端期望 | 匹配 |
|------|------|---------|:---:|
| RT包装层 | `code: 200` (success) | `code === 0` (success check) | 🔴 **不匹配** |
| 分页数据层 | `PageResult.list` | `UserPageResult.list` | ✅ |
| 状态码定义 | `RT.ok()` → code=200 | `ErrorCode.SUCCESS` → code=0 | 🔴 **架构矛盾** |

> **🔴 关键问题**: `RT.ok()` 硬编码 `code: 200`，但前端 `request.ts` 行86 检查 `code === 0`，且 `ErrorCode.SUCCESS` 定义为 `code: 0`。后端内部 RT 与 ErrorCode 之间也存在矛盾。此问题将导致所有前端API调用失败——成功响应被当作业务错误处理。
