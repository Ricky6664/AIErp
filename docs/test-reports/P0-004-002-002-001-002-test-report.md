| 更新时间 | update_time | updated_at | ❌ 不匹配 |
| 创建人ID | creator_id | created_by | ❌ 不匹配 |
| 修改人ID | updater_id | updated_by | ❌ 不匹配 |
| 其他列 | (一致) | (一致) | ✅ |

> **影响**: 运行时 SQL 将因列名不存在而报错。XML 列名与 BaseEntity 字段名 (createTime/updateTime/creatorId/updaterId) 匹配，MyBatis-Plus 下划线映射后应为 `create_time`。DDL 使用了不同命名约定 `created_at`。需要在其中一方添加显式映射或修改 DDL。
