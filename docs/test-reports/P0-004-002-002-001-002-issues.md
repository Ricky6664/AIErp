## 问题 #1 (严重): 审计列名 DDL/应用不一致

| 属性 | 值 |
|------|-----|
| 严重级别 | CRITICAL |
| 发现位置 | UserMapper.xml Base_Column_List |
| 问题描述 | XML/Entity 使用 `create_time`, `update_time`, `creator_id`, `updater_id`，但 DDL 使用 `created_at`, `updated_at`, `created_by`, `updated_by` |
| 影响范围 | 所有引用 Base_Column_List 的 SQL (selectUserPage, selectUsersByDeptId) 以及 MyBatis-Plus 自动生成的 CRUD SQL |
| 运行时表现 | PostgreSQL 报错 "column X does not exist" |
| 修复方案 | 方案A: 在 SysUser entity 的 BaseEntity 字段上添加 @TableField 显式映射到 DDL 列名；方案B: 修改 DDL 列名为 create_time/update_time/creator_id/updater_id |

## 问题 #2 (警告): sys_user_password_history 表缺失

| 属性 | 值 |
|------|-----|
| 严重级别 | WARNING |
| 发现位置 | UserMapper.xml selectPasswordHistory |
| 问题描述 | SQL 引用 `sys_user_password_history` 表，但 db/migration 中未找到对应 DDL |
| 影响范围 | selectPasswordHistory 方法运行时表不存在 |
| 修复方案 | 需要编写 sys_user_password_history 的 CREATE TABLE DDL 迁移脚本 |
