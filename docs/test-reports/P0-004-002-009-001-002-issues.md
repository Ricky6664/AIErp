## I-001：Controller 缺少工作台端点

### 问题描述

UserService 已实现 `getWorkbenchData()` 方法，UserMapper 已编写 3 条聚合 SQL，UserWorkbenchVO 已定义完整数据结构，但 UserController 中缺少对应的 REST API 端点。

任务规格文档（P0-004-002-009-001-001）明确指定：
> 主查询：/api/system/user/workbench（工作台聚合查询SQL）

### 当前状态

- ✅ UserWorkbenchVO — 已创建（含 RoleDistVO、DeptDistVO 内部类）
- ✅ UserMapper.selectWorkbenchStats() — 已实现
- ✅ UserMapper.selectRoleDistribution() — 已实现
- ✅ UserMapper.selectDeptDistribution() — 已实现
- ✅ UserService.getWorkbenchData() — 已实现
- ❌ UserController 工作台端点 — **缺失**

### 建议修复

在 `UserController.java` 中添加以下端点方法：

```java
@Operation(summary = "获取工作台聚合数据")
@SaCheckPermission("system:user:query")
@GetMapping("/workbench")
public RT<UserWorkbenchVO> workbench() {
    return RT.ok(userService.getWorkbenchData());
}
```

需要新增 import：
```java
import com.erp.system.vo.UserWorkbenchVO;
```

### 修复时机

建议在当前验证任务完成后，由后续任务（如 P0-004-002-010 或 P0-004-002-009-001-003）处理。此问题不阻塞当前任务完成，因当前任务类型为"验证/测试"，只负责发现问题而非修复。

### 风险评估

- 不影响后端编译（Service/Mapper/VO 均正确）
- 不影响已有 API（分页查询、CRUD、角色管理等均正常）
- 仅影响工作台前端对接（前端无法调用 `/api/system/user/workbench` 获取聚合数据）
