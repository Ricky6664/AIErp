### 3.6 primaryDeptId传递链路 — ❌ 失败

```
前端: assignUserDepts(userId, deptIds, primaryDeptId) 
       → POST /api/system/user/dept { userId, deptIds, primaryDeptId }
       
后端: UserDeptService.assignDepts(Long userId, List<Long> deptIds)  ← 缺少primaryDeptId参数
       → UserDeptServiceImpl.assignDepts() 
       → baseMapper.insertUserDepts(userId, deptIds)  ← 不传递primaryDeptId
       → XML: is_primary = 0  ← 硬编码为0
```

> ⚠️ primaryDeptId 从请求体到数据库的整条链路断裂：Controller缺失 → Service不接收 → Mapper不传递 → SQL硬编码0。
