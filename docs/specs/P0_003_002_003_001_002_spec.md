# P0-003-002-003-001-002 编写认证相关表索引与约束 — 验证文档

## 验证SQL

```sql
-- 1. 验证 sys_login_log 索引创建
SELECT indexname, indexdef
FROM pg_indexes
WHERE tablename = 'sys_login_log'
ORDER BY indexname;

-- 2. 验证 sys_oper_log 索引创建
SELECT indexname, indexdef
FROM pg_indexes
WHERE tablename = 'sys_oper_log'
ORDER BY indexname;

-- 3. 验证 sys_login_log tenant_id 联合索引首列
SELECT indexname, indexdef
FROM pg_indexes
WHERE tablename = 'sys_login_log'
  AND indexdef ~ '\(tenant_id';

-- 4. 验证 sys_oper_log tenant_id 联合索引首列
SELECT indexname, indexdef
FROM pg_indexes
WHERE tablename = 'sys_oper_log'
  AND indexdef ~ '\(tenant_id';

-- 5. 验证 Flyway 版本号无冲突
SELECT version, description, script, installed_on, success
FROM flyway_schema_history
WHERE version = '20260531007';
```
