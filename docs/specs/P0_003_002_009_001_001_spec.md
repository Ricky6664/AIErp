## 六、设计要点

- **三表独立管理**：库位/批次/序列号三种辅助属性各自独立建表，互不耦合
- **一行对多行**：一个明细行可对应多条辅助属性记录
- **数量一致性**：启用库位/批次管理时，同一detail_id的辅助记录qty之和必须等于明细行主表qty值
- **序列号一物一号**：启用序列号管理时，序列号记录数必须等于主表qty值
- **detail_type区分**：通过detail_type字段标识来源明细表类型（如sale_order_detail/purchase_order_detail），支持所有业务模块共享复用
- **全局序列号唯一**：整个系统内同一序列号仅允许一条未删除记录
