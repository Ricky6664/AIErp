### 3.2 部分唯一索引约束

#### 3.2.1 规则

业务唯一性字段（如编码code、单据编号order_no）必须使用**部分唯一索引**，仅对未删除数据生效：

```sql
CREATE UNIQUE INDEX uk_{table}_{field}_active
    ON {schema}.{table}(tenant_id, {field})
    WHERE is_deleted = FALSE;
```

#### 3.2.2 设计原因

| 方案 | SQL | 问题 |
|------|-----|------|
| 联合唯一索引 | `UNIQUE(tenant_id, code, is_deleted)` | is_deleted为BOOLEAN类型，同一code只能有TRUE和FALSE两条记录，无法多次删后重建 |
| 部分唯一索引 | `UNIQUE INDEX ... WHERE is_deleted = FALSE` | 仅约束未删除数据，已删除数据可有多条同code记录，支持多次删后重建 |

#### 3.2.3 索引命名规范

| 类型 | 格式 | 示例 |
|------|------|------|
| 主键索引 | `pk_{表名}` | `pk_sale_order` |
| 唯一索引 | `uk_{表名}_{字段名}` | `uk_sale_order_order_no` |
| 普通索引 | `idx_{表名}_{字段名}` | `idx_sale_order_tenant_id` |
| 联合索引 | `idx_{表名}_{字段1}_{字段2}` | `idx_{表名}_tenant_id_customer_id` |
| 部分唯一索引 | `uk_{表名}_{字段名}_active` | `uk_product_code_active` |

### 3.3 多租户联合索引约束

#### 3.3.1 规则

所有联合索引必须以tenant_id为首列：

```sql
CREATE INDEX idx_{table}_{field} ON {table}(tenant_id, {field});
```

#### 3.3.2 设计原因

- 所有业务查询默认带`WHERE tenant_id = ?`条件
- tenant_id为首列的索引能最大化索引选择性
- MyBatis-Plus多租户插件自动注入tenant_id条件，索引以tenant_id为首列可确保每次查询都能命中索引

### 3.4 外键约束策略

| 维度 | 策略 |
|------|------|
| 数据库层 | **不创建FOREIGN KEY约束** |
| 应用层 | Service层校验数据完整性 |
| 原因1 | 多租户场景需包含tenant_id的复合外键，PostgreSQL不支持跨表复合外键 |
| 原因2 | 软删除场景下外键约束无法处理is_deleted逻辑 |
| 原因3 | 大数据量下外键约束影响写入性能 |

## 4. DML幂等性规范

### 4.1 规则

所有数据初始化INSERT语句必须使用`ON CONFLICT`保证幂等性，支持Flyway重复执行不报错不重复插入。

### 4.2 DO NOTHING模式（纯初始化）

```sql
INSERT INTO {schema}.{table} (col1, col2, ...)
VALUES (val1, val2, ...)
ON CONFLICT (unique_columns) WHERE is_deleted = FALSE
DO NOTHING;
```

适用场景：预置种子数据，首次插入后不再变更。

### 4.3 DO UPDATE模式（同步更新）

```sql
INSERT INTO {schema}.{table} (col1, col2, ...)
VALUES (val1, val2, ...)
ON CONFLICT (unique_columns) WHERE is_deleted = FALSE
DO UPDATE SET
    col2 = EXCLUDED.col2,
    updated_at = CURRENT_TIMESTAMP,
    version = {table}.version + 1;
```

适用场景：需要随版本升级同步更新的配置数据。

### 4.4 注意事项

- `ON CONFLICT`子句必须使用与部分唯一索引一致的条件（含`WHERE is_deleted = FALSE`）
- `DO UPDATE`时必须更新`updated_at`和`version`字段
- 使用`EXCLUDED`引用待插入的新值
