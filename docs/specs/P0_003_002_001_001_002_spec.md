## 6. 校验函数说明

### fn_validate_common_fields
- **输入**: schema_name VARCHAR, table_name VARCHAR
- **输出**: JSONB（包含字段完整性、默认值合规、NOT NULL合规三方面检查结果）
- **用途**: CI/CD流水线或代码审查时自动化检测单表是否符合公共字段规范

### fn_batch_validate_schema
- **输入**: schema_name VARCHAR
- **输出**: TABLE（逐表返回校验结果，排除规范元数据表）
- **用途**: 批量检查Schema下所有业务表的公共字段合规性

## 8. 设计要点

- **规范表独立于业务表**：三张规范表（public_field_spec / public_default_value_spec / public_constraint_spec）共同构成完整的公共字段基座规范元数据，不参与业务逻辑
- **校验函数自动化**：fn_validate_common_fields 返回结构化JSON，可直接集成到CI/CD建表检查环节
- **与P0-003-002-001-001-001的关系**：本任务（002）在兄弟任务（001）定义的字段类型规范基础上，补充默认值规则和约束规则，两者共同构成完整的建表DDL规范
- **部分唯一索引的WHERE条件**：使用 WHERE is_deleted = FALSE 而非将 is_deleted 纳入联合索引，支持同code多次删除后重建
