# 全局规范 - 国际化开发规范

> 本文档定义ERP系统国际化（i18n）开发的完整规范，涵盖前端vue-i18n配置、多语言Key命名、语言包文件结构、后端多语言支持、翻译流程及动态语言包加载策略。系统采用vue-i18n@next（9.x）作为前端国际化框架，后端通过i18n_translation_key/i18n_translation_value表存储翻译数据。

## 1. vue-i18n配置规范

### 1.1 createI18n配置

```typescript
// src/locales/index.ts
import { createI18n } from 'vue-i18n'
import zhCN from './zh-CN'
import enUS from './en-US'

const i18n = createI18n({
  legacy: false,                // 使用Composition API模式
  locale: 'zh-CN',              // 默认语言，从localStorage/userPreference读取
  fallbackLocale: 'zh-CN',      // 回退语言，翻译缺失时使用中文
  messages: {
    'zh-CN': zhCN,
    'en-US': enUS,
  },
  missing: (locale, key) => {
    // 翻译缺失时记录警告日志，便于排查
    console.warn(`[i18n] Missing translation: ${key} for locale: ${locale}`)
  },
  silentTranslationWarn: true,  // 生产环境静默翻译警告
})

export default i18n
```

### 1.2 全局注入方式


### 1.3 语言切换机制

```typescript
// src/composables/useLocale.ts
import { useI18n } from 'vue-i18n'
import { ref, watch } from 'vue'

export function useLocale() {
  const { locale, t } = useI18n()

  // 切换语言
  const switchLocale = async (lang: string) => {
    // 1. 动态加载语言包
    const messages = await import(`../locales/${lang}/index.ts`)
    locale.value = lang
    // 2. 持久化到localStorage
    localStorage.setItem('app_locale', lang)
    // 3. 更新用户偏好（调用后端API）
    await updateUserLocale(lang)
    // 4. 刷新页面标题和面包屑
    refreshPageTitle()
  }

  // 初始化语言（优先级：用户偏好 > localStorage > 浏览器语言 > 默认中文）
  const initLocale = () => {
    const saved = localStorage.getItem('app_locale')
    const browser = navigator.language
    locale.value = saved || browser || 'zh-CN'
  }

  return { locale, t, switchLocale, initLocale }
}
```

### 2.4 命名约束

- **全小写**：Key全小写，使用驼峰命名（camelCase）连接多词
- **禁止中文**：Key中不允许出现中文字符
- **禁止缩写**：不使用无意义的缩写，如`cust`应写为`customer`
- **禁止数字**：不使用数字编号（如item1、item2），使用语义化名称
- **层级不超过4层**：超过4层时合并中间层级
- **全局唯一**：同一个Key不得在不同模块中重复定义

## 4. 后端多语言支持

### 4.1 多语言数据表结构

后端使用两张表存储翻译数据，支持动态管理：

**i18n_language（语言定义表）— 主表**

**i18n_translation_key（翻译键表）— 主表**

| 字段名 | 数据类型 | 默认中文标题 |
|--------|---------|-------------|
| translation_key | varchar(200) | 翻译键 |

| 字段名 | 数据类型 | 默认中文标题 |

### 4.3 后端翻译API

```java
@RestController
@RequestMapping("/api/system/i18n")
public class I18nController {

    // 获取指定语言的全部翻译（按模块分组）
    @GetMapping("/messages/{languageCode}")
    public R<Map<String, Map<String, String>>> getMessages(
        @PathVariable String languageCode) {
        return R.ok(i18nService.getMessagesByLanguage(languageCode));
    }

    // 获取指定模块的翻译
    @GetMapping("/messages/{languageCode}/{module}")
    public R<Map<String, String>> getModuleMessages(
        @PathVariable String languageCode,
        @PathVariable String module) {
        return R.ok(i18nService.getMessagesByModule(languageCode, module));
    }

    // 批量导入翻译
    @PostMapping("/import")
    public R<Void> importTranslations(@RequestBody List<I18nImportDTO> translations) {
        i18nService.batchImport(translations);
        return R.ok();
    }

    // 批量导出翻译
    @GetMapping("/export")
    public void exportTranslations(
        @RequestParam String languageCode,
        HttpServletResponse response) {
        i18nService.exportTranslations(languageCode, response);
    }
}
```

```java
    public R<Void> handleBusinessException(BusinessException e) {
        String message = i18nMessageService.getMessage(e.getCode(), e.getArgs());
```

## 5. 翻译流程

### 5.1 新增字段翻译流程

```
1. 确定Key命名
   → 按{模块}.{功能}.{字段}格式定义Key
   → 检查是否与已有Key冲突

2. 添加中文Key到语言包
   → 在src/locales/zh-CN/{module}.ts中添加Key和中文值
   → 同步添加到类型定义

3. 添加其他语言翻译
   → 在src/locales/en-US/{module}.ts中添加对应翻译
   → 在src/locales/zh-TW/{module}.ts中添加对应翻译（如有）
   → 确保所有语言包结构一致

4. 数据库同步
   → 在i18n_translation_key表中添加翻译键记录
   → 在i18n_translation_value表中为每种语言添加翻译值

5. 前端替换硬编码文案
   → 将模板中的中文替换为t('key')
   → 将脚本中的中文替换为t('key')或computed(() => t('key'))

6. 验证翻译
   → 切换语言验证所有翻译正确显示
   → 检查缺失翻译的警告日志
   → 检查翻译文案在UI中的显示效果（长度、换行等）
```

### 5.2 翻译质量检查清单

- [ ] Key命名符合{模块}.{功能}.{字段}规范
- [ ] 中文语言包完整（所有新增Key都有中文翻译）
- [ ] 英文语言包完整（所有新增Key都有英文翻译）
- [ ] 翻译内容准确（专业术语一致，无机器翻译痕迹）
- [ ] 翻译长度适配UI（英文通常比中文长30%~50%，检查按钮/标签是否溢出）
- [ ] 数据库翻译记录同步
- [ ] 前端代码无硬编码中文（除注释外）
- [ ] 多语言切换后页面刷新正常

### 5.3 多语言导入导出

- **导入**：支持Excel/CSV格式批量导入翻译，按模块和语言过滤
- **导出**：支持按语言、按模块导出翻译文件，用于外部翻译协作
- **比对**：导出后可与外部翻译工具比对，再导入更新

## 6. 动态语言包加载策略

### 6.1 按需懒加载设计

为减少首屏加载体积，非默认语言的语言包采用动态导入：

```typescript
// src/locales/index.ts
import { createI18n } from 'vue-i18n'
import zhCN from './zh-CN'  // 默认语言静态导入

// 支持的語言列表
const SUPPORTED_LOCALES = ['zh-CN', 'en-US', 'zh-TW', 'ja-JP'] as const

export type SupportedLocale = typeof SUPPORTED_LOCALES[number]

const i18n = createI18n({
  legacy: false,
  locale: 'zh-CN',
  fallbackLocale: 'zh-CN',
  messages: {
    'zh-CN': zhCN,  // 默认语言预加载
  },
})

// 动态加载指定语言包
export async function loadLocaleMessages(locale: SupportedLocale) {
  if (i18n.global.availableLocales.includes(locale)) {
    return // 已加载，跳过
  }

  const messages = await import(`./${locale}/index.ts`)
  i18n.global.setLocaleMessage(locale, messages.default)
}

// 切换语言（含懒加载）
export async function switchLocale(locale: SupportedLocale) {
  await loadLocaleMessages(locale)
  i18n.global.locale.value = locale
  localStorage.setItem('app_locale', locale)
  document.querySelector('html')?.setAttribute('lang', locale)
}

export default i18n
```

### 6.2 模块级懒加载

对于超大型模块，可进一步按模块拆分语言包：

```typescript
// 按需加载指定模块的翻译
export async function loadModuleMessages(
  locale: string,
  module: string
): Promise<Record<string, string>> {
  const messages = await import(`./${locale}/${module}.ts`)
  return messages.default
}

// 路由守卫中预加载即将访问模块的翻译
router.beforeEach(async (to) => {
  const module = to.meta.module as string
  if (module) {
    const locale = i18n.global.locale.value
    const moduleMessages = await loadModuleMessages(locale, module)
    i18n.global.mergeLocaleMessage(locale, { [module]: moduleMessages })
  }
})
```

### 6.3 缓存策略

```typescript
// 语言包缓存：避免重复请求后端翻译API
const messageCache = new Map<string, Record<string, any>>()
const CACHE_TTL = 5 * 60 * 1000 // 5分钟缓存

async function fetchMessages(locale: string, module: string) {
  const cacheKey = `${locale}:${module}`

  const cached = messageCache.get(cacheKey)
  if (cached && Date.now() - cached.timestamp < CACHE_TTL) {
    return cached.data
  }

  const { data } = await api.get(`/api/system/i18n/messages/${locale}/${module}`)
  messageCache.set(cacheKey, { data, timestamp: Date.now() })
  return data
}

// 清除缓存（翻译更新时调用）
export function clearMessageCache(locale?: string) {
  if (locale) {
    // 清除指定语言缓存
    for (const key of messageCache.keys()) {
      if (key.startsWith(`${locale}:`)) {
        messageCache.delete(key)
      }
    }
  } else {
    messageCache.clear()
  }
}
```

### 6.4 后端动态翻译加载

```typescript
// 应用启动时或用户切换语言时，从后端加载动态翻译并合并到前端语言包
export async function loadDynamicTranslations(locale: string) {
  try {
    const response = await fetch(`/api/system/i18n/messages/${locale}`)
    const { data } = await response.json()

    // data格式: { crm: { customer: { name: '客户名称', ... } }, sale: { ... } }
    Object.entries(data).forEach(([module, messages]) => {
      i18n.global.mergeLocaleMessage(locale, { [module]: messages })
    })
  } catch (error) {
    console.error(`[i18n] Failed to load dynamic translations for ${locale}`, error)
  }
}
```

### 8.2 格式化工具函数

封装统一的格式化工具函数，在非模板场景中使用：

```typescript
// src/utils/formatter.ts
import i18n from '@/locales'

/**
 * 格式化日期，跟随当前语言环境
 * @param date 日期值
 * @param format 格式名称，默认'short'
 */
export function formatDate(date: Date | string | number, format: 'short' | 'long' = 'short'): string {
  const dateObj = date instanceof Date ? date : new Date(date)
  return i18n.global.d(dateObj, format)
}

/**
 * 格式化货币金额，跟随当前语言环境
 * zh-CN: ¥1,234.56  en-US: $1,234.56
 */
export function formatCurrency(amount: number): string {
  return i18n.global.n(amount, 'currency')
}

/**
 * 格式化数字（保留两位小数），跟随当前语言环境
 * zh-CN: 1,234.56  en-US: 1,234.56
 */
export function formatNumber(value: number): string {
  return i18n.global.n(value, 'decimal')
}

/**
 * 格式化百分比，跟随当前语言环境
 * zh-CN: 85.60%  en-US: 85.60%
 */
export function formatPercent(value: number): string {
  return i18n.global.n(value, 'percent')
}

/**
 * 格式化整数，跟随当前语言环境
 * zh-CN: 1,234  en-US: 1,234
 */
export function formatInteger(value: number): string {
  return i18n.global.n(value, 'integer')
}
```

### 8.3 格式化规则汇总

| 类型 | zh-CN 示例 | en-US 示例 | 使用场景 |
|------|-----------|-----------|---------|
| 日期(short) | `2026/05/25` | `May 25, 2026` | 列表日期列、表单日期展示 |
| 日期(long) | `2026/05/25 14:30:00` | `May 25, 2026 2:30:00 PM` | 操作日志时间、审计记录 |
| 货币 | `¥10,000.00` | `$10,000.00` | 订单金额、报表金额 |
| 数字 | `1,234.56` | `1,234.56` | 数量、单价 |
| 百分比 | `85.60%` | `85.60%` | 折扣率、完成率 |
| 整数 | `1,234` | `1,234` | 库存数量、计数 |

### 8.4 Vxe Table列格式化集成

```typescript
// src/composables/useTableFormatter.ts
import { formatCurrency, formatDate, formatNumber } from '@/utils/formatter'

export function useTableFormatter() {
  /**
   * 货币列格式化器
   */
  const currencyFormatter = ({ cellValue }: { cellValue: number }) => {
    return formatCurrency(cellValue ?? 0)
  }

  /**
   * 日期列格式化器
   */
  const dateFormatter = ({ cellValue }: { cellValue: string }) => {
    return cellValue ? formatDate(cellValue, 'short') : ''
  }

  /**
   * 日期时间列格式化器
   */
  const dateTimeFormatter = ({ cellValue }: { cellValue: string }) => {
    return cellValue ? formatDate(cellValue, 'long') : ''
  }

  /**
   * 数字列格式化器
   */
  const numberFormatter = ({ cellValue }: { cellValue: number }) => {
    return cellValue != null ? formatNumber(cellValue) : ''
  }

  return {
    currencyFormatter,
    dateFormatter,
    dateTimeFormatter,
    numberFormatter
  }
}
```
