# 全局规范-数据视图与表配置体系

> 本文档为独立规范文档，内容自包含，无需参照外部设计文档。
>
> **适用范围**：所有展示页（列表页）的数据视图配置，以及所有录入页的表配置规则。

---

## 6.6 数据视图与表配置体系

### 6.6.1 核心区分

- **录入页**：每个表（主表或从表）均为功能点自身的单个物理表，录入操作直接读写本表
- **展示页**：列表数据不一定是本表数据，可能是多个表关联查询的结果，称为**数据视图（Data View）**

### 6.6.2 数据视图定义

数据视图是展示页的数据来源配置，一个展示页可配置一个或多个数据视图：

- （1）**单表视图**：直接查询本功能点自身表，无关联
- （2）**关联视图**：以本功能点主表为核心，LEFT JOIN关联其他表字段
- （3）**聚合视图**：从多个表中聚合统计

### 6.6.3 数据视图配置规则

- 每个展示页至少配置1个数据视图，主列表区使用主数据视图，关联信息区每个标签页使用各自的关联数据视图
- 数据视图在菜单配置中与展示页绑定，支持按视图ID动态加载列配置
- 数据视图的字段来源表及关联关系在后端元数据中定义，前端按视图字段清单渲染列表列

### 6.6.4 录入页表配置规则

- 录入页的每个表（主表、从表）均为独立物理表，录入操作直接写入对应表
- 主表：功能点核心业务单据表
- 从表：功能点明细行表或辅助信息表，通过外键关联主表
- 录入页表清单列出所有需录入的表及其字段

## 6.6.5 数据视图配置表结构

### sys_data_view — 数据视图主表

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | bigint | 是 | 主键 |
| view_name | varchar(100) | 是 | 视图名称，如"销售订单列表视图" |
| view_code | varchar(100) | 是 | 视图编码，唯一标识，如 `sale_order_list` |
| view_type | tinyint | 是 | 视图类型：1=单表视图，2=关联视图，3=聚合视图 |
| main_table | varchar(100) | 是 | 主表名，如 `sale_order` |
| main_table_alias | varchar(20) | 否 | 主表别名，默认 `t0` |
| join_config | json | 否 | JOIN配置，关联视图必填，JSON数组 |
| where_config | json | 否 | WHERE条件配置，JSON数组 |
| order_config | json | 否 | 排序配置，如 `[{"field":"create_time","direction":"DESC"}]` |
| group_config | json | 否 | 分组配置，聚合视图使用 |
| status | tinyint | 是 | 状态：0=禁用，1=启用 |
| remark | varchar(500) | 否 | 备注 |
| tenant_id | bigint | 是 | 租户ID |
| create_by | bigint | 否 | 创建人 |
| create_time | datetime | 否 | 创建时间 |
| update_by | bigint | 否 | 更新人 |
| update_time | datetime | 否 | 更新时间 |
| is_deleted | tinyint | 是 | 软删除标记，默认0 |

### sys_data_view_field — 数据视图字段配置表

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | bigint | 是 | 主键 |
| view_id | bigint | 是 | 所属视图ID，关联 sys_data_view.id |
| field_name | varchar(100) | 是 | 物理字段名，如 `customer_name` |
| field_alias | varchar(100) | 否 | 字段别名（AS），用于前端列标识 |
| source_table | varchar(100) | 是 | 字段来源表名，如 `crm_customer` |
| source_table_alias | varchar(20) | 否 | 来源表别名，如 `t1` |
| field_label | varchar(100) | 是 | 字段显示名，如"客户名称" |
| field_type | varchar(20) | 是 | 字段数据类型：string/number/date/datetime/decimal |
| field_width | int | 否 | 列宽（像素），默认120 |
| sort_order | int | 是 | 排序序号，控制列显示顺序 |
| is_visible | tinyint | 是 | 是否可见，默认1 |
| is_sortable | tinyint | 是 | 是否支持排序，默认0 |
| is_searchable | tinyint | 是 | 是否支持搜索，默认0 |
| formatter | varchar(50) | 否 | 格式化器：date/decimal/dict/status/tag 等 |
| formatter_config | json | 否 | 格式化器附加配置，如精度、字典编码 |
| tenant_id | bigint | 是 | 租户ID |

## 6.6.6 JOIN配置JSON格式

`join_config` 字段为JSON数组，每个元素描述一次JOIN操作：

```json
[
  {
    "join_type": "LEFT",
    "table": "crm_customer",
    "alias": "t1",
    "conditions": [
      {
        "left_table": "t0",
        "left_field": "customer_id",
        "operator": "=",
        "right_table": "t1",
        "right_field": "id"
      }
    ]
  },
  {
    "join_type": "LEFT",
    "table": "crm_customer_contact",
    "alias": "t2",
    "conditions": [
      {
        "left_table": "t1",
        "left_field": "default_contact_id",
        "operator": "=",
        "right_table": "t2",
        "right_field": "id"
      }
    ]
  },
  {
    "join_type": "INNER",
    "table": "sys_department",
    "alias": "t3",
    "conditions": [
      {
        "left_table": "t0",
        "left_field": "owner_dept_id",
        "operator": "=",
        "right_table": "t3",
        "right_field": "id"
      }
    ]
  }
]
```

**字段说明**：

| 属性 | 说明 |
|------|------|
| join_type | 关联类型：`LEFT`（左连接，主表数据全保留）/ `INNER`（内连接，仅保留匹配数据） |
| table | 关联表物理表名 |
| alias | 关联表别名，建议使用 `t1`、`t2` 递增编号，`t0` 固定为主表 |
| conditions | 关联条件数组，多条件时以 AND 连接 |
| conditions[].operator | 比较运算符：`=`、`!=`、`>`、`<`、`>=`、`<=` |

## 6.6.7 WHERE条件动态构建规则

`where_config` 定义固定过滤条件，前端传入的搜索参数作为动态条件，两者以 AND 合并。

**WHERE配置JSON格式**：

```json
[
  {
    "field": "t0.is_deleted",
    "operator": "=",
    "value": 0,
    "logic": "AND"
  },
  {
    "field": "t0.status",
    "operator": "IN",
    "value": [1, 2, 3],
    "logic": "AND"
  },
  {
    "field": "t0.order_date",
    "operator": ">=",
    "value": "${params.startDate}",
    "logic": "AND",
    "ignore_empty": true
  }
]
```

**支持的运算符**：

| 运算符 | SQL生成 | 说明 |
|--------|---------|------|
| = | `field = ?` | 精确匹配 |
| != | `field != ?` | 不等 |
| >、<、>=、<= | `field > ?` 等 | 范围比较 |
| LIKE | `field LIKE '%?%'` | 模糊匹配，自动包裹通配符 |
| LIKE_LEFT | `field LIKE '%?'` | 左模糊 |
| LIKE_RIGHT | `field LIKE '?%'` | 右模糊 |
| IN | `field IN (?,?)` | 多值匹配 |
| NOT_IN | `field NOT IN (?,?)` | 排除多值 |
| BETWEEN | `field BETWEEN ? AND ?` | 区间，value需为2元素数组 |
| IS_NULL | `field IS NULL` | 空值判断 |
| IS_NOT_NULL | `field IS NOT NULL` | 非空判断 |

**动态构建规则**：
1. `ignore_empty=true` 时，若 `value` 为 null/空字符串/空数组，该条件自动跳过不拼入SQL
2. `${params.xxx}` 为运行时参数占位符，由前端查询表单传入
3. 数据权限条件由 `DataPermissionInterceptor` 自动追加，不需要在 `where_config` 中配置
4. 多租户条件 `tenant_id = ?` 由 `TenantLineInnerInterceptor` 自动追加
5. 软删除条件 `is_deleted = 0` 建议配置在 `where_config` 中，作为固定条件

## 6.6.8 视图配置与前端列配置的联动机制

```
┌─────────────────┐     view_id      ┌─────────────────────┐
│  sys_data_view  │ ───────────────> │ sys_data_view_field  │
│  (视图主表)      │   1 : N         │ (字段配置表)          │
└────────┬────────┘                  └──────────┬───────────┘
         │                                      │
         │ view_code                            │ field_name
         ▼                                      ▼
┌─────────────────┐     view_id      ┌─────────────────────┐
│  前端列配置      │ ───────────────> │ sys_column_config    │
│  (页面加载时)    │                  │ (用户自定义列配置)    │
└─────────────────┘                  └─────────────────────┘
```

**联动流程**：

1. **页面初始化**：前端根据当前功能点的 `view_code` 请求后端接口 `GET /api/sys/data-view/fields?viewCode=xxx`
2. **后端返回字段清单**：按 `sort_order` 排序，包含 `field_name`、`field_label`、`field_width`、`formatter` 等
3. **前端生成列配置**：将字段清单映射为表格列定义（columns），`formatter` 映射为对应的渲染器
4. **用户个性化覆盖**：若 `sys_column_config` 存在用户自定义配置（列显隐、列宽、列顺序），则覆盖默认配置
5. **搜索条件生成**：`is_searchable=1` 的字段自动在搜索栏生成对应的输入组件

**formatter 映射表**：

| formatter值 | 前端渲染器 | 说明 |
|-------------|-----------|------|
| date | DateFormatter | 日期格式化，默认 `YYYY-MM-DD` |
| datetime | DateTimeFormatter | 日期时间，默认 `YYYY-MM-DD HH:mm:ss` |
| decimal | DecimalFormatter | 小数格式化，精度从 `formatter_config.precision` 读取 |
| dict | DictFormatter | 字典值翻译，字典编码从 `formatter_config.dictCode` 读取 |
| status | StatusFormatter | 状态标签渲染，状态映射从 `formatter_config.statusMap` 读取 |
| tag | TagFormatter | 标签渲染 |
| user | UserFormatter | 用户名称渲染 |
| dept | DeptFormatter | 部门名称渲染 |

## 6.6.9 完整视图配置示例：销售订单关联客户视图

**场景**：销售订单列表页需要展示订单基本信息，同时关联展示客户名称、客户联系人、负责部门名称。

**（1）视图主表配置（sys_data_view）**：

```json
{
  "id": 1001,
  "view_name": "销售订单列表视图",
  "view_code": "sale_order_list",
  "view_type": 2,
  "main_table": "sale_order",
  "main_table_alias": "t0",
  "join_config": [
    {
      "join_type": "LEFT",
      "table": "crm_customer",
      "alias": "t1",
      "conditions": [
        {
          "left_table": "t0",
          "left_field": "customer_id",
          "operator": "=",
          "right_table": "t1",
          "right_field": "id"
        }
      ]
    },
    {
      "join_type": "LEFT",
      "table": "crm_customer_contact",
      "alias": "t2",
      "conditions": [
        {
          "left_table": "t1",
          "left_field": "default_contact_id",
          "operator": "=",
          "right_table": "t2",
          "right_field": "id"
        }
      ]
    },
    {
      "join_type": "LEFT",
      "table": "sys_department",
      "alias": "t3",
      "conditions": [
        {
          "left_table": "t0",
          "left_field": "owner_dept_id",
          "operator": "=",
          "right_table": "t3",
          "right_field": "id"
        }
      ]
    }
  ],
  "where_config": [
    {
      "field": "t0.is_deleted",
      "operator": "=",
      "value": 0,
      "logic": "AND"
    }
  ],
  "order_config": [
    { "field": "t0.create_time", "direction": "DESC" }
  ],
  "status": 1
}
```

**（2）字段配置（sys_data_view_field）**：

| field_name | source_table | field_label | field_type | sort_order | is_visible | is_searchable | formatter |
|------------|-------------|-------------|------------|------------|------------|---------------|-----------|
| id | sale_order(t0) | 订单ID | number | 1 | 0 | 0 | - |
| order_no | sale_order(t0) | 订单编号 | string | 2 | 1 | 1 | - |
| order_date | sale_order(t0) | 订单日期 | date | 3 | 1 | 1 | date |
| customer_name | crm_customer(t1) | 客户名称 | string | 4 | 1 | 1 | - |
| contact_name | crm_customer_contact(t2) | 联系人 | string | 5 | 1 | 0 | - |
| contact_phone | crm_customer_contact(t2) | 联系电话 | string | 6 | 1 | 0 | - |
| total_amount | sale_order(t0) | 订单总额 | decimal | 7 | 1 | 0 | decimal |
| order_status | sale_order(t0) | 订单状态 | number | 8 | 1 | 1 | status |
| owner_dept_name | sys_department(t3) | 负责部门 | string | 9 | 1 | 0 | dept |
| remark | sale_order(t0) | 备注 | string | 10 | 1 | 0 | - |

**（3）最终生成的SQL（示意）**：

```sql
SELECT
  t0.id,
  t0.order_no,
  t0.order_date,
  t1.customer_name,
  t2.contact_name,
  t2.contact_phone,
  t0.total_amount,
  t0.order_status,
  t3.dept_name AS owner_dept_name,
  t0.remark
FROM sale_order t0
LEFT JOIN crm_customer t1 ON t0.customer_id = t1.id
LEFT JOIN crm_customer_contact t2 ON t1.default_contact_id = t2.id
LEFT JOIN sys_department t3 ON t0.owner_dept_id = t3.id
WHERE t0.is_deleted = 0
  AND t0.tenant_id = #{tenantId}
ORDER BY t0.create_time DESC
```
