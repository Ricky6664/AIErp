# 全局规范 - 字段配置规则体系

> 本文档定义系统全部录入字段的配置规则体系，包括通用配置规则（表单型与表格型共用）、表单型录入字段专属配置、表格型录入字段专属配置。
> 本文档为独立规范文档，内容自包含，无需参照外部设计文档。

---

## 通用配置规则（表单型与表格型共用）

### 基础标识与显示配置

- 字段显示名称（支持多语言配置）
- 字段编码（前端唯一标识）
- 数据库字段名（后端映射字段）
- 显示排序序号
- 分组归属（归属哪个表单分组/表格列分组）
- 组件占位提示文字（placeholder）
- 字段帮助提示信息（鼠标悬浮或问号图标展示的补充说明文案）
- 字段默认对齐方式（左对齐/居中/右对齐；数值型默认右对齐，其余默认左对齐）
- 状态显隐配置：新增状态是否显示、编辑状态是否显示、详情状态是否显示
- 是否隐藏字段（后台静默存值，前端不展示）

### 录入权限与校验配置

- 是否必填（前端提交校验 + 后端NOT NULL约束同步生效）
- 条件必填（联动必填规则：当某字段满足指定条件时，当前字段变为必填）
- 输入最大长度、最小长度（字符串类型）
- 数值最大值、最小值（数值类型）
- 保留小数位数（数值/金额类型）
- 自定义正则表达式校验（前端即时校验 + 后端提交校验双重生效）
- 跨字段联合校验（如：结束日期必须大于等于开始日期）
- 唯一性校验（同表内字段值不允许重复，如编码字段）
- 是否禁止编辑（只读配置；支持按状态条件配置，如审核后只读）
- 字段级权限控制（按角色配置字段可见/可编辑/隐藏三种权限）
- 数据录入范围权限（按角色/用户过滤可选数据范围）

### 数据源绑定配置

- 绑定录入组件类型（选择8.1-8.4节中任意一款已封装录入组件）
- 字典编码绑定（下拉类组件专用，绑定系统业务字典或枚举值）
- 数据过滤条件（档案选择组件：过滤停用数据、过滤所属组织等）
- 数据默认排序规则（下拉数据源排序方式）
- 下拉模式区分：严格字典匹配 / 非严格自由录入
- 多选最大选择数量限制（多选类组件专用）
- 编码规则绑定（order_no/code类字段专用，从sys_code_rule中选择关联的编码规则rule_code，新建时自动调用8.4.5组件生成编码）

### 默认值与自动赋值配置

- 固定静态默认值
- 登录人信息默认值（默认操作员、默认部门、默认仓库、默认公司）
- 系统日期/系统时间自动赋值
- 单据编号规则自动生成赋值
- 引用其他字段值作为默认值
- 条件默认值（根据业务条件匹配不同默认值）

### 联动带出配置

- 选择当前字段后，自动带出目标字段列表
- 带出字段映射关系（源字段→目标字段）
- 带出覆盖策略：始终覆盖 / 仅空值时填充 / 用户确认后覆盖
- 多级联动：一级选完联动二级、二级联动三级
- 跨层级联动带出（主表单字段选择后，带出明细表格字段默认值；明细表格字段选择后，带出主表单字段值。**约束：明细→主表反向带出仅在明细行只有一行时生效，多行时不触发反向带出；当明细行从一行变为多行时，已反向带出到主表的值保持不变，界面提示用户确认**）

### 自动计算规则

- 是否开启自动计算开关
- 触发计算条件：依赖字段值发生变更时触发
- 自定义计算公式配置
  - 基础四则运算：加减乘除、括号优先级
  - 业务常用函数：求和、求差、取整、四舍五入、税率计算、折扣计算
  - 示例：金额=数量×单价、含税金额=不含税金额×(1+税率)
- 计算结果保留小数位数
- 计算后是否自动锁定目标字段不可手动修改
- 反向计算配置（如改金额反算单价）
- 计算触发时机：值变更即时计算 / 失焦时计算 / 提交时计算
- **手动修改后的计算策略**：依赖字段变更时，若目标字段已被用户手动修改，按配置的"覆盖策略"处理——重新覆盖（重算覆盖手动值）或保留手动值（标记为脏数据不再自动计算）
- **循环计算防护**：系统在保存计算规则时构建字段依赖有向图，检测是否存在环路（包括直接循环A→B→A和间接循环A→B→C→A），若存在环路则拒绝保存并提示具体环路路径

### 显隐联动规则

- 当前字段值等于指定值，显示目标字段
- 当前字段值不等于指定值，隐藏目标字段
- 多条件组合显隐（并且/或者逻辑）
- 状态联动显隐（单据审核后隐藏录入字段）
- 显隐联动值保留策略（**字段级配置**，每个字段可独立选择）：隐藏时清空已填值 / 隐藏时保留已填值重新显示时恢复
- **显隐与必填优先级**：显隐联动优先级高于条件必填——当字段被显隐规则隐藏时，自动豁免必填校验，隐藏字段不参与提交校验
- **隐藏字段提交规则**：被隐藏字段的值仅在前端缓存，**不随表单提交到后端**（防止保留的旧值造成业务数据错误）。如确需保留并提交隐藏字段值，配置时需显式勾选"隐藏字段参与提交"

### 数据联动过滤规则

- A字段选择指定值，B字段数据源自动过滤筛选
- 跨层级联动过滤（例：主表选定仓库，明细表格库位列只显示该仓库下属库位）
- 过滤条件支持多字段组合（AND/OR逻辑）

### 单据流转专属配置

- 该字段是否允许引入单据时自动带入
- 该字段是否允许下推单据时自动携带
- 引入/下推时字段映射规则（源单字段→目标单字段，支持一对多映射）
- 引入/下推时是否允许覆盖已有数据
- 流转过程中该字段是否禁止修改

### 移动端适配配置

- 移动端是否显示此字段
- 移动端组件简化展示模式

### 日志与追溯配置

- 字段值变更是否记录操作日志
- 是否允许查看字段修改历史记录

---

## 表单型录入字段专属配置

### 表单布局配置

- 字段栅格占位列数（1列/2列/3列/4列，适配表单整体列数布局）
- 标签宽度（自适应/固定宽度值）
- 标签位置（顶部对齐/左侧对齐/右侧对齐）
- 字段是否独占一行（跨全部列宽展示）
- 分组折叠配置（字段所属分组是否默认折叠/展开）

### 表单状态联动配置

- 新增状态字段行为（可编辑/只读/隐藏）
- 编辑状态字段行为（可编辑/只读/隐藏）
- 详情状态字段行为（统一只读，由系统自动控制）
- 审核后字段锁定（单据审核通过后，指定字段自动锁定为只读，反审后恢复可编辑）
- 作废后字段锁定（单据作废后，全部字段锁定为只读）

### 表单增强校验规则

- 条件必填联动
- 跨字段联合校验
- 后端异步校验
- 校验失败提示方式（字段下方红字提示/弹窗提示/行内图标提示）

### 表单专属交互配置

- 字段变更事件触发
- 表单字段与明细表格联动
- 字段值变更确认
- 字段清空联动

---

## 表格型录入字段专属配置

### 列布局与显示配置

- 列宽度配置：固定宽度 / 最小宽度 / 自适应宽度
- 列固定配置：左固定 / 右固定 / 不固定
- 单元格数据格式化展示
  - 数值型：千分位分隔、保留小数位数、货币符号前缀
  - 百分比型：自动追加%后缀
  - 日期型：自定义日期格式
  - 布尔型：勾选图标 / 文字（是/否）
- 单元格内容超出列宽处理：自动省略+悬浮Tooltip / 自动换行
- 列标题说明提示

### 单元格编辑控制配置

- 单元格级只读条件
- 单元格编辑模式：行内直接编辑 / 弹窗编辑 / 下拉编辑
- 单元格编辑触发方式：单击 / 双击 / 按F2触发
- 单元格内容为空时的展示文案

### 行级操作与校验配置

- 明细行新增时默认赋值规则
- 明细行复制新增
- 明细行删除前置校验规则
- 行级必填校验
- 行级整行校验规则
- 行级编辑权限控制

### 联动带出扩展配置

- 同行联动带出
- 带出触发行级计算
- 带出值与行状态联动

### 自动计算扩展配置

- 行级计算（计算范围限定在当前行）
- 列级汇总计算（计算范围限定在当前列所有行）
- 跨行计算
- 主表字段与明细表格汇总联动

### 统计汇总配置

- 是否参与表格前端合计
- 合计计算方式：求和 / 求平均 / 求最大值 / 求最小值 / 计数
- 条件合计
- 合计展示别名
- 合计行展示位置（表格底部固定 / 非固定跟随滚动）
- 多级合计（分组小计+总计）

### 单元格合并与样式配置

- 是否开启单元格合并规则
- 单元格条件样式
- 单元格悬浮提示文案配置
