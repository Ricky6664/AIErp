## 2. API接口规范

### 2.1 导入接口

```
POST /api/{module}/{entity}/import
Content-Type: multipart/form-data
```

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | MultipartFile | 是 | Excel文件（.xlsx格式） |
| overrideMode | String | 否 | 冲突处理：skip（跳过）/ update（覆盖），默认skip |
| validateOnly | boolean | 否 | 仅验证不写入（预览模式），默认false |

### 2.2 导出接口

```
GET /api/{module}/{entity}/export
Content-Type: application/octet-stream
```

**查询参数：** 与列表查询接口参数完全一致（复用列表查询条件）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | int | 否 | 忽略（导出不分页） |
| pageSize | int | 否 | 忽略 |
| {filterParams} | 各种 | 否 | 与列表查询相同的筛选条件 |
| columns | String | 否 | 指定导出列（逗号分隔），为空则导出全部 |

**文件名规则：** `{module}_{entity}_{yyyyMMddHHmmss}.xlsx`

示例：`sale_order_20250526143022.xlsx`

### 3.2 表头验证

```java
/**
 * Excel表头验证器 — 校验列名匹配
 */
public class ExcelHeaderValidator {

    /**
     * 验证表头是否与模板一致
     * @param headerRow 读取到的表头行
     * @param expectedHeaders 期望的列名列表（有序）
     * @return 验证结果
     */
    public HeaderValidationResult validate(List<String> headerRow,
                                            List<ColumnDefinition> expectedHeaders) {
        List<String> errors = new ArrayList<>();

        // 1. 列数检查
        if (headerRow.size() < expectedHeaders.size()) {
            errors.add("列数不足：期望" + expectedHeaders.size() + "列，实际" + headerRow.size() + "列");
        }

        // 2. 必填列检查
        for (ColumnDefinition col : expectedHeaders) {
            if (col.isRequired() && !headerRow.contains(col.getDisplayName())) {
                errors.add("缺少必填列：" + col.getDisplayName());
            }
        }

        // 3. 列名匹配（允许顺序不同）
        Set<String> actualHeaders = new HashSet<>(headerRow);
        for (ColumnDefinition col : expectedHeaders) {
            if (!actualHeaders.contains(col.getDisplayName())) {
                // 尝试别名匹配
                boolean matched = col.getAliases().stream()
                    .anyMatch(actualHeaders::contains);
                if (!matched && col.isRequired()) {
                    errors.add("无法识别的列：" + col.getDisplayName());
                }
            }
        }

        // 4. 未知列警告
        Set<String> expectedNames = expectedHeaders.stream()
            .map(ColumnDefinition::getDisplayName)
            .collect(Collectors.toSet());
        for (String actual : headerRow) {
            if (!expectedNames.contains(actual)) {
                errors.add("未知列（将被忽略）：" + actual);
            }
        }

        return new HeaderValidationResult(errors.isEmpty(), errors);
    }
}
```

### 3.5 验证器实现

```java
/**
 * 导入数据行验证器
 */
@Component
public class ImportRowValidator {

    @Autowired
    private ProductMapper productMapper;

    @Autowired
    private CustomerMapper customerMapper;

    /**
     * 验证单行数据
     * @param rowIndex 行号（从2开始，第1行为表头）
     * @param rowData 行数据
     * @param allRows 全部行数据（用于跨行验证）
     * @return 验证错误列表（空列表表示通过）
     */
    public List<ImportFailDetail> validateRow(int rowIndex, ImportOrderRow rowData,
                                               List<ImportOrderRow> allRows) {
        List<ImportFailDetail> errors = new ArrayList<>();

        // 1. 必填校验
        if (StringUtils.isBlank(rowData.getProductCode())) {
            errors.add(new ImportFailDetail(rowIndex, "商品编码", "不能为空"));
        }
        if (rowData.getQty() == null) {
            errors.add(new ImportFailDetail(rowIndex, "数量", "不能为空"));
        }

        // 2. 数据类型校验
        if (rowData.getQty() != null && rowData.getQty().compareTo(BigDecimal.ZERO) <= 0) {
            errors.add(new ImportFailDetail(rowIndex, "数量", "必须为正数"));
        }

        // 3. 引用完整性校验
        if (StringUtils.isNotBlank(rowData.getProductCode())) {
            Product product = productMapper.selectOne(
                new LambdaQueryWrapper<Product>()
                    .eq(Product::getProductCode, rowData.getProductCode())
                    .eq(Product::getIsDeleted, false)
            );
            if (product == null) {
                errors.add(new ImportFailDetail(rowIndex, "商品编码",
                    "商品" + rowData.getProductCode() + "不存在"));
            }
        }

        // 4. 跨行唯一性校验
        long duplicateCount = allRows.stream()
            .filter(r -> r.getLineNumber() < rowIndex)
            .filter(r -> r.getOrderNo() != null && r.getOrderNo().equals(rowData.getOrderNo()))
            .count();
        if (duplicateCount > 0) {
            errors.add(new ImportFailDetail(rowIndex, "订单编号",
                "与第" + (allRows.stream()
                    .filter(r -> r.getOrderNo() != null && r.getOrderNo().equals(rowData.getOrderNo()))
                    .findFirst().get().getLineNumber()) + "行重复"));
        }

        return errors;
    }
}
```

|------|---------|------|

## 5. 异步导入

### 5.1 触发条件

| 条件 | 同步/异步 | 说明 |
|------|---------|------|
| 行数 ≤ 5,000 | 同步 | 请求内完成，直接返回结果 |
| 行数 > 5,000 | 异步 | 创建后台任务，返回taskId |
| validateOnly = true | 同步 | 仅验证不写入，始终同步返回 |

### 5.2 异步任务流程

```
前端上传文件
    │
    ▼
后端接收 → 文件验证 → 行数判断
    │
    ├──[≤5000行]──→ 同步处理 → 返回ImportResult
    │
    └──[>5000行]──→ 创建异步任务 → 返回taskId
                        │
                        ▼
                    后台线程处理
                        │
                        ├── WebSocket推送进度
                        │
                        ▼
                    处理完成 → 更新任务状态
                        │
                        ▼
                    前端轮询/WebSocket获取结果 → 展示结果
```

### 5.3 异步任务实现

```java
@Service
public class AsyncImportService {

    @Autowired
    private SysImportExportTaskMapper taskMapper;

    @Autowired
    private SimpMessagingTemplate webSocket;

    @Async("importExportExecutor")
    public void executeImportAsync(Long taskId, MultipartFile file,
                                     ImportContext context) {
        SysImportExportTask task = taskMapper.selectById(taskId);

        try {
            // 1. 更新状态为处理中
            task.setStatus("PROCESSING");
            taskMapper.updateById(task);

            // 2. 读取Excel
            List<ImportOrderRow> allRows = EasyExcel.read(file.getInputStream())
                .head(ImportOrderRow.class)
                .sheet()
                .doReadSync();

            task.setTotalCount(allRows.size());
            taskMapper.updateById(task);

            // 3. 分块处理
            int batchSize = 1000;
            List<List<ImportOrderRow>> chunks = Lists.partition(allRows, batchSize);
            List<ImportFailDetail> allFailDetails = new ArrayList<>();
            int successCount = 0;

            for (int i = 0; i < chunks.size(); i++) {
                List<ImportOrderRow> chunk = chunks.get(i);
                ChunkImportResult result = processImportChunk(chunk, context);

                successCount += result.getSuccessCount();
                allFailDetails.addAll(result.getFailDetails());

                // 更新进度
                int processed = (i + 1) * batchSize;
                task.setProcessedCount(Math.min(processed, allRows.size()));
                task.setSuccessCount(successCount);
                task.setFailCount(allFailDetails.size());
                taskMapper.updateById(task);

                // WebSocket推送进度
                webSocket.convertAndSend(
                    "/topic/import-progress/" + taskId,
                    ImportProgressVO.from(task)
                );
            }

            // 4. 生成错误报告
            String errorFileUrl = null;
            if (!allFailDetails.isEmpty()) {
                errorFileUrl = errorReportService.generate(file, allFailDetails);
            }

            // 5. 更新完成状态
            task.setStatus("COMPLETED");
            task.setErrorFileUrl(errorFileUrl);
            task.setEndTime(LocalDateTime.now());
            taskMapper.updateById(task);

            // 6. 推送完成通知
            webSocket.convertAndSend("/topic/import-progress/" + taskId,
                ImportProgressVO.completed(task));

        } catch (Exception e) {
            log.error("异步导入任务失败: taskId={}", taskId, e);
            task.setStatus("FAILED");
            task.setErrorMsg(e.getMessage());
            task.setEndTime(LocalDateTime.now());
            taskMapper.updateById(task);

            webSocket.convertAndSend("/topic/import-progress/" + taskId,
                ImportProgressVO.failed(task, e.getMessage()));
        }
    }
}
```

### 6.4 EasyExcel写入器

```java
/**
 * 导出写入配置
 */
public class ExcelExportWriter {

    /**
     * 标准导出写入（≤ 10000行）
     */
    public <T> byte[] write(List<T> data, Class<T> headClass, ExportConfig config) {
        ByteArrayOutputStream os = new ByteArrayOutputStream();

        EasyExcel.write(os, headClass)
            .sheet(config.getSheetName())
            .registerWriteHandler(new CustomCellStyleHandler())   // 自定义样式
            .registerWriteHandler(new AutoColumnWidthHandler())   // 自动列宽
            .registerWriteHandler(new FreezePaneHandler())        // 冻结表头
            .doWrite(data);

        return os.toByteArray();
    }

    /**
     * 大数据量流式导出（> 10000行）
     * 使用SXSSFWorkbook避免内存溢出
     */
    public <T> void writeStream(OutputStream outputStream,
                                 Supplier<List<T>> dataSupplier,
                                 Class<T> headClass,
                                 int batchSize) {
        // EasyExcel内部已使用SXSSFWorkbook优化
        ExcelWriter writer = EasyExcel.write(outputStream, headClass)
            .registerWriteHandler(new CustomCellStyleHandler())
            .build();

        WriteSheet sheet = EasyExcel.writerSheet("数据").build();

        int offset = 0;
        while (true) {
            List<T> batch = dataSupplier.get(); // 分批查询数据
            if (batch == null || batch.isEmpty()) break;

            writer.write(batch, sheet);
            offset += batch.size();

            if (batch.size() < batchSize) break;
        }

        writer.finish();
    }
}
```

### 6.5 大数据量导出策略

```typescript
          status.value = data.status
          processedCount.value = data.processedCount
          totalCount.value = data.totalCount
          successCount.value = data.successCount
          failCount.value = data.failCount
          message.value = data.message || ''
        })
      },
    })
    stompClient.activate()
  })

  onUnmounted(() => {
    stompClient?.deactivate()
  })

  return {
    progress, status, processedCount, totalCount,
    successCount, failCount, message,
  }
}
```

### 10.3 脱敏处理器

```java
/**
 * EasyExcel写入时脱敏拦截器
 */
public class DesensitizeWriteHandler implements CellWriteHandler {

    private final Set<String> userPermissions;

    @Override
    public void afterCellDispose(CellWriteHandlerContext context) {
        if (Boolean.TRUE.equals(context.getHead())) return; // 表头不处理

        Field field = context.getField();
        ExportDesensitize annotation = field.getAnnotation(ExportDesensitize.class);
        if (annotation == null) return;

        // 检查是否有绕过权限
        if (userPermissions.contains(annotation.bypassPermission())) return;

        // 执行脱敏
        Cell cell = context.getCell();
        String value = cell.getStringCellValue();
        if (value != null) {
            cell.setCellValue(DesensitizeUtil.desensitize(value, annotation.type()));
        }
    }
}
```

## 14. 检查清单

新增导入导出功能时，必须逐项确认：

| 检查项 | 通过标准 |
|--------|---------|
| API路径 | 遵循`/api/{module}/{entity}/import|export|import-template` |
| 文件格式 | 仅接受.xlsx，后端验证MIME类型 |
| 行数限制 | ≤ 10,000行，超限拒绝 |
| 表头验证 | 列名匹配模板，必填列不缺失 |
| 行级验证 | 必填/类型/格式/范围全部校验 |
| 业务验证 | 引用完整性/唯一性/业务约束 |
| 部分成功 | 有效行写入，无效行跳过并记录 |
| 错误报告 | 失败行生成错误报告Excel供下载 |
| 异步触发 | > 5000行自动切换异步模式 |
| 进度推送 | WebSocket实时推送处理进度 |
| 导出命名 | 文件名符合`{module}_{entity}_{timestamp}.xlsx` |
| 导出样式 | 表头加粗+背景色，列宽自适应，首行冻结 |
| 数据脱敏 | 敏感字段按用户权限级别脱敏 |
| 权限控制 | import/export/import-template各自独立权限点 |
| 数据权限 | 导出数据受数据权限拦截器控制 |
| 任务记录 | 每次导入/导出写入sys_import_export_task |
| 模板下载 | 提供带说明的标准模板 |
| 前端组件 | 使用ImportDialog和ExportButton标准组件 |
| 错误码 | 使用规范中定义的错误码 |
| 文件清理 | 临时文件按生命周期策略自动清理 |
