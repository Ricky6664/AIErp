interface ErpInputProps {

## 8.4 组件事件规范

所有录入组件统一支持以下事件，事件参数格式标准化：

| 事件名 | 触发时机 | 参数格式 | 说明 |
|--------|---------|---------|------|
| `change` / `onChange` | 值变化时 | `(value: any, oldValue: any) => void` | 核心事件，用于联动计算 |
| `blur` / `onBlur` | 失焦时 | `(value: any, event: FocusEvent) => void` | 用于触发校验 |
| `focus` / `onFocus` | 获焦时 | `(value: any, event: FocusEvent) => void` | 用于提示/联想 |
| `clear` / `onClear` | 清空时 | `() => void` | 清空回调 |
| `input` / `onInput` | 输入时（每次按键） | `(value: string) => void` | 实时输入，慎用（性能考虑） |

**change事件使用示例**：

```vue
<ErpInputNumber
  v-model="row.qty"
  :precision="qtyPrecision"
  @change="(val, oldVal) => onQtyChange(row, val, oldVal)"
/>
```

```typescript
function onQtyChange(row: any, newVal: number, oldVal: number) {
  // 联动计算金额
  row.amount = multiply(newVal, row.price);
  // 联动校验库存可用量
  checkStockAvailable(row.productId, newVal);
}
```

## 8.5 校验规则配置方式

校验规则通过字段配置规则体系统一管理，与录入组件通过 `rules` 属性绑定。

**校验规则定义**：

```typescript
interface FieldRule {
  type: 'required' | 'min' | 'max' | 'minLength' | 'maxLength'
      | 'pattern' | 'custom' | 'async';
  value?: any;                // 规则参数
  message: string;            // 校验失败提示文字
  trigger?: 'change' | 'blur'; // 触发时机，默认change
  validator?: (value: any, rule: FieldRule, row: any) => boolean | string | Promise<boolean>;
                                // 自定义/异步校验函数
}
```

**校验规则示例**：

```typescript
const fieldRules: Record<string, FieldRule[]> = {
  customerName: [
    { type: 'required', message: '客户名称不能为空' },
    { type: 'maxLength', value: 100, message: '客户名称最多100个字符' }
  ],
  phone: [
    { type: 'pattern', value: /^1[3-9]\d{9}$/, message: '手机号格式不正确' }
  ],
  orderQty: [
    { type: 'required', message: '数量不能为空' },
    { type: 'min', value: 0.000001, message: '数量必须大于0' }
  ],
  productCode: [
    { type: 'async', message: '商品编码已存在',
      validator: async (value) => {
        const exists = await checkProductCodeUnique(value);
        return !exists;
      }
    }
  ]
};
```

**与字段配置联动**：
- 字段配置表 `sys_field_config` 中 `is_required=1` 的字段自动生成 `required` 规则
- 字段配置表 `validation_rules` JSON字段存储附加校验规则
- 前端 `useFieldRules` composable 自动合并两处规则

## 8.6 表格单元格适配差异

录入组件在 **全表单** 与 **表格单元格** 中存在行为差异，需通过环境感知自动适配：

| 差异维度 | 全表单模式 | 表格单元格模式 |
|---------|-----------|--------------|
| **尺寸** | `size="default"` | `size="small"`，紧凑布局 |
| **边框** | 有边框 | 无边框（hover/focus时显示边框） |
| **Label** | 显示标签文字 | 不显示标签，表头已有列名 |
| **校验提示** | 输入框下方显示红色文字 | Tooltip气泡提示，避免撑开行高 |
| **下拉弹出方向** | 自动（默认向下） | 自动判断，底部空间不足时向上弹出 |
| **日期面板** | 正常弹出 | 弹出面板可能遮挡其他行，需z-index管理 |
| **加减按钮** | 显示（InputNumber） | 隐藏加减按钮，仅保留输入 |
| **错误状态** | 红色边框+下方文字 | 红色边框+右上角红色三角标+Tooltip |
| **Tab键导航** | 按DOM顺序 | 按表格列顺序，Enter键跳到下一行同列 |
| **快捷键** | 标准表单行为 | `Enter`提交/跳行，`Esc`取消编辑，`F2`进入编辑 |

**环境感知实现**：

```typescript
// useCellMode composable
export function useCellMode() {
  const isCellMode = inject('erpTableCellMode', false);

  const cellProps = computed(() => {
    if (!isCellMode) return {};
    return {
      size: 'small',
      controls: false,           // InputNumber隐藏加减按钮
      showLabel: false,          // 不显示标签
      errorDisplay: 'tooltip',   // 错误提示用Tooltip
    };
  });

  return { isCellMode, cellProps };
}
```

## 8.7 ErpDictSelect字典组件使用示例

### 基本用法

```vue
<!-- 订单状态字典，严格模式 -->
<ErpDictSelect
  v-model="formData.orderStatus"
  dict-code="order_status"
  :strict-mode="true"
  placeholder="请选择订单状态"
/>
```

### 多选模式

```vue
<!-- 多选字典：客户标签 -->
<ErpDictSelect
  v-model="formData.customerTags"
  dict-code="customer_tag"
  :multiple="true"
  :collapse-tags="true"
  :max-collapse-tags="3"
/>
```

### 表格单元格中使用

```vue
<el-table-column label="审核状态" prop="auditStatus" width="120">
  <template #default="{ row }">
    <!-- 展示态：字典标签渲染 -->
    <ErpDictSelect
      v-if="!row._editing"
      :model-value="row.auditStatus"
      dict-code="audit_status"
      :disabled="true"
      :render-tag="true"
      tag-type="info"
    />
    <!-- 编辑态：下拉选择 -->
    <ErpDictSelect
      v-else
      v-model="row.auditStatus"
      dict-code="audit_status"
      @change="(val) => onStatusChange(row, val)"
    />
  </template>
</el-table-column>
```

### 字典数据加载机制

```
ErpDictSelect 组件加载流程：
1. 组件挂载时，根据 dictCode 检查本地缓存（Pinia Store）
2. 若缓存命中 → 直接使用缓存字典数据
3. 若缓存未命中 → 调用 API: GET /api/sys/dict/items?dictCode=xxx
4. 后端返回字典项列表 → 写入本地缓存
5. 字典项结构: { dictValue: '1', dictLabel: '草稿', sort: 1, cssClass: 'info' }
6. 缓存有效期: 10分钟，支持手动刷新（字典管理页修改后自动通知）
```

### 字典级联用法

```vue
<!-- 省市区三级字典联动 -->
<ErpDictCascade
  v-model="formData.areaCode"
  :dict-code-list="['province', 'city', 'district']"
  :cascade-fields="['provinceCode', 'cityCode', 'districtCode']"
  @change="(val) => onAreaChange(val)"
/>
```
