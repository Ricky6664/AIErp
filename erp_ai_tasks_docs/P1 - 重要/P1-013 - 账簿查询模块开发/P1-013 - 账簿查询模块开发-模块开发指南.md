# P1-013 账簿查询模块开发 - 模块开发指南

## 一、模块概述

- **模块定位**：总账、明细账、余额表、多栏账查询，为财务核算和审计提供完整的账簿查询体系
- **前置依赖**：P0-001~P0-005（后端框架+前端框架+数据库+权限+公共组件）、P0-011（会计科目）、P1-012（凭证数据）
- **被依赖方**：P1-014（财务报表——账簿数据作为报表取数基础）
- **开发阶段**：阶段八（财务层）

### 5.5 跨期查询规则

| 规则编号 | 规则名称 | 规则说明 |
|---------|---------|---------|
| CP-001 | 期间范围限制 | 单次查询最多跨12个会计期间(一个完整会计年度)，超出范围时提示用户缩小查询范围 |
| CP-002 | 跨年度查询 | 支持跨年度查询(如202510~202603)，期初余额取起始期间的期初值，期末余额取截止期间的期末值 |
| CP-003 | 未结账期间处理 | 查询范围包含未结账期间时，该期间数据为实时计算值(包含已过账凭证)，页面提示"含未结账期间数据" |
| CP-004 | 年度结转处理 | 年度结转后，新年度的期初余额=上年度期末余额，查询新年度第一期时自动取上年度结转数据 |
| CP-005 | 期间数据一致性 | 同一查询中，总账本期发生额合计=明细账本期发生额合计=余额表本期发生额合计，三账核对一致 |

### 5.6 辅助核算维度

系统支持以下辅助核算维度，通过fin_account_balance_aux表实现多维度余额查询：

| 辅助核算类型 | 类型编码 | 适用科目类别 | 核算项来源表 | 典型使用场景 |
|------------|---------|------------|------------|------------|
| 客户核算 | customer | 应收账款(1122)、预收账款(2203) | sal_customer | 查询某客户在指定期间的应收款变动明细 |
| 供应商核算 | supplier | 应付账款(2202)、预付账款(1123) | pur_supplier | 查询某供应商在指定期间的应付款变动明细 |
| 部门核算 | dept | 管理费用(6602)、销售费用(6601) | sys_department | 查询某部门在指定期间的费用发生额 |
| 项目核算 | project | 在建工程(1604)、研发支出(5301) | prj_project | 查询某项目在指定期间的成本归集明细 |
| 员工核算 | employee | 其他应收款(1221)、应付职工薪酬(2211) | sys_employee | 查询某员工的借款/薪酬明细 |

辅助核算维度在会计科目表(fin_account)中通过auxiliary_types字段(JSONB数组)配置，一个科目可同时启用多个辅助核算维度。

### 5.7 科目余额表(fin_account_balance)更新机制

科目余额表通过凭证过账操作实时更新，更新流程如下：

```
凭证过账操作触发：
  FOR each voucherDetail IN 凭证明细行列表:
    accountBalance = SELECT * FROM fin_account_balance 
                     WHERE account_id = voucherDetail.account_id 
                     AND period_id = voucher.period_id 
                     FOR UPDATE;
    
    IF accountBalance不存在 THEN
      -- 首次发生，从上一期间结转期初余额
      prevBalance = SELECT * FROM fin_account_balance 
                    WHERE account_id = voucherDetail.account_id 
                    AND period_id = 上一期间;
      INSERT INTO fin_account_balance (
        account_id, period_id,
        begin_debit = prevBalance.end_debit (或0),
        begin_credit = prevBalance.end_credit (或0),
        period_debit, period_credit, ...
      );
    END IF;
    
    -- 更新本期发生额
    IF voucherDetail.direction = '借方' THEN
      UPDATE period_debit = period_debit + voucherDetail.amount;
    ELSE
      UPDATE period_credit = period_credit + voucherDetail.amount;
    END IF;
    
    -- 重新计算期末余额
    UPDATE end_debit = begin_debit + period_debit - period_credit (借方余额科目);
    UPDATE end_credit = begin_credit + period_credit - period_debit (贷方余额科目);
    
    -- 更新本年累计
    UPDATE year_debit = year_debit + voucherDetail.amount (借方);
    UPDATE year_credit = year_credit + voucherDetail.amount (贷方);
    
    -- 级联更新下级期间的期初余额
    UPDATE后续所有期间的begin_debit/begin_credit = 本期间的end_debit/end_credit;
```

反过账操作为上述流程的逆操作：减去对应金额并重算余额。
