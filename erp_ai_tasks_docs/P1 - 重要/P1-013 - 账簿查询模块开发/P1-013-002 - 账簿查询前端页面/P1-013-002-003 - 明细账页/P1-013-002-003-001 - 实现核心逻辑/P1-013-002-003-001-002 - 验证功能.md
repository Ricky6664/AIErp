## 五、详细开发规格
> **📦 本任务模块上下文**（来源：P1-013模块开发指南）
> - 本模块涉及数据表：参见模块开发指南
> - 本模块涉及API：/api/ledger/general-ledger, /api/ledger/general-ledger/export, /api/ledger/subsidiary-ledger, /api/ledger/subsidiary-ledger/export, /api/ledger/balance
> - 本模块业务规则：总账查询：按科目汇总各会计期间的借方发生额/贷方发生额/余额，支持科目树下钻（从一级科目逐级展开到末级科目）。总账数据仅取已过账凭证。; 明细账查询：按科目+会计期间查询凭证明细，展示借方/贷方/余额三栏式。支持从总账科目行点击下钻到明细账。
>
> 💡 开发本任务时，请结合上述模块上下文理解业务场景和数据关系。

### 5.1 验证清单
1. 核心用例验证：按账簿查询业务规则逐项验证主流程（新增/修改/删除/查询/审核）
2. 数值计算验证：金额=单价×数量、合计=∑明细，误差≤0.01
3. 状态流转验证：按状态机规则验证非法流转拒绝（如已审核→草稿被拦截）
4. 并发场景验证：乐观锁冲突时正确重试/报错

### 5.2 测试方法
1. 单元测试：JUnit5 + Mockito，覆盖Service层所有public方法
2. 接口测试：Postman/Swagger UI验证/api/ledger/*接口契约
3. 事务测试：手动抛异常验证回滚行为
4. 并发测试：使用CountDownLatch模拟并发更新，验证乐观锁生效

### 5.3 结果记录
1. 通过项：记录用例名+执行时间+断言结果
2. 未通过项：记录失败原因+堆栈+数据快照
3. 修复方案：标注代码位置+修复思路+回归验证结果
