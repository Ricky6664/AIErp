# P1-003 消息管理模块开发 - 模块开发指南

## 一、模块概述

- **模块定位**：消息中心、消息模板、单据待办、消息推送、业务预警、单据沟通、协作讨论，为系统提供实时通知与协作能力，是系统消息体系的核心基础设施
- **前置依赖**：P0-001（后端框架含WebSocket配置）、P0-002（前端框架）、P0-003（数据库）、P0-004（认证与权限）、P0-005（公共组件）
- **被依赖方**：P1-002（审批流程催办/通知）、P1-004~P1-015（所有业务模块的消息推送与待办）
- **开发阶段**：阶段六（引擎层）

## 四、模块级专属约束

1. **WebSocket连接管理**：WebSocket推送服务需支持连接池管理、断线重连、心跳检测。每个用户仅维护一个有效连接，多设备登录时需同步推送。
2. **消息模板变量替换**：模板内容支持${变量名}格式的变量替换，变量值由业务模块在发送消息时传入。模板变量列表需在模板定义时声明。
3. **待办自动创建**：单据审核/审批操作时自动创建待办记录，审核/审批完成后自动标记已办。待办数据需与P1-002审批流程联动。
4. **业务预警引擎**：定时扫描预警规则（支持cron表达式配置扫描频率），对满足预警条件的业务数据自动生成预警消息并推送通知。预警规则支持条件表达式配置。
5. **消息通知联动**：单据沟通中的@提及和回复操作需自动触发消息通知，协作讨论中的新回复也需推送通知给所有参与人。
6. **消息数据安全**：消息数据仅对接收人可见，已读状态需按接收人维度独立管理。消息删除仅标记为已删除，不物理删除。
