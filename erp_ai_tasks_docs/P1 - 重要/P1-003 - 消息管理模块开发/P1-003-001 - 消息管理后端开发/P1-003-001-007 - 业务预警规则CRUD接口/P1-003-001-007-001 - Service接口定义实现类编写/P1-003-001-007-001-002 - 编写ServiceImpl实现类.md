### 5.1 ServiceImpl实现结构
```java
@Service
@RequiredArgsConstructor
public class MsgMessageServiceImpl extends ServiceImpl<MsgMessageMapper, MsgMessageEntity> implements IMsgMessageService {
    @Override
    @Transactional(rollbackFor = Exception.class)
    public Long create(MsgMessageCreateDTO dto) {
        validateCreate(dto);
        MsgMessageEntity entity = convertToEntity(dto);
        entity.setStatus(0);
        save(entity);
        saveDetails(entity.getId(), dto.getDetails());
        return entity.getId();
    }

    @Override
    public Page<MsgMessageListVO> pageList(MsgMessageQueryDTO query) {
        return baseMapper.selectPageList(query.toPage(), query);
    }
}
```

### 5.2 关键业务逻辑
- 编码生成：调用codeGeneratorService.generate()，幂等调用
- 事务管理：@Transactional(rollbackFor=Exception.class)
- 审核状态流转：调用auditEngineService处理状态变更
- 操作日志：调用operationLogService记录操作
