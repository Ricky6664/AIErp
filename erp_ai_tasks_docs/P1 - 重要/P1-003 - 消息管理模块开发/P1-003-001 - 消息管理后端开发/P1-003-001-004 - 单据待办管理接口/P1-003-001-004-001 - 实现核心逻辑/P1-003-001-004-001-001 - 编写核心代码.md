### 5.1 核心Service实现
```java
@Service
@RequiredArgsConstructor
@Slf4j
public class MsgTodoServiceImpl implements MsgTodoService {

    private final MsgTodoMapper todoMapper;
    private final MsgWebSocketService webSocketService;
    private final AuditEngineService auditEngineService;
    private final ApplicationEventPublisher eventPublisher;

    @Override
    public PageResult<TodoListVO> getTodoList(TodoQueryDTO query) {
        // 1. 按当前用户assigneeId筛选
        Long currentUserId = SecurityUtils.getCurrentUserId();
        query.setAssigneeId(currentUserId);
        // 2. 查询msg_todo表（is_completed=false）
        Page<MsgTodoEntity> page = todoMapper.selectTodoPage(query);
        // 3. 关联源模块单据详情（通过business_type + business_id多态查询单据编号/标题）
        return convertToVO(page);
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void approveTodo(Long todoId, String opinion) {
        // 1. 查询待办记录并校验
        MsgTodoEntity todo = todoMapper.selectById(todoId);
        validateTodoOperable(todo);
        // 2. 调用源模块审批引擎（根据business_type路由到对应Service）
        auditEngineService.approve(todo.getBusinessType(), todo.getBusinessId(), opinion);
        // 3. 标记待办已办
        todo.setIsCompleted(true);
        todo.setCompleteTime(LocalDateTime.now());
        todoMapper.updateById(todo);
        // 4. 发布待办完成事件（供其他模块监听）
        eventPublisher.publishEvent(new TodoApprovedEvent(todo.getBusinessType(), todo.getBusinessId(), todoId));
        // 5. WebSocket通知创建人待办已处理
        webSocketService.pushToUser(todo.getCreatedBy(), buildTodoDoneMessage(todo));
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void rejectTodo(Long todoId, String reason) {
        if (StringUtils.isBlank(reason)) {
            throw new BusinessException("驳回原因不能为空");
        }
        MsgTodoEntity todo = todoMapper.selectById(todoId);
        validateTodoOperable(todo);
        // 调用源模块驳回
        auditEngineService.reject(todo.getBusinessType(), todo.getBusinessId(), reason);
        // 标记待办已办
        todo.setIsCompleted(true);
        todo.setCompleteTime(LocalDateTime.now());
        todoMapper.updateById(todo);
        // 通知创建人被驳回
        webSocketService.pushToUser(todo.getCreatedBy(), buildTodoRejectMessage(todo, reason));
    }

    private void validateTodoOperable(MsgTodoEntity todo) {
        if (todo == null) throw new BusinessException("待办不存在");
        if (todo.getIsCompleted()) throw new BusinessException("待办已处理");
        Long currentUserId = SecurityUtils.getCurrentUserId();
        if (!todo.getAssigneeId().equals(currentUserId)) throw new BusinessException("只能处理自己的待办");
    }
}
```

### 5.2 审批引擎路由（AuditEngineService）
```java
@Service
@RequiredArgsConstructor
public class AuditEngineService {
    private final Map<String, BusinessAuditHandler> handlerMap;

    public void approve(String businessType, Long businessId, String opinion) {
        BusinessAuditHandler handler = handlerMap.get(businessType + "AuditHandler");
        if (handler == null) throw new BusinessException("未找到业务审批处理器: " + businessType);
        handler.approve(businessId, opinion);
    }

    public void reject(String businessType, Long businessId, String reason) {
        BusinessAuditHandler handler = handlerMap.get(businessType + "AuditHandler");
        if (handler == null) throw new BusinessException("未找到业务审批处理器: " + businessType);
        handler.reject(businessId, reason);
    }
}
```

## 八、易错警示

> ⚠️ 跨模块调用审批引擎时，必须通过策略模式（handlerMap路由）解耦，不要在MsgTodoService中硬编码各业务模块的Service依赖

> ⚠️ 审批/驳回操作必须在校验待办归属权后再执行，防止越权操作

> ⚠️ WebSocket推送通知应放在事务提交后执行（@TransactionalEventListener），避免事务回滚但通知已发送

> ⚠️ 驳回原因为必填项，前端和后端均需做非空校验
