### 5.1 核心Service实现
```java
@Service
@RequiredArgsConstructor
@Slf4j
public class MsgDiscussionServiceImpl implements MsgDiscussionService {

    private final MsgDiscussionMapper discussionMapper;
    private final MsgMessageService messageService;
    private final MsgWebSocketService webSocketService;
    private final MentionParser mentionParser;

    @Override
    public PageResult<DiscussionListVO> pageByDoc(DiscussionQueryDTO query) {
        // 按business_type + business_id查询沟通记录，按send_time正序排列
        Page<MsgDiscussionEntity> page = discussionMapper.selectByBusiness(
            query.getBusinessType(), query.getBusinessId(), query.toPageable());
        // 关联查询发送人姓名、头像
        return convertToVO(page);
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public Long create(DiscussionCreateDTO dto) {
        Long currentUserId = SecurityUtils.getCurrentUserId();
        // 1. 构建沟通记录
        MsgDiscussionEntity entity = new MsgDiscussionEntity();
        entity.setBusinessType(dto.getBusinessType());
        entity.setBusinessId(dto.getBusinessId());
        entity.setSenderId(currentUserId);
        entity.setContent(dto.getContent());
        entity.setParentId(dto.getParentId() != null ? dto.getParentId() : 0L);
        entity.setAttachment(dto.getAttachment());
        discussionMapper.insert(entity);

        // 2. 解析@提及用户并通知
        List<Long> mentionedUserIds = mentionParser.parseMentionedUsers(dto.getContent());
        for (Long mentionedUserId : mentionedUserIds) {
            if (!mentionedUserId.equals(currentUserId)) {
                messageService.sendMessage(
                    "有人在单据沟通中@了您",
                    buildMentionMessage(dto, currentUserId),
                    "discussion", mentionedUserId);
                webSocketService.pushToUser(mentionedUserId, buildPushMessage(entity));
            }
        }

        // 3. 如果是回复（parent_id > 0），通知被回复人
        if (entity.getParentId() != null && entity.getParentId() > 0) {
            MsgDiscussionEntity parentMsg = discussionMapper.selectById(entity.getParentId());
            if (parentMsg != null && !parentMsg.getSenderId().equals(currentUserId)) {
                messageService.sendMessage(
                    "有人回复了您的单据沟通",
                    buildReplyMessage(dto, currentUserId),
                    "discussion", parentMsg.getSenderId());
                webSocketService.pushToUser(parentMsg.getSenderId(), buildPushMessage(entity));
            }
        }

        log.info("[单据沟通] 用户{}在{}({})新增留言, id={}", currentUserId, dto.getBusinessType(), dto.getBusinessId(), entity.getId());
        return entity.getId();
    }

    @Override
    public List<DiscussionListVO> getReplies(Long parentId) {
        List<MsgDiscussionEntity> replies = discussionMapper.selectByParentId(parentId);
        return replies.stream().map(this::toVO).collect(Collectors.toList());
    }
}
```

### 5.2 @提及解析器
```java
@Component
public class MentionParser {
    /**
     * 从沟通内容中解析@提及的用户ID
     * 格式：@用户名 或 @[userId:用户名]
     * 示例："请@[1001:张三]确认一下这个数量"  → 返回 [1001]
     */
    public List<Long> parseMentionedUsers(String content) {
        if (StringUtils.isBlank(content)) return Collections.emptyList();
        List<Long> userIds = new ArrayList<>();
        Pattern pattern = Pattern.compile("@\[(\d+):[^\]]+\]");
        Matcher matcher = pattern.matcher(content);
        while (matcher.find()) {
            userIds.add(Long.parseLong(matcher.group(1)));
        }
        return userIds.stream().distinct().collect(Collectors.toList());
    }
}
```

## 八、易错警示

> ⚠️ @提及解析正则需处理多种格式（@用户名 和 @[userId:用户名]），前端输入格式需与后端解析规则一致

> ⚠️ 自己@自己、自己回复自己 不应触发通知，需做发送人==接收人的排除判断

> ⚠️ 沟通记录通过business_type + business_id多态关联业务单据，查询时注意SQL索引覆盖（idx_msg_discussion_business）

> ⚠️ 回复通知与@提及通知可能同时触发给同一用户，需做去重避免重复通知
