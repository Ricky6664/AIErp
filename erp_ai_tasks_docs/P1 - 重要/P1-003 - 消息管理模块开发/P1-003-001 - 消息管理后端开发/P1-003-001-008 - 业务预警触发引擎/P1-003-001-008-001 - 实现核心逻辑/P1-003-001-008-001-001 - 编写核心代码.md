### 5.1 预警触发核心Service
```java
@Service
@RequiredArgsConstructor
@Slf4j
public class MsgWarningServiceImpl implements MsgWarningService {

    private final MsgWarningRuleMapper ruleMapper;
    private final MsgWarningMapper warningMapper;
    private final MsgMessageService messageService;
    private final MsgWebSocketService webSocketService;
    private final WarningConditionEvaluator conditionEvaluator;

    /**
     * 定时扫描预警规则并触发告警（@Scheduled cron可配置）
     * 幂等设计：同一规则+同一业务数据+同一日期 不重复生成预警
     */
    @Transactional(rollbackFor = Exception.class)
    @Scheduled(cron = "${msg.warning.scan-cron:0 0 * * * ?}")
    public void scanAndAlert() {
        log.info("[预警扫描] 开始执行预警规则扫描");
        List<MsgWarningRuleEntity> rules = ruleMapper.selectEnabledRules();
        int alertCount = 0;

        for (MsgWarningRuleEntity rule : rules) {
            try {
                // 1. 评估规则条件（如：库存<安全库存、应收>信用额度）
                List<WarningMatchResult> matches = conditionEvaluator.evaluate(rule);
                for (WarningMatchResult match : matches) {
                    // 2. 幂等检查：是否已生成过该预警
                    if (warningMapper.existsToday(rule.getId(), match.getBusinessId())) {
                        continue;
                    }
                    // 3. 生成预警记录
                    MsgWarningEntity warning = buildWarning(rule, match);
                    warningMapper.insert(warning);
                    // 4. 生成消息记录并推送
                    messageService.sendMessage(warning.getTitle(), warning.getContent(),
                        rule.getWarningType(), getNotifyUserIds(rule));
                    // 5. WebSocket实时推送
                    webSocketService.pushToRole(getNotifyRole(rule), buildWarningPushMessage(warning));
                    alertCount++;
                }
            } catch (Exception e) {
                log.error("[预警扫描] 规则{}执行失败", rule.getRuleCode(), e);
            }
        }
        log.info("[预警扫描] 完成，本次生成{}条预警", alertCount);
    }

    @Override
    public WarningDashboardVO getWarningDashboard(String module) {
        WarningDashboardVO vo = new WarningDashboardVO();
        // 1. 按模块统计预警数量（sale/purchase/inventory/finance）
        vo.setModuleCounts(warningMapper.countByModule());
        // 2. 近30天预警趋势数据
        vo.setTrendData(warningMapper.selectTrend(LocalDate.now().minusDays(30)));
        // 3. 预警类型分布
        vo.setDistributionData(warningMapper.selectDistribution());
        // 4. 预警明细列表（可按module过滤）
        vo.setWarningList(warningMapper.selectWarningList(module));
        return vo;
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void handleWarning(Long warningId) {
        MsgWarningEntity warning = warningMapper.selectById(warningId);
        if (warning == null) throw new BusinessException("预警记录不存在");
        if (warning.getIsHandled()) throw new BusinessException("预警已处理");
        warning.setIsHandled(true);
        warning.setHandleTime(LocalDateTime.now());
        warning.setHandlerId(SecurityUtils.getCurrentUserId());
        warningMapper.updateById(warning);
    }
}
```

### 5.2 预警条件评估器
```java
@Component
@RequiredArgsConstructor
public class WarningConditionEvaluator {

    private final InventoryQueryService inventoryQueryService;
    private final FinanceQueryService financeQueryService;

    /**
     * 评估预警规则，返回匹配的业务数据列表
     * condition_expr示例：{"field":"stock_qty","operator":"lt","value_field":"safety_stock","module":"inventory"}
     */
    public List<WarningMatchResult> evaluate(MsgWarningRuleEntity rule) {
        JsonNode condition = JsonUtils.parse(rule.getConditionExpr());
        String module = condition.get("module").asText();
        return switch (module) {
            case "inventory" -> inventoryQueryService.findBelowSafetyStock(condition);
            case "receivable" -> financeQueryService.findExceedCreditLimit(condition);
            case "payable" -> financeQueryService.findOverduePayable(condition);
            case "delivery" -> inventoryQueryService.findDelayedDelivery(condition);
            default -> Collections.emptyList();
        };
    }
}
```

## 八、易错警示

> ⚠️ 定时任务必须做幂等设计，防止重复扫描生成重复预警（通过existsToday检查+唯一约束双重保障）

> ⚠️ 单条规则执行异常不能中断整体扫描，必须在循环内try-catch，保证其他规则正常执行

> ⚠️ 预警条件评估涉及跨模块数据查询，应通过接口抽象解耦，不要在MsgWarningService中直接引用业务模块的Mapper

> ⚠️ cron表达式通过配置文件注入（${msg.warning.scan-cron}），默认每小时执行一次，生产环境可按需调整
