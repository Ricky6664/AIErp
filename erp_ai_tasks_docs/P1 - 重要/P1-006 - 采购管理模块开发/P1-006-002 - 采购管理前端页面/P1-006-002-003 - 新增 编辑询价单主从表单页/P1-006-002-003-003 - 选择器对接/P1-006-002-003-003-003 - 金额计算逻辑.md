### 5.1 金额计算公式
```typescript
// 金额计算引擎
const calcAmount = (price: number, qty: number, taxRate: number, discount: number) => {
  const amount = price * qty                           // 金额
  const afterDiscount = amount - (discount || 0)       // 折后金额
  const tax = afterDiscount * (taxRate || 0) / 100     // 税额
  const total = afterDiscount + tax                     // 价税合计
  return {
    amount: Number(amount.toFixed(4)),
    discount: Number((discount || 0).toFixed(4)),
    taxAmount: Number(tax.toFixed(4)),
    totalAmount: Number(total.toFixed(4))
  }
}
```

### 5.2 精度规则
- 所有金额保留4位小数
- 使用toFixed(4)截断，Number()转换回数字
- 汇总使用reduce累加，避免浮点精度累积误差
