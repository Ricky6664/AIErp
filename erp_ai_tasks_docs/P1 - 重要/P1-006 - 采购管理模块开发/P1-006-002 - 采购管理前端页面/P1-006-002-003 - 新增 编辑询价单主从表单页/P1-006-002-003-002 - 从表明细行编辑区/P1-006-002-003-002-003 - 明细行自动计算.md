### 5.1 自动计算逻辑
```typescript
// 单行金额计算
const calcRowAmount = (row: any) => {
  const amount = row.qty * row.price
  const tax = amount * (row.taxRate || 0) / 100
  const discount = row.discount || 0
  row.amount = Number((amount - discount).toFixed(4))
  row.taxAmount = Number(tax.toFixed(4))
  row.totalAmount = Number((row.amount + tax).toFixed(4))
}

// 明细行汇总到主表
const recalcTotal = () => {
  const rows = detailTableRef.value.getTableData().fullData
  mainForm.totalAmount = rows.reduce((sum, r) => sum + (r.totalAmount || 0), 0).toFixed(4)
}
```

### 5.2 精度控制
- 金额保留4位小数，使用toFixed(4)
- 汇总金额使用reduce累加，避免浮点精度问题
