# P1-012 凭证管理模块开发 - 模块开发指南

## 一、模块概述

- **模块定位**：凭证录入、凭证模板、自动生成凭证、凭证过账/红冲，是系统会计核算的核心模块
- **前置依赖**：P0-001~P0-005（后端框架+前端框架+数据库+权限+公共组件）、P0-011（会计科目/凭证字）、P1-010（应收）、P1-011（应付）
- **被依赖方**：P1-013（账簿查询——凭证数据作为账簿查询数据源）、P1-014（财务报表——凭证数据作为报表取数基础）、P1-015（成本核算——成本调整凭证生成）
- **开发阶段**：阶段八（财务层）

### 4.1 fin_voucher（凭证主表）— 主表

**通用必含字段**：同BaseEntity（10个，通过继承获取）

**业务字段**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 | 说明 |
|--------|---------|------|--------|---------|------|
| voucher_word_id | bigint | NOT NULL | - | 凭证字ID | 关联fin_voucher_word.id，凭证字名称由关联查询获取 |
| voucher_word | varchar(20) | NOT NULL | - | 凭证字 | 冗余快速展示字段，由系统根据voucher_word_id自动填充，不可手工修改 |
| voucher_no | varchar(50) | NOT NULL | 编码引擎自动生成 | 凭证号 | 凭证字+会计期间+流水号，同凭证字同期间内唯一连续 |
| voucher_date | date | NOT NULL | - | 凭证日期 | 记账日期 |
| period_id | bigint | NOT NULL | - | 会计期间ID | 关联fin_accounting_period.id |
| attachment_count | int | - | 0 | 附件张数 | 原始凭证附件数量 |
| debit_total | decimal(18,8) | NOT NULL | 0 | 借方合计 | 所有明细行借方金额之和 |
| credit_total | decimal(18,8) | NOT NULL | 0 | 贷方合计 | 所有明细行贷方金额之和，必须等于debit_total |
| status | varchar(30) | NOT NULL | 'draft' | 状态 | 枚举：draft(草稿)/posted(已过账)/reversed(已红冲) |
| remark | varchar(500) | - | - | 备注 | 可选 |

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| pk_fin_voucher | 主键 | id | 主键索引 |
| uk_fin_voucher_no | 部分唯一 | tenant_id, voucher_word_id, period_id, voucher_no WHERE is_deleted=false | 同租户同凭证字同期间凭证号唯一 |
| idx_fin_voucher_period | 普通 | period_id | 按会计期间查询 |
| idx_fin_voucher_date | 普通 | voucher_date | 按凭证日期查询 |
| idx_fin_voucher_status | 普通 | status | 按状态筛选 |

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |
|--------|---------|------|---------|
| 借贷平衡 | 保存/提交 | debit_total = credit_total | "凭证借贷不平衡，差额={debit_total - credit_total}" |
| 至少两条明细 | 保存 | 明细行数 >= 2 | "凭证至少需要两条明细行" |
| 凭证号连续 | 新增 | 编码引擎保证同凭证字同期间内流水号连续 | "凭证号生成异常" |
| 过账后不可改 | 修改/删除 | status='posted'时禁止修改和删除 | "已过账凭证不可修改，请先反过账" |

## 六、Service层业务逻辑规格

### 6.1 FinVoucherService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(VoucherQueryDTO) | 无(只读) | 按期间/凭证字/状态筛选 + 摘要模糊搜索 |
| getById(Long) | 无(只读) | 返回VoucherDetailVO，含明细行列表 |
| create(VoucherCreateDTO) | @Transactional | 借贷平衡校验 → 编码引擎生成voucherNo → 自动填充voucherWord → 计算debitTotal/creditTotal → save主从 → 操作日志 |
| update(id, VoucherUpdateDTO) | @Transactional | 存在性校验 → 已过账禁止修改 → 借贷平衡校验 → 乐观锁更新主从 |
| delete(Long) | @Transactional | 存在性校验 → 已过账禁止删除 → 逻辑删除主从 |
| post(Long) | @Transactional | 存在性校验 → 状态=草稿 → 标记已过账 → 逐行更新fin_account_balance(期初+本期+期末余额) → 级联更新后续期间期初余额 |
| reverse(Long) | @Transactional | 存在性校验 → 状态=已过账 → 生成反向凭证(借贷互换) → 原凭证标记已红冲 |
