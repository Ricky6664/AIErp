### 5.1 集成Service — AuditApprovalIntegrationService

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class AuditApprovalIntegrationService {

    private final ApprovalEngineService approvalEngineService;  // P1-002提供
    private final AuditConfigService auditConfigService;

    public Long createApprovalInstance(String docType, Long docId) {
        // 1. 读取审批流程配置
        SysAuditConfigEntity config = auditConfigService.getConfig(docType);
        if (!config.getApprovalEnabled()) {
            throw new BusinessException("当前单据类型未启用审批流程");
        }

        // 2. 解析审批节点定义（从 approval_flow_config JSON字段）
        ApprovalFlowConfig flowConfig = JSON.parseObject(
            config.getApprovalFlowConfig(), ApprovalFlowConfig.class);

        // 3. 调用P1-002创建审批实例
        ApprovalCreateParam param = new ApprovalCreateParam();
        param.setBizType(docType);
        param.setBizId(docId);
        param.setApplicantId(UserContext.getCurrentUserId());
        param.setFlowDefinitionId(flowConfig.getFlowDefinitionId());
        param.setNodes(flowConfig.getNodes());

        Long approvalInstanceId = approvalEngineService.createInstance(param);
        log.info("审批实例创建成功: docType={}, docId={}, approvalInstanceId={}",
            docType, docId, approvalInstanceId);
        return approvalInstanceId;
    }
}
```

### 5.2 审批回调实现 — ApprovalCallbackImpl

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class ApprovalCallbackImpl implements ApprovalCallbackInterface {

    private final DocumentStatusMapper documentStatusMapper;
    private final AuditLogMapper auditLogMapper;
    private final ApplicationEventPublisher eventPublisher;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void approved(String bizType, Long bizId, String approvalOpinion) {
        DocumentStatusEntity docStatus = documentStatusMapper
            .selectForUpdate(bizType, bizId);
        if (docStatus == null || docStatus.getStatus() != 1) {
            log.warn("审批通过回调忽略: 单据不存在或非已提交状态");
            return;
        }

        // Submitted(1) -> Approved(2)
        documentStatusMapper.updateStatus(bizType, bizId, 2);

        SysAuditLogEntity logEntity = new SysAuditLogEntity();
        logEntity.setDocType(bizType);
        logEntity.setDocId(bizId);
        logEntity.setOperationType("APPROVE");
        logEntity.setOperatorId(UserContext.getSystemUserId());
        logEntity.setFromStatus(1);
        logEntity.setToStatus(2);
        logEntity.setOpinion("审批流程通过: " + approvalOpinion);
        logEntity.setCreatedAt(LocalDateTime.now());
        auditLogMapper.insert(logEntity);

        eventPublisher.publishEvent(new AuditApprovedEvent(bizType, bizId));
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void rejected(String bizType, Long bizId, String rejectReason) {
        DocumentStatusEntity docStatus = documentStatusMapper
            .selectForUpdate(bizType, bizId);
        if (docStatus == null || docStatus.getStatus() != 1) {
            log.warn("审批驳回回调忽略: 单据不存在或非已提交状态");
            return;
        }

        // Submitted(1) -> Rejected(3)
        documentStatusMapper.updateStatus(bizType, bizId, 3);

        SysAuditLogEntity logEntity = new SysAuditLogEntity();
        logEntity.setDocType(bizType);
        logEntity.setDocId(bizId);
        logEntity.setOperationType("REJECT");
        logEntity.setOperatorId(UserContext.getSystemUserId());
        logEntity.setFromStatus(1);
        logEntity.setToStatus(3);
        logEntity.setOpinion("审批流程驳回: " + rejectReason);
        logEntity.setCreatedAt(LocalDateTime.now());
        auditLogMapper.insert(logEntity);
    }
}
```

### 5.4 关键业务规则

1. **集成触发条件**：仅当sys_audit_config.approval_enabled=true时，submit操作调用createApprovalInstance创建审批实例
2. **回调幂等**：approved()/rejected()回调需校验单据当前状态，非Submitted(1)状态直接忽略（防止重复回调）
3. **系统操作人**：审批回调中的操作人使用系统用户(UserContext.getSystemUserId())，区别于人工审核
4. **配置存储**：审批节点定义存储在sys_audit_config.approval_flow_config字段（JSON格式），由AuditConfigService管理
5. **跨模块调用**：调用P1-002的ApprovalEngineService应在事务外执行，避免长事务

### 5.5 数据交互

- 涉及数据表：sys_audit_config（读取approval_flow_config）, sys_audit_log（写入审批回调日志）, 业务单据状态表
- 涉及API：POST /api/engine/audit/submit（间接触发）, P1-002回调接口
- 涉及跨模块调用：ApprovalEngineService.createInstance()（P1-002提供）

## 八、易错警示

> ⚠️ 跨模块调用P1-002的createInstance必须在事务外执行，避免长事务持有行级锁

> ⚠️ 审批回调必须做幂等处理——P1-002可能因网络重试发送多次回调

> ⚠️ 回调操作人使用系统用户ID，勿使用当前登录用户（回调可能由异步线程触发）

> ⚠️ approval_flow_config的JSON解析需做异常处理，格式错误时抛出明确BusinessException

> ⚠️ 多租户隔离：P1-002回调时需传递tenant_id上下文，确保数据隔离正确
