### 5.1 核心Service — AuditEngineService.unconfirm

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class AuditEngineService {

    private final AuditConfigService auditConfigService;
    private final AuditLogMapper auditLogMapper;
    private final DocumentStatusMapper documentStatusMapper;
    private final RedissonClient redissonClient;

    /**
     * 反审操作
     * 状态流转：Approved(2) -> Draft(0)
     * 前提条件：不存在下游关联单据
     */
    @Transactional(rollbackFor = Exception.class)
    public void unconfirm(AuditOperationDTO dto) {
        // 1. Redis分布式锁
        String lockKey = String.format("audit:lock:%s:%d", dto.getDocType(), dto.getDocId());
        RLock lock = redissonClient.getLock(lockKey);
        if (!lock.tryLock(0, 10, TimeUnit.SECONDS)) {
            throw new BusinessException("单据正在处理中，请稍后重试");
        }
        try {
            // 2. 行级锁获取单据状态
            DocumentStatusEntity docStatus = documentStatusMapper
                .selectForUpdate(dto.getDocType(), dto.getDocId());
            if (docStatus == null) {
                throw new BusinessException("单据不存在");
            }
            if (docStatus.getStatus() != 2) {
                throw new BusinessException("仅已审核状态单据可反审，当前状态：" + docStatus.getStatus());
            }

            // 3. 下游单据检查（可插拔机制，每种单据类型可注册不同的检查器）
            List<DownstreamChecker> checkers = auditConfigService
                .getDownstreamCheckers(dto.getDocType());
            for (DownstreamChecker checker : checkers) {
                DownstreamCheckResult result = checker.check(dto.getDocId());
                if (result.hasDownstream()) {
                    throw new BusinessException(String.format(
                        "该单据已有关联下游单据[%s]，无法反审",
                        result.getDownstreamDocNo()));
                }
            }

            // 4. 状态回退 Approved(2) -> Draft(0)
            int fromStatus = docStatus.getStatus();
            documentStatusMapper.updateStatus(dto.getDocType(), dto.getDocId(), 0);

            // 5. 插入反审日志
            SysAuditLogEntity logEntity = new SysAuditLogEntity();
            logEntity.setDocType(dto.getDocType());
            logEntity.setDocId(dto.getDocId());
            logEntity.setOperationType("UNAUDIT");
            logEntity.setOperatorId(UserContext.getCurrentUserId());
            logEntity.setFromStatus(fromStatus);
            logEntity.setToStatus(0);
            logEntity.setOpinion("反审操作");
            logEntity.setCreatedAt(LocalDateTime.now());
            auditLogMapper.insert(logEntity);

            log.info("反审成功: docType={}, docId={}, operator={}",
                dto.getDocType(), dto.getDocId(), UserContext.getCurrentUserId());
        } finally {
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }
}
```

### 5.2 下游检查器接口 — DownstreamChecker

```java
/**
 * 下游单据检查器接口
 * 各业务模块实现此接口注册到审核引擎，反审时自动调用
 */
public interface DownstreamChecker {

    /**
     * 检查指定单据是否存在下游关联单据
     * @param docId 上游单据ID
     * @return 检查结果，包含是否存在下游及下游单据编号
     */
    DownstreamCheckResult check(Long docId);
}

@Data
public class DownstreamCheckResult {
    private boolean hasDownstream;
    private String downstreamDocNo;

    public static DownstreamCheckResult none() {
        DownstreamCheckResult r = new DownstreamCheckResult();
        r.setHasDownstream(false);
        return r;
    }

    public static DownstreamCheckResult exists(String docNo) {
        DownstreamCheckResult r = new DownstreamCheckResult();
        r.setHasDownstream(true);
        r.setDownstreamDocNo(docNo);
        return r;
    }
}
```

### 5.4 关键业务规则

1. **状态约束**：仅Approved(2)状态单据可执行反审，其他状态抛出BusinessException
2. **下游单据检查**：通过AuditConfigService.getDownstreamCheckers(docType)获取该单据类型的所有检查器，逐一检查。若存在下游单据则拦截反审，错误信息包含下游单据编号
3. **可插拔设计**：各业务模块（销售、采购、库存）通过实现DownstreamChecker接口并注册到Spring容器，审核引擎自动发现并调用
4. **状态回退**：反审统一回退至Draft(0)状态，而非回退到Submitted(1)
5. **并发控制**：PostgreSQL行级锁 + Redis分布式锁(key=`audit:lock:{docType}:{docId}`, TTL=10s)

### 5.5 数据交互

- 涉及数据表：sys_audit_log（写入反审日志）, 业务单据状态表（更新status字段）, 下游业务单据表（检查关联）
- 涉及API：POST /api/engine/audit/unconfirm（反审）
- 涉及DTO：AuditOperationDTO(docType, docId)

## 八、易错警示

> ⚠️ 下游检查器必须在事务内调用，确保检查与反审操作的原子性

> ⚠️ 下游检查器异常时应阻断反审（fail-fast），不可吞掉异常后继续反审

> ⚠️ 行级锁SELECT FOR UPDATE必须在事务内执行，否则锁不生效

> ⚠️ 反审回退目标状态固定为Draft(0)，不要误回退到Submitted(1)

> ⚠️ 多租户隔离：tenant_id由拦截器自动附加，业务代码勿手动处理

> ⚠️ DownstreamChecker实现类需注意性能，避免全表扫描，使用索引查询关联单据
