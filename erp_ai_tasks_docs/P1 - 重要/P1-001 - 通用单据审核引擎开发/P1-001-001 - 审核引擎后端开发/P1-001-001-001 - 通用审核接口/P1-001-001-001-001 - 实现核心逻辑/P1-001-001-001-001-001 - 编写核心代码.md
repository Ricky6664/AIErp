## 二、任务目标

实现通用审核引擎的提交审核(submit)与审核通过(approve)两大核心操作。submit操作需校验单据为草稿状态(status=0)后流转为已提交(status=1)，并根据sys_audit_config.approval_enabled配置决定是触发P1-002审批流程还是直接自动审核通过(status=2)；approve操作需通过PostgreSQL行级锁(SELECT FOR UPDATE)确保并发安全，校验已提交状态(status=1)后流转至已审核(status=2)，并记录审核意见至sys_audit_log

### 5.1 核心Service — AuditEngineService

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class AuditEngineService {

    private final AuditConfigService auditConfigService;
    private final AuditLogMapper auditLogMapper;
    private final DocumentStatusMapper documentStatusMapper;
    private final ApprovalIntegrationService approvalIntegrationService;
    private final ApplicationEventPublisher eventPublisher;
    private final RedissonClient redissonClient;

    /**
     * 提交审核
     * 状态流转：Draft(0) -> Submitted(1)
     * 若 approval_enabled=true -> 创建P1-002审批实例
     * 若 approval_enabled=false 且 auto_confirm=true -> 直接审核通过至 Approved(2)
     */
    @Transactional(rollbackFor = Exception.class)
    public void submit(AuditSubmitDTO dto) {
        // 1. Redis分布式锁防并发提交
        String lockKey = String.format("audit:lock:%s:%d", dto.getDocType(), dto.getDocId());
        RLock lock = redissonClient.getLock(lockKey);
        if (!lock.tryLock(0, 10, TimeUnit.SECONDS)) {
            throw new BusinessException("单据正在处理中，请勿重复提交");
        }
        try {
            // 2. 获取单据当前状态（行级锁）
            DocumentStatusEntity docStatus = documentStatusMapper
                .selectForUpdate(dto.getDocType(), dto.getDocId());
            if (docStatus == null) {
                throw new BusinessException("单据不存在");
            }
            if (docStatus.getStatus() != 0) {
                throw new BusinessException("仅草稿状态单据可提交审核，当前状态：" + docStatus.getStatus());
            }

            // 3. 查询审核配置
            SysAuditConfigEntity config = auditConfigService.getConfig(dto.getDocType());

            // 4. 状态流转 Draft(0) -> Submitted(1)
            int fromStatus = docStatus.getStatus();
            documentStatusMapper.updateStatus(dto.getDocType(), dto.getDocId(), 1);

            // 5. 插入审核日志
            insertAuditLog(dto.getDocType(), dto.getDocId(), "SUBMIT",
                fromStatus, 1, dto.getSubmitRemark());

            // 6. 审批流程路由
            if (config.getApprovalEnabled()) {
                // approval_enabled=true -> 创建P1-002审批实例，等待审批回调
                approvalIntegrationService.createApprovalInstance(
                    dto.getDocType(), dto.getDocId());
            } else if (config.getAutoConfirm()) {
                // auto_confirm=true -> 直接自动审核通过 Submitted(1) -> Approved(2)
                documentStatusMapper.updateStatus(dto.getDocType(), dto.getDocId(), 2);
                insertAuditLog(dto.getDocType(), dto.getDocId(), "APPROVE",
                    1, 2, "系统自动审核通过");
                eventPublisher.publishEvent(new AuditApprovedEvent(
                    dto.getDocType(), dto.getDocId()));
            }
            // else: 保持Submitted(1)状态，等待人工审核
        } finally {
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }

    /**
     * 审核通过
     * 状态流转：Submitted(1) -> Approved(2)
     * 使用 SELECT FOR UPDATE 行级锁 + Redis分布式锁双重保障
     */
    @Transactional(rollbackFor = Exception.class)
    public void approve(AuditApproveDTO dto) {
        String lockKey = String.format("audit:lock:%s:%d", dto.getDocType(), dto.getDocId());
        RLock lock = redissonClient.getLock(lockKey);
        if (!lock.tryLock(0, 10, TimeUnit.SECONDS)) {
            throw new BusinessException("单据正在处理中，请稍后重试");
        }
        try {
            // 行级锁获取单据状态
            DocumentStatusEntity docStatus = documentStatusMapper
                .selectForUpdate(dto.getDocType(), dto.getDocId());
            if (docStatus == null) {
                throw new BusinessException("单据不存在");
            }
            if (docStatus.getStatus() != 1) {
                throw new BusinessException("仅已提交状态单据可审核通过，当前状态：" + docStatus.getStatus());
            }

            // opinion审核意见必填
            if (StringUtils.isBlank(dto.getOpinion())) {
                throw new BusinessException("审核意见不能为空");
            }

            // 状态流转 Submitted(1) -> Approved(2)
            documentStatusMapper.updateStatus(dto.getDocType(), dto.getDocId(), 2);

            // 插入审核日志
            insertAuditLog(dto.getDocType(), dto.getDocId(), "APPROVE",
                1, 2, dto.getOpinion());

            // 发布审核通过事件，通知下游模块
            eventPublisher.publishEvent(new AuditApprovedEvent(
                dto.getDocType(), dto.getDocId()));
        } finally {
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }

    private void insertAuditLog(String docType, Long docId, String operationType,
                                 int fromStatus, int toStatus, String opinion) {
        SysAuditLogEntity log = new SysAuditLogEntity();
        log.setDocType(docType);
        log.setDocId(docId);
        log.setOperationType(operationType);
        log.setOperatorId(UserContext.getCurrentUserId());
        log.setFromStatus(fromStatus);
        log.setToStatus(toStatus);
        log.setOpinion(opinion);
        log.setCreatedAt(LocalDateTime.now());
        auditLogMapper.insert(log);
    }
}
```

### 5.2 Controller层

```java
@RestController
@RequestMapping("/api/engine/audit")
@RequiredArgsConstructor
public class AuditEngineController {

    private final AuditEngineService auditEngineService;

    @PostMapping("/submit")
    public Result<Void> submit(@Valid @RequestBody AuditSubmitDTO dto) {
        auditEngineService.submit(dto);
        return Result.ok();
    }

    @PostMapping("/approve")
    public Result<Void> approve(@Valid @RequestBody AuditApproveDTO dto) {
        auditEngineService.approve(dto);
        return Result.ok();
    }
}
```

### 5.3 关键业务规则

1. **状态流转约束**：submit仅允许Draft(0)状态单据操作；approve仅允许Submitted(1)状态单据操作
2. **审批流程路由**：sys_audit_config.approval_enabled=true时，submit后创建P1-002审批实例而非直接通过；approval_enabled=false且auto_confirm=true时自动审核通过
3. **并发控制**：PostgreSQL `SELECT ... FOR UPDATE` 行级锁 + Redis分布式锁(key=`audit:lock:{docType}:{docId}`, TTL=10s) 双重保障
4. **审核意见**：approve操作opinion字段必填，submit操作submitRemark可选
5. **日志记录**：每次状态变更均写入sys_audit_log，记录操作人(operator_id)、操作类型(operation_type)、操作前后状态(from_status->to_status)及审核意见(opinion)
6. **事件发布**：审核通过后发布AuditApprovedEvent，下游模块可监听此事件执行后续业务

### 5.4 数据交互

- 涉及数据表：sys_audit_config（读取审核配置）, sys_audit_log（写入审核日志）, 业务单据状态表（更新status字段）
- 涉及API：POST /api/engine/audit/submit（提交审核）, POST /api/engine/audit/approve（审核通过）
- 涉及DTO：AuditSubmitDTO(docType, docId, submitRemark), AuditApproveDTO(docType, docId, opinion)

## 八、易错警示

> ⚠️ 并发控制：approve必须同时使用PostgreSQL行级锁(SELECT FOR UPDATE)和Redis分布式锁，双重保障防止并发审核通过同一单据

> ⚠️ 事务边界：调用P1-002创建审批实例属于远程调用，应放在本地事务之外或使用编程式事务控制，避免长事务持有行级锁

> ⚠️ 审核日志不可篡改：sys_audit_log仅INSERT不允许UPDATE/DELETE，确保审核轨迹完整可追溯

> ⚠️ 事件发布时机：AuditApprovedEvent必须在事务提交后发布（使用@TransactionalEventListener(phase=AFTER_COMMIT)），防止事务回滚但事件已消费

> ⚠️ 多租户隔离：tenant_id由拦截器自动附加到SQL，业务代码勿手动处理

> ⚠️ DTO参数校验：使用@Valid + @NotBlank注解校验必填字段，opinion在approve时必填
