### 5.1 配置更新Service — AuditConfigService.updateConfig

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class AuditConfigService {

    private final SysAuditConfigMapper auditConfigMapper;
    private final RedisTemplate<String, Object> redisTemplate;
    private static final String CONFIG_CACHE_PREFIX = "audit:config:";
    private static final long CONFIG_CACHE_TTL_HOURS = 2;

    @Transactional(rollbackFor = Exception.class)
    public void updateConfig(SysAuditConfigUpdateDTO dto) {
        // 1. 互斥校验：auto_confirm 和 approval_enabled 不可同时为 true
        if (Boolean.TRUE.equals(dto.getAutoConfirm())
                && Boolean.TRUE.equals(dto.getApprovalEnabled())) {
            throw new BusinessException(
                "自动确认(auto_confirm)与审批流程(approval_enabled)不可同时启用");
        }

        // 2. 查询现有配置
        SysAuditConfigEntity existing = auditConfigMapper.selectByDocType(dto.getDocType());
        if (existing == null) {
            throw new BusinessException("审核配置不存在: " + dto.getDocType());
        }

        // 3. 更新配置
        if (dto.getAutoConfirm() != null) existing.setAutoConfirm(dto.getAutoConfirm());
        if (dto.getApprovalEnabled() != null) existing.setApprovalEnabled(dto.getApprovalEnabled());
        if (dto.getMaxAuditLevel() != null) existing.setMaxAuditLevel(dto.getMaxAuditLevel());
        auditConfigMapper.updateById(existing);

        // 4. 主动失效Redis缓存
        String cacheKey = CONFIG_CACHE_PREFIX + dto.getDocType();
        redisTemplate.delete(cacheKey);
        log.info("审核配置更新并清除缓存: docType={}", dto.getDocType());
    }

    @Cacheable(value = "auditConfig", key = "#docType", unless = "#result == null")
    public SysAuditConfigEntity getConfig(String docType) {
        return auditConfigMapper.selectByDocType(docType);
    }
}
```

### 5.2 自动确认监听器 — AutoConfirmListener

```java
@Component
@RequiredArgsConstructor
@Slf4j
public class AutoConfirmListener {

    private final AuditConfigService auditConfigService;
    private final AuditEngineService auditEngineService;

    @EventListener
    public void onDocCreated(DocCreatedEvent event) {
        String docType = event.getDocType();
        Long docId = event.getDocId();

        try {
            SysAuditConfigEntity config = auditConfigService.getConfig(docType);
            if (config == null || !Boolean.TRUE.equals(config.getAutoConfirm())) {
                return;  // 未启用自动确认，跳过
            }

            log.info("自动确认触发: docType={}, docId={}", docType, docId);

            AuditSubmitDTO submitDTO = new AuditSubmitDTO();
            submitDTO.setDocType(docType);
            submitDTO.setDocId(docId);
            submitDTO.setSubmitRemark("系统自动确认");
            auditEngineService.submit(submitDTO);
            // auto_confirm=true时submit内部已自动approve

            log.info("自动确认完成: docType={}, docId={}", docType, docId);
        } catch (Exception e) {
            log.error("自动确认失败: docType={}, docId={}, error={}",
                docType, docId, e.getMessage(), e);
            // 自动确认失败不阻断单据创建流程
        }
    }
}
```

### 5.3 Controller层

### 5.4 关键业务规则

1. **互斥校验**：auto_confirm=true与approval_enabled=true不可同时设置，updateConfig时校验，违反抛出BusinessException
2. **缓存策略**：Redis缓存key=`audit:config:{docType}`，TTL=2小时；配置更新时主动delete缓存
3. **自动确认**：监听DocCreatedEvent，若配置auto_confirm=true则自动调用submit（submit内部自动approve至Approved(2)）
4. **仅对新单据生效**：auto_confirm参数变更不影响已有单据，仅对变更后新创建的单据触发自动确认
5. **异常隔离**：自动确认失败不阻断单据创建主流程（try-catch后仅记录日志）

### 5.5 数据交互

- 涉及数据表：sys_audit_config（配置CRUD）, sys_param（系统参数读取）
- 涉及API：PUT /api/engine/audit/config（更新配置）, GET /api/engine/audit/config/{docType}（查询配置）
- 涉及缓存：Redis key `audit:config:{docType}`，TTL=2h
- 涉及事件：DocCreatedEvent（监听）

## 八、易错警示

> ⚠️ 互斥校验必须同时在前端表单和后端Service层双重保障

> ⚠️ Redis缓存delete操作需在事务提交后执行（使用@TransactionalEventListener），避免事务回滚但缓存已清

> ⚠️ AutoConfirmListener中自动确认失败必须catch，不可抛出异常影响单据创建主流程

> ⚠️ @EventListener与@TransactionalEventListener区别：前者在事务内执行，后者在事务提交后执行

> ⚠️ 缓存TTL设置2小时，避免配置变更后长时间不生效

> ⚠️ 多租户隔离：sys_audit_config需按tenant_id隔离，缓存key也需包含tenant_id
