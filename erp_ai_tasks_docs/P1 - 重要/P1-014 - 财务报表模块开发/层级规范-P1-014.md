## 1. 模块架构约束

### 1.1 模块定位
资产负债表、利润表、现金流量表，为企业管理层和外部审计提供标准化财务报表。属于财务层模块（阶段八），是财务模块的终端输出，基于凭证和账簿数据通过取数公式计算生成三大财务报表。

### 1.2 依赖关系
- 前置依赖：P0-001~P0-005（基础框架层）、P0-011（会计科目）、P1-012（凭证数据）、P1-013（账簿数据）
- 后续依赖：无（财务报表为财务模块的终端输出，无下游依赖）

### 1.3 技术约束
- 技术栈：Spring Boot + MyBatis-Plus + PostgreSQL；取数公式引擎支持自定义表达式解析；报表缓存机制避免重复计算
- 性能约束：报表生成支持异步计算（数据量大时）；缓存机制按模板+期间+行次唯一索引
- 安全约束：资产负债表必须平衡校验（资产=负债+所有者权益）；报表生成日志记录data_hash防篡改；导出格式需符合国家会计准则

## 2. 数据模型关系

### 2.1 核心数据表
| 表名 | 说明 | 关键字段 |
|------|------|---------|
| fin_report_template | 报表模板配置表 | report_type(资产负债表/利润表/现金流量表), template_name, period_type, layout_json(JSONB), print_config_json |
| fin_report_line_item | 报表行项定义表 | template_id, line_code(行次编码), line_name, line_type(标题行/数据行/合计行), parent_line_id, calc_formula |
| fin_report_formula | 取数公式配置表 | line_item_id, formula_type(科目取数/行次运算/常数), account_code_start/end, balance_direction, operator, multiplier |
| fin_report_cache | 报表数据缓存表 | template_id, period_id, line_code, line_value, calc_time, calc_status(计算中/已完成/异常) |
| fin_report_generate_log | 报表生成日志表 | template_id, period_id, generate_type, status, data_hash |

### 2.2 表关系图
- fin_report_template 1:N fin_report_line_item：一个模板包含多个行项定义
- fin_report_line_item 1:N fin_report_formula：一个行项可配置多个取数公式
- fin_report_template 1:N fin_report_cache：一个模板按期间缓存已计算的报表数据
- fin_report_template 1:N fin_report_generate_log：记录每次报表生成操作
- 数据来源：fin_account_balance（科目余额表）+ fin_voucher_detail（凭证明细）+ fin_cash_flow_item（现金流量项目）

### 2.3 数据流转
1. 报表模板配置：定义报表类型 → 配置行项（层级结构）→ 配置取数公式
2. 报表生成：校验试算平衡 → 按行次顺序解析取数公式 → 执行公式计算 → 写入 fin_report_cache
3. 报表查询：优先读取缓存 → 缓存过期时重新计算
4. 报表钻取：报表项目 → 科目总账 → 科目明细账 → 记账凭证（四级钻取）
5. 期末自动生成：期末结账触发 → 自动生成三大报表 → 生成成功后才允许结账
6. 凭证变更处理：凭证反过账 → 标记受影响期间缓存为过期 → 下次查询重新计算

## 3. 业务流程

### 3.1 核心业务流程
1. 模板管理：创建报表模板 → 定义行项结构 → 配置取数公式
2. 报表生成：选择模板+期间 → 试算平衡校验 → 执行公式计算 → 缓存结果
3. 资产负债表：按资产负债类科目(1xxx~2xxx)汇总 → 平衡校验（资产=负债+所有者权益）
4. 利润表：按损益类科目(5xxx~6xxx)汇总 → 计算营业收入/成本/利润/净利润
5. 现金流量表：按现金类科目明细 → 按流量分类归集到经营/投资/筹资三大活动
6. 报表对比：两期数据对比分析（变动额+变动率）
7. 报表导出：Excel/PDF导出，格式符合国家会计准则

### 3.2 业务规则
- 取数公式三种类型：
  - 科目取数公式：QC(科目起始, 科目结束, 取数方向, 期间) — 支持JE(借方)/DE(贷方)/YE(余额)/QC(期初)/LJ(累计借方)/LD(累计贷方)
  - 行次运算公式：R(行次) 运算符 R(行次) — 引用其他行次值
  - 常数公式：直接赋值
- 资产负债表平衡校验：资产合计(行次60) = 负债合计(行次120) + 所有者权益合计(行次150)，不平衡阻止期末结账
- 现金流量表仅取已审核凭证
- 单元格四级钻取：报表项目 → 科目总账 → 明细账 → 记账凭证
- 期末自动生成：期末结账触发 + 每月1日凌晨自动生成上月月报
- 凭证反过账标记缓存过期，下次重新计算

### 3.3 状态流转
报表生成状态：计算中 → 已完成 / 异常
报表缓存状态：有效 → 过期（凭证变更触发）→ 重新计算

## 5. 开发顺序约束

### 5.1 必须顺序执行的任务
1. **财务报表后端开发（P1-014-001）**必须先完成：
   - 报表模板/行项/公式数据模型设计
   - 取数公式引擎（科目取数/行次运算/常数三种类型）
   - 报表生成服务（含试算平衡校验+异步计算）
   - 报表缓存机制
   - 资产负债表平衡校验
   - 报表钻取服务（四级钻取）
   - 报表对比分析服务
   - 报表导出服务（Excel/PDF）
2. **财务报表前端页面（P1-014-002）**依赖后端完成：
   - 三大报表展示页面（固定行列表格+单元格钻取）
   - 报表工作台

### 5.2 可并行执行的任务
- 报表模板管理与取数公式配置可并行开发
- 资产负债表与利润表生成逻辑可并行开发
- 现金流量表与报表缓存机制可并行开发
- 报表钻取服务与报表对比服务可并行开发
- Excel导出与PDF导出可并行开发
- 前端三个报表页面可并行开发
