# P1-014 财务报表模块开发 - 模块开发指南

## 一、模块概述

- **模块定位**：资产负债表、利润表、现金流量表，为企业管理层和外部审计提供标准化财务报表
- **前置依赖**：P0-001~P0-005（后端框架+前端框架+数据库+权限+公共组件）、P0-011（会计科目）、P1-012（凭证数据）、P1-013（账簿数据）
- **被依赖方**：无（财务报表为财务模块的终端输出，无下游依赖）
- **开发阶段**：阶段八（财务层）

### 5.3 取数公式配置规则

取数公式支持以下三种类型，可组合使用：

**类型一：科目取数公式**

从fin_account_balance表按科目编码范围+余额方向取数，公式格式：
```
QC(科目编码起始, 科目编码结束, 取数方向, 期间)
```
- `QC(1001, 1009, JE, :period)` → 取科目1001~1009在指定期间的借方发生额合计
- `QC(1001, 1009, DE, :period)` → 取科目1001~1009在指定期间的贷方发生额合计
- `QC(1001, 1009, YE, :period)` → 取科目1001~1009在指定期间的期末余额合计
- `QC(1001, 1009, QC, :period)` → 取科目1001~1009在指定期间的期初余额合计
- `QC(1001, 1009, LJ, :period)` → 取科目1001~1009从年初到指定期间的累计借方发生额
- `QC(1001, 1009, LD, :period)` → 取科目1001~1009从年初到指定期间的累计贷方发生额

**类型二：行次运算公式**

引用其他报表行次的值进行四则运算，公式格式：
```
R(行次编码) 运算符 R(行次编码)
```
- `R(10) + R(11) + R(12)` → 第10+11+12行次值之和
- `R(20) - R(21)` → 第20行次值减第21行次值
- `R(30) * 0.25` → 第30行次值的25%

**类型三：常数公式**

直接赋值常数，用于固定行项目。

| 规则编号 | 触发条件 | 执行动作 | 说明 |
|---------|---------|---------|------|
| AR-001 | 会计期间执行期末结账(fin_period.close操作) | 自动生成该期间的三大报表 | 结账前自动触发报表生成，生成成功后才允许完成结账 |

| AR-004 | 报表数据校验 | 资产负债表平衡校验 | 生成完成后自动校验：资产合计=负债合计+所有者权益合计，不平衡时标记异常 |

### 5.6 资产负债表平衡校验规则

资产负债表编制完成后，系统自动执行以下校验：

```
校验公式：资产合计(行次60) = 负债合计(行次120) + 所有者权益合计(行次150)

IF 行次60.value ≠ 行次120.value + 行次150.value THEN
  error_msg = "资产负债表不平衡，差额=" + (行次60.value - 行次120.value - 行次150.value)
  calc_status = '异常'
  阻止期末结账操作
ELSE
  calc_status = '已完成'
  允许期末结账
```

### 5.7 报表单元格钻取链路

报表单元格支持三级钻取，形成完整的审计追溯链路：

```
第一级：报表项目（如"货币资金"行次）
  ↓ 点击钻取
第二级：科目总账（如1001库存现金、1002银行存款、1009其他货币资金的总账汇总）
  ↓ 点击钻取
第三级：科目明细账（如100201工商银行账户的明细账凭证明细）
  ↓ 点击钻取
第四级：记账凭证（具体凭证详情页面）
```
