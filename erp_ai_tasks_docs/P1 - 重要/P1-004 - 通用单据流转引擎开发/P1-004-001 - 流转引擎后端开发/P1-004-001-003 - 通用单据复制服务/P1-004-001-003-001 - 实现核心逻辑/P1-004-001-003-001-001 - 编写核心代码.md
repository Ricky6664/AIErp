## 五、详细开发规格



### 5.1 核心业务逻辑
```java
@Service
@RequiredArgsConstructor
public class BizDocRelationCoreService {
    private final BizDocRelationMapper flowMapper;

    @Transactional(rollbackFor = Exception.class)
    public Result processBusiness(BizDocRelationDTO dto) {
        // 1. 业务规则校验
        validateBusinessRules(dto);
        // 2. 主流程处理
        BizDocRelationEntity entity = doProcess(dto);
        // 3. 数据持久化
        flowMapper.insert(entity);
        // 4. 日志记录
        logService.record("BizDocRelation", entity.getId(), "执行核心业务");
        return Result.ok(entity.getId());
    }
}
```

### 5.2 关键业务规则
- 单据流转路径控制；上下游关联关系校验；流转日志记录；强制流转与标准流转模式切换

### 5.3 数据交互

## 八、易错警示

> ⚠️ 并发控制：审核操作使用行级锁(SELECT FOR UPDATE)或分布式锁

> ⚠️ 事务一致性：多表操作使用@Transactional，远程调用放在事务外

> ⚠️ 关键操作必须记录日志(操作人+操作类型+操作对象+操作前后状态)

> ⚠️ 异常处理：捕获具体异常类型，勿捕获Exception后吞掉

> ⚠️ 多租户隔离：tenant_id由拦截器自动附加，业务代码勿手动处理
