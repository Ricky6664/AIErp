### 5.1 辅助方法清单
```java
/** 编码生成（幂等调用） */
private String generateCode() {
    return codeGeneratorService.generate("wms");
}

/** Entity→VO转换 */
private WmsInventoryDetailVO convertToDetailVO(WmsInventoryEntity entity) {
    WmsInventoryDetailVO vo = BeanUtil.copyProperties(entity, WmsInventoryDetailVO.class);
    vo.setDetails(getDetailList(entity.getId()));
    return vo;
}

/** 金额汇总计算 */
private BigDecimal calculateTotal(List<WmsInventoryDetailEntity> details) {
    return details.stream()
        .map(d -> AmountCalculator.calc(d.getPrice(), d.getQty(), d.getTaxRate(), d.getDiscount()))
        .reduce(BigDecimal.ZERO, BigDecimal::add);
}
```
