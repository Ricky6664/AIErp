# P1-007 库存管理模块开发 - 模块开发指南

## 一、模块概述

- **模块定位**：库存全功能管理，包括库存引擎（出入库/成本/批次序列号/预警）和业务单据（其他出入库/盘点/调拨/报损报溢/组装拆卸/库存查询/预警/成本查询），是系统库存数据的核心管理模块
- **前置依赖**：P0-001~P0-005（后端框架+前端框架+数据库+权限+公共组件）、P0-007（商品）、P0-010（仓库库位）、P1-001（审核引擎）、P1-004（流转引擎）、P1-005（销售出库）、P1-006（采购入库）
- **被依赖方**：P1-008（生产管理——领料/入库触发库存变动）、P1-009（委外管理——领料/入库触发库存变动）、P1-015（成本核算——库存成本）
- **开发阶段**：阶段七（业务层）

## 五、模块级专属约束

1. **库存增减原子操作**：inv_stock表行级锁+数量增减+版本号乐观锁，所有出入库单据审核时必须通过库存引擎Service执行增减操作，确保库存数据一致性。
2. **成本计算方法**：系统参数inv.cost_method控制全局成本方法（移动加权平均/先进先出/手工指定），按商品可覆盖成本方法。入库时重新加权平均单价，出库时按当前均价或批次顺序匹配成本。
3. **库位/批次/序列号三表处理**：所有出入库事务单据审核后，若涉及库位信息则自动更新inv_stock_location，若涉及批次信息则自动更新inv_batch_trace，若涉及序列号信息则自动更新inv_serial_trace。
4. **库存核心表唯一索引**：inv_stock联合唯一索引(product_id, warehouse_id, tenant_id)，inv_stock_location联合唯一索引(product_id, warehouse_id, location_id, tenant_id)，inv_batch_trace联合唯一索引(product_id, warehouse_id, batch_no, tenant_id)，inv_serial_trace联合唯一索引(serial_no, product_id, tenant_id)。
5. **盘点联动**：盘点单完成后，盘盈自动生成报溢单并增加库存，盘亏自动生成报损单并扣减库存。
6. **组装/拆卸BOM校验**：组装单审核时校验BOM完整性，子件库存充足才允许扣减；拆卸单审核时组合件扣减、子件按BOM展开增加。
7. **反审冲回**：所有出入库单据反审时，库存数据必须反向冲回，包括inv_stock、inv_stock_location、inv_batch_trace、inv_serial_trace。
