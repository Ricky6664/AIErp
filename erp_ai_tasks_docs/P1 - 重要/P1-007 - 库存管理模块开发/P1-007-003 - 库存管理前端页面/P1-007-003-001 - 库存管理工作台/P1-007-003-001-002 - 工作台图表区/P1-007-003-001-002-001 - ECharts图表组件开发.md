## 五、详细开发规格


### 5.1 图表组件
```vue
<template>
  <div ref="chartRef" :style="{ width: '100%', height: height + 'px' }" />
</template>

<script setup>
import * as echarts from 'echarts'
const chartRef = ref()
let chart = null
onMounted(() => {
  chart = echarts.init(chartRef.value)
  chart.setOption(props.option)
  window.addEventListener('resize', () => chart.resize())
})
watch(() => props.option, (val) => chart.setOption(val), { deep: true })
</script>
```

## 八、易错警示

> ⚠️ chart实例在onBeforeUnmount中dispose()释放，避免内存泄漏

> ⚠️ resize监听在onMounted添加、onBeforeUnmount移除

> ⚠️ setOption使用notMerge: false(增量更新)，全量更新传true

> ⚠️ 空数据时展示占位图+提示文案，勿展示空图表
