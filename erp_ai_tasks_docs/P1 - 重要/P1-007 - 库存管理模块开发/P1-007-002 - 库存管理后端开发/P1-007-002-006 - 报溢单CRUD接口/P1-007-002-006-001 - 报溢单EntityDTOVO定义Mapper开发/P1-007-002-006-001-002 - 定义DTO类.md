## 五、详细开发规格


> **📦 本任务模块上下文**（来源：P1-007模块开发指南）
> - 本模块涉及数据表：inv_warehouse, inv_location, inv_other_outbound, inv_other_outbound_detail, inv_other_inbound, inv_other_inbound_detail, inv_stocktake, inv_stocktake_detail, inv_transfer, inv_transfer_detail
> - 本模块涉及API：/api/inventory/stock-engine, /api/inventory/available-qty, /api/inventory/occupied-qty, /api/inventory/intransit-qty, /api/inventory/cost
> - 本模块业务规则：库存增减原子操作：inv_stock表行级锁+数量增减+版本号乐观锁，所有出入库单据审核时必须通过库存引擎Service执行增减操作，确保库存数据一致性。; 成本计算方法：系统参数inv.cost_method控制全局成本方法（移动加权平均/先进先出/手工指定），按商品可覆盖成本方法。入库时重新加权平均单价，出库时按当前均价或批次顺序匹配成本。
>
> 💡 开发本任务时，请结合上述模块上下文理解业务场景和数据关系。
### 5.1 CreateDTO（新增请求）
```java
@Data
public class WmsInventoryCreateDTO {
    @NotBlank(message = "名称不能为空")
    private String wmsName;

    @NotNull(message = "日期不能为空")
    @JsonFormat(pattern = "yyyy-MM-dd")
    private LocalDate bizDate;

    @NotNull(message = "明细行不能为空")
    @Size(min = 1, message = "至少一条明细行")
    private List<WmsInventoryDetailCreateDTO> details;
}
```

### 5.2 UpdateDTO（修改请求）
```java
@Data
public class WmsInventoryUpdateDTO extends WmsInventoryCreateDTO {
    @NotNull(message = "ID不能为空")
    private Long id;
    private Integer version;  // 乐观锁版本号
}
```

### 5.3 QueryDTO（查询请求）
```java
@Data
public class WmsInventoryQueryDTO extends PageQuery {
    private String wmsNo;    // 单据编号(模糊查询)
    private String wmsName;  // 名称(模糊查询)
    private Integer status;        // 审核状态
    private LocalDate startDate;   // 开始日期
    private LocalDate endDate;     // 结束日期
}
```

## 八、易错警示

> ⚠️ CreateDTO的@NotBlank/@NotNull校验message必须明确(中文提示)

> ⚠️ UpdateDTO必须包含id字段+@NotNull校验

> ⚠️ QueryDTO继承PageQuery，勿自定义pageNum/pageSize字段

> ⚠️ 日期类型使用LocalDate/LocalDateTime，勿用java.util.Date

> ⚠️ 明细行DTO使用@Size(min=1)校验非空，勿用@NotNull
