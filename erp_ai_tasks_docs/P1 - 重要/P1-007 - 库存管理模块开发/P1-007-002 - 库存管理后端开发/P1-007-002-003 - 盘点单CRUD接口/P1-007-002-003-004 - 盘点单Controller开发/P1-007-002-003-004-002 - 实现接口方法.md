### 5.1 接口方法实现
```java
@GetMapping("/{id}")
@Operation(summary = "查询详情")
public R<WmsInventoryDetailVO> detail(@PathVariable Long id) {
    return R.ok(wmsService.getDetail(id));
}

@PutMapping
@Operation(summary = "修改")
public R<Boolean> update(@Valid @RequestBody WmsInventoryUpdateDTO dto) {
    return R.ok(wmsService.update(dto));
}

@DeleteMapping("/{id}")
@Operation(summary = "删除")
public R<Boolean> delete(@PathVariable Long id) {
    return R.ok(wmsService.delete(id));
}
```

## 八、易错警示

> ⚠️ @RequestBody必须配合@Valid使用，触发DTO校验注解

> ⚠️ @PathVariable的name属性必须与路径变量名一致

> ⚠️ GET请求参数使用QueryDTO接收(自动绑定)，勿用多个@RequestParam

> ⚠️ 统一R<T>响应包装，异常由全局异常处理器捕获

> ⚠️ 权限注解@PreAuthorize或自定义权限注解勿遗漏
