### 5.1 Entity类定义
```java
@Data
@TableName("inv_warehouse")
@EqualsAndHashCode(callSuper = true)
public class WmsInventoryEntity extends BaseEntity {
    @TableId(type = IdType.ASSIGN_ID)
    private Long id;

    @TableField("wms_no")
    private String wmsNo;  // 单据编号

    @TableField("wms_name")
    private String wmsName;  // 名称

    @TableField("status")
    private Integer status;  // 审核状态(0草稿/1待审核/2已审核/3已驳回/4已作废)

    @TableField("remark")
    private String remark;  // 备注

    @TableLogic
    @TableField("is_deleted")
    private Integer isDeleted;  // 逻辑删除(0正常/1删除)
}
```

### 5.2 关键字段说明
| 数据库字段 | Java属性 | 类型 | 说明 |
|-----------|---------|------|------|
| id | id | Long | 主键(雪花算法) |
| wms_no | wmsNo | String | 单据编号(编码引擎生成) |
| status | status | Integer | 审核状态枚举 |
| tenant_id | tenantId | Long | 多租户ID(继承BaseEntity) |
| is_deleted | isDeleted | Integer | 逻辑删除标记 |
| create_time | createTime | LocalDateTime | 创建时间(继承BaseEntity) |

## 八、易错警示

> ⚠️ @TableName的表名必须与数据库DDL一致，注意schema前缀

> ⚠️ @TableId(type=ASSIGN_ID)雪花算法主键，勿用AUTO_INCREMENT

> ⚠️ @TableLogic逻辑删除字段(is_deleted)勿遗漏，且类型为Integer

> ⚠️ @TableField的列名映射(驼峰→下划线)勿遗漏任何字段

> ⚠️ 继承BaseEntity(含tenant_id/create_time等公共字段)，勿重复定义
