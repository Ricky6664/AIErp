### 5.1 ListVO（列表展示）
```java
@Data
public class ProdWorkOrderListVO {
    private Long id;
    private String prodNo;
    private String prodName;
    private Integer status;
    private String statusName;  // 字典翻译：状态名称
    @JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss")
    private LocalDateTime createTime;
    private String creatorName;  // 创建人姓名
}
```

### 5.2 DetailVO（详情展示）
```java
@Data
public class ProdWorkOrderDetailVO extends ProdWorkOrderListVO {
    private String remark;
    private Integer version;
    private List<ProdWorkOrderDetailVO> details;  // 明细行列表
    @JsonFormat(pattern = "yyyy-MM-dd")
    private LocalDate bizDate;
}
```

## 八、易错警示

> ⚠️ @JsonFormat的pattern格式与服务端统一(yyyy-MM-dd HH:mm:ss)

> ⚠️ 字典翻译字段(如statusName)命名规范：原字段名+Name/Label

> ⚠️ 金额字段使用BigDecimal，勿用double/float

> ⚠️ ListVO仅包含列表展示字段，避免返回过多数据
