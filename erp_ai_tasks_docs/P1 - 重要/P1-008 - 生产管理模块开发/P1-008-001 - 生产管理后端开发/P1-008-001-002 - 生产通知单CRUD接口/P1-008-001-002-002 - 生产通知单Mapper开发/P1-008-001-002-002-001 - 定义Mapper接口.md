### 5.1 Mapper接口定义
```java
@Mapper
public interface ProdWorkOrderMapper extends BaseMapper<ProdWorkOrderEntity> {
    /**
     * 分页查询ProdWorkOrder列表（含关联数据）
     */
    Page<ProdWorkOrderListVO> selectPageList(
        @Param("page") Page<?> page,
        @Param("query") ProdWorkOrderQueryDTO query
    );

    /**
     * 查询ProdWorkOrder详情（含明细行）
     */
    ProdWorkOrderDetailVO selectDetailById(@Param("id") Long id);
}
```

## 八、易错警示

> ⚠️ 继承BaseMapper<Entity>，泛型参数勿写错

> ⚠️ @Mapper注解必须添加，否则Spring无法扫描

> ⚠️ 方法参数使用@Param注解指定名称，多参数时必须添加

> ⚠️ 分页查询第一个参数必须是Page<?>
