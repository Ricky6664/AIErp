### 5.1 Mapper XML结构
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN" "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.erp.prod.mapper.ProdWorkOrderMapper">
    <resultMap id="BaseResultMap" type="com.erp.prod.entity.ProdWorkOrderEntity">
        <id column="id" property="id"/>
        <result column="prod_no" property="prodNo"/>
        <result column="status" property="status"/>
    </resultMap>

    <sql id="Base_Column_List">
        id, prod_no, prod_name, status, remark, tenant_id, is_deleted, create_time
    </sql>

    <select id="selectPageList" resultType="com.erp.prod.vo.ProdWorkOrderListVO">
        SELECT t.*, d.dict_label AS status_name
        FROM prod_notice t
        LEFT JOIN sys_dict_data d ON d.dict_value = t.status AND d.dict_type = 'audit_status'
        WHERE t.is_deleted = 0
        <if test="query.prodNo != null and query.prodNo != ''">
            AND t.prod_no LIKE CONCAT('%', #{query.prodNo}, '%')
        </if>
        <if test="query.status != null">
            AND t.status = #{query.status}
        </if>
        ORDER BY t.create_time DESC
    </select>
</mapper>
```

## 八、易错警示

> ⚠️ namespace必须与Mapper接口全限定名完全一致

> ⚠️ 动态SQL中<if>标签test属性使用OGNL表达式，注意null判断

> ⚠️ LIKE查询使用CONCAT('%', #{param}, '%')，勿用字符串拼接(防SQL注入)

> ⚠️ resultMap中column名与数据库一致，property名与Java属性一致

> ⚠️ 多租户tenant_id条件由拦截器自动添加，XML中勿手动添加
