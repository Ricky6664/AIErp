# P1-008 生产管理模块开发 - 模块开发指南

## 一、模块概述

- **模块定位**：生产全链路业务管理，覆盖生产通知→MRP运算→领料→入库→工序移交→进度查询→统计，是系统生产业务的核心模块
- **前置依赖**：P0-001~P0-005（后端框架+前端框架+数据库+权限+公共组件）、P0-007（商品含BOM/工序）、P0-008（客户）、P0-010（仓库）、P1-007（库存引擎）
- **被依赖方**：P1-007（库存管理——生产领料/退料/入库/退库触发库存变动）、P1-015（成本核算——生产成本核算）
- **开发阶段**：阶段七（业务层）

### 4.1 prod_notice（生产通知单主表）— 主表

**通用必含字段**：同BaseEntity（10个，id/tenant_id/created_at/updated_at/created_by/updated_by/is_deleted/owner_dept_id/owner_id/version）

**业务字段**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 | 说明 |
|--------|---------|------|--------|---------|------|
| order_no | varchar(50) | NOT NULL | 编码引擎自动生成 | 生产通知单号 | 同租户唯一 |
| order_date | date | NOT NULL | 当前日期 | 单据日期 | 必填 |
| source_order_id | bigint | - | - | 来源销售订单ID | 关联sale_order.id，可追溯来源 |
| mrp_result_id | bigint | - | - | MRP运算结果ID | 关联prod_mrp_result.id，MRP下推时回填 |
| notice_date | date | NOT NULL | 当前日期 | 通知日期 | 必填 |
| plan_start_date | date | NOT NULL | - | 计划开始日期 | 必填 |
| plan_end_date | date | NOT NULL | - | 计划结束日期 | 必填，>= plan_start_date |

## 五、模块级专属约束

1. **BOM自动展开**：生产通知单明细选择产品后，系统根据BOM（来自P0-007商品管理）自动递归展开子件，展示预计用料（BOM子件用量×生产数量），支持多级BOM与替代料展示。
2. **MRP运算引擎**：MRP运算包含四个核心步骤——需求分析（销售订单+生产通知需求汇总）、BOM展开（多级递归+用量计算）、库存可用量检查（现有库存+在途+占用→净需求）、计划订单建议（净需求→采购建议/生产建议/委外建议）。运算结果按运算批次ID存储，支持"待确认/已确认/已忽略"状态流转。
3. **库存联动**：生产领料单/超领单审核后自动扣减库存，退料单审核后自动增加库存；生产入库单/来料入库单审核后自动增加库存，退库单审核后自动扣减库存。所有库存变动统一调用P1-007库存引擎。
4. **领料BOM用量校验**：生产领料单明细需与BOM标准用量比对，超过标准用量时强制走超领单流程（prod_over_picking），超领原因必填。
5. **序列号管理**：生产领料单明细、生产入库单明细支持序列号子表（doc_detail_serial），出库/入库时需扫描/录入序列号，序列号与明细关联。
6. **工序移交-接收闭环**：工序移交单（prod_process_handover）由移交人发起，接收单（prod_process_accept）由接收人确认，接收时拆分合格数量与不合格数量，不合格数量触发质量处理流程。
7. **生产进度计算**：生产进度查询按通知单维度计算完成率（已生产数量/计划数量）、工序进度、领料进度、入库进度，并对逾期任务做标记。
8. **未生产/未领料/未入库清单**：这三个聚合查询为只读视图，数据来源于明细表数量字段差值（如produced_qty < qty），支持下推快捷操作（未生产→下推生产通知单、未领料→下推领料单、未入库→下推入库单）。
9. **通知变更记录**：生产通知单审核后修改时自动创建变更记录（prod_notice_change），对比变更前后差异，变更原因必填。
10. **多单位换算**：所有明细行支持is_multi_unit多单位模式，conversion_rate存储主/辅单位转换比例，base_qty为换算后基础数量，参与库存与用量计算。
