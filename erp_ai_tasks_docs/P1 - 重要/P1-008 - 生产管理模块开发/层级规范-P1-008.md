## 1. 模块架构约束

### 1.1 模块定位
生产全链路业务管理，覆盖生产通知→MRP运算→领料→入库→工序移交→进度查询→统计，是系统生产业务的核心模块。属于业务层模块（阶段七），是系统中最复杂的业务模块之一，包含MRP运算引擎和多类型单据管理。

### 1.2 依赖关系
- 前置依赖：P0-001~P0-005（基础框架层）、P0-007（商品含BOM/工序）、P0-008（客户）、P0-010（仓库）、P1-007（库存引擎）
- 后续依赖：P1-007（库存管理——生产领料/退料/入库/退库触发库存变动）、P1-015（成本核算——生产成本核算）

### 1.3 技术约束
- 技术栈：Spring Boot + MyBatis-Plus + PostgreSQL；MRP运算引擎需支持大批量数据递归计算
- 性能约束：MRP运算（BOM多级递归展开+库存可用量检查）需优化算法性能；生产进度查询需聚合计算
- 安全约束：BOM展开数据不可手动篡改；领料BOM用量校验严格执行；通知变更记录不可删除

### 2.2 表关系图
- prod_notice 1:N prod_notice_detail：通知单主从结构，明细含BOM展开数据
- prod_notice 1:N prod_notice_change：通知单审核后修改自动创建变更记录
- prod_notice 1:N prod_picking/prod_receipt/prod_process_handover：通知单下推生成各类型单据
- prod_mrp_config → prod_mrp_result：MRP运算配置触发运算生成结果
- prod_mrp_result → prod_notice：MRP结果确认后下推生成生产通知单
- prod_process_handover 1:1 prod_process_accept：移交单与接收单配对

### 2.3 数据流转
1. MRP运算：配置运算参数 → 执行运算（需求分析→BOM展开→库存检查→计划建议）→ 确认结果 → 下推生产通知单
2. 生产通知单创建 → 审核 → BOM自动展开 → 查看未生产/未领料/未入库清单
3. 领料流程：查看未领料清单 → 创建领料单（BOM用量校验）→ 超领走超领单 → 审核 → 库存扣减
4. 退料流程：创建退料单 → 审核 → 库存增加
5. 入库流程：查看未入库清单 → 创建入库单 → 审核 → 库存增加
6. 退库流程：创建退库单 → 审核 → 库存扣减
7. 工序管理：移交单发起 → 接收单确认（合格/不合格拆分）
8. 进度查询：按通知单维度计算完成率/工序进度/领料进度/入库进度

## 3. 业务流程

### 3.1 核心业务流程
1. MRP运算：配置参数 → 执行运算 → 查看结果（采购建议/生产建议/委外建议）→ 确认下推
2. 生产通知：创建/下推通知单 → 审核 → BOM自动展开 → 变更管理
3. 生产领料：未领料清单 → 领料单（BOM校验）→ 超领单（超量时强制）→ 退料单
4. 生产入库：未入库清单 → 入库单 → 退库单；来料入库/退库
5. 工序管理：移交单 → 接收单（合格/不合格拆分）→ 不合格触发质量处理
6. 进度查询：完成率+工序进度+领料进度+入库进度+逾期标记
7. 统计分析：按产品/部门/时间维度汇总

### 3.2 业务规则
- BOM自动展开：选择产品后根据BOM递归展开子件，支持多级BOM与替代料
- MRP运算四步骤：需求分析 → BOM展开 → 库存可用量检查 → 计划订单建议
- 库存联动：领料/超领扣减库存，退料增加库存，入库/来料入库增加库存，退库扣减库存
- 领料BOM用量校验：超过标准用量强制走超领单流程，超领原因必填
- 序列号管理：领料/入库支持序列号扫描/录入
- 工序移交-接收闭环：接收时拆分合格/不合格数量
- 生产进度计算：完成率=已生产数量/计划数量，逾期任务自动标记
- 通知变更后修改自动创建变更记录，变更原因必填
- 多单位换算：conversion_rate 存储转换比例，base_qty 为基础数量

### 3.3 状态流转
生产通知单状态（扩展）：
```
草稿 → 待审核 → 已审核 → 已排产 → 已完成 → 已关闭
                    ↓
                  已驳回 → 草稿（重新编辑）
                  已作废
```
MRP运算结果状态：待确认 → 已确认 / 已忽略

## 5. 开发顺序约束

### 5.1 必须顺序执行的任务
1. **生产管理后端开发（P1-008-001）**必须先完成：
   - 生产通知单CRUD + BOM自动展开
   - MRP运算引擎（需求分析→BOM展开→库存检查→计划建议）
   - 领料单/超领单/退料单CRUD
   - 入库单/退库单/来料入库/来料退库CRUD
   - 工序移交/接收单CRUD
   - 进度查询与统计
2. **生产管理前端页面（P1-008-002）**依赖后端完成

### 5.2 可并行执行的任务

- 领料单与退料单可并行开发

- 工序移交与工序接收可并行开发
