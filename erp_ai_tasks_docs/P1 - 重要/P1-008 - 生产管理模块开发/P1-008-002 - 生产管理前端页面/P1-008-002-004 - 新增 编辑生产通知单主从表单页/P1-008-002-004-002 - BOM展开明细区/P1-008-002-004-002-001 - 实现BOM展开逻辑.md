### 5.1 BOM展开实现
```java
public List<BomExpandResult> expandBom(Long bomId, BigDecimal quantity) {
    List<BomExpandResult> results = new ArrayList<>();
    expandBomRecursive(bomId, quantity, 0, results);
    return results;
}

private void expandBomRecursive(Long bomId, BigDecimal qty, int level, List<BomExpandResult> results) {
    List<BomDetail> details = bomDetailMapper.selectByBomId(bomId);
    for (BomDetail d : details) {
        BigDecimal needQty = qty.multiply(d.getUsageQty());
        results.add(new BomExpandResult(d.getMaterialId(), needQty, level));
        // 递归展开子BOM
        Long subBomId = bomMapper.selectByMaterialId(d.getMaterialId());
        if (subBomId != null) expandBomRecursive(subBomId, needQty, level + 1, results);
    }
}
```
