### 5.1 MRP运算触发
```java
public String triggerMrp(MrpParam param) {
    String taskId = IdUtil.fastSimpleUUID();
    // 异步执行MRP运算
    CompletableFuture.runAsync(() -> {
        try {
            mrpProgress.put(taskId, new Progress(0, "开始运算"));
            List<MrpResult> results = calculateMrp(param);
            mrpResultService.saveBatch(results);
            mrpProgress.put(taskId, new Progress(100, "运算完成"));
        } catch (Exception e) {
            mrpProgress.put(taskId, new Progress(-1, "运算失败：" + e.getMessage()));
        }
    });
    return taskId;
}
```
