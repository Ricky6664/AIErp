# P1-015 成本核算模块开发 - 模块开发指南

## 一、模块概述

- **模块定位**：销售订单/出库/生产/委外成本核算与库存成本调整，为企业提供精确的成本数据支撑
- **前置依赖**：P0-001~P0-005（后端框架+前端框架+数据库+权限+公共组件）、P0-007（商品）、P0-011（财务基础）、P1-005（销售出库）、P1-007（库存成本）、P1-008（生产）、P1-009（委外）
- **被依赖方**：无（成本核算为终端业务模块，无下游依赖）
- **开发阶段**：阶段八（财务层）

## 六、Service层业务逻辑规格

### 6.1 CostSaleOrderService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(CostSaleOrderQueryDTO) | 无(只读) | 按订单明细/商品/期间/状态筛选 |
| calculate(orderDetailId) | @Transactional | 归集材料/人工/制造/委外成本 → 计算总成本 → 毛利=销售金额-总成本 → 毛利率=毛利/销售金额 |

### 6.2 CostSaleOutboundService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(CostSaleOutboundQueryDTO) | 无(只读) | 按出库明细/商品/期间筛选 |
| calculate(outboundDetailId) | @Transactional | 按inv.cost_method参数(移动加权/FIFO/手工指定)计算出库成本 → 写入成本核算表 |

### 6.3 CostProductionService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(CostProductionQueryDTO) | 无(只读) | 按生产通知/商品/期间筛选 |
| calculate(noticeDetailId) | @Transactional | 归集直接材料(领料单) + 直接人工(工资分摊) + 制造费用(按工时/产量/金额比例分摊) → 计算总成本和单位成本 |

### 6.4 CostOutsourceService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(CostOutsourceQueryDTO) | 无(只读) | 按委外通知/商品/期间筛选 |
| calculate(noticeDetailId) | @Transactional | 归集发料成本(委外领料单) + 加工费(委外入库单) → 计算总成本和单位成本 |

### 6.5 CostInventoryAdjustService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(CostAdjustQueryDTO) | 无(只读) | 按仓库/日期/状态筛选 |
| getById(Long) | 无(只读) | 返回CostAdjustDetailVO |
| create(CostAdjustCreateDTO) | @Transactional | 编码生成 → save主从 → 审核时自动调整库存成本 → 生成调整凭证(联动P1-012) |
| update(id, CostAdjustUpdateDTO) | @Transactional | 存在性校验 → 已审核禁止修改 → 乐观锁更新 |
| delete(Long) | @Transactional | 存在性校验 → 已审核禁止删除 → 逻辑删除 |

### 6.6 CostWorkbenchService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| getWorkbenchData() | 无(只读) | 聚合查询：本月销售成本/生产成本/委外成本汇总 + 成本趋势 + 毛利概览 + 成本异常预警(毛利率偏低/单位成本大幅波动) |
