## 五、详细开发规格
> **本任务模块上下文**
> - 涉及数据表：cost_order(成本核算单), cost_order_detail(核算明细), cost_allocation(成本分摊表), cost_adjustment(成本调整表)
> - 涉及API：/api/cost/order/*, /api/cost/allocation/*, /api/cost/adjustment/*, /api/cost/summary/*

### 5.1 核心功能
1. 联调成本核算工作台所有组件：KPI卡片+图表+列表+快捷入口
2. 组件间通过事件总线或props传递状态
3. 数据源接口统一加载，展示loading状态
4. 路由跳转保持工作台状态

### 5.2 数据交互
1. 工作台聚合接口：GET /api/cost/workbench
2. 各组件按需刷新，不全量重载
3. 使用Vue3 provide/inject共享工作台状态

### 5.3 关键逻辑
1. 首次进入并发加载所有数据源
2. 刷新按钮触发全量重载
3. 组件错误时展示fallback UI
4. 无Hydration错误（SSR兼容）

### 5.4 验证
1. 所有KPI卡片数据正确展示
2. 图表渲染无错位
3. 列表数据与接口一致
4. 路由跳转、返回、刷新均正常
