## 1. 模块架构约束

### 1.1 模块定位
销售订单/出库/生产/委外成本核算与库存成本调整，为企业提供精确的成本数据支撑。属于财务层模块（阶段八），是终端业务模块，无下游依赖，负责归集和计算各业务环节的成本数据。

### 1.2 依赖关系
- 前置依赖：P0-001~P0-005（基础框架层）、P0-007（商品）、P0-011（财务基础）、P1-005（销售出库）、P1-007（库存成本）、P1-008（生产）、P1-009（委外）
- 后续依赖：无（成本核算为终端业务模块，无下游依赖）；成本调整会反向联动P1-012（凭证管理）

### 1.3 技术约束
- 技术栈：Spring Boot + MyBatis-Plus + PostgreSQL；成本计算使用BigDecimal确保精度
- 性能约束：成本核算按会计期间批量执行，大批量数据计算需优化性能；生产成本分摊计算涉及多维度归集
- 安全约束：成本方法必须与P1-007库存引擎保持一致；成本调整后必须生成调整凭证确保账实一致

## 2. 数据模型关系

### 2.1 核心数据表
| 表名 | 说明 | 关键字段 |
|------|------|---------|
| cost_sale_order | 销售订单成本核算表 | 核算单号, 订单明细ID, 商品ID, 数量, 材料/人工/制造/委外成本, 总成本, 销售金额, 毛利, 毛利率 |
| cost_sale_outbound | 销售出库成本核算表 | 核算单号, 出库明细ID, 商品ID, 数量, 单位成本, 总成本 |
| cost_production | 生产成本核算表 | 核算单号, 生产通知明细ID, 商品ID, 数量, 直接材料, 直接人工, 制造费用, 总成本, 单位成本 |
| cost_outsource | 委外成本核算表 | 核算单号, 委外通知明细ID, 商品ID, 数量, 发料成本, 加工费, 总成本, 单位成本 |
| cost_inventory_adjust / _detail | 库存成本调整单主/从表 | 调整单号, 仓库ID, 商品ID, 原单位成本, 调整后单位成本, 差异金额 |

### 2.2 表关系图
- cost_sale_order 通过订单明细ID关联 sale_order_detail（销售订单明细）
- cost_sale_outbound 通过出库明细ID关联 sale_outbound_detail（销售出库明细）
- cost_production 通过生产通知明细ID关联 prod_notice_detail（生产通知明细）
- cost_outsource 通过委外通知明细ID关联 sub_notice_detail（委外通知明细）
- cost_inventory_adjust 1:N cost_inventory_adjust_detail：调整单主从结构
- 成本调整后联动P1-012凭证管理生成调整凭证

### 2.3 数据流转
1. 销售出库成本核算：执行核算 → 按成本方法（移动加权平均/FIFO/手工指定）计算出库成本 → 写入 cost_sale_outbound
2. 销售订单成本核算：汇总出库成本 → 计算毛利（销售收入-销售成本-税额）→ 写入 cost_sale_order
3. 生产成本核算：归集材料成本（领料单）+ 人工成本 + 制造费用 → 按工时/产量/金额比例分摊 → 写入 cost_production
4. 委外成本核算：归集材料成本（领料单）+ 加工费（入库单）→ 按通知单维度计算 → 写入 cost_outsource
5. 库存成本调整：手工/自动调整 → 计算差异金额 → 生成调整凭证（联动P1-012）

## 3. 业务流程

### 3.1 核心业务流程
1. 销售出库成本核算：选择期间 → 执行核算（按inv.cost_method计算出库成本）→ 查看结果
2. 销售订单成本核算：按订单维度汇总出库成本 → 计算毛利和毛利率 → 查看结果
3. 生产成本核算：归集直接材料+直接人工+制造费用 → 分摊计算 → 查看结果
4. 委外成本核算：归集发料成本+加工费 → 计算单位成本 → 查看结果
5. 库存成本调整：手工调整/系统自动调整 → 计算差异 → 生成调整凭证
6. 成本异常预警：成本波动超阈值自动标记预警

### 3.2 业务规则
- 成本方法统一：销售出库成本方法由 inv.cost_method 参数控制，与P1-007库存引擎保持一致
- 生产成本归集：材料成本（生产领料单）+ 人工成本（工资分摊）+ 制造费用（间接费用分摊）
- 生产成本分摊：支持按工时/产量/金额比例分摊
- 委外成本归集：材料成本（委外领料单）+ 加工费（委外入库单）
- 毛利计算：毛利=销售收入-销售成本-税额；毛利率=毛利/销售收入×100%
- 库存成本调整：支持手工和系统自动两种方式，调整后自动生成调整凭证
- 核算期间：按会计期间（月度）执行，结果存储到成本核算表
- 成本异常预警：毛利率异常偏低/单位成本大幅波动时自动标记

### 3.3 状态流转
成本核算状态：待核算 → 已核算
库存成本调整单状态（P1-001管理）：草稿(0) → 已审核(2)（审核后生成调整凭证）

## 5. 开发顺序约束

### 5.1 必须顺序执行的任务
1. **成本核算后端开发（P1-015-001）**必须先完成：
   - 销售出库成本核算服务（按成本方法计算）
   - 销售订单成本核算服务（汇总+毛利计算）
   - 生产成本核算服务（归集+分摊）
   - 委外成本核算服务（归集+计算）
   - 库存成本调整服务（调整+凭证生成联动）
   - 成本异常预警
   - 成本核算工作台
2. **成本核算前端页面（P1-015-002）**依赖后端完成

### 5.2 可并行执行的任务
- 销售出库成本核算与销售订单成本核算可并行开发
- 生产成本核算与委外成本核算可并行开发
- 库存成本调整与成本异常预警可并行开发
- 各成本核算导出功能可并行开发
- 前端各页面可在对应后端API完成后并行开发
