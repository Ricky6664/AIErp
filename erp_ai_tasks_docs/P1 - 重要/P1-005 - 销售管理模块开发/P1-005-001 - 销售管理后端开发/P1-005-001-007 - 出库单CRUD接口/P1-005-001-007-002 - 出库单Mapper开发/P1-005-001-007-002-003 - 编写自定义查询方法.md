### 5.1 自定义查询方法
```java
// Mapper接口中声明
List<SaleQuotationListVO> selectByCondition(@Param("query") SaleQuotationQueryDTO query);
Long countByStatus(@Param("status") Integer status);
List<Map<String, Object>> selectStatistics(@Param("startDate") LocalDate startDate, @Param("endDate") LocalDate endDate);
```

### 5.2 对应XML SQL
```xml
<select id="selectStatistics" resultType="java.util.Map">
    SELECT DATE(create_time) AS biz_date, COUNT(*) AS total, 
           SUM(CASE WHEN status = 2 THEN 1 ELSE 0 END) AS approved_count
    FROM sale_quotation
    WHERE is_deleted = 0 AND create_time BETWEEN #{startDate} AND #{endDate}
    GROUP BY DATE(create_time)
    ORDER BY biz_date
</select>
```
