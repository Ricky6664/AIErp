### 5.1 流转校验规则
```java
public void validateFlow(Long sourceDocId, String targetDocType) {
    // 1. 上游单据必须已审核
    Integer status = getSourceStatus(sourceDocId);
    if (status != 2) throw new BusinessException("上游单据未审核，无法下推");
    // 2. 关联数据完整性
    if (hasIncompleteRelations(sourceDocId))
        throw new BusinessException("上游单据关联数据不完整");
    // 3. 已执行数量校验
    BigDecimal remainQty = getRemainQty(sourceDocId);
    if (remainQty.compareTo(BigDecimal.ZERO) <= 0)
        throw new BusinessException("上游单据已全部执行完毕");
}
```
