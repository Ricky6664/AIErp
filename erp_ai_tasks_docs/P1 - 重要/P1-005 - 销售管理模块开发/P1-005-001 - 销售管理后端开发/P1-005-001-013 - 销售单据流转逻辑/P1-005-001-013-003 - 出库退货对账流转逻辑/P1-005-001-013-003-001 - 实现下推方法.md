### 5.1 下推方法实现
```java
@Transactional(rollbackFor = Exception.class)
public Long pushDown(Long sourceDocId, String targetDocType) {
    // 1. 流转校验
    validateFlow(sourceDocId, targetDocType);
    // 2. 查询上游单据+明细
    SourceDoc source = getSourceDoc(sourceDocId);
    // 3. 数据映射到下游单据
    TargetDoc target = mapToTarget(source, targetDocType);
    // 4. 扣减已执行数量
    deductExecutedQty(sourceDocId, target.getDetails());
    // 5. 保存下游单据
    return saveTargetDoc(target);
}
```
