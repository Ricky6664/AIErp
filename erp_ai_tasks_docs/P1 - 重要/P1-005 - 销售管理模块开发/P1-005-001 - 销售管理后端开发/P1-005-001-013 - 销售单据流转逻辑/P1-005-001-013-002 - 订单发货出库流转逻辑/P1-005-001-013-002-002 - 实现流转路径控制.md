### 5.1 流转路径控制逻辑
```java
public void validateFlowPath(String sourceDocType, String targetDocType) {
    // 1. 读取系统参数获取流转路径配置
    String flowPath = sysParamService.getValue("sale.order_flow_path");
    if (StrUtil.isBlank(flowPath)) {
        throw new BusinessException("流转路径未配置，请联系管理员");
    }
    // 2. 校验目标单据类型是否在流转路径中
    List<String> allowedTargets = parseFlowPath(flowPath, sourceDocType);
    boolean forceFlow = sysParamService.getBoolean("sale.force_flow", false);
    if (forceFlow && !allowedTargets.contains(targetDocType)) {
        throw new BusinessException("不允许跳过流转环节");
    }
}
```
