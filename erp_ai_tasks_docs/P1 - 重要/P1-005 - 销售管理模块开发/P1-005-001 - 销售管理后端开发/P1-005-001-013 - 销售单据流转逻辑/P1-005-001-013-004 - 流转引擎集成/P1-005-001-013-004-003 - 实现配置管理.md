### 5.1 配置管理实现
```java
@Service
public class SaleQuotationConfigService {
    @Autowired
    private SysParamService sysParamService;

    public SaleQuotationConfig getConfig() {
        return SaleQuotationConfig.builder()
            .flowPath(sysParamService.getValue("sale.order_flow_path"))
            .forceFlow(sysParamService.getBoolean("sale.force_flow", false))
            .autoConfirm(sysParamService.getBoolean("sale.auto_confirm", false))
            .build();
    }

    public void updateConfig(SaleQuotationConfig config) {
        sysParamService.setValue("sale.order_flow_path", config.getFlowPath());
        sysParamService.setValue("sale.force_flow", config.getForceFlow().toString());
    }
}
```
