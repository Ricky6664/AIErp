### 5.1 Mapper接口定义
```java
@Mapper
public interface SaleQuotationMapper extends BaseMapper<SaleQuotationEntity> {
    /**
     * 分页查询SaleQuotation列表（含关联数据）
     */
    Page<SaleQuotationListVO> selectPageList(
        @Param("page") Page<?> page,
        @Param("query") SaleQuotationQueryDTO query
    );

    /**
     * 查询SaleQuotation详情（含明细行）
     */
    SaleQuotationDetailVO selectDetailById(@Param("id") Long id);
}
```

## 八、易错警示

> ⚠️ 继承BaseMapper<Entity>，泛型参数勿写错

> ⚠️ @Mapper注解必须添加，否则Spring无法扫描

> ⚠️ 方法参数使用@Param注解指定名称，多参数时必须添加

> ⚠️ 分页查询第一个参数必须是Page<?>
