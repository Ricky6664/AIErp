### 5.1 数据加载逻辑
```typescript
const loading = ref(false)
const tableData = ref([])
const pagination = reactive({ pageNum: 1, pageSize: 10, total: 0 })

const loadData = async () => {
  loading.value = true
  try {
    const res = await api.getSaleQuotationPage({ ...searchForm, ...pagination })
    tableData.value = res.data.records
    pagination.total = res.data.total
  } finally {
    loading.value = false
  }
}
```

### 5.2 分页事件
- 页码变更(current-change)：更新pageNum，重新加载
- 每页条数变更(size-change)：更新pageSize，重置pageNum=1，重新加载
