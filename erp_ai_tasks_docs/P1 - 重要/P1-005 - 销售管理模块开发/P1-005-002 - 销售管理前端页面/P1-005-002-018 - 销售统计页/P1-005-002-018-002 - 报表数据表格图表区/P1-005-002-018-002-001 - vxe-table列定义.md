### 5.1 列定义配置
```typescript
const columns: VxeTablePropTypes.Columns = [
  { type: 'selection', width: 50, fixed: 'left' },
  { field: 'saleNo', title: '编号', width: 150, sortable: true },
  { field: 'saleName', title: '名称', minWidth: 200 },
  { field: 'status', title: '状态', width: 100, slots: { default: 'status_slot' } },
  { field: 'createTime', title: '创建时间', width: 180, formatter: formatDate },
  { field: 'action', title: '操作', width: 200, fixed: 'right', slots: { default: 'action_slot' } }
]
```

### 5.2 自定义渲染插槽
- status_slot: 使用el-tag渲染状态标签(颜色映射：0灰/1橙/2绿/3红/4浅灰)
- action_slot: 操作按钮(查看/编辑/删除/审核)

## 八、易错警示

> ⚠️ 大数据量(>1000行)使用vxe-table虚拟滚动(scroll-y)

> ⚠️ fixed: 'left'/'right'固定列不宜过多(建议≤3列)

> ⚠️ minWidth和width区分使用：固定内容用width，弹性内容用minWidth

> ⚠️ 自定义插槽名称与template #slot_name一致
