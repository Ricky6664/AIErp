# P1-011 应付管理模块开发 - 模块开发指南

## 一、模块概述

- **模块定位**：应付全链路管理，覆盖应付款→应付票→付款→核销→发票→账龄分析，是系统财务应付业务的核心模块
- **前置依赖**：P0-001~P0-005（后端框架+前端框架+数据库+权限+公共组件）、P0-009（供应商）、P0-011（财务基础）、P1-001（审核引擎）、P1-004（流转引擎）、P1-006（采购入库/对账）、P1-009（委外）
- **被依赖方**：P1-012（凭证管理——应付单/付款单生成凭证）
- **开发阶段**：阶段八（财务层）
