# P1-009 委外管理模块开发 - 模块开发指南

## 一、模块概述

- **模块定位**：委外全链路业务管理，覆盖委外通知→领退料→入库退库→工序移交接收→统计，是系统委外业务的核心模块
- **前置依赖**：P0-001~P0-005（后端框架+前端框架+数据库+权限+公共组件）、P0-007（商品含BOM）、P0-009（供应商）、P0-010（仓库）、P1-001（审核引擎）、P1-004（流转引擎）、P1-007（库存引擎）
- **被依赖方**：P1-011（应付管理——委外产生应付款）、P1-015（成本核算——委外成本）
- **开发阶段**：阶段七（业务层）

| totalQty | BigDecimal | @JsonFormat(pattern="#,##0.000000") | 总数量 |
| totalProcessAmount | BigDecimal | @JsonFormat(pattern="#,##0.00") | 加工费合计 |
| status | String | - | 状态 |

**OverPickingCreateDTO**：noticeId + warehouseId + pickingDate + overReason + details(List<OverPickingDetailDTO>)
**ReturnCreateDTO**：noticeId + warehouseId + returnDate + details(List<ReturnDetailDTO>)

**PickingListVO**：id + orderNo + noticeNo + warehouseName + pickingDate + status + createdAt
**OverPickingListVO**：id + orderNo + noticeNo + warehouseName + pickingDate + overReason + status
**ReturnListVO**：id + orderNo + noticeNo + warehouseName + returnDate + status
