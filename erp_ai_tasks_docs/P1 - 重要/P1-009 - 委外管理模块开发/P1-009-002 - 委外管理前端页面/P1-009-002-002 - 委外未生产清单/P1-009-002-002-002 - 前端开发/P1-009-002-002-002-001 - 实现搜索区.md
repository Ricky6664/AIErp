## 五、详细开发规格
> **本任务模块上下文**
> - 涉及数据表：outsource_order(委外订单), outsource_order_detail(订单明细), outsource_receive(委外收货单), outsource_settle(委外结算单)
> - 涉及API：/api/outsource/order/*, /api/outsource/receive/*, /api/outsource/settle/*, /api/outsource/material/*

### 5.1 核心功能
1. 使用el-form构建委外管理搜索表单，包含常用筛选字段（状态/日期范围/关键字）
2. 下拉类字段使用字典组件或远程搜索（供应商/商品/仓库等）
3. 日期范围使用el-date-picker type="daterange"
4. 搜索/重置按钮使用el-button，绑定事件

### 5.2 数据交互
1. 搜索条件序列化为Query对象，传递给列表接口
2. 字典类搜索项通过/sys/dict接口加载
3. 日期范围返回startDate/endDate两个参数

### 5.3 关键逻辑
1. 搜索条件变化后防抖300ms避免频繁请求
2. 重置按钮清空条件并刷新列表（调父组件refresh方法）
3. 支持回车键触发搜索（@keyup.enter）
4. 搜索条件展开/收起（高级搜索）

### 5.4 验证
1. 各搜索条件过滤结果准确
2. 多条件组合搜索结果正确
3. 重置后列表恢复全量数据
4. 搜索交互流畅无卡顿
