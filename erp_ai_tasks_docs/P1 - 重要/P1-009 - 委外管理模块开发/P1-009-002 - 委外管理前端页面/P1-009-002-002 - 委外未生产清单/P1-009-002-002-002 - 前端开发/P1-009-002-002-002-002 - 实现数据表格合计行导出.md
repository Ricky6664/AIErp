## 五、详细开发规格
> **本任务模块上下文**
> - 涉及数据表：outsource_order(委外订单), outsource_order_detail(订单明细), outsource_receive(委外收货单), outsource_settle(委外结算单)
> - 涉及API：/api/outsource/order/*, /api/outsource/receive/*, /api/outsource/settle/*, /api/outsource/material/*

### 5.1 核心功能
1. 使用el-table的summary-method属性展示合计行
2. 合计行包含：数量合计、金额合计、其他数值字段合计
3. 导出按钮调用xlsx库生成Excel，包含合计行
4. 导出列宽自适应、数字格式保留小数位

### 5.2 数据交互
1. 合计行数据由后端返回（避免前端计算误差）
2. 导出接口：GET /api/subcontract/export，返回文件流
3. 文件下载使用Blob + URL.createObjectURL

### 5.3 关键逻辑
1. 合计行使用fixed="bottom"固定显示
2. 导出时包含当前筛选条件（导出过滤后的数据）
3. 数值字段保留指定小数位（金额4位，数量6位）
4. 大数据量导出（≥1万行）使用异步任务

### 5.4 验证
1. 合计行数据正确（与后端返回一致）
2. 导出Excel打开无报错
3. 数值精度无丢失
4. 大数据量导出不卡死页面
