## 五、详细开发规格
> **本任务模块上下文**
> - 涉及数据表：outsource_order(委外订单), outsource_order_detail(订单明细), outsource_receive(委外收货单), outsource_settle(委外结算单)
> - 涉及API：/api/outsource/order/*, /api/outsource/receive/*, /api/outsource/settle/*, /api/outsource/material/*

### 5.1 核心功能
1. 按委外管理业务需求编写对应Mapper SQL
2. 关联查询使用LEFT JOIN并处理NULL（COALESCE）
3. 分页使用MyBatis-Plus Page或RowBounds

### 5.2 数据交互
1. Mapper接口入参：QueryDTO或@Param多参数
2. 返回值：Entity/List<Entity>/Page<Entity>/自定义VO
3. 复杂SQL使用XML映射文件（/mapper/subcontract/）

### 5.3 关键逻辑
1. SQL遵循PostgreSQL 15语法规范
2. WHERE条件必含tenant_id = #{tenantId} AND is_deleted = false
3. 排序字段使用索引字段，避免filesort
4. 批量操作使用saveBatch/updateBatch（批次大小500）

### 5.4 验证
1. SQL执行结果与预期一致
2. EXPLAIN ANALYZE确认查询计划合理
3. 大数据量场景（≥10万行）响应≤1s
4. 边界条件（空数据/NULL/特殊字符）不报错
