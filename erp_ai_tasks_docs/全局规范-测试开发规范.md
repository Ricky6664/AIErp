### 2.2 Service层单元测试

```java
@ExtendWith(MockitoExtension.class)
class SaleOrderServiceTest {

    @InjectMocks
    private SaleOrderServiceImpl saleOrderService;

    @Mock
    private SaleOrderMapper saleOrderMapper;

    @Mock
    private SaleOrderDetailMapper detailMapper;

    @Mock
    private CodeGeneratorService codeGeneratorService;

    // ===== given/when/then三段式 =====

    @Test
    @DisplayName("创建销售订单 - 正常流程 - 返回订单ID")
    void should_createOrderSuccessfully_when_validInput() {
        // given — 准备测试数据和Mock行为
        SaleOrderCreateDTO dto = TestDataFactory.buildSaleOrderCreateDTO();
        when(codeGeneratorService.generate("SALE_ORDER")).thenReturn("SO-2025-0001");
        when(saleOrderMapper.insert(any(SaleOrder.class))).thenReturn(1);
        when(detailMapper.insert(any(SaleOrderDetail.class))).thenReturn(1);

        // when — 执行被测方法
        Long orderId = saleOrderService.createOrder(dto);

        // then — 断言结果和交互
        assertThat(orderId).isNotNull();
        verify(saleOrderMapper).insert(argThat(order -> {
            assertThat(order.getOrderNo()).isEqualTo("SO-2025-0001");
            assertThat(order.getStatus()).isEqualTo("DRAFT");
            return true;
        }));
        verify(detailMapper, times(dto.getDetails().size())).insert(any());
    }

    @Test
    @DisplayName("创建销售订单 - 客户不存在 - 抛出异常")
    void should_throwException_when_customerNotFound() {
        // given
        SaleOrderCreateDTO dto = TestDataFactory.buildSaleOrderCreateDTO();
        dto.setCustomerId(999L);
        when(customerMapper.selectById(999L)).thenReturn(null);

        // when & then
        assertThatThrownBy(() -> saleOrderService.createOrder(dto))
            .isInstanceOf(BusinessException.class)
            .hasMessageContaining("客户不存在");
    }

    @Test
    @DisplayName("审核销售订单 - 库存不足 - 抛出异常")
    void should_throwException_when_insufficientStock() {
        // given
        SaleOrder order = TestDataFactory.buildSaleOrder();
        order.setStatus("DRAFT");
        when(saleOrderMapper.selectById(order.getId())).thenReturn(order);
        when(stockService.checkAvailable(anyLong(), any())).thenReturn(false);

        // when & then
        assertThatThrownBy(() -> saleOrderService.audit(order.getId()))
            .isInstanceOf(BusinessException.class)
            .hasMessageContaining("库存不足");
    }
}
```

## 3. 后端Mock策略

### 3.1 Service层Mock策略

- **Mock外部依赖**：Service层Mock所有外部依赖（其他Service、第三方API、消息队列等）
- **不Mock数据库**：Service单元测试中Mock Mapper，集成测试中使用真实数据库
- **Mock原则**：只Mock直接依赖，不Mock被测类自身的方法

```java
@ExtendWith(MockitoExtension.class)
class SaleOrderServiceTest {

    @InjectMocks
    private SaleOrderServiceImpl saleOrderService;

    // Mock直接依赖
    @Mock private SaleOrderMapper saleOrderMapper;
    @Mock private StockService stockService;          // 库存服务
    @Mock private CodeGeneratorService codeService;   // 编码服务
    @Mock private MessageService messageService;      // 消息服务
    @Mock private RedisTemplate<String, Object> redisTemplate;  // Redis

    // 不Mock的：SaleOrderService自身的方法
}
```

### 3.2 Controller层Mock策略

- **Mock Service**：Controller层Mock所有Service层依赖，仅测试参数校验和路由分发
- **MockBean注解**：使用`@MockBean`替代Spring容器中的真实Bean

```java
@WebMvcTest(SaleOrderController.class)
class SaleOrderControllerTest {

    @MockBean
    private SaleOrderService saleOrderService;  // Mock Service

    @MockBean
    private PermissionService permissionService; // Mock权限服务
}
```

### 3.3 Mock数据规范

- **使用TestDataFactory**：Mock返回数据统一通过TestDataFactory构造，保证数据结构完整
- **边界场景覆盖**：每个Mock场景至少覆盖正常值、空值、边界值
- **异常Mock**：使用`when(...).thenThrow(...)`模拟异常场景

```java
// 正常场景
when(saleOrderMapper.selectById(1L)).thenReturn(TestDataFactory.buildSaleOrder());

// 空值场景
when(saleOrderMapper.selectById(999L)).thenReturn(null);

// 异常场景
when(saleOrderMapper.insert(any())).thenThrow(new DuplicateKeyException("编码重复"));
```

## 6. 测试覆盖率要求

### 6.1 覆盖率目标

| 层级 | 行覆盖率 | 分支覆盖率 | 说明 |

### 7.5 并发安全测试

```java
@Test
@DisplayName("编码生成 - 多线程并发 - 不产生重复编码")
void should_generateUniqueCodes_when_concurrentRequests() throws Exception {
    int threadCount = 50;
    ExecutorService executor = Executors.newFixedThreadPool(threadCount);
    List<Future<String>> futures = new ArrayList<>();

    for (int i = 0; i < threadCount; i++) {
        futures.add(executor.submit(() ->
            codeGeneratorService.generate("SALE_ORDER")
        ));
    }

    Set<String> codes = new HashSet<>();
    for (Future<String> future : futures) {
        String code = future.get(10, TimeUnit.SECONDS);
        assertThat(codes.add(code))
            .as("编码不应重复: " + code)
            .isTrue();
    }

    assertThat(codes).hasSize(threadCount);
    executor.shutdown();
}
```
