# P0-010 仓库与库位管理开发 - 模块开发指南

## 一、模块概述

- **模块定位**：仓库定义 + 库位管理，为库存及所有出入库业务提供基础数据支撑
- **前置依赖**：P0-001（后端框架）、P0-002（前端框架）、P0-003（数据库）、P0-004（认证与权限）、P0-005（公共组件）、P0-006（组织架构提供部门/员工数据）、P0-007（商品管理提供商品数据）
- **被依赖方**：P1-007（库存管理）、P1-005（销售管理-出库）、P1-006（采购管理-入库）、P1-008（生产入库/领料）、P1-009（委外收发）
- **开发阶段**：阶段五（基础数据）

### 模块级专属约束

1. **仓库编码唯一性**：仓库编码在系统内全局唯一，编码生成需在事务内完成，禁止并发重复。
2. **库位编码唯一性**：库位编码在同一仓库内唯一，新增/修改时需进行仓库范围内唯一性校验。
3. **仓库删除关联校验**：删除仓库前需校验该仓库下是否存在库位、库存、在途单据，存在时禁止删除并返回关联数据清单。
4. **库位删除关联校验**：删除库位前需校验该库位是否存在库存记录，存在时禁止删除。
5. **工作台聚合性能**：工作台聚合查询（仓库总数/库位总数/库存预警数/出入库汇总）需使用@Cacheable缓存策略，缓存TTL=5min，缓存命中率≥90%。
6. **仓库利用率计算**：仓库利用率 = 已用库位数 / 总库位数 × 100%，保留2位小数，当总库位数为0时返回0%。
