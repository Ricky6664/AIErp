### 5.1 聚合指标
- KPI卡片数据：模块核心统计指标（总数/启用数/异常预警数/业务关键统计）
- 图表趋势数据：按时间维度(日/周/月)分组统计

### 5.2 SQL结构
```sql
-- KPI聚合查询
SELECT
    COUNT(*) AS total_count,
    COUNT(CASE WHEN status = 1 THEN 1 END) AS active_count
    -- 其他KPI指标
FROM inv_warehouse, inv_location
WHERE tenant_id = :tenantId AND is_deleted = false;

-- 趋势查询
SELECT DATE_TRUNC('day', created_time) AS period, COUNT(*) AS count
FROM inv_warehouse, inv_location
WHERE tenant_id = :tenantId AND is_deleted = false
    AND created_time BETWEEN :startDate AND :endDate
GROUP BY period ORDER BY period;
```

### 5.3 数据源
- 使用数据视图(DV_xxx)作为查询数据源
- 多租户隔离：WHERE tenant_id = :tenantId

### 5.4 性能优化
- 关键查询添加复合索引(tenant_id + status + is_deleted)
- 使用@Cacheable缓存策略，TTL=5min
- EXPLAIN分析确认查询走索引

## 八、易错警示

> ⚠️ 聚合SQL必须包含 tenant_id 过滤条件，确保多租户数据隔离

> ⚠️ 大表聚合查询要使用索引，EXPLAIN确认走索引

> ⚠️ 金额字段使用SUM时注意精度，使用COALESCE处理NULL值

> ⚠️ 日期范围查询使用BETWEEN时注意边界值(包含起止日期)

> ⚠️ 避免在WHERE子句中使用函数，防止索引失效
