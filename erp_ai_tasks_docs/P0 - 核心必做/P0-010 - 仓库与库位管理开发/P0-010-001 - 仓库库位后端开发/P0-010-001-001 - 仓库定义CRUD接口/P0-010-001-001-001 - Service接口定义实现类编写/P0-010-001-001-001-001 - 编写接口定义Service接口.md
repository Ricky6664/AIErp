### 5.1 接口定义
- 接口名：IWarehouseService，继承 IServiceX<WarehouseEntity>
- 包路径：com.erp.warehouse.service

### 5.2 方法签名
```java
public interface IWarehouseService extends IServiceX<WarehouseEntity> {
    WarehouseVO create(@Valid WarehouseCreateDTO dto);
    WarehouseVO update(Long id, @Valid WarehouseUpdateDTO dto);
    void delete(Long id);
    WarehouseVO getById(Long id);
    PageResult<WarehouseVO> pageList(WarehouseQueryDTO query);
}
```

### 5.3 入参DTO/返回VO
- CreateDTO字段：warehouseCode(仓库编码-全局唯一), warehouseName(仓库名称), warehouseType(仓库类型:实体/虚拟/委外), address(地址), managerId(仓管员ID), phone(联系电话), status(启用状态)
- UpdateDTO：与CreateDTO相同字段 + @NotNull Long id
- QueryDTO：pageNum, pageSize, 
- VO：warehouseCode(仓库编码-全局唯一), warehouseName(仓库名称), warehouseType(仓库类型:实体/虚拟/委外), address(地址), managerId(仓管员ID), phone(联系电话), status(启用状态) + id + createdTime + updatedTime

### 5.4 注解要求
- 写操作方法(create/update/delete)标注 @Transactional(rollbackFor = Exception.class)
- 接口方法JavaDoc注释完整(@param, @return)

## 八、易错警示

> ⚠️ 事务注解@Transactional仅加在写操作方法(create/update/delete)，读操作不加

> ⚠️ DTO字段校验注解(@NotNull/@NotBlank/@Size)与ServiceImpl校验保持一致

> ⚠️ 接口方法JavaDoc注释必须完整，包含@param和@return说明

> ⚠️ 方法返回类型统一使用VO对象，不直接返回Entity

> ⚠️ 异常统一抛出BusinessException，不要抛原生RuntimeException
