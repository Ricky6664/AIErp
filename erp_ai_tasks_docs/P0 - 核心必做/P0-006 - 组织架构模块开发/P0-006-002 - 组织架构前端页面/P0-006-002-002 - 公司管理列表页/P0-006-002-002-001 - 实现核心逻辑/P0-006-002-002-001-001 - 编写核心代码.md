### 5.1 核心功能
1. 创建CompanyList.vue列表页，采用P04单一列表页类型展示公司数据
2. 搜索栏：公司名称/简称关键字搜索(el-input)、启用状态筛选(el-select:全部/启用/禁用)、搜索/重置按钮
3. 操作栏：新增公司按钮(v-permission="'org:company:add'")、批量删除按钮
4. el-table展示：公司名称/简称/统一社会信用代码/法人/注册资本/地址/联系电话/启用状态/操作列
5. 操作列：编辑(v-permission)、删除(v-permission)、查看详情按钮
6. el-pagination分页组件，默认每页20条

### 5.2 数据交互
**公司列表查询**：`GET /api/org/company?pageNum=1&pageSize=20&keyword=xxx&enabled=true`
```json
{
  "code": 200,
  "data": {
    "records": [{ "id": 1, "companyName": "XX科技有限公司", "shortName": "XX科技", "creditCode": "91110000MA12345678", "legalPerson": "张三", "registeredCapital": "1000万", "address": "北京市海淀区", "phone": "010-12345678", "enabled": true }],
    "total": 3, "pageNum": 1, "pageSize": 20
  }
}
```
**涉及数据表**：org_company

### 5.3 关键逻辑
- **统一社会信用代码校验**：列表中展示完整18位信用代码，新增/编辑时前端校验格式(正则：`^[0-9A-HJ-NP-RTUW-Y]{2}\d{6}[0-9A-HJ-NP-RTUW-Y]{10}$`)
- **状态切换**：使用el-switch组件切换启用/禁用状态，切换时调用PUT接口更新enabled字段
- **删除前校验**：删除公司前检查是否存在关联部门(org_department.company_id)，有则提示"该公司下存在部门，无法删除"
- **注册资本格式化**：金额以"万"为单位显示，如"1000万"；输入时仅允许数字
- **导出功能**：支持导出公司列表为Excel文件，使用xlsx库生成

### 5.4 验证
1. 列表正确展示公司数据，分页功能正常
2. 关键字搜索和状态筛选功能正常
3. 删除有下属部门的公司时提示无法删除
4. 信用代码格式校验正确，非法格式提示错误
5. 状态切换立即生效，列表数据更新

## 八、易错警示

> ⚠️ 操作按钮使用v-permission指令控制权限：新增v-permission="'org:company:add'"、编辑v-permission="'org:company:edit'"、删除v-permission="'org:company:delete'"

> ⚠️ API调用使用useApi composable，不要直接使用axios；列表查询/删除/状态切换统一通过composable封装

> ⚠️ 国际化使用$t()函数，表格列标题、按钮文本、提示信息均通过i18n key引用，不要硬编码中文

> ⚠️ el-table的删除操作必须二次确认(ElMessageBox.confirm)，避免误操作

> ⚠️ el-pagination的page-size和current-page使用v-model双向绑定，切换页码时重置选中状态(清空checkbox)
