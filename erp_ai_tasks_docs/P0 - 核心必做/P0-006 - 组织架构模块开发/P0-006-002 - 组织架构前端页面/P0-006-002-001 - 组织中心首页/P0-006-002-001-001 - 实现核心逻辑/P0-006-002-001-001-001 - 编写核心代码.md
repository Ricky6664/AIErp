### 5.1 核心功能
1. 创建OrgCenter.vue组织中心首页，采用P02工作台页面类型，展示组织架构图总览
2. 左侧组织树：使用el-tree展示公司→部门的层级树形结构，加载GET /api/org/department/tree
3. 右侧详情区：点击树节点显示对应公司/部门的详情信息(基本信息+下属部门列表+岗位列表)
4. 树节点右键菜单：新增子部门/编辑/删除/查看岗位等快捷操作
5. 搜索过滤：el-input输入关键字实时过滤组织树节点(filter-node-method)
6. 面包屑导航：显示当前选中节点的组织路径(如：XX科技 / 技术中心 / 研发部)

### 5.2 数据交互
**组织树数据**：`GET /api/org/department/tree`
```json
[{
  "id": 1, "name": "XX科技有限公司", "type": "company", "code": "COMP001",
  "children": [{ "id": 10, "name": "技术中心", "type": "business", "children": [
    { "id": 101, "name": "研发部", "type": "business", "children": [] }
  ]}]
}]
```
**节点详情**：`GET /api/org/company/{id}` 或 `GET /api/org/department/{id}`

### 5.3 关键逻辑
- **混合树结构**：组织树顶层节点为公司(org_company)，公司下为部门(org_department)；使用统一的数据结构{id, name, type, code, children}，type区分company/department
- **节点点击加载详情**：监听el-tree的node-click事件，根据node.type分别调用公司详情或部门详情接口；详情区使用v-if切换显示内容
- **树节点过滤**：el-tree的filter-node-method根据输入关键字匹配节点名称，匹配到的节点及其父节点均显示
- **右键菜单**：使用自定义contextmenu组件，右键点击树节点弹出操作菜单，操作完成后刷新树数据
- **面包屑生成**：通过el-tree的getNode方法获取当前节点的路径链，拼接为面包屑数组

### 5.4 验证
1. 组织树正确展示公司→部门的层级结构
2. 点击公司节点右侧显示公司详情，点击部门节点显示部门详情
3. 搜索过滤正确高亮匹配节点，未匹配节点折叠
4. 右键菜单操作(新增/编辑/删除)功能正常
5. 面包屑正确显示当前节点的组织路径

## 八、易错警示

> ⚠️ 操作按钮使用v-permission指令控制权限，右键菜单中的编辑/删除操作也需权限控制

> ⚠️ API调用使用useApi composable，el-tree的load数据使用async/await处理，注意catch错误

> ⚠️ 国际化使用$t()函数，树节点文本和右键菜单文本通过i18n key引用

> ⚠️ el-tree的filter-node-method回调函数必须是纯函数，不要在内部修改响应式数据

> ⚠️ 右键菜单(contextmenu)组件需要监听全局click事件来关闭，组件卸载时移除事件监听避免内存泄漏
