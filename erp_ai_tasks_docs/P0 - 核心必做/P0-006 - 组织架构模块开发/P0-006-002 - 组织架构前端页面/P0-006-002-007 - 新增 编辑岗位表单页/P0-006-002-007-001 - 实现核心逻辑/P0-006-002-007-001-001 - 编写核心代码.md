### 5.1 核心功能
1. 创建PositionForm.vue表单弹窗页，使用el-dialog(中尺寸width:560px)展示岗位表单
2. 表单字段：所属部门(el-tree-select必填)、岗位名称(必填)、岗位编码(必填/编辑只读)、岗位级别(el-select:P1-P10/M1-M5)、岗位类型(el-select:管理/技术/操作)、排序号(el-input-number)、启用状态(el-switch)
3. 表单校验：岗位名称2-50字符必填、岗位编码2-30字符(大写字母+数字+下划线)必填
4. 编辑模式：调用GET /api/org/position/{id}回填表单，岗位编码只读
5. 保存逻辑：新增POST /api/org/position，编辑PUT /api/org/position/{id}

### 5.2 数据交互
**新增岗位请求**：`POST /api/org/position`
```json
{ "departmentId": 101, "positionName": "高级开发工程师", "positionCode": "SENIOR_DEV", "positionLevel": "P7", "positionType": "tech", "sortOrder": 1, "enabled": true }
```
**组件Props/Events**：
- Props: visible(boolean), positionId(number), defaultDepartmentId(number)
- Emits: update:visible, success

### 5.3 关键逻辑
- **岗位编码唯一性**：同一部门内岗位编码不可重复，后端校验department_id+position_code组合唯一性
- **岗位编码格式校验**：正则`^[A-Z][A-Z0-9_]{1,29}$`，必须大写字母开头
- **部门树形下拉**：el-tree-select展示公司→部门树，仅可选择部门节点(不可选公司节点)
- **岗位级别联动**：管理类型岗位显示M1-M5级别选项，技术类型显示P1-P10选项，操作类型显示O1-O5选项
- **排序号默认值**：新增时排序号默认为同部门下最大排序号+1

### 5.4 验证
1. 新增岗位表单校验正确，必填项为空时提示错误
2. 岗位编码格式非法(小写/特殊字符)时提示格式要求
3. 同一部门内岗位编码重复时返回错误
4. 岗位类型切换后岗位级别选项联动更新
5. 编辑模式正确回填数据，编码只读

## 八、易错警示

> ⚠️ API调用使用useApi composable，部门树数据加载使用async/await处理

> ⚠️ 国际化使用$t()函数，表单label、岗位级别选项、岗位类型选项通过i18n key引用

> ⚠️ 岗位类型切换时必须清空并重新加载岗位级别选项，避免数据不一致(management→M1-M5, technical→P1-P10, operation→O1-O5)

> ⚠️ 编辑模式下岗位编码只读(disabled=true)，不要通过CSS隐藏disabled状态导致用户困惑

> ⚠️ el-dialog关闭时必须resetFields()重置表单，部门树选择器需要清空选中状态
