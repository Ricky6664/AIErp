### 5.1 核心功能
1. 创建PositionList.vue列表页，采用P04单一列表页类型展示岗位数据
2. 搜索栏：岗位名称/编码关键字搜索(el-input)、所属部门筛选(el-tree-select)、岗位类型筛选(el-select:管理/技术/操作)、启用状态筛选、搜索/重置按钮
3. 操作栏：新增岗位按钮(v-permission="'org:position:add'")、批量删除按钮
4. el-table展示：岗位名称/岗位编码/所属部门名称/岗位级别/岗位类型/排序号/启用状态/操作列
5. 操作列：编辑(v-permission)、删除(v-permission)按钮
6. el-pagination分页组件

### 5.2 数据交互
**岗位列表查询**：`GET /api/org/position?pageNum=1&pageSize=20&keyword=xxx&departmentId=10&positionType=tech&enabled=true`
```json
{
  "code": 200,
  "data": {
    "records": [{ "id": 1, "positionName": "高级开发工程师", "positionCode": "SENIOR_DEV", "departmentName": "研发部", "positionLevel": "P7", "positionType": "tech", "sortOrder": 1, "enabled": true }],
    "total": 56, "pageNum": 1, "pageSize": 20
  }
}
```
**涉及数据表**：org_position LEFT JOIN org_department ON department_id

### 5.3 关键逻辑
- **岗位类型标签**：management→"管理"(红色tag)、tech→"技术"(蓝色tag)、operation→"操作"(绿色tag)
- **部门树形筛选**：使用el-tree-select展示部门树，选择部门后筛选该部门及其所有子部门下的岗位
- **删除前校验**：删除岗位前检查是否有员工关联该岗位(hrm_employee.position_id)，有则提示"该岗位下有在职员工，无法删除"
- **岗位编码规范**：大写字母+下划线格式，如SENIOR_DEV、HR_MANAGER、FIN_ACCOUNTANT
- **批量操作**：支持checkbox多选，提供批量删除和批量启用/禁用功能

### 5.4 验证
1. 列表正确展示岗位数据，部门名称通过关联查询显示
2. 关键字/部门/类型/状态组合筛选功能正常
3. 删除有员工关联的岗位时提示无法删除
4. 岗位类型标签颜色正确区分
5. 分页功能正常，切换页码/每页条数正确

## 八、易错警示

> ⚠️ 操作按钮使用v-permission指令控制权限：新增v-permission="'org:position:add'"、编辑/删除同理

> ⚠️ API调用使用useApi composable，列表查询和删除操作统一封装

> ⚠️ 国际化使用$t()函数，表格列标题、按钮文本、类型标签文本通过i18n key引用

> ⚠️ el-tree-select部门筛选加载时需要调用部门树接口，数据量大时考虑添加loading状态和缓存

> ⚠️ 批量删除操作需要先校验所有选中项是否可删除(有无员工关联)，建议逐一调用删除接口并汇总结果
