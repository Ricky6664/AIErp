# P0-006 组织架构模块开发 - 模块开发指南

## 一、模块概述

- **模块定位**：公司管理 + 部门管理 + 岗位管理，为所有业务模块提供公司、部门、岗位、员工基础数据支撑
- **前置依赖**：P0-001（后端框架）、P0-002（前端框架）、P0-003（数据库）、P0-004（认证与权限）、P0-005（公共组件）
- **被依赖方**：P0-007~P0-012（商品/CRM/SRM/WMS/财务基础/HRM）、P1-005~P1-010（销售/采购/库存/生产/委外/质检）
- **开发阶段**：阶段五（基础数据）

## 四、数据表完整字段定义

> 以下字段定义为开发时的唯一权威来源。所有DDL/Entity/Mapper任务必须严格遵照此定义。
> 通用必含字段（10个）不再在每张表中重复列出，通过继承BaseEntity获取。

### 4.1 org_company（公司表）— 主表

**通用必含字段（通过继承BaseEntity获取）**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 |
|--------|---------|------|--------|---------|
| id | bigint | PRIMARY KEY | 雪花算法(ASSIGN_ID) | 主键ID |
| tenant_id | bigint | NOT NULL | - | 租户ID |
| created_at | timestamp | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | timestamp | NOT NULL | CURRENT_TIMESTAMP | 更新时间 |
| created_by | bigint | NOT NULL | 当前登录用户ID | 创建人ID |
| updated_by | bigint | NOT NULL | 当前登录用户ID | 修改人ID |
| is_deleted | boolean | NOT NULL | false | 是否删除 |
| owner_dept_id | bigint | - | 创建人所属部门ID | 所属部门ID |
| owner_id | bigint | - | created_by值 | 数据负责人ID |
| version | int | NOT NULL | 1 | 版本号(乐观锁) |

**业务字段**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 | 说明 |
|--------|---------|------|--------|---------|------|
| company_name | varchar(200) | NOT NULL | - | 公司名称 | 必填，同一租户下不重复 |
| company_short_name | varchar(100) | - | - | 公司简称 | 可选，用于列表展示 |
| credit_code | varchar(50) | UNIQUE(WHERE is_deleted=false) | - | 统一社会信用代码 | 18位，格式：2位登记管理部门代码+6位行政区划+10位主体识别号 |
| legal_person | varchar(50) | - | - | 法人 | 法定代表人姓名 |
| registered_capital | decimal(18,8) | - | - | 注册资本 | 单位：万元，物理DDL统一decimal(18,8)，显示精度由系统参数控制 |
| address | varchar(300) | - | - | 注册地址 | 公司注册地址 |
| phone | varchar(30) | - | - | 联系电话 | 公司联系电话 |
| enable_flag | boolean | NOT NULL | true | 是否启用 | 启用/禁用状态 |

**扩展字段（所有业务表统一预留）**：

| 字段名 | 数据类型 | 说明 |
|--------|---------|------|
| ext_str1~ext_str10 | varchar(200) | 扩展字符串字段 |
| ext_num1~ext_num5 | decimal(18,8) | 扩展数值字段 |
| ext_date1~ext_date3 | date | 扩展日期字段 |
| ext_bool1~ext_bool3 | boolean | 扩展布尔字段 |
| ext_json | jsonb | 扩展JSON字段 |

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| pk_org_company | 主键 | id | 主键索引 |
| uk_org_company_credit_code | 部分唯一 | credit_code WHERE is_deleted=false | 信用代码唯一(仅未删除记录) |
| uk_org_company_name | 部分唯一 | tenant_id, company_name WHERE is_deleted=false | 同租户公司名称唯一 |
| idx_org_company_tenant | 普通 | tenant_id, enable_flag | 租户+启用状态查询 |

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |
|--------|---------|------|---------|
| 公司名称唯一 | 新增/修改 | 同tenant_id下is_deleted=false不能有同名公司 | "公司名称已存在" |
| 信用代码唯一 | 新增/修改 | 同tenant_id下is_deleted=false不能有同代码 | "统一社会信用代码已存在" |
| 信用代码格式 | 新增/修改 | 正则：^[0-9A-HJ-NP-RTUW-Y]{2}\d{6}[0-9A-HJ-NP-RTUW-Y]{10}$ | "统一社会信用代码格式不正确" |
| 删除前关联检查 | 删除 | org_department.company_id是否有引用 | "该公司下存在部门，无法删除" |
| 注册资本非负 | 新增/修改 | registered_capital >= 0 | "注册资本不能为负数" |

### 4.2 org_department（部门表）— 主表

**通用必含字段**：同org_company（10个，通过继承BaseEntity获取）

**业务字段**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 | 说明 |
|--------|---------|------|--------|---------|------|
| dept_name | varchar(100) | NOT NULL | - | 部门名称 | 必填，同一公司下不重复 |
| dept_code | varchar(50) | NOT NULL | 编码引擎自动生成 | 部门编码 | 由编码引擎生成，唯一 |
| parent_id | bigint | - | 0 | 上级部门ID | 0或null表示顶级部门，树形结构 |
| company_id | bigint | NOT NULL | - | 公司ID | 关联org_company.id |
| manager_id | bigint | - | - | 部门负责人ID | 关联hrm_employee.id |
| dept_type | varchar(30) | - | 'functional' | 部门类型 | 枚举：business(业务)/functional(职能)/project(项目) |
| sort_no | int | NOT NULL | 0 | 排序号 | 数值越小越靠前 |
| enable_flag | boolean | NOT NULL | true | 是否启用 | 启用/禁用状态 |

**扩展字段**：同org_company

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| pk_org_department | 主键 | id | 主键索引 |
| uk_org_department_code | 部分唯一 | tenant_id, dept_code WHERE is_deleted=false | 同租户部门编码唯一 |
| uk_org_department_name | 部分唯一 | tenant_id, company_id, parent_id, dept_name WHERE is_deleted=false | 同公司同上级下部门名唯一 |
| idx_org_department_company | 普通 | company_id | 按公司查询部门 |
| idx_org_department_parent | 普通 | parent_id | 按上级查下级(树形查询) |

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |
|--------|---------|------|---------|
| 部门名称唯一 | 新增/修改 | 同company_id+parent_id下不重复 | "同一上级下部门名称已存在" |
| 部门编码唯一 | 新增 | 编码引擎保证唯一 | "部门编码已存在" |
| 公司存在性 | 新增/修改 | company_id必须在org_company中存在且未删除 | "所属公司不存在" |
| 循环引用检查 | 新增/修改 | parent_id不能指向自身或子孙部门 | "不能将部门设为自身或其下属部门的子部门" |
| 删除前关联检查 | 删除 | 检查子部门+岗位+员工是否引用 | "该部门下存在子部门/岗位/员工，无法删除" |

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |
|--------|---------|------|---------|

| 岗位编码唯一 | 新增 | 编码引擎保证唯一 | "岗位编码已存在" |
| 部门存在性 | 新增/修改 | department_id必须在org_department中存在且未删除 | "所属部门不存在" |
| 删除前关联检查 | 删除 | 检查员工是否引用该岗位 | "该岗位下存在员工，无法删除" |

| phone | String | @Size(max=30) | 联系电话 |

**CompanyUpdateDTO**：同CreateDTO + Long id字段
**CompanyQueryDTO**：keyword(String模糊搜索) + enabled(Boolean) + PageQuery分页参数

**CompanyListVO**：

| 字段名 | Java类型 | 注解 | 说明 |
|--------|---------|------|------|
| id | Long | - | 主键 |
| companyName | String | - | 公司名称 |
| companyShortName | String | - | 公司简称 |
| creditCode | String | - | 统一社会信用代码 |
| legalPerson | String | - | 法人 |
| registeredCapital | BigDecimal | @JsonFormat(pattern="#,##0.00") | 注册资本 |
| phone | String | - | 联系电话 |
| enableFlag | Boolean | - | 启用状态 |
| createdAt | LocalDateTime | @JsonFormat(pattern="yyyy-MM-dd HH:mm:ss") | 创建时间 |

**CompanyDetailVO**：含ListVO全部字段 + address + 扩展字段 + 创建人/修改人名称

### 5.2 部门管理

**DeptCreateDTO**：

| 字段名 | Java类型 | 校验注解 | 说明 |
|--------|---------|---------|------|
| deptName | String | @NotBlank, @Size(max=100) | 部门名称 |
| parentId | Long | - | 上级部门ID(0为顶级) |
| companyId | Long | @NotNull | 公司ID |
| managerId | Long | - | 部门负责人ID |
| deptType | String | @Pattern(regexp="business|functional|project") | 部门类型 |
| sortNo | Integer | @Min(0) | 排序号 |

**DeptUpdateDTO**：同CreateDTO + Long id字段
**DeptQueryDTO**：companyId(必填) + keyword(模糊搜索) + enableFlag + PageQuery

**DeptListVO**：id + deptName + deptCode + parentId + companyName + managerName + deptType + sortNo + enableFlag
**DeptTreeVO**：id + deptName + deptCode + parentId + children(List<DeptTreeVO>) + enableFlag

### 5.3 岗位管理
