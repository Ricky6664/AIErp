## 五、详细开发规格

### 5.1 OrgCompanyService接口定义

继承IServiceX\<OrgCompany\>，声明以下5个方法：

```java
public interface OrgCompanyService extends IServiceX<OrgCompany> {
    PageResult<CompanyListVO> page(CompanyQueryDTO query);
    CompanyDetailVO getById(Long id);
    Long create(CompanyCreateDTO dto);
    void update(Long id, CompanyUpdateDTO dto);
    void delete(Long id);
}
```

- page方法：@Transactional(readOnly=true)，支持keyword模糊搜索companyName/companyShortName + enabled筛选
- getById方法：@Transactional(readOnly=true)，返回CompanyDetailVO含全部字段
- create方法：@Transactional，名称唯一性校验 → DTO转Entity → save → 操作日志
- update方法：@Transactional，存在性校验 → 名称唯一性校验(排除自身) → 乐观锁更新 → 操作日志
- delete方法：@Transactional，存在性校验 → 关联部门检查 → 逻辑删除 → 操作日志

### 5.2 DTO定义

**CompanyCreateDTO**：

| 字段名 | Java类型 | 校验注解 | 说明 |
|--------|---------|---------|------|
| companyName | String | @NotBlank(message="公司名称不能为空"), @Size(max=200) | 公司名称 |
| companyShortName | String | @Size(max=100) | 公司简称 |
| creditCode | String | @Pattern(regexp="^[0-9A-HJ-NP-RTUW-Y]{2}\\d{6}[0-9A-HJ-NP-RTUW-Y]{10}$") | 统一社会信用代码 |
| legalPerson | String | @Size(max=50) | 法人 |
| registeredCapital | BigDecimal | @DecimalMin("0") | 注册资本(万元) |
| address | String | @Size(max=300) | 注册地址 |
| phone | String | @Size(max=30) | 联系电话 |

**CompanyUpdateDTO**：同CreateDTO字段 + Long id(@NotNull)字段
**CompanyQueryDTO**：keyword(String，模糊搜索companyName/companyShortName) + enabled(Boolean) + 继承PageQuery(pageNum+pageSize)

### 5.3 VO定义

**CompanyListVO**：id(Long) + companyName(String) + companyShortName(String) + creditCode(String) + legalPerson(String) + registeredCapital(BigDecimal, @JsonFormat(pattern="#,##0.00")) + phone(String) + enableFlag(Boolean) + createdAt(LocalDateTime, @JsonFormat(pattern="yyyy-MM-dd HH:mm:ss"))

**CompanyDetailVO**：含ListVO全部字段 + address(String) + ext_str1~10 + ext_num1~5 + ext_date1~3 + ext_bool1~3 + ext_json + createdByName + updatedByName

### 5.4 字段映射关系

- DTO字段 → Entity字段：companyName → company_name, companyShortName → company_short_name, creditCode → credit_code, legalPerson → legal_person, registeredCapital → registered_capital, address → address, phone → phone
- 不暴露给前端的字段：tenant_id, is_deleted, version, owner_dept_id, owner_id（由系统自动填充）
- enableFlag由update接口单独控制，不在CreateDTO/UpdateDTO中

## 八、易错警示

> ⚠️ Service接口只声明方法签名，不包含实现逻辑；@Transactional注解加在实现类方法上，不要加在接口上

> ⚠️ DTO不要包含is_deleted、tenant_id、version等系统字段，这些由BaseEntity和框架自动处理

> ⚠️ CompanyQueryDTO继承PageQuery时确保keyword/enabled字段有正确的getter/setter或使用Lombok@Data

> ⚠️ creditCode正则中的反斜杠需要双重转义：Java字符串中`\\d`表示正则中的`\d`

> ⚠️ CompanyDetailVO的扩展字段(ext_str1~10等)需完整定义，不可遗漏
