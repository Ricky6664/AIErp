### 5.2 测试用例清单

| 测试方法名 | 测试场景 | 预期结果 |
|-----------|---------|---------|
| test_create_success | 正常新增公司，参数完整合法 | 返回非null的ID，数据库中存在对应记录 |
| test_create_duplicateName | 同租户下新增同名公司 | 抛出BusinessException，message包含"公司名称已存在" |
| test_create_invalidCreditCode | 信用代码格式不合法(如少于18位) | 抛出BusinessException，message包含"格式不正确" |
| test_create_duplicateCreditCode | 信用代码与已有公司重复 | 抛出BusinessException，message包含"信用代码已存在" |
| test_create_negativeCapital | 注册资本为负数 | 抛出MethodArgumentNotValidException |
| test_update_success | 正常修改公司名称 | 数据库中名称已更新，version递增 |
| test_update_duplicateNameExcludeSelf | 修改为其他公司的名称 | 抛出BusinessException |
| test_update_notFound | 修改不存在的公司ID | 抛出BusinessException，message包含"公司不存在" |
| test_delete_success | 删除无关联部门的公司 | 删除成功，记录is_deleted=true |
| test_delete_hasDepartment | 删除存在关联部门的公司 | 抛出BusinessException，message包含"存在部门" |
| test_delete_notFound | 删除不存在的公司ID | 抛出BusinessException |
| test_page_keywordSearch | keyword模糊搜索 | 返回结果companyName或shortName包含keyword |
| test_page_enabledFilter | enabled=true筛选 | 返回结果全部enableFlag=true |
| test_transaction_rollback | create过程中抛出异常 | 数据库无新增记录(事务回滚) |

## 八、易错警示

> ⚠️ 测试类使用@SpringBootTest时注意数据库连接配置，使用测试专用数据库或H2内存数据库

> ⚠️ 测试数据准备使用@BeforeEach而非@BeforeAll，确保每个测试方法的数据隔离

> ⚠️ 事务回滚测试不能依赖测试类级别的@Transactional注解，需单独验证数据库实际状态

> ⚠️ Mock外部依赖(如编码引擎、操作日志服务)时使用@MockBean，不要修改真实服务的Bean定义

> ⚠️ 多租户测试需要手动设置TenantContext，否则tenant_id为空导致查询条件不匹配
