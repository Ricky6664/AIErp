## 五、详细开发规格

### 5.1 OrgPositionService接口定义

继承IServiceX\<OrgPosition\>，声明以下5个方法：

```java
public interface OrgPositionService extends IServiceX<OrgPosition> {
    PageResult<PositionListVO> page(PositionQueryDTO query);
    PositionDetailVO getById(Long id);
    Long create(PositionCreateDTO dto);
    void update(Long id, PositionUpdateDTO dto);
    void delete(Long id);
}
```

- page方法：@Transactional(readOnly=true)，按departmentId筛选 + keyword模糊搜索positionName/positionCode
- getById方法：@Transactional(readOnly=true)，返回PositionDetailVO含departmentName关联字段
- create方法：@Transactional，部门存在性校验 → 名称唯一性校验 → 编码引擎生成positionCode → save
- update方法：@Transactional，存在性校验 → 名称唯一性校验(排除自身) → 乐观锁更新
- delete方法：@Transactional，员工引用检查 → 逻辑删除

### 5.2 DTO定义

**PositionCreateDTO**：

| 字段名 | Java类型 | 校验注解 | 说明 |
|--------|---------|---------|------|
| positionName | String | @NotBlank(message="岗位名称不能为空"), @Size(max=100) | 岗位名称 |
| departmentId | Long | @NotNull(message="所属部门不能为空") | 所属部门ID |
| positionLevel | String | @Size(max=30) | 岗位级别(P1-P10/M1-M5/O1-O5) |
| positionType | String | @Pattern(regexp="management\|technical\|operation") | 岗位类型 |
| sortNo | Integer | @Min(0) | 排序号 |

**PositionUpdateDTO**：同CreateDTO字段 + Long id(@NotNull)字段
**PositionQueryDTO**：departmentId(Long) + keyword(String, 模糊搜索positionName/positionCode) + enableFlag(Boolean) + 继承PageQuery

### 5.3 VO定义

**PositionListVO**：id(Long) + positionName(String) + positionCode(String) + departmentName(String, 关联查询) + positionLevel(String) + positionType(String) + sortNo(Integer) + enableFlag(Boolean)

**PositionDetailVO**：含ListVO全部字段 + 扩展字段(ext_str1~10等) + createdByName + updatedByName

### 5.4 字段映射关系

- DTO字段 → Entity字段：positionName → position_name, departmentId → department_id, positionLevel → position_level, positionType → position_type, sortNo → sort_no
- positionCode由编码引擎自动生成，CreateDTO中不需要传入
- departmentName在VO中通过LEFT JOIN org_department关联查询获得

## 八、易错警示

> ⚠️ positionCode由编码引擎自动生成，不要在CreateDTO中要求前端传入；VO中展示positionCode用于列表显示

> ⚠️ positionType的枚举值为management/technical/operation，注意与前端展示文本(管理/技术/操作)的映射转换

> ⚠️ Service接口只声明方法签名，不包含实现逻辑；@Transactional注解加在实现类方法上

> ⚠️ PositionQueryDTO的departmentId为可选筛选条件，不传时查询全部岗位；前端可能通过部门树选择器传入

> ⚠️ 岗位名称唯一性校验范围是同departmentId下，不是全局唯一；注意SQL条件包含department_id
