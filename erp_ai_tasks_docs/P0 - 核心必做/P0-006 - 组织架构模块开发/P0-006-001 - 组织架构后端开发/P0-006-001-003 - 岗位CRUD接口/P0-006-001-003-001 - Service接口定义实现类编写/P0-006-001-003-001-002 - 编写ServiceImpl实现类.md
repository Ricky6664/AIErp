## 五、详细开发规格

### 5.1 OrgPositionServiceImpl实现

继承ServiceImplX\<OrgPositionMapper, OrgPosition\>，实现OrgPositionService接口：

```java
@Service
public class OrgPositionServiceImpl extends ServiceImplX<OrgPositionMapper, OrgPosition>
    implements OrgPositionService {

    @Override
    @Transactional(readOnly = true)
    public PageResult<PositionListVO> page(PositionQueryDTO query) { ... }

    @Override
    @Transactional(readOnly = true)
    public PositionDetailVO getById(Long id) { ... }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public Long create(PositionCreateDTO dto) { ... }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void update(Long id, PositionUpdateDTO dto) { ... }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void delete(Long id) { ... }
}
```

### 5.2 page方法实现逻辑

1. 构建LambdaQueryWrapper，条件：is_deleted=false
2. 若departmentId非空：AND department_id=query.departmentId
3. 若keyword非空：嵌套条件 WHERE (position_name LIKE '%keyword%' OR position_code LIKE '%keyword%')
4. 若enableFlag非空：AND enable_flag = enableFlag
5. 按sort_no ASC, created_at DESC排序
6. Entity列表 → PositionListVO列表，departmentName通过departmentId关联查询org_department获得
7. 返回PageResult\<PositionListVO\>

### 5.3 create方法实现逻辑

1. **部门存在性校验**：查询org_department WHERE id=dto.departmentId AND is_deleted=false，不存在抛BusinessException(ErrorCode.NOT_FOUND, "所属部门不存在")
2. **岗位名称唯一性校验**：查询is_deleted=false AND tenant_id=当前租户 AND department_id=dto.departmentId AND position_name=dto.positionName，存在抛BusinessException(ErrorCode.DUPLICATE, "同一部门下岗位名称已存在")
3. **编码引擎生成positionCode**：调用CodeEngineService.generateCode("POS", dto.departmentId)生成唯一岗位编码
4. **DTO → Entity转换 + save**
5. 记录操作日志，返回entity.getId()

### 5.4 update方法实现逻辑

1. **存在性校验**：getById(id)，不存在抛BusinessException
2. **名称唯一性校验(排除自身)**：同create但排除id != 当前id
3. 若departmentId变更：需要重新校验新部门下的名称唯一性
4. **乐观锁更新**：updateById(entity)，version字段由MyBatis-Plus乐观锁插件处理
5. 记录操作日志

### 5.5 delete方法实现逻辑

1. **存在性校验**
2. **员工引用检查**：查询hrm_employee WHERE position_id=id AND is_deleted=false，count>0抛BusinessException(ErrorCode.REFERENCE_EXISTS, "该岗位下存在员工，无法删除")
3. **逻辑删除** + 操作日志

### 5.6 集成点

- **编码引擎**：调用CodeEngineService.generateCode()生成positionCode，格式由编码规则配置决定
- **操作日志**：通过OperLogService记录增删改操作
- **多租户隔离**：tenant_id由TenantContext自动注入
- **乐观锁**：@Version注解的version字段，updateById时自动处理

## 八、易错警示

> ⚠️ @Transactional加在实现方法上，不要加在接口上；写方法必须指定rollbackFor=Exception.class

> ⚠️ 避免大事务：只读方法(page/getById)加readOnly=true，减少数据库锁开销

> ⚠️ 业务异常使用BusinessException(ErrorCode.XXX, "消息")，不要使用RuntimeException

> ⚠️ 岗位名称唯一性校验范围是同departmentId下，SQL条件必须包含department_id和is_deleted=false和tenant_id

> ⚠️ update方法中若departmentId发生变更，需要在新部门下重新做名称唯一性校验，否则可能出现同部门下重名岗位
