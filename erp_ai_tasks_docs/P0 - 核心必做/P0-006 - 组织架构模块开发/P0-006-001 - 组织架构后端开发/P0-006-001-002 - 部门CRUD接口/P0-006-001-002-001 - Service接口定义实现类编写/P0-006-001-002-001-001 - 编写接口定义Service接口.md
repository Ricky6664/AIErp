## 五、详细开发规格

### 5.1 OrgDepartmentService接口定义

继承IServiceX\<OrgDepartment\>，声明以下6个方法：

```java
public interface OrgDepartmentService extends IServiceX<OrgDepartment> {
    PageResult<DeptListVO> page(DeptQueryDTO query);
    List<DeptTreeVO> tree(Long companyId);
    DeptDetailVO getById(Long id);
    Long create(DeptCreateDTO dto);
    void update(Long id, DeptUpdateDTO dto);
    void delete(Long id);
}
```

- page方法：@Transactional(readOnly=true)，按companyId筛选 + keyword模糊搜索deptName/deptCode
- tree方法：@Transactional(readOnly=true)，查询公司下全部部门，构建parent→children树形结构返回
- getById方法：@Transactional(readOnly=true)，返回DeptDetailVO，含companyName/managerName关联查询
- create方法：@Transactional，公司存在性校验 → 名称唯一性校验 → 编码引擎生成deptCode → 循环引用检查 → save
- update方法：@Transactional，存在性校验 → 名称唯一性校验(排除自身) → 循环引用检查 → 乐观锁更新
- delete方法：@Transactional，子部门检查 → 岗位检查 → 员工检查 → 逻辑删除

### 5.2 DTO定义

**DeptCreateDTO**：

| 字段名 | Java类型 | 校验注解 | 说明 |
|--------|---------|---------|------|
| deptName | String | @NotBlank(message="部门名称不能为空"), @Size(max=100) | 部门名称 |
| parentId | Long | - | 上级部门ID(0或null为顶级) |
| companyId | Long | @NotNull(message="所属公司不能为空") | 公司ID |
| managerId | Long | - | 部门负责人ID |
| deptType | String | @Pattern(regexp="business\|functional\|project") | 部门类型 |
| sortNo | Integer | @Min(0) | 排序号 |

**DeptUpdateDTO**：同CreateDTO字段 + Long id(@NotNull)字段
**DeptQueryDTO**：companyId(Long, 必填) + keyword(String, 模糊搜索deptName/deptCode) + enableFlag(Boolean) + 继承PageQuery

### 5.3 VO定义

**DeptListVO**：id(Long) + deptName(String) + deptCode(String) + parentId(Long) + companyName(String, 关联查询) + managerName(String, 关联查询) + deptType(String) + sortNo(Integer) + enableFlag(Boolean)

**DeptTreeVO**：id(Long) + deptName(String) + deptCode(String) + parentId(Long) + children(List\<DeptTreeVO\>, 递归) + enableFlag(Boolean)

**DeptDetailVO**：含ListVO全部字段 + 扩展字段(ext_str1~10等) + createdByName + updatedByName

### 5.4 字段映射关系

- DTO字段 → Entity字段：deptName → dept_name, deptCode → dept_code, parentId → parent_id, companyId → company_id, managerId → manager_id, deptType → dept_type, sortNo → sort_no
- deptCode由编码引擎自动生成，CreateDTO中不需要传入
- companyName/managerName在VO中通过LEFT JOIN关联查询获得，不在Entity中存储

## 八、易错警示

> ⚠️ DeptTreeVO的children字段类型为List\<DeptTreeVO\>，是递归结构，序列化时注意避免无限循环(JSON框架通常能正确处理null的List)

> ⚠️ deptCode由编码引擎自动生成，不要在CreateDTO中要求前端传入；前端传入的code值应被忽略

> ⚠️ DeptQueryDTO的companyId是必填项，查询时必须按公司隔离数据，避免跨公司数据泄露

> ⚠️ Service接口只声明方法签名，不包含实现逻辑；@Transactional注解加在实现类方法上

> ⚠️ parentId为0或null均表示顶级部门，接口层需要统一处理这两种情况
