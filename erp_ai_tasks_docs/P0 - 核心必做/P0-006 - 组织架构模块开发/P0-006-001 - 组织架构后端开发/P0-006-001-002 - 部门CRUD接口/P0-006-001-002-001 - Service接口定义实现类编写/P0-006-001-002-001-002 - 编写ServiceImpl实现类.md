### 5.2 page方法实现逻辑

1. 构建LambdaQueryWrapper，条件：is_deleted=false AND company_id=query.companyId（必填）
2. 若keyword非空：嵌套条件 WHERE (dept_name LIKE '%keyword%' OR dept_code LIKE '%keyword%')
3. 若enableFlag非空：AND enable_flag = enableFlag
4. 按sort_no ASC, created_at DESC排序
5. 调用page()获取分页结果
6. Entity列表 → DeptListVO列表，companyName通过companyId关联查询org_company获得，managerName通过managerId关联查询hrm_employee获得
7. 返回PageResult\<DeptListVO\>

### 5.3 tree方法实现逻辑

1. 查询条件：company_id=companyId AND is_deleted=false，按sort_no ASC排序
2. Entity列表 → DeptTreeVO列表
3. 构建树形结构：使用Map\<Long, DeptTreeVO\>存储id→node映射，遍历列表将每个节点添加到其parent的children中
4. parentId为0或null的节点为根节点，收集所有根节点返回List\<DeptTreeVO\>

### 5.4 create方法实现逻辑

1. **公司存在性校验**：查询org_company WHERE id=dto.companyId AND is_deleted=false，不存在抛BusinessException(ErrorCode.NOT_FOUND, "所属公司不存在")
2. **部门名称唯一性校验**：查询is_deleted=false AND tenant_id=当前租户 AND company_id=dto.companyId AND parent_id=dto.parentId AND dept_name=dto.deptName，存在抛BusinessException(ErrorCode.DUPLICATE, "同一上级下部门名称已存在")
3. **编码引擎生成deptCode**：调用CodeEngineService.generateCode("DEPT", dto.companyId)生成唯一部门编码
4. **循环引用检查**（若parentId非空且非0）：查询当前parentId的所有祖先节点链，确认不包含自身（新增时自身ID尚未生成，此步主要用于update）
5. **DTO → Entity转换 + save**
6. 记录操作日志，返回entity.getId()

### 5.5 update方法实现逻辑

1. **存在性校验**：getById(id)，不存在抛BusinessException
2. **名称唯一性校验(排除自身)**：同create但排除id != 当前id
3. **循环引用检查**：若parentId变更，查询以parentId为根的所有子孙部门ID列表，若包含当前id则抛BusinessException(ErrorCode.INVALID_PARAM, "不能将部门设为自身或其下属部门的子部门")
4. **乐观锁更新**：updateById(entity)
5. 记录操作日志

### 5.6 delete方法实现逻辑

1. **存在性校验**
2. **子部门检查**：查询org_department WHERE parent_id=id AND is_deleted=false，count>0抛BusinessException(ErrorCode.REFERENCE_EXISTS, "该部门下存在子部门，无法删除")
3. **岗位检查**：查询org_position WHERE department_id=id AND is_deleted=false，count>0抛BusinessException("该部门下存在岗位，无法删除")
4. **员工检查**：查询hrm_employee WHERE dept_id=id AND is_deleted=false，count>0抛BusinessException("该部门下存在员工，无法删除")
5. **逻辑删除** + 操作日志

### 5.7 循环引用检查算法

```java
private void checkCircularReference(Long deptId, Long parentId) {
    if (parentId == null || parentId == 0) return;
    if (parentId.equals(deptId)) {
        throw new BusinessException(ErrorCode.INVALID_PARAM, "不能将部门设为自身的子部门");
    }
    // 递归查询parent的所有祖先
    OrgDepartment parent = getById(parentId);
    if (parent != null && parent.getParentId() != null) {
        checkCircularReference(deptId, parent.getParentId());
    }
}
```

## 八、易错警示

> ⚠️ @Transactional加在实现方法上，不要加在接口上；写方法必须指定rollbackFor=Exception.class

> ⚠️ 避免大事务：只读方法(page/tree/getById)加readOnly=true；tree方法查询全量部门数据时注意性能，大数据量考虑缓存

> ⚠️ 业务异常使用BusinessException(ErrorCode.XXX, "消息")，不要使用RuntimeException

> ⚠️ 循环引用检查必须递归向上遍历全部祖先节点，仅检查直接parent不够（A→B→C，将C的parent改为A会形成环）

> ⚠️ tree方法构建Map时注意parentId为null和0的统一处理，两者都表示根节点
