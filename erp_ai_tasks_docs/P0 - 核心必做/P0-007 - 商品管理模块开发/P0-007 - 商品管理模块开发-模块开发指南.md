# P0-007 商品管理模块开发 - 模块开发指南

## 一、模块概述

- **模块定位**：商品档案 + 分类 + BOM + 工序 + 多单位 + 安全库存 + 定价体系（标准价/购价/销价/竞品），为销售、采购、库存、生产、委外等所有业务模块提供商品基础数据支撑
- **前置依赖**：P0-001（后端框架）、P0-002（前端框架）、P0-003（数据库）、P0-004（认证与权限）、P0-005（公共组件）、P0-006（组织架构提供公司/部门数据）
- **被依赖方**：P1-005~P1-009（销售/采购/库存/生产/委外）
- **开发阶段**：阶段五（基础数据）

## 八、模块级专属约束

1. **基线与扩展优先级**：设计文档11.5节定义的19个功能点为基线（工作台/商品中心/商品分类/标准工序/商品基本信息/商品多单位/商品控制策略/商品安全库存/商品附件/商品其他信息/商品标准价/商品购价核定/商品销价核定/商品竞品/商品BOM/商品BOM成本/商品工序/商品工序参数/商品工序加工价格），V8补充的8个扩展项（商品价格/属性/规格/条码/图片/关联/标签/序列号模板）为增强扩展项。开发执行时19个基线功能点优先开发，8个扩展项在基线完成后开发。
2. **商品图片管理(P0-007-002-032)为用户明确要求保留项**，即使在扩展项中也须确保开发完成。
3. **商品编码唯一性**：商品编码通过数据库行级锁保证唯一性，编码生成需在事务内完成序号递增。
4. **BOM层级校验**：BOM层级展开深度限制10层，需进行循环引用检测。
5. **多单位转换率**：所有非基础单位的转换率必须以基础单位为基准进行换算。
