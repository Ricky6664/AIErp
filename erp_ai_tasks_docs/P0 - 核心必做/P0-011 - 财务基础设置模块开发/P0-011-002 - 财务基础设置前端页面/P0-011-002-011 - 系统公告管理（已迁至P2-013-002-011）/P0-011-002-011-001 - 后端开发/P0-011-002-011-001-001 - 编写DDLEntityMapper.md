### 5.1 表结构设计
```sql
CREATE TABLE sys_announcement (
    id BIGINT PRIMARY KEY,
    tenant_id BIGINT NOT NULL,
    title VARCHAR(200) NOT NULL,
    content TEXT,
    announcement_type VARCHAR(50),
    publish_time TIMESTAMP,
    is_top BOOLEAN DEFAULT false,
    status INT DEFAULT 1,
    created_by BIGINT,
    created_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_by BIGINT,
    updated_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    is_deleted BOOLEAN DEFAULT false,
    version INT DEFAULT 0
);
```

### 5.2 Entity
AnnouncementEntity extends BaseEntityX, @TableName("sys_announcement")
字段：title, content, announcementType, publishTime, isTop, status

### 5.3 Mapper
AnnouncementMapper extends BaseMapperX<AnnouncementEntity>
自定义：selectUnreadList(tenant_id + is_deleted=false + 用户已读关联)

### 5.4 Flyway
命名: V{日期}{序号}__create_sys_announcement.sql
含回滚注释(DROP TABLE)

## 八、易错警示

> ⚠️ 金额字段使用decimal(18,8)，不要用FLOAT/DOUBLE

> ⚠️ 日期时间统一使用TIMESTAMP，不要用DATE或VARCHAR

> ⚠️ 唯一索引必须包含 WHERE is_deleted = false 条件(部分唯一索引)

> ⚠️ Flyway版本号格式V{日期}{序号}，确保不与其他迁移脚本冲突

> ⚠️ Entity字段使用@TableField标注列映射，@TableLogic标注逻辑删除字段
