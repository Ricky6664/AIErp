### 5.1 页面搭建
页面路由：/system/cache
- 顶部统计卡片：总Key数、内存占用、命中率
- 中间搜索：Key模式匹配输入框
- 下方表格：Key名称、TTL、操作列(查看Value/删除)

### 5.2 数据绑定
- Key列表：GET /api/system/cache/list?pattern=xxx
- Value详情：GET /api/system/cache/{key}/value
- 删除：DELETE /api/system/cache/{key}

### 5.3 交互逻辑
- Key搜索：输入模式后回车
- 查看Value：弹窗JSON高亮
- 删除：二次确认
- 批量删除：勾选多行

### 5.4 组件集成
- VxeTable(虚拟滚动), StatCard, JsonViewer(vue-json-pretty)
