### 5.1 接口定义
- 接口名：IAccountingPeriodService，继承 IServiceX<AccountingPeriodEntity>
- 包路径：com.erp.finance.service

### 5.2 方法签名
```java
public interface IAccountingPeriodService extends IServiceX<AccountingPeriodEntity> {
    AccountingPeriodVO create(@Valid AccountingPeriodCreateDTO dto);
    AccountingPeriodVO update(Long id, @Valid AccountingPeriodUpdateDTO dto);
    void delete(Long id);
    AccountingPeriodVO getById(Long id);
    PageResult<AccountingPeriodVO> pageList(AccountingPeriodQueryDTO query);
}
```

### 5.3 入参DTO/返回VO
- CreateDTO字段：fiscalYear(会计年度), period(会计期间), startDate(开始日期), endDate(结束日期), periodStatus(期间状态:未开始/进行中/已结账), isYearEnd(是否年结期间)
- UpdateDTO：与CreateDTO相同字段 + @NotNull Long id
- QueryDTO：pageNum, pageSize, 
- VO：fiscalYear(会计年度), period(会计期间), startDate(开始日期), endDate(结束日期), periodStatus(期间状态:未开始/进行中/已结账), isYearEnd(是否年结期间) + id + createdTime + updatedTime

### 5.4 注解要求
- 写操作方法(create/update/delete)标注 @Transactional(rollbackFor = Exception.class)
- 接口方法JavaDoc注释完整(@param, @return)

## 八、易错警示

> ⚠️ 事务注解@Transactional仅加在写操作方法(create/update/delete)，读操作不加

> ⚠️ DTO字段校验注解(@NotNull/@NotBlank/@Size)与ServiceImpl校验保持一致

> ⚠️ 接口方法JavaDoc注释必须完整，包含@param和@return说明

> ⚠️ 方法返回类型统一使用VO对象，不直接返回Entity

> ⚠️ 异常统一抛出BusinessException，不要抛原生RuntimeException
