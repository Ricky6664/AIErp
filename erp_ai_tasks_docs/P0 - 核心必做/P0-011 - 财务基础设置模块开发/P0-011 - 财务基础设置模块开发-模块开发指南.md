# P0-011 财务基础设置模块开发 - 模块开发指南

## 一、模块概述

- **模块定位**：币种汇率 + 银行账户 + 会计科目管理 + 凭证字管理 + 会计期间，为后续所有财务模块提供基础数据支撑
- **前置依赖**：P0-001（后端框架）、P0-002（前端框架）、P0-003（数据库）、P0-004（认证与权限）、P0-005（公共组件）、P0-006（组织架构提供公司数据）、P0-007（商品管理）
- **被依赖方**：P2-013（总账管理）、P2-014（应收应付）、P2-015（固定资产）、P2-016（成本管理）
- **开发阶段**：阶段五（基础数据）

### 模块级专属约束

1. **功能点优先级**：币种汇率 → 银行账户 → 会计科目 → 凭证字 → 会计期间顺序开发，会计科目与会计期间为核心配置项。
2. **币种编码唯一性**：币种编码全局唯一，汇率日期需校验有效性（不得晚于当前日期+30天）。
3. **银行账号唯一性**：银行账号在系统内全局唯一，新增/修改时需进行唯一性校验。
4. **会计科目编码规则**：科目编码需按级次规则生成（如4-2-2-2），每级长度固定，科目编码全局唯一；末级科目标记需在新增/修改时自动计算。
5. **会计科目级次校验**：新增子科目时，需校验上级科目是否存在且为非末级科目；删除科目时，需校验是否存在下级科目、是否被凭证引用。
6. **会计期间不可重叠**：同一会计年度内的会计期间日期范围不可重叠，新增/修改时需进行日期范围重叠校验。
7. **科目余额表更新机制**：凭证审核时自动更新科目余额表对应科目和期间的发生额；期末结账时自动将本期期末结转至下期期初。
