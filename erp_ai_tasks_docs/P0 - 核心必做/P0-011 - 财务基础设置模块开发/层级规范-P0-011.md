## 1. 模块架构约束

### 1.1 模块定位
P0-011负责开发ERP系统的财务基础设置功能，包括币种汇率管理、银行账户管理、会计科目管理（树形结构）、凭证字管理、会计期间管理，以及科目余额表、现金流量项目、辅助核算类别等扩展配置。本模块为后续所有财务模块（P2-013总账管理、P2-014应收应付、P2-015固定资产、P2-016成本管理）提供基础数据支撑。

### 1.2 依赖关系
- 前置依赖：
  - P0-001（后端框架）
  - P0-002（前端框架）
  - P0-003（数据库提供fin_*系列表）
  - P0-004（认证与权限）
  - P0-005（公共组件提供页面基座/选择器）
  - P0-006（组织架构提供公司数据——银行账户关联公司）
  - P0-007（商品管理——财务基础设置可能被商品标准价引用）
- 后续依赖：
  - P2-013（总账管理）——引用会计科目/凭证字/会计期间
  - P2-014（应收应付）——引用币种汇率/银行账户/会计科目
  - P2-015（固定资产）——引用会计科目/会计期间
  - P2-016（成本管理）——引用会计科目/币种汇率

### 1.3 技术约束
- **技术栈约束**：Spring Boot 3.4.x + MyBatis-Plus 3.5.5 + Vue3 + Element Plus + Vxe Table
- **性能约束**：会计科目树加载 < 300ms（1000个科目节点）；会计期间列表查询 < 100ms
- **安全约束**：会计科目编码全局唯一；银行账号全局唯一；会计期间不可重叠；删除科目需校验下级科目和凭证引用

## 2. 数据模型关系

### 2.1 核心数据表
| 表名 | 说明 | 关键字段 |
|------|------|---------|
| fin_currency_rate | 币种汇率表 | currency_code, currency_name, base_currency, exchange_rate, rate_date, rate_type |
| fin_bank_account | 银行账户表 | account_name, bank_account, bank_name, bank_branch, currency, account_type, is_enabled |
| fin_account | 会计科目表 | account_code, account_name, parent_id, account_level, account_type, account_category, balance_direction, is_last_level |
| fin_voucher_word | 凭证字表 | word_name, word_code, sort_order, is_enabled |
| fin_accounting_period | 会计期间表 | fiscal_year, fiscal_period, start_date, end_date, period_status, is_year_end |
| fin_account_balance | 科目余额表 | account_id, period_id, begin_debit, begin_credit, current_debit, current_credit, end_debit, end_credit |
| fin_cash_flow_item | 现金流量项目表 | item_code, item_name, parent_id, item_category, item_level |
| fin_auxiliary_type | 辅助核算类别表 | type_code, type_name, source_table, source_field |

### 2.2 表关系图
- `fin_account`（树形自引用，parent_id）：会计科目为树形结构，支持多级科目
- `fin_account` 1:N `fin_account_balance`：一个科目在多个会计期间有余额记录
- `fin_accounting_period` 1:N `fin_account_balance`：一个会计期间包含多个科目的余额
- `fin_cash_flow_item`（树形自引用）：现金流量项目为树形结构
- `fin_currency_rate`：独立表，按币种+日期管理汇率
- `fin_bank_account`：独立表，银行账户全局管理
- `fin_voucher_word`：独立表，凭证字配置
- `fin_auxiliary_type`：独立表，辅助核算类别配置
- `fin_account_balance`联合唯一索引：(account_id, period_id, tenant_id)

### 2.3 数据流转
1. **会计科目管理流程**：新增顶级科目 → 设置科目编码（按级次规则如4-2-2-2）→ 设置科目类型/类别/余额方向 → 保存 → 可新增子科目 → 末级科目标记自动计算
2. **会计期间管理流程**：新增会计年度 → 创建12个月度期间 → 设置期间状态（未开始→进行中→已结账）→ 期末结账时自动将本期期末结转至下期期初
3. **科目余额更新流程**：凭证审核 → 自动更新fin_account_balance对应科目和期间的发生额 → 期末结账 → 本期期末余额结转至下期期初

## 3. 业务流程

### 3.1 核心业务流程
1. **财务基础设置后端开发**（P0-011-001）：
   - 币种汇率CRUD（含币种编码唯一性+汇率日期有效性校验：不得晚于当前日期+30天）
   - 银行账户CRUD（含银行账号全局唯一性校验）
   - 会计科目CRUD（含科目编码唯一性+级次校验+末级标记自动计算+删除下级科目/凭证引用校验）
   - 凭证字CRUD
   - 会计期间CRUD（含期间日期不可重叠校验+凭证引用校验）
   - 最新汇率查询接口（按币种+基准币种查询最近生效汇率）
   - 当前进行中会计期间查询接口
   - 工作台聚合接口
2. **财务基础设置前端页面**（P0-011-002）：
   - 财务基础设置工作台（P02）
   - 币种汇率列表页（P04）+ 表单页（P07弹窗中）
   - 银行账户列表页（P04）+ 表单页（P07弹窗中）
   - 会计科目管理树形列表页（P05）+ 表单页（P07弹窗中）
   - 凭证字管理列表页（P04）+ 表单页（P07弹窗中）

### 3.2 业务规则
- **功能点优先级**：币种汇率 → 银行账户 → 会计科目 → 凭证字 → 会计期间顺序开发，会计科目与会计期间为核心配置项
- **币种编码唯一性**：币种编码全局唯一，汇率日期需校验有效性
- **银行账号唯一性**：银行账号在系统内全局唯一
- **会计科目编码规则**：科目编码按级次规则生成（如4-2-2-2），每级长度固定，全局唯一；末级科目标记在新增/修改时自动计算
- **会计科目级次校验**：新增子科目时需校验上级科目存在且为非末级；删除科目时需校验无下级科目且未被凭证引用
- **会计期间不可重叠**：同一会计年度内的会计期间日期范围不可重叠
- **科目余额表更新机制**：凭证审核时自动更新科目余额表；期末结账时自动将本期期末结转至下期期初

### 3.3 状态流转
- **会计期间状态**：未开始(not_started) → 进行中(in_progress) → 已结账(closed)，已结账后不可修改凭证
- **年结期间**：特殊期间，is_year_end=true，用于年度结转
- **银行账户启用状态**：启用(enabled) ↔ 禁用(disabled)
- **会计科目启用状态**：启用(enabled) ↔ 禁用(disabled)，禁用后不可被新凭证引用

## 5. 开发顺序约束

### 5.1 必须顺序执行的任务
1. **P0-011-001 财务基础设置后端开发**（前端依赖后端接口）
2. **P0-011-001** → **P0-011-002 财务基础设置前端页面**

后端内部开发顺序（推荐按功能点优先级串行）：
1. 币种汇率CRUD（独立模块，无前置依赖）
2. 银行账户CRUD（独立模块）
3. 会计科目CRUD（核心配置项，树形结构较复杂）
4. 凭证字CRUD（独立模块）
5. 会计期间CRUD（核心配置项，与科目余额表关联）

### 5.2 可并行执行的任务
- 币种汇率CRUD、银行账户CRUD、凭证字CRUD三者完全独立，可并行开发
- 前端页面中币种汇率、银行账户、凭证字管理三个页面可并行开发
- 会计科目管理页面和会计期间管理页面可并行开发（各自独立页面类型）
