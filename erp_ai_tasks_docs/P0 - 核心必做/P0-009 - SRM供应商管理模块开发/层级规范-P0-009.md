## 1. 模块架构约束

### 1.1 模块定位
P0-009负责开发ERP系统的SRM供应商管理功能，包括供应商档案管理、供应商分类（树形）、标签管理、联系人/地址/附件/评价/财务配置管理、供应商画像、供应商品类管理、供应商准入管理。本模块为采购模块（P1-006）提供供应商基础数据支撑，为应付管理（P1-009）提供供应商财务配置数据。

### 1.2 依赖关系
- 前置依赖：
  - P0-001（后端框架）
  - P0-002（前端框架）
  - P0-003（数据库提供srm_*系列表）
  - P0-004（认证与权限）
  - P0-005（公共组件提供页面基座/选择器）
  - P0-006（组织架构提供公司/部门/员工数据）
  - P0-007（商品管理提供商品数据——供应商品类可能关联商品）
- 后续依赖：
  - P1-006（采购管理）——引用供应商数据（询价/采购订单/入库等）
  - P1-009（应付管理）——引用供应商财务配置（付款/发票/核销等）

### 1.3 技术约束
- **技术栈约束**：Spring Boot 3.4.x + MyBatis-Plus 3.5.5 + Redis（缓存）+ Vue3 + Element Plus + Vxe Table
- **性能约束**：供应商列表查询 < 200ms（10万供应商）；供应商画像聚合接口 ≤ 500ms
- **安全约束**：供应商数据按数据权限过滤（owner_id/owner_dept_id）；供应商名称同一公司主体下唯一

## 2. 数据模型关系

### 2.1 核心数据表
| 表名 | 说明 | 关键字段 |
|------|------|---------|
| srm_supplier | 供应商主表 | supplier_code, supplier_name, short_name, class_id, purchaser_id, purchase_dept_id, company_id, source, status |
| srm_supplier_class | 供应商分类表 | class_name, parent_id, sort_order, is_enabled |
| srm_tag_definition | 供应商标签定义表 | tag_name, tag_color, tag_group, sort_order |
| srm_supplier_contact | 供应商联系人表 | supplier_id, contact_name, nickname, gender, is_default, position |
| srm_supplier_comm | 供应商联系方式表 | supplier_id, contact_id, comm_type, comm_value, comm_label, is_default |
| srm_supplier_address | 供应商地址表 | supplier_id, address_type, country, province, city, district, detail_address, is_default |
| srm_supplier_tag_rel | 供应商标签关联表 | supplier_id, tag_id |
| srm_supplier_attachment | 供应商附件表 | supplier_id, file_name, file_path, file_size |
| srm_supplier_evaluation | 供应商评价表 | supplier_id, evaluator_id, quality_score, delivery_score, service_score, price_score, total_score |
| srm_supplier_finance | 供应商财务配置表 | supplier_id, currency, invoice_type, settlement_method, payable_limit, tax_no, bank_account |

### 2.2 表关系图
- `srm_supplier_class`（树形自引用）1:N `srm_supplier`：分类与供应商一对多
- `srm_supplier` 1:N `srm_supplier_contact` → `srm_supplier_contact` 1:N `srm_supplier_comm`：供应商-联系人-联系方式三级
- `srm_supplier` 1:N `srm_supplier_address`：供应商与地址一对多（发货/收票/其他）
- `srm_supplier` N:N `srm_tag_definition`（通过srm_supplier_tag_rel）：供应商与标签多对多
- `srm_supplier` 1:N `srm_supplier_attachment`：供应商与附件一对多
- `srm_supplier` 1:N `srm_supplier_evaluation`：供应商与评价一对多
- `srm_supplier` 1:1 `srm_supplier_finance`：供应商与财务配置一对一
- `srm_supplier` 1:N `srm_supplier_qualification`：供应商与准入记录一对多
- `srm_supplier_category` N:N `srm_supplier`：品类与供应商多对多关联

### 2.3 数据流转
1. **供应商新增流程**：选择分类 → 填写基本信息 → 编码引擎生成供应商编码 → 名称唯一性校验 → 选择公司主体 → 保存供应商主表 → 可继续维护联系人/地址/标签/附件/评价/财务配置
2. **供应商准入流程**：选择供应商 → 新增准入记录 → 提交审核（待提交→待审核）→ 审核通过/驳回 → 通过后归档（已归档不可回退）
3. **供应商评价流程**：选择供应商 → 新增评价 → 填写质量/交期/服务/价格四项评分 → 系统自动计算综合评分 → 保存评价记录

## 3. 业务流程

### 3.1 核心业务流程
1. **SRM后端开发**（P0-009-001）：
   - 供应商分类CRUD（树形结构）
   - 标签定义CRUD
   - 供应商主表CRUD（含名称唯一性校验+公司主体范围校验）
   - 供应商联系人CRUD（主从保存+联系方式唯一性校验）
   - 供应商地址/附件/评价/财务配置CRUD
   - 供应商标签批量绑定/解绑（事务保证）
   - 供应商品类CRUD（含供应商关联校验）
   - 供应商准入CRUD（含准入状态流转+操作日志记录）
   - 供应商画像聚合接口 + SRM工作台聚合接口
2. **SRM前端页面**（P0-009-002）：
   - SRM工作台（P02）
   - 供应商中心（P03主从列表+P06主从表单，关联信息区含7个标签页）
   - 供应商分类（P05树形列表）
   - 各子功能列表页（P04）+ 表单页（P07）
   - 供应商画像（P12画像页）
   - 供应商准入（P04列表+P07弹窗大，含附件上传+状态流转）

### 3.2 业务规则
- **功能点优先级**：12个基线功能点按顺序开发；V11.0补充的供应商品类、供应商准入作为扩展项在基线完成后开发
- **供应商名称唯一性**：供应商名称在同一公司主体下必须唯一
- **联系人联系方式唯一性**：同一供应商下联系方式值（手机号/邮箱）需唯一性参数控制
- **供应商评价综合评分**：综合评分按"质量×0.3 + 交期×0.25 + 服务×0.25 + 价格×0.2"公式自动计算，前端与后端均保留校验逻辑
- **供应商准入状态流转**：按"待提交→待审核→已通过/已驳回→已归档"顺序流转，已归档后不可回退，状态变更需记录操作日志
- **品类关联校验**：删除供应商品类前需校验是否有关联供应商，存在关联时禁止删除并返回关联清单

### 3.3 状态流转
- **供应商审核状态**：草稿(draft) → 待审核(pending) → 已审核(approved) → 已禁用(disabled)
- **供应商准入状态**：待提交(pending_submit) → 待审核(pending_review) → 已通过(approved) / 已驳回(rejected) → 已归档(archived)
- **供应商启用状态**：启用(enabled) ↔ 禁用(disabled)

## 5. 开发顺序约束

### 5.1 必须顺序执行的任务
1. **P0-009-001 SRM后端开发**（前端依赖后端接口）
2. **P0-009-001** → **P0-009-002 SRM前端页面**

后端内部开发顺序：
1. 供应商分类CRUD（供应商主表依赖分类树）
2. 标签定义CRUD（供应商标签关联依赖标签定义）
3. 供应商主表CRUD（联系人/地址/标签等依赖供应商主表）
4. 联系人/地址/标签/附件/评价/财务配置CRUD
5. 供应商品类CRUD → 供应商准入CRUD（V11.0扩展项）
6. 供应商画像聚合接口 + 工作台聚合接口

### 5.2 可并行执行的任务
- 供应商联系人、供应商地址、供应商附件、供应商评价、供应商财务配置CRUD可并行
- 供应商品类和供应商准入CRUD可并行（均为V11.0扩展项）
- 前端页面中各子功能列表页/表单页可并行开发
- 供应商画像页面与供应商评价/财务配置页面可并行开发
