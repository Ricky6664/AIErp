# P0-009 SRM供应商管理模块开发 - 模块开发指南

## 一、模块概述

- **模块定位**：供应商档案管理 + 供应商分类 + 标签 + 联系人/地址/附件/评价/财务配置 + 供应商画像 + 供应商品类 + 供应商准入，为采购模块提供供应商基础数据支撑
- **前置依赖**：P0-001（后端框架）、P0-002（前端框架）、P0-003（数据库）、P0-004（认证与权限）、P0-005（公共组件）、P0-006（组织架构提供公司/部门/员工数据）、P0-007（商品管理提供商品数据）
- **被依赖方**：P1-006（采购管理）、P1-009（应付管理）
- **开发阶段**：阶段五（基础数据）

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |
|--------|---------|------|---------|

| 循环引用检查 | 新增/修改 | parent_id不能指向自身或子孙分类 | "不能将分类设为自身或其子分类的下级" |
| 删除前关联检查 | 删除 | 检查子分类+供应商是否引用 | "该分类下存在子分类或供应商，无法删除" |

## 八、模块级专属约束

1. **功能点优先级**：设计文档11.4节定义的12个功能点（工作台/供应商中心/供应商分类/标签定义/供应商基本信息/供应商联系人/供应商地址/供应商标签/供应商画像/供应商附件/供应商评价/供应商财务配置）按顺序开发；V11.0补充的供应商品类、供应商准入作为扩展项在基线完成后开发。
2. **供应商名称唯一性**：供应商名称在同一公司主体下必须唯一，新增/修改时需进行唯一性校验，校验失败时返回明确的业务异常提示。
3. **联系人联系方式唯一性**：同一供应商下联系方式值（手机号/邮箱）需进行唯一性参数控制，防止重复录入。
4. **供应商评价综合评分**：综合评分需按"质量×0.3 + 交期×0.25 + 服务×0.25 + 价格×0.2"公式自动计算，前端与后端均保留校验逻辑。
5. **供应商准入状态流转**：供应商准入状态按"待提交→待审核→已通过/已驳回→已归档"顺序流转，已归档后不可回退，状态变更需记录操作日志。
6. **品类关联校验**：删除供应商品类前需校验是否有关联供应商，存在关联时禁止删除并返回关联供应商清单。
