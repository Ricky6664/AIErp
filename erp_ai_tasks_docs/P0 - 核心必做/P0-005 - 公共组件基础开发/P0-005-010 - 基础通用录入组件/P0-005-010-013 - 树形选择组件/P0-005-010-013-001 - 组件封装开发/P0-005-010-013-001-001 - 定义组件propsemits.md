### 5.1 核心功能
针对「001 - 组件封装开发」定义组件Props/Emit接口：
1. 定义TypeScript接口类型(Props接口 + Emit接口 + 内部State类型)
2. 使用defineProps<T>()声明Props(withDefaults设置默认值)
3. 使用defineEmits<T>()声明Events(类型安全的事件签名)
4. 定义组件Exposed方法(defineExpose暴露给父组件调用的方法)
5. 编写TypeScript类型单元测试(类型兼容性验证)
### 5.2 数据交互
- Props接口定义：
- modelValue: any - 组件值v-model
- disabled: boolean - 禁用/只读
- fieldConfig: FieldConfig - 字段配置
- rules: ValidatorRule[] - 校验规则
- placeholder: string - 占位提示

- Events接口定义：
- update:modelValue - 值变更
- focus - 获取焦点
- blur - 失去焦点
- validate - 校验结果

- Slots接口定义：
- prefix - 前缀插槽
- suffix - 后缀插槽
- append - 追加内容插槽

- Expose接口定义：
  - validate(): Promise<boolean> - 校验方法
  - reset(): void - 重置方法
### 5.3 关键逻辑
1. Props类型约束：使用TypeScript interface定义严格类型
2. 默认值设置：withDefaults确保Props未传时有合理默认值
3. 运行时校验：props validator函数校验运行时传入值
4. Emit类型安全：defineEmits泛型确保事件名和参数类型正确
5. 文档注释：每个Props/Emit添加JSDoc注释说明用途
### 5.4 验证
1. TypeScript类型编译无报错
2. Props默认值在未传时正确生效
3. Props类型校验运行时不报错
4. Emit事件签名类型安全
5. defineExpose方法可被父组件正确调用

## 八、易错警示

> ⚠️ v-model双向绑定必须通过emit('update:modelValue')触发，不能直接修改props

> ⚠️ 组件defineProps使用TypeScript类型定义(defineProps<{...}>())而非运行时声明

> ⚠️ 表格大数据量(>1000行)使用vxe-table虚拟滚动，避免DOM节点过多导致卡顿
