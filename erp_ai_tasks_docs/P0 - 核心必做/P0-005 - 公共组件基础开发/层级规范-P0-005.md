## 1. 模块架构约束

### 1.1 模块定位
P0-005是ERP系统前端组件库的核心，负责开发15种页面类型基座组件、20种录入组件、3种字典组件、42种业务选择器、业务增强组件、组合式函数，以及数据字典管理和系统参数管理后端+前端。本模块为所有业务页面提供统一渲染基座，业务模块开发者通过传入视图编号和配置参数即可渲染完整页面，实现"配置驱动"的开发模式。

### 1.2 依赖关系
- 前置依赖：P0-001（后端框架提供字典/参数API）、P0-002（前端框架提供组件渲染环境）
- 后续依赖：P0-006~P0-012（全部基础数据模块）、P1全部模块、P2全部模块（所有前端业务页面均依赖公共组件库）

### 1.3 技术约束
- **技术栈约束**：Vue 3.x Composition API + Element Plus 2.x + Vxe Table 4.x + TinyMCE（富文本）+ SortableJS（拖拽排序）
- **性能约束**：表格组件渲染1000行数据 < 500ms；字典下拉组件首次加载 < 200ms（缓存后续 < 50ms）；选择器弹窗打开 < 100ms
- **安全约束**：富文本内容XSS过滤；文件上传类型/大小限制；组件props严格类型校验

## 2. 数据模型关系

### 2.1 核心数据表
| 表名 | 说明 | 关键字段 |
|------|------|---------|
| sys_dict_type | 字典类型表 | dict_type_code(唯一), dict_type_name, status, sort_order |
| sys_dict_data | 字典数据表 | dict_type_id, dict_value, dict_label, sort_order, status, css_class |
| sys_param | 系统参数表 | param_group, param_code(唯一), param_name, param_value, value_type(string/number/boolean/json) |

### 2.2 表关系图
- `sys_dict_type` 1:N `sys_dict_data`：一个字典类型包含多个字典项，按sort_order排序
- `sys_param`：独立表，按param_group分组管理
- 组件层不直接管理数据库表，通过props/emits与业务页面交互

### 2.3 数据流转
1. **字典组件数据流**：字典下拉组件挂载 → 根据dict_type_code请求/api/system/dict/data/by-code/{dictTypeCode} → 后端Redis缓存命中返回 → 组件缓存到本地 → 字典变更时@CacheEvict刷新
2. **系统参数数据流**：前端paramStore一次性拉取/api/system/params → 缓存到Pinia → 业务组件通过paramCode读取参数值 → 数值精度/分页大小等由参数驱动
3. **页面类型组件数据流**：业务页面传入viewCode → useDataView加载视图字段元数据 → 页面类型组件根据字段配置动态渲染查询区/表格/表单

## 3. 业务流程

### 3.1 核心业务流程
1. **基础通用录入组件**（P0-005-010）：开发20种录入组件（文本/数字/日期/开关/单选/多选/树形选择/附件/图片/富文本等），每种均支持v-model+:disabled+字段配置集成
2. **常用查询区组件**（P0-005-001）：开发QueryPanel.vue（模糊查询+常用字段筛选+折叠展开）
3. **功能操作区组件**（P0-005-002）：开发ActionBar.vue（列表页/表单页按钮布局+头部扩展工具栏）
4. **列表数据表格组件**（P0-005-003）：开发ListTable.vue（Vxe Table封装+列排序/筛选/格式设置/行高/合计）
5. **录入数据表格组件**（P0-005-004）：开发EntryTable.vue（可编辑表格+行拖拽+单元格渲染引擎）
6. **关联信息区/明细从表区域**（P0-005-005/006）：开发RelatedInfoArea.vue + DetailTableArea.vue
7. **主表单录入区组件**（P0-005-007）：开发MasterForm.vue（表单渲染器+布局配置+校验引擎+联动引擎）
8. **标签页容器组件**（P0-005-008）：开发TabPageContainer.vue
9. **15种页面类型基座组件**（P0-005-009）：组装P01~P15页面类型（依赖P0-005-001~008全部基础组件）
10. **字典类下拉组件**（P0-005-011）：开发3种字典组件（通用下拉/多选/级联）
11. **ERP业务选择器**（P0-005-012）：开发7大体系42种选择器（客户/供应商/商品/仓库/组织/财务/生产）
12. **通用业务功能组件**（P0-005-013）：开发引入/下推/复制/草稿/审核/打印/导出/导入/审批/附件/消息/比对等16种组件
13. **业务增强组件**（P0-005-014）：开发BOM配方/费用分摊/省市区/预警/库存可用量/字段配置设计器等
14. **组合式函数**（P0-005-015）：开发usePageState/useTableConfig/useFieldConfig/usePermission/useDataView/useCodeRule
15. **数据字典管理**（P0-005-016）：后端CRUD+Redis缓存+前端管理页面
16. **系统参数管理**（P0-005-017）：后端CRUD+Redis缓存+前端管理页面

### 3.2 业务规则
- **组件驱动原则**：所有页面类型（P01-P15）必须开发为独立可复用的页面类型组件，业务模块通过配置驱动渲染，不单独开发页面
- **录入组件统一接口**：所有20种录入组件必须支持v-model受控模式+:disabled只读模式+字段配置集成
- **表格列配置持久化**：ListTable和EntryTable的列显隐/顺序/宽度/固定列设置必须持久化到localStorage（用户级），同时支持后端API跨设备同步
- **字典组件缓存策略**：首次加载后缓存到本地，通过Redis @Cacheable保证后端缓存命中
- **业务选择器懒加载**：所有树形选择器必须支持异步懒加载子节点
- **组合式函数命名规范**：所有composables必须以use前缀命名

### 3.3 状态流转
- **页面状态（usePageState）**：新增态(add) ↔ 编辑态(edit) ↔ 详情态(detail)，含数据脏检测+离开拦截
- **字典状态**：启用(enabled) ↔ 禁用(disabled)，禁用后字典组件不加载该类型数据
- **参数值类型**：string / number / boolean / json，参数值类型在新增时确定，修改时校验一致性

## 4. 接口契约

### 4.1 对外接口
| 接口路径 | 方法 | 说明 |
|---------|------|------|
| /api/system/dict/type | GET/POST | 字典类型列表查询/新增 |
| /api/system/dict/type/{id} | GET/PUT/DELETE | 字典类型详情/修改/删除 |
| /api/system/dict/data/by-code/{dictTypeCode} | GET | 按字典类型编码查询字典数据（供组件使用） |
| /api/system/dict/cache/refresh | POST | 手动刷新字典缓存 |
| /api/system/param | GET/POST | 系统参数列表查询/新增 |
| /api/system/param/{id} | GET/PUT/DELETE | 系统参数详情/修改/删除 |
| /api/system/param/by-code/{paramCode} | GET | 按编码查询参数值 |
| /api/system/param/by-group/{group} | GET | 按分组查询参数列表 |
| /api/system/params | GET | 一次性拉取全部系统参数（供前端paramStore） |
| /api/system/param/cache/refresh | POST | 手动刷新参数缓存 |

### 4.2 依赖接口
- P0-001-007提供的系统参数服务基础（sys_param表+Redis缓存机制）
- P0-003-002提供的sys_dict_type/sys_dict_data/sys_param数据表
- P0-002提供的Vue3+Element Plus+Vxe Table组件渲染环境
- 后续业务模块提供的各业务选择器数据接口（客户/供应商/商品/仓库等列表）
