### 5.1 核心功能
针对「001 - 前端页面开发」实现数据绑定与交互逻辑：
1. 封装API调用层(useApi composable或axios请求封装)，定义请求/响应TypeScript类型
2. 实现数据加载逻辑(分页查询/详情加载)，绑定到组件响应式状态
3. 实现数据变更事件处理(增删改操作 -> API调用 -> 状态刷新)
4. 实现路由跳转与页面间参数传递(useRouter + query/params)
5. 集成加载状态(loading骨架屏/Spinner)和异常处理(ErrorBoundary)
### 5.2 数据交互
- API请求封装：
  - useApi().getList<T>(params) -> Promise<PageResult<T>>
  - useApi().getDetail<T>(id) -> Promise<T>
  - useApi().save(data) -> Promise<void>

- 数据绑定：
  - tableData: ref<T[]>([]) - 列表数据
  - formData: reactive<T>({}) - 表单数据
  - loading: ref<boolean>(false) - 加载状态
### 5.3 关键逻辑
1. onMounted -> 调用getList加载初始数据 -> 绑定到tableData
2. handleSearch -> 组装查询参数 -> 调用getList -> 更新tableData
3. handleSave -> 表单校验 -> 调用save API -> 成功后刷新列表
4. handleDelete -> 确认弹窗 -> 调用delete API -> 成功后刷新列表
5. watch(查询参数) -> 防抖300ms -> 自动触发handleSearch
### 5.4 验证
1. API调用参数组装正确(分页/排序/筛选参数)
2. 响应数据正确绑定到组件(列表/表单/详情)
3. 增删改操作后数据正确刷新
4. loading状态正确显示/隐藏
5. 路由跳转参数传递正确
