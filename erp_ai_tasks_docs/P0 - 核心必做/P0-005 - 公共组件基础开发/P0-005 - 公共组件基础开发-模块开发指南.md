# P0-005 公共组件基础开发 - 模块开发指南

## 一、模块概述

- **模块定位**：15种页面类型基座组件 + 20种录入组件 + 3种字典组件 + 42种业务选择器 + 业务增强组件 + 组合式函数 + 数据字典管理 + 系统参数管理，为所有业务页面提供统一渲染基座
- **前置依赖**：P0-001（后端框架）、P0-002（前端框架）
- **被依赖方**：P0-006~P0-012（全部基础数据模块）、P1全部模块、P2全部模块
- **开发阶段**：阶段四（测试与公共组件）

### 子模块详细说明

#### P0-005-001 常用查询区组件（QueryPanel.vue）
- 多字段模糊查询区（上部分：或关系匹配多字段，搜索框+搜索字段下拉选择）
- 常用字段查询区（下部分：且关系组合筛选，根据字段配置动态渲染筛选条件）
- 查询区折叠/展开控制（超过3行自动折叠/展开切换按钮）

#### P0-005-002 功能操作区组件（ActionBar.vue）
- 列表页功能操作区（左右分排按钮布局：左侧主操作+右侧扩展操作）
- 表单页功能操作区（左右分排按钮布局：左侧保存/提交+右侧关闭）
- 头部扩展工具栏组件（铺满/刷新/格式设置/行高调整下拉面板）

#### P0-005-003 列表数据表格组件（ListTable.vue）
- Vxe Table基础封装（基于vxe-table组件封装、统一默认配置、事件代理）
- 列排序功能（服务端排序+客户端排序双模式）
- 列搜索筛选功能（按字段类型差异化筛选条件：文本模糊/数字范围/日期范围/字典勾选）
- 列格式自定义设置（显隐/顺序拖拽/列宽调整/固定列设置+持久化到localStorage）
- 行高度/字体大小7档设置（紧凑/较小/默认/较大/宽松/超大/超宽松）
- 一键初始化/一键清空搜索排序
- 表格合计列配置（接收后端计算返回的合计行数据并展示）
- 基础标配功能（选中行高亮/省略Tooltip/斑马纹/纵向边框/前端分页/服务端分页切换）

#### P0-005-004 录入数据表格组件（EntryTable.vue）
- Vxe Table可编辑封装（基于vxe-table edit模式、单元格编辑态/展示态切换）
- 行拖拽改序（SortableJS集成+行号自动重排）
- 列格式自定义设置（同ListTable列格式设置逻辑复用）
- 行高度/字体大小7档设置（同ListTable）
- 表格合计列配置（前端实时计算合计行，根据列配置的合计公式）
- 录入组件单元格渲染引擎（根据字段配置的field_type自动渲染对应录入组件）
- 详情只读态自动转禁用（根据页面状态将全部编辑组件切换为只读文本展示）

#### P0-005-005 关联信息区组件（RelatedInfoArea.vue）
- 左侧分组导航栏（点击分组展开/折叠子项）
- 右侧标签页容器（多标签页切换+标签页懒加载）
- 标签页显隐权限配置支持（根据字段权限控制标签页显示/隐藏）
- 数据刷新机制（单击主行刷新当前标签页/切换标签页自动刷新）
- 头部扩展工具栏（新增按钮/放大查看按钮）

#### P0-005-006 明细从表区域组件（DetailTableArea.vue）
- 纯标签页模式容器（多个从表标签页切换+懒加载）
- 头部扩展工具栏（添加x行/铺满按钮）
- 区域铺满切换（主表单铺满/明细铺满双模式切换）

#### P0-005-007 主表单录入区组件（MasterForm.vue）
- 表单字段渲染器（FormField.vue：根据字段配置自动渲染录入组件+标签+校验提示）

- 表单校验引擎（必填/条件必填/正则/跨字段联合/唯一性/后端异步校验规则链）
- 表单联动引擎（联动带出值/自动计算/显隐联动/数据联动过滤）

#### P0-005-008 标签页容器组件（TabPageContainer.vue）

## 四、模块级专属约束

1. **组件驱动原则**：所有页面类型（P01-P15）必须开发为独立可复用的页面类型组件，每个功能点页面通过配置驱动渲染，不单独开发页面。业务模块开发者通过传入视图编号和配置参数即可渲染完整页面。
2. **录入组件统一接口**：所有20种录入组件必须支持v-model受控模式、:disabled只读模式、字段配置集成（field_type映射+校验规则绑定+联动规则绑定），保证在任何页面类型中行为一致。
3. **表格组件列配置持久化**：ListTable和EntryTable的列显隐/顺序/宽度/固定列设置必须持久化到localStorage（用户级），同时支持后端API保存以实现跨设备同步。
4. **字典组件缓存策略**：字典类下拉组件首次加载后缓存字典数据到本地，通过Redis @Cacheable保证后端缓存命中，字典变更后通过@CacheEvict自动刷新。
5. **业务选择器懒加载**：所有树形选择器（客户分类/供应商分类/商品分类/部门树/科目树）必须支持异步懒加载子节点，避免一次性加载全量数据。
6. **组合式函数命名规范**：所有composables必须以use前缀命名（usePageState/useTableConfig/useFieldConfig/usePermission/useDataView/useCodeRule），返回响应式状态和方法供页面组件调用。
7. **数据字典与系统参数迁入说明**：P0-005-016和P0-005-017从P2-013迁入P0阶段，目的是在P1业务模块开发前就提供字典管理和参数管理界面，确保P1模块可直接使用字典下拉组件绑定字典源、通过参数编码读取系统参数值。
