## 五、详细开发规格


> **📦 本任务模块上下文**（来源：P0-005模块开发指南）
> - 本模块涉及数据表：sys_dict_type, sys_dict_data, sys_param
> - 本模块涉及API：/api/system/dict/type, /api/system/dict/type/batch-status, /api/system/dict/type/import, /api/system/dict/type/export, /api/system/dict/data
> - 本模块业务规则：组件驱动原则：所有页面类型（P01-P15）必须开发为独立可复用的页面类型组件，每个功能点页面通过配置驱动渲染，不单独开发页面。业务模块开发者通过传入视图编号和配置参数即可渲染完整页面。; 录入组件统一接口：所有20种录入组件必须支持v-model受控模式、:disabled只读模式、字段配置集成（field_type映射+校验规则绑定+联动规则绑定），保证在任何页面类型中行为一致。
>
> 💡 开发本任务时，请结合上述模块上下文理解业务场景和数据关系。### 5.1 页面搭建
基于P10组件演示基座组件搭建，页面标题"通用数据导入弹窗表格"
- 使用VxeTable定义查询结果表格列配置
- 列配置包含：字段名、标题、宽度、对齐、格式化、排序

### 5.2 数据绑定
- 主查询：GET /api/common/import/template（查询接口）
- 响应式数据：导入模板列, 数据行, 校验结果, 导入进度
- 查询参数：分页参数(pageNum, pageSize)、排序参数(sortField, sortOrder)
- 列格式化：日期格式化、金额千分位、状态字典翻译、百分比显示

### 5.3 交互逻辑
- 搜索：表格列支持列头排序、列宽拖拽调整
- 表格操作：行单击选中、行双击打开详情、右键菜单、列固定
- 表单校验：N/A（表格展示层）

### 5.4 组件集成
- 使用ImportDialog, VxeTable, TemplateDownload, ImportProgress, ValidationErrors
- 列配置使用columns数组定义，支持动态列
- 自定义列渲染使用slots（如状态标签、操作按钮）
- 大数据量启用virtualScroll虚拟滚动
