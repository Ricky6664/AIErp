## 五、详细开发规格


> **📦 本任务模块上下文**（来源：P0-005模块开发指南）
> - 本模块涉及数据表：sys_dict_type, sys_dict_data, sys_param
> - 本模块业务规则：所有20种录入组件必须支持v-model受控模式、:disabled只读模式、字段配置集成（field_type映射+校验规则绑定+联动规则绑定）。

### 5.1 组件Props
- modelValue: any - v-model双向绑定值
- fieldConfig: FieldConfig - 字段配置（类型/校验/联动规则）
- disabled: boolean - 只读/禁用模式
- placeholder: string - 占位提示

### 5.2 组件Events
- update:modelValue - 值变更事件（v-model双向绑定）
- change - 值确认变更事件
- focus/blur - 焦点事件

### 5.3 组件Slots
- prefix - 前缀插槽
- suffix - 后缀插槽
- default - 默认内容插槽

### 5.4 核心逻辑
1. setup()中声明响应式状态(ref/reactive)和计算属性(computed)
2. 实现v-model双向绑定（emit('update:modelValue', newValue)）
3. 集成字段配置（field_type映射组件类型+校验规则绑定+联动规则绑定）
4. 错误处理：try-catch包裹异步操作，错误信息统一展示

## 八、易错警示

> ⚠️ @ConfigurationProperties的prefix路径必须全小写、中划线分隔（如auth-config）

> ⚠️ 敏感配置（密码、密钥）不要写在application.yml中，使用环境变量或配置中心

> ⚠️ 配置类必须标注@Component或@EnableConfigurationProperties，否则不会生效
