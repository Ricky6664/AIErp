### 5.1 声明文件内容
```typescript
// src/types/global.d.ts

/** 通用键值对对象 */
declare type RecordObject<T = unknown> = Record<string, T>

/** 分页查询参数 */
declare interface PageQuery {
  pageNum: number
  pageSize: number
  [key: string]: unknown
}

/** 分页响应结果（对应后端PageResult<T>） */
declare interface PageResult<T> {
  records: T[]
  total: number
  pageNum: number
  pageSize: number
  pages: number
}

/** 统一API响应结构（对应后端R<T>） */
declare interface ApiResult<T = unknown> {
  code: number
  message: string
  data: T
}

/** 第三方库类型补全 */
declare interface Window {
  NProgress: {
    start: () => void
    done: () => void
    set: (n: number) => void
    inc: (amount?: number) => void
  }
}
```

### 5.2 关键设计点
| 类型 | 用途 | 注意事项 |
|------|------|---------|
| RecordObject<T> | 替代`Record<string, any>` | 默认T=unknown，强制使用者显式指定类型 |
| PageQuery | 所有分页请求的参数基类 | 业务查询DTO通过`extends PageQuery`扩展筛选条件 |
| PageResult<T> | 所有分页响应 | 泛型T为记录类型，与后端PageResult字段对齐 |
| ApiResult<T> | 统一API响应 | 与后端R<T>类的code/message/data字段对齐 |

### 5.3 使用示例
```typescript
// 业务代码中使用全局类型
import apiClient from '@/utils/request'

async function getSaleOrderPage(params: PageQuery & { billNo?: string }) {
  const { data } = await apiClient.get<ApiResult<PageResult<SaleOrderVO>>>(
    '/api/sale/order', { params }
  )
  return data.data  // 类型为 PageResult<SaleOrderVO>
}
```

## 八、易错警示

> ⚠️ 使用 declare global 包裹全局类型声明，确保模块作用域正确

> ⚠️ 避免使用 any 类型，优先使用 unknown 或具体泛型

> ⚠️ 第三方库类型补全不要与 @types/ 包冲突
