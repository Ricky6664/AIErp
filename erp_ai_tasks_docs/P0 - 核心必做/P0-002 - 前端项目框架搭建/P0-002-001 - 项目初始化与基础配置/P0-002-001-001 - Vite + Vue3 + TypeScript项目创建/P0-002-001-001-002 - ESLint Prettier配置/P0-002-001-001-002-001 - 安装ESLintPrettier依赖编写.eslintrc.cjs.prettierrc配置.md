### 5.1 依赖安装
```bash
pnpm add -D eslint@^8.x prettier@^3.x \
  eslint-plugin-vue@^9.x \
  @typescript-eslint/eslint-plugin@^6.x \
  @typescript-eslint/parser@^6.x \
  eslint-config-prettier \
  eslint-plugin-prettier
```

### 5.2 .eslintrc.cjs 配置
```js
module.exports = {
  root: true,
  env: { browser: true, es2021: true, node: true },
  parser: 'vue-eslint-parser',
  parserOptions: {
    parser: '@typescript-eslint/parser',
    ecmaVersion: 'latest',
    sourceType: 'module'
  },
  extends: [
    'plugin:vue/vue3-recommended',
    'plugin:@typescript-eslint/recommended',
    'plugin:prettier/recommended',   // 必须在最后
    'prettier'                       // eslint-config-prettier 关闭冲突规则
  ],
  rules: {
    'vue/multi-word-component-names': 'off',
    '@typescript-eslint/no-explicit-any': 'warn',
    '@typescript-eslint/no-unused-vars': ['error', { argsIgnorePattern: '^_' }]
  }
}
```
- `extends` 顺序至关重要：`prettier` 必须放最后，否则会与 ESLint 规则冲突
- `parser: 'vue-eslint-parser'` 处理 `<template>` 部分，`parserOptions.parser` 处理 `<script>` 部分

### 5.3 .prettierrc 配置
```json
{
  "semi": false,
  "singleQuote": true,
  "tabWidth": 2,
  "printWidth": 100,
  "trailingComma": "none",
  "arrowParens": "always",
  "endOfLine": "lf"
}
```

### 5.4 忽略文件
- `.eslintignore`：`dist`、`node_modules`、`*.d.ts`、`auto-imports.d.ts`、`components.d.ts`
- `.prettierignore`：`dist`、`node_modules`、`pnpm-lock.yaml`

### 5.5 package.json scripts
```json
{
  "lint": "eslint . --ext .vue,.js,.jsx,.cjs,.mjs,.ts,.tsx,.cts,.mts --fix",
  "format": "prettier --write \"src/**/*.{vue,ts,tsx,css,scss,json}\""
}
```

### 5.6 关键配置项说明
| 配置项 | 作用 | 注意事项 |
|--------|------|----------|
| `eslint-config-prettier` | 关闭与 Prettier 冲突的 ESLint 规则 | 必须在 extends 最后 |
| `eslint-plugin-prettier` | 将 Prettier 规则作为 ESLint 规则运行 | 通过 `plugin:prettier/recommended` 引入 |
| `vue-eslint-parser` | 解析 `.vue` 文件的 `<template>` 部分 | ESLint 8.x 必须显式指定 |
| `.cjs` 后缀 | package.json 有 `"type": "module"` 时 ESLint 配置必须用 CJS 格式 | 否则报 ERR_REQUIRE_ESM |
