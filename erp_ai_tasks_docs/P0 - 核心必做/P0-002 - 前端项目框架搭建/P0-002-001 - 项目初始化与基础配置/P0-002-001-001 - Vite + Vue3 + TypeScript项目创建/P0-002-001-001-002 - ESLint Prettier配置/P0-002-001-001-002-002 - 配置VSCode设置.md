### 5.1 .vscode/settings.json
创建项目级 VSCode 配置，确保团队成员统一编辑器行为：
```json
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit"
  },
  "[vue]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[typescript]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[javascript]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[json]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[scss]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "eslint.validate": [
    "javascript",
    "javascriptreact",
    "typescript",
    "typescriptreact",
    "vue"
  ],
  "files.eol": "\n"
}
```

### 5.2 .vscode/extensions.json
推荐团队成员安装的扩展：
```json
{
  "recommendations": [
    "vue.volar",
    "dbaeumer.vscode-eslint",
    "esbenp.prettier-vscode"
  ]
}
```

### 5.3 关键配置项说明
| 配置项 | 作用 | 注意事项 |
|--------|------|----------|
| `editor.formatOnSave` | 保存时自动运行 Prettier 格式化 | 必须配合 `defaultFormatter` 使用 |
| `source.fixAll.eslint` | 保存时自动修复 ESLint 可修复的错误 | `"explicit"` 表示仅手动保存时触发 |
| `eslint.validate` | 指定 ESLint 检查的文件类型 | 必须包含 `vue` 否则 `.vue` 文件不检查 |
| `[vue].defaultFormatter` | 指定 `.vue` 文件的格式化工具 | 必须设为 Prettier 而非 ESLint |
| `files.eol` | 统一行尾为 LF | 避免 Windows CRLF 导致 Prettier 报错 |

### 5.4 环境适配
- `.vscode/settings.json` 优先级高于用户级 VSCode 设置，团队成员打开项目自动生效
- 需要每位开发者安装 VSCode 扩展：ESLint（dbaeumer.vscode-eslint）和 Prettier（esbenp.prettier-vscode）
- `.vscode/` 目录应纳入 Git 版本控制，确保团队统一
- 如开发者使用 WebStorm，需在 `.idea/` 中做等效配置（不在本任务范围）

## 八、易错警示

> ⚠️ `.vscode/settings.json` 是项目级配置，会覆盖用户级设置，必须提交到 Git 仓库

> ⚠️ `editor.defaultFormatter` 的扩展 ID 必须准确：Prettier 是 `esbenp.prettier-vscode`，ESLint 是 `dbaeumer.vscode-eslint`

> ⚠️ `editor.tabSize` 应与 `.prettierrc` 的 `tabWidth: 2` 保持一致（VSCode 默认从 Prettier 配置读取）
