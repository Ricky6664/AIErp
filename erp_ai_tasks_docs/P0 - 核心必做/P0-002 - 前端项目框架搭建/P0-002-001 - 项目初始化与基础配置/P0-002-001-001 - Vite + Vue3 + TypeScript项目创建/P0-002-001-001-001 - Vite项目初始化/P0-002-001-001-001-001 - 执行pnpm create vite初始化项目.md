### 5.1 项目初始化流程
1. **执行脚手架命令**：在目标目录下运行 `pnpm create vite@latest erp-ai-web --template vue-ts`
   - `--template vue-ts`：指定使用 Vue + TypeScript 模板（非普通 vue 模板）
   - 生成的项目名：`erp-ai-web`
2. **验证生成目录结构**：
   ```
   erp-ai-web/
   ├── index.html
   ├── package.json
   ├── tsconfig.json
   ├── tsconfig.app.json
   ├── tsconfig.node.json
   ├── vite.config.ts
   ├── public/
   └── src/
       ├── App.vue
       ├── main.ts
       └── style.css
   ```
3. **配置 package.json**：
   - `name`: `"erp-ai-web"`
   - `version`: `"0.1.0"`
   - `type`: `"module"`（Vite 默认已设置）
   - `scripts` 完整配置：
     ```json
     {
       "dev": "vite",
       "build": "vue-tsc && vite build",
       "preview": "vite preview",
       "lint": "eslint . --ext .vue,.js,.jsx,.cjs,.mjs,.ts,.tsx,.cts,.mts --fix",
       "format": "prettier --write src/"
     }
     ```
4. **版本确认**：检查 package.json 中依赖版本
   - `vue`: `^3.5.x`
   - `typescript`: `^5.x`
   - `vite`: `^6.x`
   - `vue-tsc`: `^2.x`

### 5.2 关键配置项
1. **模板选择**：必须使用 `vue-ts`，生成 `.ts` 文件和 TypeScript 配置；普通 `vue` 模板不包含 TypeScript 支持
2. **包管理器**：必须使用 pnpm 9.x，生成 `pnpm-lock.yaml`；禁止使用 npm/yarn
3. **scripts 配置**：
   - `dev`：启动 Vite 开发服务器（默认 localhost:5173）
   - `build`：先执行 `vue-tsc` 类型检查，再执行 `vite build` 构建
   - `lint`：需后续配置 ESLint 后生效
   - `format`：需后续配置 Prettier 后生效

### 5.3 环境适配
- **Node.js 版本**：要求 Node.js 18+（Vite 6.x 最低要求）
- **pnpm 镜像源**：如内网访问慢，配置 `pnpm config set registry https://registry.npmmirror.com`
- **依赖安装**：初始化后需执行 `pnpm install` 安装基础依赖（vue、vite、typescript 等）
- **IDE 支持**：推荐 VSCode + Vue - Official 扩展（原 Volar）
