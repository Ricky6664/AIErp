## 五、详细开发规格

> **📦 验证任务说明**
> 本任务为验证任务，需逐项验证前置任务（执行pnpm create vite初始化项目）的交付物是否符合规格。

### 5.1 验证清单
| 序号 | 验证项 | 预期结果 | 验证方法 |
|:---:|--------|---------|---------|
| 1 | pnpm install 安装依赖 | 无 ERR 报错，生成 node_modules 和 pnpm-lock.yaml | 终端执行 `pnpm install` 检查退出码为 0 |
| 2 | pnpm dev 启动开发服务器 | 终端输出 `Local: http://localhost:5173/` | 执行 `pnpm dev` 观察终端输出 |
| 3 | 浏览器访问 localhost:5173 | 显示 Vite + Vue 默认欢迎页面，无控制台报错 | Chrome 打开并检查 DevTools Console |
| 4 | pnpm build 构建 | 终端无报错，生成 dist/ 目录 | 执行 `pnpm build` 检查退出码 |
| 5 | dist/ 目录结构 | 包含 index.html + assets/ 子目录（含 .js/.css 文件） | 文件管理器查看 dist/ 目录 |
| 6 | pnpm preview 预览 | localhost:4173 正常显示构建产物页面 | 执行 `pnpm preview` 并浏览器访问 |

### 5.2 测试方法
1. **依赖安装验证**：执行 `pnpm install`，确认无 ERR 级别日志，`node_modules/` 目录正常生成
2. **开发服务器验证**：
   - 执行 `pnpm dev`，确认终端输出 `VITE v6.x.x ready`
   - Chrome 打开 `http://localhost:5173`，确认页面渲染
   - 打开 DevTools → Console，确认无红色错误信息
3. **构建验证**：
   - 执行 `pnpm build`，确认 vue-tsc 类型检查和 vite build 均成功
   - 检查 dist/ 目录下 index.html 是否正确引用 assets 中的 JS/CSS 文件
4. **预览验证**：
   - 执行 `pnpm preview`，确认 `http://localhost:4173` 可访问
   - 页面内容与 dev 模式一致

### 5.3 问题处理
- **pnpm install 失败**：检查 Node.js 版本（需 18+）、pnpm 版本（需 9.x）、网络连通性
- **pnpm dev 端口占用**：检查 5173 端口是否被占用，或修改 vite.config.ts 中 `server.port`
- **pnpm build 类型检查失败**：vue-tsc 报错需检查 TypeScript 类型问题，参照后续 TypeScript 配置任务修复
- **dist 目录为空**：检查 vite.config.ts 中 `build.outDir` 配置是否为 `dist`

## 八、易错警示

> ⚠️ pnpm install 必须在项目根目录（erp-ai-web/）执行，不要在子目录执行

> ⚠️ 验证必须在 clean install 后进行，不要复用旧 node_modules

> ⚠️ pnpm dev 如遇端口 5173 占用，需先 kill 占用进程或修改 vite.config.ts 中 server.port
