### 5.1 环境变量读取方式
```ts
// Vite 通过 import.meta.env 暴露环境变量
const appTitle = import.meta.env.VITE_APP_TITLE          // string
const apiBaseUrl = import.meta.env.VITE_API_BASE_URL     // string
const useMock = import.meta.env.VITE_USE_MOCK === 'true' // boolean（手动转换）
const mode = import.meta.env.MODE                         // 'development' | 'production'
const isDev = import.meta.env.DEV                         // boolean
const isProd = import.meta.env.PROD                       // boolean
```

### 5.2 Axios baseURL 配置
```ts
// src/utils/request.ts
import axios from 'axios'

const service = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL as string,
  timeout: 15000
})
```

### 5.3 Mock 开关控制
```ts
// src/main.ts 或 src/utils/mock.ts
if (import.meta.env.VITE_USE_MOCK === 'true') {
  // 动态导入 mock 模块
  const { setupMock } = await import('@/mock')
  setupMock()
}
```

### 5.4 页面标题设置
```ts
// src/router/index.ts 或路由守卫中
document.title = import.meta.env.VITE_APP_TITLE as string
```

### 5.5 TypeScript 类型支持
在 `src/env.d.ts` 中声明变量类型（详见 TypeScript 全局类型声明任务）：
```ts
interface ImportMetaEnv {
  readonly VITE_APP_TITLE: string
  readonly VITE_API_BASE_URL: string
  readonly VITE_USE_MOCK: string
}
```

### 5.6 关键配置项
| 配置项 | 作用 | 注意事项 |
|--------|------|----------|
| `import.meta.env.VITE_*` | 读取自定义环境变量 | 仅 `VITE_` 前缀变量可用 |
| `import.meta.env.MODE` | 当前模式名 | `'development'` 或 `'production'` |
| `import.meta.env.DEV` | 是否开发模式 | Vite 内置，boolean |
| `import.meta.env.PROD` | 是否生产模式 | Vite 内置，boolean |
| `as string` 类型断言 | 告知 TS 变量类型 | 配合 env.d.ts 类型声明使用 |

### 5.7 环境适配
- `import.meta.env` 是 Vite 编译时静态替换，不是运行时读取
- 生产构建时 `import.meta.env.DEV` 会被替换为 `false`，相关代码会被 tree-shaking
- 不要在模板字符串中动态拼接环境变量名（如 `import.meta.env[\`VITE_${key}\`]`），Vite 无法静态分析
- 环境变量在构建后不可更改（已硬编码到产物中）

## 八、易错警示

> ⚠️ `import.meta.env` 的值都是字符串类型，布尔值必须 `=== 'true'` 转换

> ⚠️ 不要在运行时动态拼接环境变量名，Vite 在编译时静态替换

> ⚠️ 生产构建后环境变量值已硬编码到产物中，无法通过修改 `.env` 文件更改

> ⚠️ `import.meta.env` 只能在客户端代码中使用，`vite.config.ts` 中需使用 `loadEnv()`
