## 五、详细开发规格

> **📦 验证任务说明**

### 5.1 验证清单
| 序号 | 验证项 | 预期结果 | 验证方法 |
|:---:|--------|---------|---------|
| 1 | `.env.development` 文件存在且含正确变量 | VITE_API_BASE_URL=/api, VITE_USE_MOCK=true | 查看文件内容 |
| 2 | `.env.production` 文件存在且含正确变量 | VITE_API_BASE_URL=https://api.erp.com | 查看文件内容 |
| 3 | `.env.local` 被 .gitignore 忽略 | `git status` 不显示 .env.local | 检查 git 状态 |
| 4 | `pnpm dev` 加载 development 变量 | `import.meta.env.VITE_USE_MOCK` 为 `'true'` | Console 打印确认 |
| 5 | `pnpm build` 加载 production 变量 | `import.meta.env.VITE_USE_MOCK` 为 `'false'` | 构建后检查产物中的值 |
| 6 | `.env.local` 覆盖优先级正确 | 本地 VITE_API_BASE_URL 覆盖 .env.development | Console 打印确认 |
| 7 | 非 VITE_ 前缀变量不可读取 | 设置 `MY_VAR=xxx`，`import.meta.env.MY_VAR` 为 undefined | 添加测试变量验证 |

### 5.2 测试方法
1. **开发环境验证**：
   - 执行 `pnpm dev`
   - 在浏览器 Console 中执行 `console.log(import.meta.env)` 查看所有暴露的变量
   - 确认 `VITE_APP_TITLE`、`VITE_API_BASE_URL`、`VITE_USE_MOCK` 值正确
2. **生产构建验证**：
   - 执行 `pnpm build`
   - 在 dist/assets/ 中找到主 JS 文件
   - `grep` 搜索 `VITE_USE_MOCK` 对应的值（应为 `false`）
3. **本地覆盖验证**：
   - 在 `.env.local` 中设置 `VITE_APP_TITLE=本地测试`
   - 重启 `pnpm dev`
   - Console 打印确认覆盖生效
4. **忽略验证**：
   - 执行 `git status` 确认 `.env.local` 不在变更列表中

### 5.3 问题处理
- **环境变量 undefined**：确认变量名以 `VITE_` 开头，修改后需重启 `pnpm dev`
- **覆盖不生效**：确认 `.env.local` 文件名正确（不是 `.env.local.txt`）
- **生产构建中变量值不对**：检查 `.env.production` 文件内容，确认构建 mode 为 `production`
- **`.env.local` 被 git 追踪**：执行 `git rm --cached .env.local` 从追踪中移除
