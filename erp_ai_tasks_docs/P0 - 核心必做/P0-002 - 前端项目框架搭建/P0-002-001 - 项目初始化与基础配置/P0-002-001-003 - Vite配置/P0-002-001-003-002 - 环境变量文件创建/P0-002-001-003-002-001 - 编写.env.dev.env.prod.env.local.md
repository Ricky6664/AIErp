### 5.1 环境变量文件结构
```
erp-web/
├── .env                 # 所有模式共享的默认变量
├── .env.development     # pnpm dev 时加载
├── .env.production      # pnpm build 时加载
└── .env.local           # 本地覆盖（任何模式下都加载，gitignore）
```

### 5.2 .env（共享默认值）
```properties
# 所有环境共享的默认配置
VITE_APP_TITLE=ERP-AI
```

### 5.3 .env.development（开发环境）
```properties
# 开发环境变量
VITE_APP_TITLE=ERP-AI开发环境
VITE_API_BASE_URL=/api
VITE_USE_MOCK=true
VITE_WS_URL=ws://localhost:8080/ws
```

### 5.4 .env.production（生产环境）
```properties
# 生产环境变量
VITE_APP_TITLE=ERP-AI
VITE_API_BASE_URL=https://api.erp.com
VITE_USE_MOCK=false
VITE_WS_URL=wss://api.erp.com/ws
```

### 5.5 .env.local（本地覆盖）
```properties
# 本地覆盖（不纳入 Git 版本控制）
# 每个开发者可自定义本地配置
VITE_API_BASE_URL=http://localhost:8080/api
```

### 5.6 关键配置项
| 配置项 | 作用 | 注意事项 |
|--------|------|----------|
| `VITE_` 前缀 | Vite 只暴露 `VITE_` 前缀的变量到 `import.meta.env` | 无前缀的变量只能在 `vite.config.ts` 中通过 `loadEnv` 读取 |
| `.env.local` | 本地覆盖文件 | 必须加入 `.gitignore`，不提交到仓库 |
| `VITE_USE_MOCK` | Mock 开关 | 开发环境为 `true`，生产为 `false` |
| 值类型 | 所有值都是字符串 | 布尔值需手动转换：`env.VITE_USE_MOCK === 'true'` |

### 5.7 .gitignore 配置
确保 `.env.local` 被忽略：
```
# 环境变量本地覆盖文件
.env.local
.env.*.local
```

### 5.8 环境适配
- Vite 根据 `--mode` 参数决定加载哪个 `.env.[mode]` 文件
- `pnpm dev` 默认 mode 为 `development`，`pnpm build` 默认 mode 为 `production`
- `.env` 文件在所有模式下都会加载，优先级最低
- `.env.local` 优先级高于 `.env.[mode]`
- 修改 `.env` 文件后需要重启 `pnpm dev`（环境变量在启动时读取）

## 八、易错警示

> ⚠️ 环境变量名必须以 `VITE_` 开头，否则 `import.meta.env` 无法读取

> ⚠️ 所有环境变量值都是字符串类型，布尔值需 `=== 'true'` 判断

> ⚠️ 修改 `.env` 文件后必须重启 `pnpm dev`，变量在启动时一次性读取
