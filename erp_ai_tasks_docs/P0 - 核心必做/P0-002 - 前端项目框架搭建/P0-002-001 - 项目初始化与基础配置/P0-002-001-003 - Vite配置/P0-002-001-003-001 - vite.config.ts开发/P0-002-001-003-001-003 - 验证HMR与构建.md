## 五、详细开发规格

> **📦 验证任务说明**
> 本任务为验证任务，需逐项验证 vite.config.ts 中 HMR 热更新和生产构建配置是否符合规格。

### 5.1 验证清单
| 序号 | 验证项 | 预期结果 | 验证方法 |
|:---:|--------|---------|---------|
| 1 | HMR 热更新 | 修改 `.vue` 文件后浏览器无需刷新自动更新 | `pnpm dev` 后修改 App.vue 观察浏览器 |
| 2 | HMR 状态保持 | 修改样式不影响组件状态（如计数值保持） | 修改 CSS 后检查组件状态未重置 |
| 3 | `build.target: es2015` | 构建产物兼容 ES2015 语法 | `pnpm build` 后检查 dist/ 中无 ES2020+ 语法 |
| 4 | `build.outDir: dist` | 构建输出到 dist/ 目录 | 执行构建后确认 dist/ 目录生成 |
| 5 | `manualChunks` 分包 | dist/assets/ 中生成 vendor.js/vue.js/element-plus.js 独立 chunk | `ls dist/assets/` 查看文件名 |
| 6 | `chunkSizeWarningLimit: 1500` | chunk < 1500KB 无警告，> 1500KB 有终端警告 | 构建后观察终端是否有 warning |
| 7 | 构建产物总大小 | dist/ 总大小合理（< 2MB） | `du -sh dist/` 检查 |

### 5.2 测试方法
1. **HMR 测试**：
   - 执行 `pnpm dev` 启动开发服务器
   - 修改 `src/App.vue` 中模板文本，确认浏览器自动更新
   - 修改 CSS 样式，确认样式更新但组件状态保持
2. **构建测试**：
   - 执行 `pnpm build`
   - 检查 dist/ 目录下 assets/ 文件列表
   - 确认有类似 `vendor-xxx.js`、`vue-xxx.js`、`element-plus-xxx.js` 的独立 chunk
3. **兼容性测试**：
   - 检查构建产物中是否包含 ES2015+ 语法（如 `?.` 可选链操作符）
   - target: es2015 应将新语法转译为旧语法

### 5.3 问题处理
- **HMR 不生效**：检查 `@vitejs/plugin-vue` 是否在 plugins 中、浏览器是否支持 WebSocket
- **分包未生效**：检查 `rollupOptions.output.manualChunks` 配置格式是否正确
- **构建产物过大**：检查是否有依赖未被 manualChunks 分离、是否意外全量引入了 Element Plus
- **target 未生效**：检查 `build.target` 拼写、确认 `esbuild` 未覆盖该配置

## 八、易错警示

> ⚠️ HMR 需要浏览器支持 WebSocket，某些公司网络可能阻断 WS 连接

> ⚠️ `manualChunks` 中的包名必须与 `node_modules` 中一致，拼写错误会导致分包不生效

> ⚠️ `build.target: es2015` 可能无法转译所有新语法（如 `BigInt`），需根据目标浏览器调整

> ⚠️ 验证 HMR 时确保 `pnpm dev` 正在运行，不要使用 `pnpm build` 的产物测试
