### 5.1 安装依赖
```bash
pnpm add vxe-table vxe-pc-ui @vxe-ui/core
```

### 5.2 全局注册（main.ts）
```ts
import { createApp } from 'vue'
import { setupVxeTable } from '@/plugins/vxe-table'
import App from './App.vue'

const app = createApp(App)

// 注册顺序：VxeUI → VxeTable
setupVxeTable(app)

app.mount('#app')
```

### 5.3 国际化配置
```ts
// src/plugins/vxe-table.ts
import VXETable from 'vxe-table'
import { i18n } from '@/locales'  // 项目 vue-i18n 实例

VXETable.setup({
  i18n: (key: string, args?: Record<string, unknown>) => {
    return i18n.global.t(key, args ?? {})
  }
})
```
- `i18n` 回调函数将 Vxe Table 内部文本转发到 vue-i18n 处理
- 必须在 `app.use(VxeTable)` 之后调用 `VXETable.setup()`

### 5.4 默认参数配置
```ts
VXETable.setup({
  table: {
    border: true,          // 默认显示边框
    resizable: true,       // 默认允许列宽拖拽调整
    showOverflow: true,    // 默认内容溢出显示 tooltip
    emptyText: '暂无数据', // 空数据提示文本
    autoResize: true       // 自动监听容器大小变化
  },
  pager: {
    pageSize: 20,          // 默认每页 20 条
    pageSizes: [10, 20, 50, 100]  // 可选分页大小
  }
})
```

### 5.5 关键配置项
| 配置项 | 作用 | 注意事项 |
|--------|------|----------|
| `app.use(VxeUI).use(VxeTable)` | 全局注册 | VxeUI 必须在 VxeTable 之前注册 |
| `VXETable.setup({ i18n })` | 国际化对接 | 必须在 app.use() 之后调用 |
| `table.border: true` | 全局默认表格边框 | ERP 系统建议默认开启 |
| `table.showOverflow: true` | 单元格溢出 tooltip | 避免内容截断 |
| `pager.pageSize: 20` | 默认分页大小 | 与后端接口约定一致 |

### 5.6 环境适配
- Vxe Table 样式需在 `main.ts` 中引入：`import 'vxe-pc-ui/lib/style.css'` 和 `import 'vxe-table/lib/style.css'`
- `VXETable.setup()` 是全局单例配置，只需调用一次
- 国际化回调中的 `t` 函数必须是 vue-i18n 实例的 `global.t`
- 如果项目不使用 i18n，可省略 i18n 配置（Vxe Table 内置中文）

## 八、易错警示

> ⚠️ `app.use(VxeUI)` 必须在 `app.use(VxeTable)` 之前，否则部分 UI 组件缺失

> ⚠️ `VXETable.setup()` 必须在 `app.use()` 之后调用

> ⚠️ i18n 回调函数中的 `t` 必须是 `i18n.global.t`（全局实例），非组件内的 `useI18n().t`

> ⚠️ Vxe Table 样式 CSS 文件必须在 `main.ts` 中引入，否则组件无样式
