### 5.2 函数签名定义
```ts
// src/plugins/vxe-table.ts
import type { App } from 'vue'
import VxeUI from 'vxe-pc-ui'
import VxeTable from 'vxe-table'

/**
 * Vxe Table 全局注册插件
 * @param app - Vue 应用实例
 */
export function setupVxeTable(app: App): void {
  app.use(VxeUI).use(VxeTable)
}
```

### 5.3 配置类型定义
```ts
/**
 * Vxe Table 国际化配置类型
 */
interface VxeI18nConfig {
  i18n: (key: string, args?: Record<string, unknown>) => string
}

/**
 * Vxe Table 默认参数配置类型
 */
interface VxeDefaultConfig {
  table: {
    border: boolean
    resizable: boolean
    showOverflow: boolean | string
    emptyText?: string
  }
}
```

### 5.4 类型声明扩展
在 `src/types/global.d.ts` 中扩展 VxeTable 相关类型：
```ts
/// <reference types="vxe-table" />
/// <reference types="vxe-pc-ui" />

declare module 'vxe-table' {
  export interface VxeTablePropTypes {
    // 扩展自定义属性类型
  }
}
```

### 5.5 关键配置项
| 类型 | 用途 | 注意事项 |
|------|------|----------|
| `setupVxeTable(app: App): void` | 全局注册入口函数 | 在 main.ts 中调用 |
| `VxeI18nConfig` | 国际化回调类型 | 对接 vue-i18n 的 t 函数 |
| `VxeDefaultConfig` | 默认参数类型 | 定义表格全局默认行为 |
| `/// <reference types="..." />` | 类型声明引用 | 确保 IDE 类型提示正确 |

### 5.6 环境适配
- 类型定义文件不影响运行时，仅影响开发时类型检查
- `/// <reference types="vxe-table" />` 确保全局类型可用
- 避免在类型声明中使用 `any`，使用 `unknown` 或具体泛型替代
- 类型定义文件需被 `tsconfig.json` 的 `include` 覆盖

## 八、易错警示

> ⚠️ 类型定义文件中使用 `interface` 而非 `type` 定义可扩展类型

> ⚠️ `/// <reference types="..." />` 必须放在文件顶部

> ⚠️ 避免使用 `any` 类型，优先使用 `unknown` 或具体泛型

> ⚠️ Vxe Table 4.x 的类型导出方式与 3.x 不同，注意版本差异
