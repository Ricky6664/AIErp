### 5.2 重复请求取消
```ts
const pendingMap = new Map<string, AbortController>()

function getRequestKey(config: InternalAxiosRequestConfig): string {
  const { url, method, params, data } = config
  return [url, method, JSON.stringify(params), JSON.stringify(data)].join('&')
}

// 请求拦截器中
service.interceptors.request.use((config) => {
  const key = getRequestKey(config)
  if (pendingMap.has(key)) {
    pendingMap.get(key)!.abort()  // 取消前一个相同请求
    pendingMap.delete(key)
  }
  const controller = new AbortController()
  config.signal = controller.signal
  pendingMap.set(key, controller)
  return config
})
```

### 5.3 全局 Loading 管理
```ts
import NProgress from 'nprogress'
import 'nprogress/nprogress.css'

NProgress.configure({ showSpinner: false })

let requestCount = 0

// 请求拦截器：启动 loading
const startLoading = () => {
  if (requestCount === 0) NProgress.start()
  requestCount++
}

// 响应拦截器：结束 loading
const endLoading = () => {
  requestCount--
  if (requestCount <= 0) {
    requestCount = 0
    NProgress.done()
  }
}
```

### 5.4 请求重试机制
```ts
service.interceptors.response.use(undefined, async (error) => {
  const config = error.config
  if (!config || !config.retry) return Promise.reject(error)

  config.__retryCount = config.__retryCount || 0
  if (config.__retryCount >= config.retry) return Promise.reject(error)

  config.__retryCount++
  await new Promise(resolve => setTimeout(resolve, config.retryDelay || 1000))
  return service(config)
})
```
- 重试仅适用于 GET 请求（幂等），POST/PUT/DELETE 禁止自动重试
- `config.retry: 3` 表示最多重试 3 次，`config.retryDelay: 1000` 间隔 1 秒

### 5.5 关键配置项
| 配置项 | 作用 | 注意事项 |
|--------|------|----------|
| `pendingMap` | 缓存进行中的请求 | Map key 必须包含 url + method + params + data |
| `AbortController` | 取消请求 | 比已废弃的 `CancelToken` 更标准 |
| `NProgress.showSpinner: false` | 隐藏右上角转圈 | 使用项目自定义 loading 效果 |
| `requestCount` | 并发请求计数 | 避免多个并发请求结束时 NProgress 提前关闭 |
| `config.retry` | 重试次数 | 仅用于 GET 请求，POST 请求不可重试 |

### 5.6 环境适配
- 重复请求取消可防止用户快速双击按钮导致重复提交
- NProgress 在路由切换时也可使用（路由守卫中调用 `NProgress.start/done`）
- 某些请求可配置 `config.silent = true` 跳过 loading（如后台轮询接口）
- `AbortController` 需要浏览器支持（Chrome 66+/Firefox 57+/Safari 12.1+）

## 八、易错警示

> ⚠️ `pendingMap` 的 key 生成必须一致（请求拦截器和响应拦截器用同一函数）

> ⚠️ `requestCount` 必须 >= 0 保护，避免计数异常导致 NProgress 无法关闭

> ⚠️ 重试机制仅适用于 GET 请求，POST/PUT/DELETE 禁止自动重试（避免重复操作）

> ⚠️ `AbortController` 的 `signal` 必须在请求拦截器中赋值到 `config.signal`
