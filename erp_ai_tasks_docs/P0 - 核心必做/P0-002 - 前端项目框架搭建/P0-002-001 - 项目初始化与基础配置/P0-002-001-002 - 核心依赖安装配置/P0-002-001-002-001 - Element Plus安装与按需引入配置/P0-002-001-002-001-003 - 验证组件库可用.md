### 5.1 验证清单
| 序号 | 验证项 | 预期结果 | 验证方法 |
|:---:|--------|---------|---------|
| 1 | Element Plus 组件按需自动引入 | 模板中使用 `<el-button>` 无需手动 import | 创建测试组件 `pnpm dev` 验证渲染 |
| 2 | Vue API 自动导入 | `<script setup>` 中使用 `ref`/`computed` 无需 import | 创建测试文件确认无 TS 报错 |
| 3 | ElMessage 方法自动导入 | 直接调用 `ElMessage.success()` 无需 import | 测试调用确认弹出提示 |
| 4 | 主题色 `--el-color-primary: #409EFF` 生效 | `<el-button type="primary">` 背景色为 #409EFF | DevTools 检查 computed style |
| 5 | 构建产物按需引入 | `pnpm build` 后 dist/ 总大小 < 500KB | 执行构建后 `du -sh dist/` |
| 6 | 类型声明文件生成 | `auto-imports.d.ts` 和 `components.d.ts` 存在 | `ls src/*.d.ts` 确认文件存在 |
| 7 | Element Plus 样式正常加载 | 组件样式（按钮/输入框/表格）渲染正确 | 浏览器访问测试页面检查 |

### 5.2 测试方法
1. **创建测试页面** `src/views/test-element.vue`：
   ```vue
   <script setup lang="ts">
   const count = ref(0)  // 自动导入 ref
   const msg = computed(() => `Count: ${count.value}`)  // 自动导入 computed
   const handleClick = () => ElMessage.success('点击成功')  // 自动导入
   </script>
   <template>
     <el-button type="primary" @click="handleClick">{{ msg }}</el-button>
     <el-input v-model="count" />
   </template>
   ```
2. 执行 `pnpm dev`，浏览器访问测试页面
3. 检查按钮渲染、点击消息弹出、输入框交互
4. 执行 `pnpm build` 检查产物大小

### 5.3 问题处理
- **组件不渲染**：检查 `components.d.ts` 是否生成、`Components` 插件是否在 `vite.config.ts` 中配置
- **ref/computed 报未定义**：检查 `auto-imports.d.ts` 是否生成、`.gitignore` 是否误删该文件
- **样式缺失**：检查 `ElementPlusResolver` 是否在 AutoImport 和 Components 两处都配置
- **主题色不生效**：检查 `src/styles/element-plus.scss` 是否在 `main.ts` 中引入、`:root` 选择器优先级
