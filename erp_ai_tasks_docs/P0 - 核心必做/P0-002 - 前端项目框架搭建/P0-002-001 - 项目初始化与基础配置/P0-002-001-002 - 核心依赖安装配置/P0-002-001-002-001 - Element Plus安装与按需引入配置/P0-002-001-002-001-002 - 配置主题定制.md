### 5.1 主题定制方式
Element Plus 2.x 使用 CSS 变量作为设计 Token，主题定制通过覆盖 CSS 变量实现：
```scss
/* src/styles/element-plus.scss */
:root {
  /* 品牌色 */
  --el-color-primary: #409EFF;
  --el-color-success: #67C23A;
  --el-color-warning: #E6A23C;
  --el-color-danger: #F56C6C;
  --el-color-info: #909399;

  /* 字体 */
  --el-font-size-base: 14px;
  --el-font-family: 'Helvetica Neue', Helvetica, 'PingFang SC', 'Hiragino Sans GB',
    'Microsoft YaHei', Arial, sans-serif;

  /* 圆角 */
  --el-border-radius-base: 4px;
  --el-border-radius-small: 2px;

  /* 间距 */
  --el-padding-base: 8px;

  /* 过渡 */
  --el-transition-duration: 0.3s;
}
```

### 5.2 vite.config.ts 配合
```ts
Components({
  resolvers: [ElementPlusResolver({ importStyle: 'sass' })]
})
```
- `importStyle: 'sass'`：引入 SCSS 源文件而非编译后 CSS，支持 SCSS 变量覆盖
- 如不需要 SCSS 变量覆盖，使用默认的 `importStyle: true`（引入编译后 CSS）

### 5.3 main.ts 引入
```ts
import '@/styles/element-plus.scss'
```
- 在 `main.ts` 中引入自定义主题文件，确保在 Element Plus 组件样式之后加载

### 5.4 关键配置项
| 配置项 | 作用 | 注意事项 |
|--------|------|----------|
| `--el-color-primary` | 主色调，影响按钮/链接/开关等 | 默认 #409EFF，修改后所有主色组件联动 |
| `--el-font-size-base` | 基础字号 | ERP 系统建议 14px |
| `--el-border-radius-base` | 基础圆角 | 企业级系统通常 4px |
| `importStyle: 'sass'` | 引入 SCSS 源文件 | 需要安装 `sass` 依赖 |
| `--el-color-primary-light-*` | 主色阶梯色（1-9） | 自动生成，无需手动配置 |

### 5.5 环境适配
- 主题文件 `src/styles/element-plus.scss` 需要在 `main.ts` 中全局引入
- CSS 变量覆盖方式优先级高于 SCSS 变量覆盖，推荐使用 CSS 变量
- 如使用 `importStyle: 'sass'`，需额外安装 `pnpm add -D sass`
- 修改主题后无需重启 Vite 开发服务器，HMR 自动生效

## 八、易错警示

> ⚠️ `importStyle: 'sass'` 需要安装 `sass` 依赖（`pnpm add -D sass`），否则构建报错

> ⚠️ CSS 变量覆盖使用 `:root` 选择器，不要用 `body`（优先级不够）

> ⚠️ 主题文件必须在 `main.ts` 中引入，且放在 Element Plus 样式之后

> ⚠️ 不要同时使用 SCSS 变量覆盖和 CSS 变量覆盖两种方式，选择其一即可
