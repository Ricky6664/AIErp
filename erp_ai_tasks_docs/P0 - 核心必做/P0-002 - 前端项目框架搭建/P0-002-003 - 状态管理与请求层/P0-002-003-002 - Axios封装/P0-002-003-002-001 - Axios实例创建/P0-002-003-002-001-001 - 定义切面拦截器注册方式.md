### 5.1 Axios实例配置

在`erp-web/src/utils/request.ts`中创建Axios实例：
```typescript
import axios from 'axios'
import type { AxiosInstance, InternalAxiosRequestConfig, AxiosResponse } from 'axios'

const apiClient: AxiosInstance = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,  // 从Vite环境变量读取
  timeout: 30000,                                // 请求超时30秒
  headers: {
    'Content-Type': 'application/json',
  },
})
```

### 5.2 拦截器注册

```typescript
// 请求拦截器
apiClient.interceptors.request.use(
  (config: InternalAxiosRequestConfig) => {
    const userStore = useUserStore()
    if (userStore.token) {
      config.headers.Authorization = `Bearer ${userStore.token}`
    }
    // 注入语言标识
    const appStore = useAppStore()
    config.headers['Accept-Language'] = appStore.language
    return config
  },
  (error) => Promise.reject(error)
)

// 响应拦截器（具体逻辑由P0-002-003-002-002任务实现）
apiClient.interceptors.response.use(
  (response: AxiosResponse) => { /* 由响应拦截器任务实现 */ },
  (error) => { /* 由响应拦截器任务实现 */ }
)
```

### 5.3 导出

```typescript
export default apiClient
```

所有API模块统一import此实例发起请求。

## 八、易错警示

> ⚠️ Axios拦截器中401刷新token时需加锁（isRefreshing标记），防止并发请求触发多次刷新

> ⚠️ `import.meta.env.VITE_API_BASE_URL`变量名必须以`VITE_`开头，否则Vite不会暴露到客户端

> ⚠️ 请求拦截器中获取store要延迟到函数内部调用`useUserStore()`，不要在模块顶层获取（Pinia可能未初始化）

> ⚠️ headers对象中Authorization的值格式为`Bearer {token}`，注意Bearer后有空格
