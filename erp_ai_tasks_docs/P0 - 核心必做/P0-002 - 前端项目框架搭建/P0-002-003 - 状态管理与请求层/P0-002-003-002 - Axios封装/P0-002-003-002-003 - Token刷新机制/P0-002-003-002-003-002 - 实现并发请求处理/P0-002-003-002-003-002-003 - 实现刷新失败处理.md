### 5.1 handleRefreshFailure函数

在`erp-web/src/utils/request/tokenRefresh.ts`中实现：
```typescript
function handleRefreshFailure() {
  // 1. reject所有排队请求
  pendingQueue.forEach(({ reject }) => {
    reject(new Error('登录已过期，请重新登录'))
  })
  pendingQueue.length = 0

  // 2. 清除登录态
  const userStore = useUserStore()
  userStore.token = ''
  userStore.userInfo = null
  userStore.permissions = []
  userStore.roles = []
  localStorage.removeItem('erp_user')
  localStorage.removeItem('erp_refresh_token')

  // 3. 重置刷新标记
  isRefreshing = false

  // 4. 提示用户
  ElMessage.warning('会话已过期，请重新登录')

  // 5. 跳转登录页（避免在登录页重复跳转）
  const router = useRouter()
  if (router.currentRoute.value.path !== '/login') {
    router.replace('/login')
  }
}
```

### 5.2 调用时机

在handleTokenRefresh的catch块中调用：
```typescript
catch (error) {
  handleRefreshFailure()
  return Promise.reject(error)
}
```

### 5.3 防止重复跳转

跳转前检查当前路由是否为`/login`，避免在登录页再次触发刷新失败导致重复跳转。

## 八、易错警示

> ⚠️ 跳转登录页前要先reject所有排队请求，避免Promise泄漏（内存泄漏）

> ⚠️ 登录页跳转用`router.replace`而非`router.push`，避免用户点击回退到失效页面

> ⚠️ 清除token要同时清localStorage（`erp_user`、`erp_refresh_token`）和store中的状态

> ⚠️ `useUserStore()`和`useRouter()`必须在函数内部调用，不能在模块顶层调用
