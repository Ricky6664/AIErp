### 5.1 Getters定义

#### 5.1.1 isMobile: (state) => boolean
- 逻辑：`state.device === 'mobile'`
- 用途：布局组件判断是否显示移动端遮罩、是否自动折叠侧边栏
- 返回类型：`boolean`

#### 5.1.2 sidebarStatus: (state) => string
- 逻辑：`state.sidebarCollapsed ? 'closed' : 'opened'`
- 用途：CSS class绑定，如`:class="appStore.sidebarStatus"`控制侧边栏动画
- 返回类型：`'closed' | 'opened'`

#### 5.1.3 currentTheme: (state) => ThemeType
- 逻辑：直接返回`state.theme`
- 用途：主题切换组件展示当前主题状态
- 返回类型：`'light' | 'dark'`

#### 5.1.4 locale: (state) => string
- 逻辑：直接返回`state.language`
- 用途：Axios请求拦截器注入`Accept-Language`头
- 返回类型：`string`

### 5.2 类型约束

- 所有getter必须有明确的返回类型声明
- getter中禁止做DOM操作，保持纯计算
- isMobile的判断阈值(768px)要与CSS媒体查询断点保持一致

### 5.3 与组件集成

组件中通过`const appStore = useAppStore()`获取store实例，在模板中使用`appStore.isMobile`、`:class="appStore.sidebarStatus"`等getter属性。
