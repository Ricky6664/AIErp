### 5.1 State/接口设计

定义TypeScript接口`IAppState`：
```typescript
// erp-web/src/types/app.d.ts
export type DeviceType = 'desktop' | 'mobile'
export type ThemeType = 'light' | 'dark'

export interface IAppState {
  sidebarCollapsed: boolean
  device: DeviceType
  theme: ThemeType
  language: string
  activeMenu: string
}
```

### 5.2 State初始值

使用Pinia defineStore创建appStore，state函数返回`IAppState`初始值：
- `sidebarCollapsed`：从localStorage读取（key: `erp_app_sidebar`），默认`false`
- `device`：根据`window.innerWidth < 768`判断，初始为`'desktop'`或`'mobile'`
- `theme`：从localStorage读取（key: `erp_app_theme`），默认`'light'`
- `language`：从localStorage读取（key: `erp_app_lang`），默认`'zh-CN'`
- `activeMenu`：空字符串`''`（由路由守卫动态设置）

### 5.3 持久化策略

配置`pinia-plugin-persistedstate`持久化插件：
- `persist.key`：`'erp_app'`
- `persist.pick`：`['sidebarCollapsed', 'theme', 'language']`
- 不持久化：`device`（每次启动根据窗口宽度判断）、`activeMenu`（由路由动态决定）

### 5.4 与组件集成

组件中通过`const appStore = useAppStore()`获取store实例，访问`appStore.sidebarCollapsed`等状态。

## 八、易错警示

> ⚠️ device初始值要根据`window.innerWidth`判断，SSR场景需延迟到`onMounted`中执行

> ⚠️ theme初始值要与CSS变量/Element Plus主题保持一致，避免闪烁

> ⚠️ 不要在State中存放不可序列化的大数据对象（如DOM引用、函数等），持久化插件无法序列化

> ⚠️ language默认值`'zh-CN'`需与i18n初始化配置一致
