### 5.1 Getters定义

#### 5.1.1 getDictByType: (state) => (dictType: string) => DictItem[]
- 逻辑：`(dictType: string) => state.dictMap[dictType] || []`
- 用途：在模板中遍历字典列表渲染下拉选项或标签
- 返回类型：函数式getter，接收dictType参数返回DictItem数组

#### 5.1.2 getDictLabel: (state) => (dictType: string, dictValue: string | number) => string
- 逻辑：在`state.dictMap[dictType]`中find匹配`String(item.dictValue) === String(dictValue)`的item，返回`item?.dictLabel || String(dictValue)`
- 用途：下拉框回显、表格列字典值翻译（如状态码0→"正常"、1→"停用"）
- 返回类型：函数式getter，接收dictType和dictValue参数返回string

#### 5.1.3 getConfig: (state) => (key: string) => string
- 逻辑：`(key: string) => state.systemConfig[key] || ''`
- 用途：获取系统参数（如默认分页大小、文件上传大小限制等）
- 返回类型：函数式getter，接收key参数返回string

### 5.2 类型约束

- 函数式getter使用箭头函数返回箭头函数，明确声明参数和返回类型
- getDictLabel中dictValue参数可能是string或number，统一用String()转换后比较
- getter中禁止做异步操作，字典未加载时返回空数组或空字符串

### 5.3 与组件集成

模板中使用示例：
```html
<el-select v-model="form.status">
  <el-option v-for="item in paramStore.getDictByType('sys_user_status')" :key="item.dictValue" :label="item.dictLabel" :value="item.dictValue" />
</el-select>
<el-tag>{{ paramStore.getDictLabel('sys_user_status', row.status) }}</el-tag>
```

## 八、易错警示

> ⚠️ getter返回数组时不要直接push修改state，使用新数组替换

> ⚠️ 字典未加载时getter返回空数组`[]`，不要返回undefined，否则模板`v-for`报错

> ⚠️ getDictLabel中dictValue比较要统一转String，后端可能返回数字类型而字典值是字符串

> ⚠️ 函数式getter（接收参数）在Pinia Options API中写法为`getterName: (state) => (param) => ...`
