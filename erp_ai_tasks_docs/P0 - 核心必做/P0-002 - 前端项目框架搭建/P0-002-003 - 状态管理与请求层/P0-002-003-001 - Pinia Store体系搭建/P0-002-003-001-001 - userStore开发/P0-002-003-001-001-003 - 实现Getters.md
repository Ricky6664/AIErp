### 5.1 Getters定义

#### 5.1.1 isLoggedIn: (state) => boolean
- 逻辑：`!!state.token`
- 用途：路由守卫和模板中判断登录状态
- 返回类型：`boolean`

#### 5.1.2 hasPermission: (state) => (perm: string) => boolean
- 逻辑：`(perm: string) => state.permissions.includes(perm)`
- 用途：按钮级权限判断，如`v-if="userStore.hasPermission('system:user:add')"`
- 返回类型：函数式getter，接收perm参数返回boolean

#### 5.1.3 avatar: (state) => string
- 逻辑：`state.userInfo?.avatar || '/default-avatar.png'`
- 用途：头部用户头像展示，空值时返回默认头像
- 返回类型：`string`

#### 5.1.4 nickname: (state) => string
- 逻辑：`state.userInfo?.nickname || state.userInfo?.username || '用户'`
- 用途：头部用户名展示
- 返回类型：`string`

### 5.2 类型约束

- 所有getter必须有明确的返回类型声明
- 函数式getter（如hasPermission）使用箭头函数返回箭头函数
- getter中禁止做异步操作，必须保持同步纯计算

### 5.3 与组件集成

组件中通过`const userStore = useUserStore()`获取store实例，直接访问`userStore.isLoggedIn`、`userStore.avatar`等getter属性，getter自动响应式更新。

## 八、易错警示

> ⚠️ getter中不要做异步操作，getter必须是同步纯计算

> ⚠️ getter返回值要做空值兜底（如avatar用`||`或`??`），避免undefined导致模板渲染报错

> ⚠️ 函数式getter（hasPermission）使用箭头函数返回箭头函数，注意Pinia Options API中getter的this绑定

> ⚠️ 不要在getter中直接引用其他store，如需要请通过参数传入
