## 二、任务目标

在后端数据库sys_menu表中初始化系统菜单数据：每条菜单记录包含menu_name(名称)、path(前端路由路径)、component(组件路径)、icon(Element Plus图标名)、order_num(排序序号)、perms(权限标识如system:user:list)、parent_id(父级菜单ID, 0为顶级)、menu_type(目录M/菜单C/按钮F)、visible(是否可见)、status(状态)，通过SQL脚本INSERT初始化核心模块菜单(系统管理/组织架构/基础数据等)

## 五、详细开发规格

> **📦 模块上下文**
> - 任务类型：后端菜单数据初始化 — SQL脚本编写
> - 技术栈：PostgreSQL 15.x + Flyway数据库迁移
> - 数据表：`sys_menu`（系统菜单表，存储前端路由和权限配置）

### 5.1 sys_menu表结构（关键字段）

| 字段名 | 类型 | 说明 |
|:------|:-----|:-----|
| menu_id | bigint PK | 菜单ID（雪花算法） |
| menu_name | varchar(50) | 菜单名称 |
| parent_id | bigint | 父菜单ID，0为顶级 |
| order_num | int | 排序序号 |
| path | varchar(200) | 前端路由路径 |
| component | varchar(255) | 组件路径（如system/user/index） |
| menu_type | char(1) | M=目录 C=菜单 F=按钮 |
| perms | varchar(100) | 权限标识（如system:user:list） |
| icon | varchar(100) | Element Plus图标名 |
| visible | char(1) | 0=显示 1=隐藏 |
| status | char(1) | 0=正常 1=停用 |

### 5.2 初始化SQL示例

```sql
-- 系统管理目录
INSERT INTO sys_menu VALUES (1, '系统管理', 0, 1, '/system', '', 'M', '', 'Setting', '0', '0');
-- 用户管理菜单
INSERT INTO sys_menu VALUES (100, '用户管理', 1, 1, 'user', 'system/user/index', 'C', 'system:user:list', 'User', '0', '0');
-- 用户管理按钮权限
INSERT INTO sys_menu VALUES (1001, '用户查询', 100, 1, '', '', 'F', 'system:user:query', '', '0', '0');
INSERT INTO sys_menu VALUES (1002, '用户新增', 100, 2, '', '', 'F', 'system:user:add', '', '0', '0');
INSERT INTO sys_menu VALUES (1003, '用户修改', 100, 3, '', '', 'F', 'system:user:edit', '', '0', '0');
INSERT INTO sys_menu VALUES (1004, '用户删除', 100, 4, '', '', 'F', 'system:user:remove', '', '0', '0');
```

### 5.3 与前端集成

后端`GET /auth/info`接口返回当前用户的菜单树（根据角色过滤），permissionStore接收菜单数据后调用`loadComponent`映射组件路径，通过`router.addRoute()`动态注册路由。

## 八、易错警示

> ⚠️ SQL脚本使用Flyway版本化命名（V1.0.1__xxx.sql），不要手动修改已执行的迁移脚本

> ⚠️ menu_type='F'的按钮权限不需要path和component字段，仅用于后端接口权限校验

> ⚠️ parent_id=0表示顶级目录，不要写成NULL

> ⚠️ component字段路径要与前端`import.meta.glob('@/views/**/*.vue')`扫描范围匹配
