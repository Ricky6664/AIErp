### 5.1 验证清单

| 序号 | 验证项 | 预期结果 | 验证方法 |
|:---:|--------|---------|---------|
| 1 | Element Plus组件颜色一致性 | el-button--primary 背景色为 --color-primary 值 | DevTools Computed 检查 |
| 2 | Element Plus组件圆角正确 | el-input/el-card 圆角为 --radius-md 值 | DevTools Computed 检查 border-radius |
| 3 | Element Plus组件阴影正确 | el-card 阴影为 --shadow-md 值 | DevTools Computed 检查 box-shadow |
| 4 | 暗色模式EP组件适配 | 切换暗色后 el-input 背景/文本/边框色跟随变化 | Console切换 + DevTools |
| 5 | 响应式断点EP组件适配 | 不同屏幕宽度下 el-table/el-form 布局正确 | DevTools Device Toolbar |

### 5.2 测试方法

1. **DevTools Computed 样式**：选中 EP 组件 → Computed tab → 检查 `--el-color-primary`/`--el-border-radius-base` 等变量值
2. **暗色模式切换**：Console 执行 `document.documentElement.classList.toggle('dark')`，确认 EP 组件样式平滑切换
3. **EP组件覆盖检查**：确认 `element-override.scss` 中 `@forward ... with (...)` 语法正确编译
4. **响应式验证**：使用 DevTools Device Toolbar 切换屏幕尺寸，检查 EP 表格/表单布局

### 5.3 问题处理

- EP组件颜色未覆盖：检查 `element-override.scss` 引入顺序，必须在 `element-plus` 样式之前
- 暗色模式EP样式不变：检查 `html.dark` 下是否有 `--el-*` 变量覆盖
- SCSS编译错误：检查 `@forward ... with (...)` 语法，确保 `$colors` map 结构正确

## 八、易错警示

> ⚠️ Element Plus 主题定制通过 SCSS 变量覆盖实现，不要用 CSS 变量直接覆盖 EP 的 SCSS 编译产物

> ⚠️ 暗色模式使用 `html.dark` 选择器覆盖CSS变量，不要使用 `@media (prefers-color-scheme)`

> ⚠️ `element-override.scss` 必须在 `element-plus` 样式之前引入，否则覆盖不生效

> ⚠️ Tailwind CSS 4 使用 CSS-based 配置（`app.css`），不使用 `tailwind.config.ts`

> ⚠️ 所有 Tailwind 颜色类必须引用 CSS 变量，不要硬编码颜色值
