### 5.1 配置结构

文件路径：`erp-web/src/styles/element-override.scss`

通过覆盖 Element Plus 的 SCSS 变量实现主题定制，在 Element Plus 样式引入之前加载：

```scss
/* Element Plus SCSS变量覆盖 */
@forward 'element-plus/theme-chalk/src/common/var.scss' with (
  $colors: (
    'primary': ('base': var(--color-primary)),
    'success': ('base': var(--color-success)),
    'warning': ('base': var(--color-warning)),
    'danger': ('base': var(--color-danger)),
    'info': ('base': var(--color-info)),
  ),
  $border-radius: (
    'base': var(--radius-md),
    'small': var(--radius-sm),
    'round': 20px,
  ),
);

/* Element Plus暗色模式覆盖 */
html.dark {
  --el-color-primary: var(--color-primary);
  --el-bg-color: var(--color-bg);
  --el-bg-color-page: var(--color-bg-page);
  --el-text-color-primary: var(--color-text-primary);
  --el-text-color-regular: var(--color-text-regular);
  --el-border-color: var(--color-border);
  --el-fill-color-blank: var(--color-bg);
}
```

### 5.2 关键配置项

| SCSS变量/CSS变量 | 用途 | 值来源 |
|-----------------|------|--------|
| `$colors.primary.base` | Element Plus主色调 | `var(--color-primary)` |
| `$border-radius.base` | 组件基础圆角 | `var(--radius-md)` |
| `--el-color-primary` | EP主色CSS变量(暗色模式) | `var(--color-primary)` |
| `--el-bg-color` | EP背景色(暗色模式) | `var(--color-bg)` |
| `--el-text-color-primary` | EP文本色(暗色模式) | `var(--color-text-primary)` |
| `--el-border-color` | EP边框色(暗色模式) | `var(--color-border)` |

### 5.3 与项目集成

- `element-override.scss` 在 `erp-web/src/main.ts` 中通过 `import './styles/element-override.scss'` 引入，且必须在 `import 'element-plus'` 之前
- SCSS 变量覆盖通过 `@forward ... with (...)` 语法实现，Vite 的 SCSS 预处理器会在编译时生效
- 暗色模式覆盖使用 `html.dark` 选择器，切换时 Element Plus 组件样式自动更新
- Vite 配置中需添加 `css.preprocessorOptions.scss` 配置确保 SCSS 变量全局可用

## 八、易错警示

> ⚠️ CSS变量命名统一使用 `--color-xxx`/`--radius-xxx` 格式

> ⚠️ 暗色模式使用 `html.dark` 选择器覆盖CSS变量，不要使用 `@media (prefers-color-scheme)`

> ⚠️ Element Plus 主题定制通过 SCSS 变量覆盖实现，不要用 CSS 变量直接覆盖 EP 的 SCSS 编译产物

> ⚠️ `element-override.scss` 必须在 `element-plus` 样式之前引入，否则覆盖不生效

> ⚠️ Tailwind CSS 4 使用 CSS-based 配置（`app.css`），不使用 `tailwind.config.ts`
