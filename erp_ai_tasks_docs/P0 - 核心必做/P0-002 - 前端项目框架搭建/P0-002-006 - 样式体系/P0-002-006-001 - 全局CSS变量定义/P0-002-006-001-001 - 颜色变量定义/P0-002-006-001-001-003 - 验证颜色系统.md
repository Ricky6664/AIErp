### 5.1 验证清单

| 序号 | 验证项 | 预期结果 | 验证方法 |
|:---:|--------|---------|---------|
| 1 | :root CSS颜色变量完整性 | 11个颜色变量全部定义 | DevTools Elements → Computed tab 逐一检查 |
| 2 | 变量值正确 | --color-primary=#409EFF, --color-success=#67C23A 等 | DevTools Computed 查看具体值 |
| 3 | Tailwind颜色扩展类可用 | text-primary/bg-primary/border-primary 等生效 | 在测试页面使用 class 检查颜色 |
| 4 | html.dark覆盖变量 | 暗色模式下 --color-bg=#141414, --color-text-primary=#E5EAF3 | 切换暗色模式后 DevTools 检查 |
| 5 | Element Plus组件使用主色调 | el-button--primary 背景色为 --color-primary | DevTools Computed 检查 |

### 5.2 测试方法

1. **浏览器视觉检查**：打开开发页面，确认主色调按钮/链接/文本颜色符合设计稿
2. **DevTools Computed 样式**：选中元素 → Computed tab → 搜索 `--color-` 查看变量值
3. **暗色模式切换**：在 Console 执行 `document.documentElement.classList.toggle('dark')`，确认颜色平滑切换
4. **Tailwind工具类验证**：在测试组件中使用 `text-primary`、`bg-page` 等 class，确认颜色正确

### 5.3 问题处理

- CSS变量未生效：检查 `variables.css` 是否在 `main.ts` 中正确引入，检查选择器优先级
- Tailwind类不生效：检查 `app.css` 中 `@theme` 块是否正确引用了 CSS 变量
- 暗色模式不切换：检查 `html.dark` 选择器是否正确覆盖所有变量，检查是否有内联样式覆盖

## 八、易错警示

> ⚠️ CSS变量命名统一使用 `--color-xxx` 格式，不要混用 `--primary-color` 等命名

> ⚠️ 暗色模式使用 `html.dark` 选择器覆盖CSS变量，不要使用 `@media (prefers-color-scheme)`

> ⚠️ Tailwind CSS 4 使用 CSS-based 配置（`app.css`），不使用 `tailwind.config.ts`

> ⚠️ Tailwind 禁止使用 `dark:` 前缀，暗色模式通过 CSS 变量自动切换

> ⚠️ 验证时注意 CSS 选择器优先级，内联样式 > ID选择器 > class选择器 > 标签选择器
