### 5.1 配置结构

文件路径：`erp-web/src/styles/variables.css`

```css
:root {
  /* 主色调 - Element Plus默认蓝色系 */
  --color-primary: #409EFF;
  --color-success: #67C23A;
  --color-warning: #E6A23C;
  --color-danger: #F56C6C;
  --color-info: #909399;

  /* 文本颜色 */
  --color-text-primary: #303133;
  --color-text-regular: #606266;
  --color-text-secondary: #909399;

  /* 背景色 */
  --color-bg: #ffffff;
  --color-bg-page: #E6E6FA;

  /* 边框色 */
  --color-border: #DCDFE6;
}

/* 暗色模式覆盖 */
html.dark {
  --color-text-primary: #E5EAF3;
  --color-text-regular: #CFD3DC;
  --color-text-secondary: #A3A6AD;
  --color-bg: #141414;
  --color-bg-page: #1d1e1f;
  --color-border: #4C4D4F;
}
```

### 5.2 关键配置项

| 变量名 | 用途 | 值 |
|--------|------|-----|
| `--color-primary` | 主色调，按钮/链接/高亮 | #409EFF |
| `--color-success` | 成功状态色 | #67C23A |
| `--color-warning` | 警告状态色 | #E6A23C |
| `--color-danger` | 危险/错误色 | #F56C6C |
| `--color-info` | 信息提示色 | #909399 |
| `--color-text-primary` | 主要文本色 | #303133 |
| `--color-text-regular` | 常规文本色 | #606266 |
| `--color-text-secondary` | 次要文本色 | #909399 |
| `--color-bg` | 容器背景色 | #ffffff |
| `--color-bg-page` | 页面全局背景色 | #E6E6FA |
| `--color-border` | 边框色 | #DCDFE6 |

### 5.3 与项目集成

- `variables.css` 在 `erp-web/src/main.ts` 中通过 `import './styles/variables.css'` 引入，确保应用初始化时即生效
- Tailwind CSS 4 在 `erp-web/app.css` 中通过 `@theme` 引用这些 CSS 变量，实现 Tailwind 工具类与 CSS 变量联动
- Element Plus 主题覆盖在 `erp-web/src/styles/element-override.scss` 中读取这些变量
- 暗色模式通过 `document.documentElement.classList.toggle('dark')` 切换，变量自动覆盖

## 八、易错警示

> ⚠️ CSS变量命名统一使用 `--color-xxx` 格式，不要使用 `--primary-color` 等倒序命名

> ⚠️ 暗色模式使用 `html.dark` 选择器覆盖CSS变量，不要使用 `@media (prefers-color-scheme)`

> ⚠️ Tailwind CSS 4 使用 CSS-based 配置（app.css），不使用 tailwind.config.ts

> ⚠️ 不要在CSS变量值中使用Tailwind的 `dark:` 前缀，暗色模式通过CSS变量自动切换

> ⚠️ 所有颜色类必须引用CSS变量（`var(--color-xxx)`），不要硬编码颜色值，否则无法跟随主题切换
