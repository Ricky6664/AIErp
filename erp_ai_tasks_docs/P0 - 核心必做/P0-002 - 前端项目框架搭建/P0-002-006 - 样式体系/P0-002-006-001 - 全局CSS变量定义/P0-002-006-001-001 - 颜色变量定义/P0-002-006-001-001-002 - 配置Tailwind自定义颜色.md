### 5.1 配置结构

文件路径：`erp-web/app.css`（Tailwind CSS 4 CSS-based 配置入口）

Tailwind CSS 4 不再使用 `tailwind.config.ts`，而是在 CSS 文件中通过 `@theme` 块扩展主题：

```css
@import "tailwindcss";

@theme {
  /* 颜色Token - 引用CSS变量 */
  --color-primary: var(--color-primary);
  --color-success: var(--color-success);
  --color-warning: var(--color-warning);
  --color-danger: var(--color-danger);
  --color-info: var(--color-info);

  --color-text-primary: var(--color-text-primary);
  --color-text-regular: var(--color-text-regular);
  --color-text-secondary: var(--color-text-secondary);

  --color-bg: var(--color-bg);
  --color-bg-page: var(--color-bg-page);
  --color-border: var(--color-border);
}
```

### 5.2 关键配置项

| Tailwind Token | 映射CSS变量 | 生成的工具类示例 |
|----------------|------------|----------------|
| `--color-primary` | `var(--color-primary)` | `text-primary`, `bg-primary`, `border-primary` |
| `--color-success` | `var(--color-success)` | `text-success`, `bg-success` |
| `--color-warning` | `var(--color-warning)` | `text-warning`, `bg-warning` |
| `--color-danger` | `var(--color-danger)` | `text-danger`, `bg-danger` |
| `--color-info` | `var(--color-info)` | `text-info`, `bg-info` |
| `--color-bg-page` | `var(--color-bg-page)` | `bg-bg-page` |

### 5.3 与项目集成

- `app.css` 在 `erp-web/src/main.ts` 中通过 `import '../app.css'` 引入
- `app.css` 中 `@import "tailwindcss"` 加载 Tailwind 基础层
- `@theme` 块中定义的颜色 Token 自动映射为 Tailwind 工具类
- 颜色值全部引用 `variables.css` 中的 CSS 变量，暗色模式自动切换
- **禁止使用 `dark:` 前缀**，暗色模式通过 CSS 变量自动覆盖实现

## 七、验收标准

| 序号 | 检查项 | 验证方法 |
|:---:|--------|---------|
| 1 | `text-primary`/`bg-primary`/`border-primary` 等工具类可用 | 在页面使用 class="text-primary" 检查颜色为 #409EFF |

| 3 | 暗色模式下Tailwind颜色自动切换 | 切换 `html.dark` 后 `text-primary` 值不变但文本色/背景色跟随变化 |

## 八、易错警示

> ⚠️ Tailwind CSS 4 使用 CSS-based 配置（`app.css`），不使用 `tailwind.config.ts`

> ⚠️ Tailwind 禁止使用 `dark:` 前缀，暗色模式通过 CSS 变量自动切换

> ⚠️ CSS变量命名统一使用 `--color-xxx` 格式，Tailwind @theme 中 Token 名与 CSS 变量名保持一致

> ⚠️ 所有 Tailwind 颜色类必须引用 CSS 变量（`var(--color-xxx)`），不要硬编码颜色值

> ⚠️ 暗色模式使用 `html.dark` 选择器覆盖 CSS 变量，不要使用 `@media (prefers-color-scheme)`
