### 5.1 验证清单

| 序号 | 验证项 | 预期结果 | 验证方法 |
|:---:|--------|---------|---------|
| 1 | :root间距变量完整性 | xs/sm/md/lg/xl 5个间距变量全部定义 | DevTools Elements → Computed |
| 2 | :root圆角变量完整性 | sm/md/lg 3个圆角变量全部定义 | DevTools Elements → Computed |
| 3 | :root阴影变量完整性 | sm/md/lg 3个阴影变量全部定义 | DevTools Elements → Computed |
| 4 | 变量值正确 | --spacing-md=16px, --radius-lg=8px, --shadow-md 值正确 | DevTools Computed 查看 |
| 5 | Tailwind间距扩展类可用 | p-xs/m-md/gap-lg 等生效 | 在测试页面使用 class 检查 |
| 6 | Tailwind圆角/阴影类可用 | rounded-md/shadow-lg 等生效 | DevTools Computed 检查 |
| 7 | html.dark覆盖阴影变量 | 暗色模式下阴影值适配 | 切换暗色模式后 DevTools 检查 |

### 5.2 测试方法

1. **DevTools Computed 样式**：选中 `<body>` → Computed tab → 搜索 `--spacing`/`--radius`/`--shadow` 查看变量值
2. **Tailwind工具类验证**：在测试组件中使用 `p-md`、`rounded-lg`、`shadow-md` 等 class，DevTools 检查对应属性
3. **暗色模式切换**：Console 执行 `document.documentElement.classList.toggle('dark')`，确认阴影变量变化
4. **视觉检查**：使用间距工具类的区块间距均匀，圆角/阴影效果符合设计稿

### 5.3 问题处理

- 间距变量未生效：检查 `variables.css` 引入顺序，确保在 Tailwind `app.css` 之前
- Tailwind间距类不生成：检查 `app.css` 中 `@theme` 块是否包含 `--spacing-*` Token
- 暗色模式阴影不变化：检查 `html.dark` 下是否有 `--shadow-*` 变量覆盖

## 八、易错警示

> ⚠️ CSS变量命名统一使用 `--spacing-xxx`/`--radius-xxx`/`--shadow-xxx` 格式

> ⚠️ 暗色模式使用 `html.dark` 选择器覆盖CSS变量，不要使用 `@media (prefers-color-scheme)`

> ⚠️ Tailwind CSS 4 使用 CSS-based 配置（`app.css`），不使用 `tailwind.config.ts`

> ⚠️ 间距/圆角/阴影值与 `variables.css` 和 `app.css` 两处保持同步
