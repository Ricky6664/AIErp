### 5.1 配置结构

文件路径：`erp-web/src/styles/variables.css`（与颜色变量共用同一文件，追加间距/圆角/阴影部分）

```css
:root {
  /* 间距 */
  --spacing-xs: 4px;
  --spacing-sm: 8px;
  --spacing-md: 16px;
  --spacing-lg: 24px;
  --spacing-xl: 32px;

  /* 圆角 */
  --radius-sm: 2px;
  --radius-md: 4px;
  --radius-lg: 8px;

  /* 阴影 */
  --shadow-sm: 0 1px 2px rgba(0,0,0,0.05);
  --shadow-md: 0 4px 6px rgba(0,0,0,0.1);
  --shadow-lg: 0 10px 15px rgba(0,0,0,0.1);
}
```

### 5.2 关键配置项

| 变量名 | 用途 | 值 |
|--------|------|-----|
| `--spacing-xs` | 极小间距（图标与文字间距） | 4px |
| `--spacing-sm` | 小间距（表单项内部间距） | 8px |
| `--spacing-md` | 中间距（区块内间距） | 16px |
| `--spacing-lg` | 大间距（区块间距） | 24px |
| `--spacing-xl` | 超大间距（页面级间距） | 32px |
| `--radius-sm` | 小圆角（按钮/输入框） | 2px |
| `--radius-md` | 中圆角（卡片） | 4px |
| `--radius-lg` | 大圆角（弹窗/区块容器） | 8px |
| `--shadow-sm` | 小阴影（hover状态） | 0 1px 2px rgba(0,0,0,0.05) |
| `--shadow-md` | 中阴影（弹出层） | 0 4px 6px rgba(0,0,0,0.1) |
| `--shadow-lg` | 大阴影（模态框） | 0 10px 15px rgba(0,0,0,0.1) |

### 5.3 与项目集成

- `variables.css` 在 `erp-web/src/main.ts` 中引入，确保应用初始化时即生效
- Tailwind CSS 4 在 `erp-web/app.css` 中通过 `@theme { --spacing-xs: 4px; ... }` 引用，使 `p-xs`/`m-md`/`rounded-lg` 等工具类可用
- SCSS工具类在 `erp-web/src/styles/tools/_layout.scss` 中通过 `var(--spacing-xxx)` 引用
- 暗色模式下阴影变量需在 `html.dark` 中覆盖（暗色背景上阴影需要更淡）

## 八、易错警示

> ⚠️ CSS变量命名统一使用 `--spacing-xxx`/`--radius-xxx`/`--shadow-xxx` 格式

> ⚠️ 暗色模式使用 `html.dark` 选择器覆盖CSS变量，不要使用 `@media (prefers-color-scheme)`

> ⚠️ Tailwind CSS 4 使用 CSS-based 配置（app.css），不使用 tailwind.config.ts

> ⚠️ 间距/圆角/阴影值统一使用CSS变量，不要写硬编码的像素值，方便后续统一调整
