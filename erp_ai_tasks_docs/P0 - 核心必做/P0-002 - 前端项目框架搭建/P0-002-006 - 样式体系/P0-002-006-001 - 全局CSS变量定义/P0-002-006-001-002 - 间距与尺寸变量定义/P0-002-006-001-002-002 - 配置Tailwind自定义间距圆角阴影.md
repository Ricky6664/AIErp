### 5.1 配置结构

文件路径：`erp-web/app.css`（Tailwind CSS 4 CSS-based 配置入口，追加间距/圆角/阴影Token）

在 `@theme` 块中扩展间距、圆角、阴影 Token：

```css
@theme {
  /* 间距Token */
  --spacing-xs: 4px;
  --spacing-sm: 8px;
  --spacing-md: 16px;
  --spacing-lg: 24px;
  --spacing-xl: 32px;

  /* 圆角Token */
  --radius-sm: 2px;
  --radius-md: 4px;
  --radius-lg: 8px;

  /* 阴影Token */
  --shadow-sm: 0 1px 2px rgba(0,0,0,0.05);
  --shadow-md: 0 4px 6px rgba(0,0,0,0.1);
  --shadow-lg: 0 10px 15px rgba(0,0,0,0.1);
}
```

### 5.2 关键配置项

| Tailwind Token | 值 | 生成的工具类示例 |
|----------------|---|----------------|
| `--spacing-xs` | 4px | `p-xs`, `m-xs`, `gap-xs` |
| `--spacing-sm` | 8px | `p-sm`, `m-sm`, `gap-sm` |
| `--spacing-md` | 16px | `p-md`, `m-md`, `gap-md` |
| `--spacing-lg` | 24px | `p-lg`, `m-lg`, `gap-lg` |
| `--spacing-xl` | 32px | `p-xl`, `m-xl`, `gap-xl` |
| `--radius-sm` | 2px | `rounded-sm` |
| `--radius-md` | 4px | `rounded-md` |
| `--radius-lg` | 8px | `rounded-lg` |
| `--shadow-sm` | 0 1px 2px... | `shadow-sm` |
| `--shadow-md` | 0 4px 6px... | `shadow-md` |
| `--shadow-lg` | 0 10px 15px... | `shadow-lg` |

### 5.3 与项目集成

- `app.css` 中 `@theme` 块定义的间距 Token 自动映射为 Tailwind 的 `p-*`/`m-*`/`gap-*` 工具类
- 圆角 Token 映射为 `rounded-*`，阴影 Token 映射为 `shadow-*`
- 值与 `variables.css` 中的 CSS 变量保持一致
- 暗色模式下阴影 Token 需在 `html.dark` 中覆盖（暗色背景上阴影需更淡）

## 八、易错警示

> ⚠️ Tailwind CSS 4 使用 CSS-based 配置（`app.css`），不使用 `tailwind.config.ts`

> ⚠️ CSS变量命名统一使用 `--spacing-xxx`/`--radius-xxx`/`--shadow-xxx` 格式

> ⚠️ 暗色模式使用 `html.dark` 选择器覆盖CSS变量，不要使用 `@media (prefers-color-scheme)`

> ⚠️ 间距/圆角/阴影值与 `variables.css` 保持一致，避免两处定义不同步
