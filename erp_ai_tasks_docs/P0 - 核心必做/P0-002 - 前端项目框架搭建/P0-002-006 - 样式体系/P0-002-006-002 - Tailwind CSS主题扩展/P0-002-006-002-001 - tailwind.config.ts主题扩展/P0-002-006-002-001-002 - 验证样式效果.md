### 5.1 验证清单

| 序号 | 验证项 | 预期结果 | 验证方法 |
|:---:|--------|---------|---------|
| 1 | Tailwind颜色工具类可用 | text-primary/bg-primary/border-primary 等颜色正确 | DevTools Computed 检查 |
| 2 | Tailwind间距工具类可用 | p-xs/m-md/gap-lg 等间距值正确 | DevTools Computed 检查 padding/margin |
| 3 | Tailwind圆角工具类可用 | rounded-sm/rounded-md/rounded-lg 圆角正确 | DevTools Computed 检查 border-radius |
| 4 | Tailwind阴影工具类可用 | shadow-sm/shadow-md/shadow-lg 阴影正确 | DevTools Computed 检查 box-shadow |
| 5 | Element Plus组件一致性 | el-button/el-input 等使用项目设计Token | DevTools Computed 检查 |
| 6 | 暗色模式正常切换 | html.dark 下所有颜色/阴影变量自动覆盖 | Console切换 + DevTools |
| 7 | 响应式断点正常 | sm/md/lg/xl 断点布局正确 | 调整浏览器窗口宽度验证 |

### 5.2 测试方法

1. **浏览器视觉检查**：打开测试页面，确认 Tailwind 工具类样式效果符合设计稿
2. **DevTools Computed 样式**：逐一检查 Tailwind 颜色/间距/圆角/阴影工具类的 Computed 值
3. **暗色模式切换**：Console 执行 `document.documentElement.classList.toggle('dark')`，确认样式平滑切换
4. **响应式验证**：使用 DevTools Device Toolbar 切换不同屏幕尺寸，检查布局断点

### 5.3 问题处理

- Tailwind类不生成：检查 `app.css` 中 `@theme` 块语法是否正确
- 暗色模式不切换：检查 `html.dark` 选择器是否覆盖所有变量
- 响应式断点不生效：检查 `app.css` 中 `@theme` 是否定义了 `--breakpoint-*` Token

## 八、易错警示

> ⚠️ Tailwind CSS 4 使用 CSS-based 配置（`app.css`），不使用 `tailwind.config.ts`

> ⚠️ Tailwind 禁止使用 `dark:` 前缀，暗色模式通过 CSS 变量自动切换

> ⚠️ 暗色模式使用 `html.dark` 选择器覆盖CSS变量，不要使用 `@media (prefers-color-scheme)`

> ⚠️ 所有 Tailwind 颜色类必须引用 CSS 变量，不要硬编码颜色值

> ⚠️ 响应式断点仅在布局类中使用（如 `md:erp-flex`），颜色/阴影类不需要响应式
