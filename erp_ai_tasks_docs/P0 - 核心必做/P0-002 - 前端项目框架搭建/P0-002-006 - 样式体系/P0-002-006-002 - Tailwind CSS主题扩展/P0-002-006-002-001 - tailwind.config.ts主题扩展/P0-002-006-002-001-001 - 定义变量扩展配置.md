### 5.1 配置结构

文件路径：`erp-web/app.css`（Tailwind CSS 4 CSS-based 配置入口）

本任务定义 Tailwind CSS 4 的完整主题扩展，包括颜色、间距、圆角、阴影、字体等所有设计 Token：

```css
@import "tailwindcss";

@theme {
  /* 颜色Token - 引用CSS变量 */
  --color-primary: var(--color-primary);
  --color-success: var(--color-success);
  --color-warning: var(--color-warning);
  --color-danger: var(--color-danger);
  --color-info: var(--color-info);
  --color-text-primary: var(--color-text-primary);
  --color-text-regular: var(--color-text-regular);
  --color-text-secondary: var(--color-text-secondary);
  --color-bg: var(--color-bg);
  --color-bg-page: var(--color-bg-page);
  --color-border: var(--color-border);

  /* 间距Token */
  --spacing-xs: 4px;
  --spacing-sm: 8px;
  --spacing-md: 16px;
  --spacing-lg: 24px;
  --spacing-xl: 32px;

  /* 圆角Token */
  --radius-sm: 2px;
  --radius-md: 4px;
  --radius-lg: 8px;

  /* 阴影Token */
  --shadow-sm: 0 1px 2px rgba(0,0,0,0.05);
  --shadow-md: 0 4px 6px rgba(0,0,0,0.1);
  --shadow-lg: 0 10px 15px rgba(0,0,0,0.1);
}
```

### 5.2 关键配置项

| 类别 | Token示例 | 生成的工具类 |
|------|----------|------------|
| 颜色 | `--color-primary` | `text-primary`, `bg-primary`, `border-primary` |
| 间距 | `--spacing-md` | `p-md`, `m-md`, `gap-md`, `w-md`, `h-md` |
| 圆角 | `--radius-lg` | `rounded-lg` |
| 阴影 | `--shadow-md` | `shadow-md` |

### 5.3 与项目集成

- `app.css` 在 `erp-web/src/main.ts` 中引入，作为 Tailwind CSS 4 的唯一配置入口
- 颜色 Token 引用 `variables.css` 中的 CSS 变量，暗色模式自动切换
- 间距/圆角/阴影 Token 与 `variables.css` 中的值保持同步
- **禁止使用 `dark:` 前缀**，暗色模式通过 CSS 变量自动覆盖实现

## 八、易错警示

> ⚠️ Tailwind CSS 4 使用 CSS-based 配置（`app.css`），不使用 `tailwind.config.ts`

> ⚠️ Tailwind 禁止使用 `dark:` 前缀，暗色模式通过 CSS 变量自动切换

> ⚠️ CSS变量命名统一使用 `--color-xxx`/`--spacing-xxx`/`--radius-xxx`/`--shadow-xxx` 格式

> ⚠️ 所有 Tailwind 颜色类必须引用 CSS 变量（`var(--color-xxx)`），不要硬编码颜色值

> ⚠️ 暗色模式使用 `html.dark` 选择器覆盖 CSS 变量，不要使用 `@media (prefers-color-scheme)`
