### 5.1 验证清单

| 序号 | 验证项 | 预期结果 | 验证方法 |
|:---:|--------|---------|---------|
| 1 | 首屏外图片不加载 | Network中首屏外图片无请求 | DevTools Network 筛选 Img 类型 |
| 2 | 200px预加载 | 距视口200px时开始加载 | 缓慢滚动观察 Network 请求时机 |
| 3 | 加载后停止观察 | 图片加载后不再触发observer | 打断点检查 unobserve 调用 |
| 4 | 加载失败显示占位图 | 无效URL显示placeholder | 设置无效URL验证 |
| 5 | unmounted释放observer | 组件卸载后observer被disconnect | DevTools Memory 检查 |
| 6 | URL更新时重新加载 | v-lazy-img绑定值变化时加载新图 | 动态修改绑定值验证 |

### 5.2 测试方法

1. **网络请求检查**：DevTools Network 筛选 Img 类型，滚动页面观察图片请求时机
2. **预加载距离验证**：使用 DevTools 标尺测量图片加载触发时距视口的距离，应为 ~200px
3. **错误回退验证**：设置无效图片 URL，确认 `onerror` 触发后显示 placeholder
4. **内存泄漏检测**：包含 v-lazy-img 的组件挂载 → 卸载 → 挂载循环 10 次，DevTools Memory 检查

### 5.3 问题处理

- 图片不加载：检查 `IntersectionObserver` 的 `rootMargin` 是否设为 `200px`
- 图片重复加载：检查 `entry.isIntersecting` 后是否调用 `observer.unobserve(el)`
- 内存泄漏：检查 `unmounted` 中是否 `observer.disconnect()`
- 占位图不显示：检查 mounted 时是否设置了初始 `el.src` 为 data URI 占位图

## 八、易错警示

> ⚠️ v-lazy-img 的 IntersectionObserver `rootMargin` 设为 `200px` 预加载

> ⚠️ `unmounted` 钩子中必须 `observer.disconnect()`，否则内存泄漏

> ⚠️ 占位图使用 inline SVG data URI，避免额外 HTTP 请求

> ⚠️ 加载成功后必须 `observer.unobserve(el)`，否则每次进入视口都会重新加载

> ⚠️ TypeScript 扩展 DOM 类型使用 `interface extends HTMLImageElement`，禁止 `(el as any)` 写法
