### 5.1 文件结构与接口设计

文件路径：`erp-web/src/directives/lazy-img.ts`

```typescript
import type { Directive } from 'vue'

/** 扩展HTMLImageElement，挂载observer实例 */
interface LazyImgElement extends HTMLImageElement {
  _lazyObserver?: IntersectionObserver
  _lazyErrorSrc?: string
}

/**
 * v-lazy-img 图片懒加载指令
 * 绑定值为图片URL字符串
 */
export const vLazyImg: Directive<LazyImgElement, string> = {
  mounted(el, binding) {
    // 实现见5.2
  },
  updated(el, binding) {
    // URL变化时更新
  },
  unmounted(el) {
    el._lazyObserver?.disconnect()
  }
}
```

### 5.2 核心实现逻辑

1. **IntersectionObserver 监听**：`rootMargin: '200px'` 预加载视口外 200px 的图片，`threshold: 0.01`
2. **加载触发**：`entry.isIntersecting` 为 true 时，`el.src = binding.value`，然后 `observer.unobserve(el)` 停止监听
3. **错误处理**：`el.onerror = () => { el.src = el._lazyErrorSrc || '/placeholder.png' }`
4. **占位图**：mounted 时设置 `el.src` 为 1x1 透明占位图（`data:image/gif;base64,...`），避免空白
5. **生命周期清理**：`unmounted` 中 `observer.disconnect()` 释放资源，防止内存泄漏
6. **TypeScript 扩展**：通过 `interface LazyImgElement extends HTMLImageElement` 扩展 DOM 类型，避免 `(el as any)` 写法

### 5.3 使用方式

```vue
<template>
  <img v-lazy-img="'https://cdn.example.com/photo.jpg'"
       class="w-full h-48 object-cover"
       alt="商品图片" />
</template>
```

- 绑定值为图片 URL 字符串
- 图片进入视口（含 200px 预加载区）时自动加载
- 列表渲染场景中显著减少首屏 HTTP 请求数
- 需在 `erp-web/src/main.ts` 中全局注册：`app.directive('lazy-img', vLazyImg)`

## 八、易错警示

> ⚠️ v-lazy-img 的 IntersectionObserver `rootMargin` 设为 `200px` 预加载，不要设为 0（用户会看到空白闪烁）

> ⚠️ `unmounted` 钩子中必须 `observer.disconnect()`，否则组件销毁后 observer 仍在监听，导致内存泄漏

> ⚠️ 占位图使用 inline SVG data URI（`data:image/svg+xml,...`），避免额外 HTTP 请求

> ⚠️ `onerror` 回退图推荐使用项目统一的默认图片路径

> ⚠️ TypeScript 扩展 DOM 类型使用 `interface extends HTMLImageElement`，禁止 `(el as any)` 写法
