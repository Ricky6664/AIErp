### 5.1 文件结构与接口设计

文件路径：`erp-web/src/directives/virtual-scroll.ts`

```typescript
import type { Directive, DirectiveBinding, VNode } from 'vue'

/** 虚拟滚动指令绑定值 */
export interface VirtualScrollOptions<T = unknown> {
  /** 数据源数组 */
  items: T[]
  /** 每行固定高度（px） */
  itemHeight: number
  /** 渲染函数，返回VNode */
  render: (item: T, index: number) => VNode
  /** 上下各缓冲行数，默认3 */
  buffer?: number
}

/** 内部状态 */
interface VirtualScrollState {
  startIndex: number
  endIndex: number
  scrollTop: number
  heightCache: Map<number, number>
}
```

### 5.2 核心实现逻辑

1. **可视区域计算**：根据容器 `clientHeight` 和 `itemHeight` 计算可视行数 `visibleCount = Math.ceil(containerHeight / itemHeight)`
2. **缓冲区机制**：实际渲染范围 `[startIndex - buffer, endIndex + buffer]`，buffer 默认 3 行
3. **定位方式**：每个渲染项使用 `position: absolute` + `transform: translateY(${offset}px)` 定位，**禁止使用 top/margin-top**（性能差）
4. **滚动监听**：`container.addEventListener('scroll', handleScroll, { passive: true })`，scroll 事件中更新 `startIndex`/`endIndex`
5. **动态高度缓存**：当 `itemHeight` 不固定时，使用 `ResizeObserver` 或 `getBoundingClientRect()` 测量每项实际高度，存入 `heightCache: Map<number, number>`
6. **总高度占位**：容器内放置一个 `totalHeight` 高度的占位 div（`height: ${items.length * itemHeight}px`），撑出滚动条
7. **生命周期清理**：`unmounted` 钩子中 `removeEventListener('scroll')` 并清理 `heightCache`

### 5.3 使用方式

```vue
<template>
  <div v-virtual-scroll="{ items: list, itemHeight: 48, render: renderItem }"
       style="height: 600px; overflow-y: auto;" />
</template>
```

- 指令绑定值为 `VirtualScrollOptions` 对象
- 容器必须设置固定高度和 `overflow-y: auto`
- 支持 10 万条数据流畅渲染，DOM 节点数始终为可视区 ± buffer 行

## 八、易错警示

> ⚠️ v-virtual-scroll 使用 `transform: translateY` 定位，不要使用 `top`/`margin-top`（触发重排，性能差）

> ⚠️ 容器必须设置固定高度和 `overflow-y: auto`，否则无法产生滚动

> ⚠️ 动态高度场景需缓存每项实际高度（`heightCache: Map`），重新计算总高度

> ⚠️ scroll 事件使用 `{ passive: true }` 避免阻塞主线程

> ⚠️ TypeScript 严格模式，`Directive` 泛型必须指定 `HTMLElement` 和绑定值类型，禁止使用 any
