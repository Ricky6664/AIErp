### 5.1 配置结构

文件路径：`erp-web/vite.config.ts`

```typescript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig(({ mode }) => ({
  plugins: [vue()],
  build: {
    target: 'es2015',
    rollupOptions: {
      output: {
        manualChunks: {
          vue: ['vue', 'vue-router', 'pinia'],
          elementPlus: ['element-plus'],
          vendor: ['axios', 'dayjs', 'lodash-es'],
        },
      },
    },
    minify: 'terser',
    terserOptions: {
      compress: {
        drop_console: mode === 'production',
        drop_debugger: mode === 'production',
      },
    },
    sourcemap: mode !== 'production',
    chunkSizeWarningLimit: 1500,
  },
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true,
      },
    },
  },
  resolve: {
    alias: { '@': '/src' },
  },
}))
```

### 5.2 关键配置项

| 配置项 | 用途 | 值 |
|--------|------|-----|
| `build.target` | 最低兼容浏览器版本 | `es2015` |
| `manualChunks.vue` | Vue全家桶分包 | `['vue', 'vue-router', 'pinia']` |
| `manualChunks.elementPlus` | Element Plus独立分包 | `['element-plus']` |
| `manualChunks.vendor` | 第三方工具库分包 | `['axios', 'dayjs', 'lodash-es']` |
| `minify` | 压缩工具 | `terser` |
| `terserOptions.compress.drop_console` | 生产环境移除console | `mode === 'production'` |
| `sourcemap` | 源码映射（仅开发环境） | `mode !== 'production'` |
| `chunkSizeWarningLimit` | chunk大小警告阈值 | `1500` (KB) |

### 5.3 与项目集成

- `vite.config.ts` 是 Vite 构建的唯一配置入口
- `manualChunks` 分包策略将 vue 全家桶、element-plus、业务 vendor 分开，利用浏览器缓存
- 生产环境构建命令：`pnpm build`，产物输出到 `erp-web/dist/`
- 开发环境 `server.proxy` 将 `/api` 请求代理到后端 `http://localhost:8080`
- `resolve.alias` 配置 `@` 指向 `src` 目录，简化导入路径

## 八、易错警示

> ⚠️ vite.config.ts `manualChunks` 分包：vue全家桶、element-plus、业务vendor分开

> ⚠️ 单chunk不超过300KB gzipped，超过需进一步拆分

> ⚠️ 生产环境 `drop_console: true` 移除所有 console，但不要移除 `console.warn`/`console.error`

> ⚠️ `resolve.alias` 中 `@` 必须指向 `src` 目录，否则 `import @/xxx` 无法解析

> ⚠️ `server.proxy` 需要 `changeOrigin: true`，否则后端可能拒绝跨域请求

> ⚠️ 环境变量使用 `VITE_` 前缀（如 `VITE_API_BASE_URL`），Vite 仅暴露此前缀变量
