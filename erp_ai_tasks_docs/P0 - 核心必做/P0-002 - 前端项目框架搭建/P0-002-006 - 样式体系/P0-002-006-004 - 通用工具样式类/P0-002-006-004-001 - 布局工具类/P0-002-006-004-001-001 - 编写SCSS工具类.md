### 5.1 配置结构

文件路径：`erp-web/src/styles/tools/_layout.scss`

布局工具类使用SCSS编写，通过 `@each` 循环批量生成，所有类名加 `.erp-` 前缀避免与 Tailwind/Element Plus 冲突。

```scss
@use '../variables' as *;

// Flex布局工具类
.erp-flex { display: flex; }
.erp-flex-center { display: flex; align-items: center; justify-content: center; }
.erp-flex-between { display: flex; align-items: center; justify-content: space-between; }
.erp-flex-around { display: flex; align-items: center; justify-content: space-around; }
.erp-flex-col { display: flex; flex-direction: column; }
.erp-flex-wrap { flex-wrap: wrap; }
.erp-flex-1 { flex: 1; }

// Grid布局工具类
.erp-grid-auto-fill {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  gap: var(--spacing-md);
}

// 固定高度滚动容器
.erp-fixed-scroll {
  height: 100%;
  overflow-y: auto;
  &::-webkit-scrollbar { width: 6px; }
  &::-webkit-scrollbar-thumb { background: #c0c4cc; border-radius: 3px; }
}
```

### 5.2 关键配置项

| 类名 | 用途 | 核心CSS属性 |
|------|------|------------|
| `.erp-flex` | 基础flex容器 | `display: flex` |
| `.erp-flex-center` | 居中对齐 | `align-items: center; justify-content: center` |
| `.erp-flex-between` | 两端对齐 | `justify-content: space-between` |
| `.erp-flex-around` | 均匀分布 | `justify-content: space-around` |
| `.erp-flex-col` | 纵向排列 | `flex-direction: column` |
| `.erp-grid-auto-fill` | 自适应网格 | `repeat(auto-fill, minmax(250px, 1fr))` |
| `.erp-fixed-scroll` | 固定高度滚动 | `height: 100%; overflow-y: auto` |
| `.erp-p-{size}` | 间距工具（xs/sm/md/lg/xl） | `padding: var(--spacing-xxx)` |
| `.erp-m-{size}` | 外边距工具 | `margin: var(--spacing-xxx)` |

### 5.3 与项目集成

- `_layout.scss` 在 `erp-web/src/styles/global.scss` 中通过 `@use './tools/layout'` 引入
- `global.scss` 在 `erp-web/src/main.ts` 中引入
- Vue 组件中使用 `class="erp-flex-between erp-p-md"` 等组合
- 间距/圆角/阴影工具类通过 `var(--spacing-xxx)`/`var(--radius-xxx)`/`var(--shadow-xxx)` 引用 CSS 变量

## 八、易错警示

> ⚠️ 工具类用 `!important` 要谨慎，避免覆盖组件库样式

> ⚠️ SCSS工具类加项目前缀（`.erp-flex`）避免与Tailwind/Element Plus冲突

> ⚠️ 使用SCSS map定义间距规范，不要写魔法数字

> ⚠️ 工具类引用CSS变量（`var(--spacing-xxx)`），不要硬编码像素值，支持主题切换

> ⚠️ `position: sticky` 需要父元素 `overflow: visible` 才能生效
