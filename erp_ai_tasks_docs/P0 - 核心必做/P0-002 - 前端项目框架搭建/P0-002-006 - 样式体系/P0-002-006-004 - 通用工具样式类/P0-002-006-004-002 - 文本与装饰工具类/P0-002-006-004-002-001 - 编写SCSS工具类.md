### 5.1 配置结构

文件路径：`erp-web/src/styles/tools/_text.scss`

文本与装饰工具类使用SCSS编写，通过 `@each` 循环和 CSS 变量批量生成，所有类名加 `.erp-` 前缀。

```scss
@use '../variables' as *;

// 单行省略
.erp-text-ellipsis {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}

// 多行省略
@for $i from 2 through 5 {
  .erp-text-truncate-#{$i} {
    display: -webkit-box;
    -webkit-box-orient: vertical;
    -webkit-line-clamp: $i;
    overflow: hidden;
    text-overflow: ellipsis;
  }
}

// 颜色工具类（引用CSS变量）
$color-map: (primary, success, warning, danger, info);
@each $name in $color-map {
  .erp-text-#{$name} { color: var(--color-#{$name}); }
  .erp-bg-#{$name} { background-color: var(--color-#{$name}); }
}

// 过渡动画
.erp-transition-fade { transition: opacity 0.3s ease; }
.erp-transition-scale { transition: transform 0.2s ease; }
.erp-transition-all { transition: all 0.3s ease; }
```

### 5.2 关键配置项

| 类名 | 用途 | 核心CSS属性 |
|------|------|------------|
| `.erp-text-ellipsis` | 单行文本省略 | `overflow: hidden; text-overflow: ellipsis; white-space: nowrap` |
| `.erp-text-truncate-{2-5}` | 多行文本省略 | `-webkit-line-clamp: N` |
| `.erp-text-{color}` | 文本颜色 | `color: var(--color-xxx)` |
| `.erp-bg-{color}` | 背景颜色 | `background-color: var(--color-xxx)` |
| `.erp-transition-{type}` | 过渡动画 | `transition: xxx 0.3s ease` |
| `.erp-font-{size}` | 字体大小 | `font-size: var(--font-size-xxx)` |
| `.erp-text-{align}` | 文本对齐 | `text-align: left/center/right` |

### 5.3 与项目集成

- `_text.scss` 在 `erp-web/src/styles/global.scss` 中通过 `@use './tools/text'` 引入
- Vue 组件中使用 `class="erp-text-ellipsis erp-text-primary"` 等组合
- 颜色工具类引用 `var(--color-xxx)` 变量，暗色模式自动切换
- 过渡动画工具类用于 hover/focus 等交互场景

## 八、易错警示

> ⚠️ text-ellipsis 必须配合 `overflow:hidden` 和 `white-space:nowrap`

> ⚠️ 多行省略的 `-webkit-box-orient: vertical` 容易被 autoprefixer 删除，需添加 `/* autoprefixer: ignore next */` 注释

> ⚠️ 颜色工具类必须引用CSS变量（`var(--color-xxx)`），不要硬编码颜色值，否则无法跟随主题切换

> ⚠️ SCSS工具类加项目前缀（`.erp-text-`）避免与Tailwind/Element Plus冲突

> ⚠️ `transition` 不要使用 `all` 大范围过渡，指定具体属性（`transition: opacity 0.3s`）性能更好
