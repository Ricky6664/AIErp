### 5.1 验证清单

| 序号 | 验证项 | 预期结果 | 验证方法 |
|:---:|--------|---------|---------|
| 1 | 国内CDN加载正常 | 字体从 fonts.loli.net 加载 | DevTools Network 筛选 Font 类型 |
| 2 | CDN加载时间合理 | 字体加载 < 3秒 | DevTools Network Timing 面板 |
| 3 | 环境变量正确 | VITE_EXTERNAL_CDN_BASE 值正确 | Console 打印 import.meta.env |
| 4 | CDN超时自动切换 | 主CDN超时后切换备用CDN | 修改hosts模拟超时，观察Network |
| 5 | 字体正常渲染 | 页面字体显示正确 | 视觉检查 |
| 6 | CDN全部失败回退本地 | 所有CDN失败时使用本地字体 | 断网后检查字体渲染 |
| 7 | preconnect加速生效 | CDN域名DNS预解析 | DevTools Network → Timing |

### 5.2 测试方法

1. **网络请求检查**：DevTools Network 筛选 Font/CSS 类型，确认从正确的 CDN 域名加载
2. **超时切换测试**：修改 hosts 文件屏蔽主 CDN 域名，观察是否自动切换到备用 CDN
3. **字体渲染验证**：页面加载后视觉检查字体是否正确显示，无 FOUT（Flash of Unstyled Text）
4. **环境变量检查**：Console 中打印 `import.meta.env.VITE_EXTERNAL_CDN_BASE` 确认值正确
5. **全失败回退测试**：断网或屏蔽所有 CDN 域名，确认本地字体文件可用

### 5.3 问题处理

- CDN加载超时：检查超时时间设置（应为 3000ms），确认超时后切换逻辑正确
- 字体不显示：检查 `<link rel="preload">` 是否正确，检查本地回退字体文件是否存在
- 环境变量未读取：检查 `.env` 文件中变量是否使用 `VITE_` 前缀
- FOUT闪烁：检查是否使用 `<link rel="preload" as="style">` 预加载

## 八、易错警示

> ⚠️ 国内CDN使用 `fonts.loli.net` 替代 `fonts.googleapis.com`

> ⚠️ CDN切换使用环境变量（`VITE_EXTERNAL_CDN_BASE`），不要硬编码URL

> ⚠️ 字体加载超时应设为 3000ms，超时后回退到系统字体

> ⚠️ 使用 `<link rel="preload">` 预加载关键字体，避免 FOIT（Flash of Invisible Text）

> ⚠️ `index.html` 中为CDN域名添加 `<link rel="preconnect">` 加速域名解析
