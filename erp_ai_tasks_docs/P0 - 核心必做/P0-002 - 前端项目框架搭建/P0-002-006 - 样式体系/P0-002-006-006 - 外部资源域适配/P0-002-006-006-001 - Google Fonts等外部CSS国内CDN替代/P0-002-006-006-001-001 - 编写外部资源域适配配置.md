### 5.1 配置结构

文件路径：`erp-web/src/utils/cdn-fallback.ts`

CDN 资源加载工具，支持国内/国外 CDN 自动切换和超时回退：

```typescript
/** CDN配置 */
interface CdnConfig {
  /** 国内CDN基础URL */
  domesticBase: string
  /** 国外CDN基础URL */
  internationalBase: string
  /** 加载超时时间（ms） */
  timeout: number
}

const CDN_CONFIG: CdnConfig = {
  domesticBase: 'https://fonts.loli.net',
  internationalBase: 'https://fonts.googleapis.com',
  timeout: 3000,
}
```

### 5.2 关键配置项

| 环境变量/配置项 | 用途 | 值 |
|----------------|------|-----|
| `VITE_EXTERNAL_CDN_BASE` | 当前环境CDN基础URL | 国内：fonts.loli.net，国外：fonts.googleapis.com |
| `VITE_CDN_FALLBACK_URL` | 备用CDN地址 | 超时后切换的备选源 |
| `cdnConfig.timeout` | 资源加载超时时间 | 3000ms |
| `cdnConfig.domesticBase` | 国内CDN | fonts.loli.net |
| `cdnConfig.internationalBase` | 国外CDN | fonts.googleapis.com |

### 5.3 与项目集成

- CDN 配置在 `erp-web/.env.development`/`.env.production` 中通过 `VITE_EXTERNAL_CDN_BASE` 环境变量切换
- `cdn-fallback.ts` 在应用初始化时加载，动态注入外部 CSS/字体链接到 `<head>`
- 字体加载使用 `<link rel="preload" as="style">` 预加载，超时后自动切换到备用 CDN
- 所有 CDN 资源加载失败时回退到本地字体文件（`erp-web/public/fonts/`）
- `erp-web/index.html` 中为 CDN 域名添加 `<link rel="preconnect">` 加速域名解析

## 八、易错警示

> ⚠️ 国内 CDN 使用 `fonts.loli.net` 替代 `fonts.googleapis.com`，不要使用已失效的镜像源

> ⚠️ CDN 切换使用环境变量（`VITE_EXTERNAL_CDN_BASE`），不要硬编码 URL

> ⚠️ 字体加载超时设为 3000ms，超时后回退到系统字体（`font-family: system-ui, sans-serif`）

> ⚠️ 使用 `<link rel="preload" as="style">` 预加载关键字体，避免 FOIT（Flash of Invisible Text）

> ⚠️ `index.html` 中为 CDN 域名添加 `<link rel="preconnect">` 加速域名解析
