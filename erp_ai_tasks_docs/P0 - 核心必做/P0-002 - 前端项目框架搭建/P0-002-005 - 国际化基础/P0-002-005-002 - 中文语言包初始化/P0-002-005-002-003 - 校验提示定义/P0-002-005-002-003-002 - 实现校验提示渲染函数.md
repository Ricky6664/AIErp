### 5.1 词条结构设计
实现校验提示渲染工具函数，支持占位符替换和多规则聚合：
```typescript
import { i18n } from '@/i18n'

// 校验规则接口定义
interface ValidationRule {
  type: 'required' | 'format' | 'length' | 'range' | 'custom'
  subType?: string        // format下的子类型：phone/email/idCard/url
  min?: number            // 最小值/最小长度
  max?: number            // 最大值/最大长度
}

/**
 * 替换占位符：将${xxx}替换为params中的对应值
 */
function replacePlaceholders(template: string, params: Record<string, any>): string {
  return template.replace(/\$\{(\w+)\}/g, (_, key) => {
    return params[key] !== undefined ? String(params[key]) : ''
  })
}
```

### 5.2 导出与聚合
- 实现主渲染函数`renderValidationMessage`：
```typescript
export function renderValidationMessage(rule: ValidationRule, label: string): string {
  // 根据规则类型构建i18n Key
  const key = rule.subType
    ? `validation.${rule.type}.${rule.subType}`
    : rule.type === 'required'
      ? 'validation.required'
      : `validation.${rule.type}.range` // 默认使用range子项
  // 获取模板并替换占位符
  const template = i18n.global.t(key)
  return replacePlaceholders(template, { label, min: rule.min, max: rule.max })
}
```
- 函数放在`erp-web/src/utils/validation.ts`工具文件中
- 使用具名导出，组件和表单校验器按需import

### 5.3 特殊处理
- 占位符替换使用正则`/\$\{(\w+)\}/g`匹配所有`${xxx}`格式
- 未定义的占位符替换为空字符串，不要保留原始`${xxx}`或抛出异常
- 多规则错误聚合：`getValidationMessages(rules: ValidationRule[], label: string): string`将多条错误用换行符拼接
- 与Element Plus表单集成：在el-form-item的validator回调中调用renderValidationMessage生成提示

## 七、验收标准

| 序号 | 检查项 | 验证方法 |
|:---:|--------|---------|
| 1 | 必填校验提示正确 | `renderValidationMessage({type:'required'}, '用户名')`→'用户名不能为空' |
| 2 | 格式校验提示正确 | `renderValidationMessage({type:'format',subType:'phone'}, '手机号')`→'请输入正确的手机号格式' |
| 3 | 范围校验含min/max | `renderValidationMessage({type:'length',subType:'range',min:6,max:20}, '密码')`→'密码长度须在6-20个字符之间' |
| 4 | 多规则聚合展示 | 传入2条规则→返回2行提示文本，以换行符分隔 |
| 5 | 未定义占位符处理 | 模板含`${unknown}`但params无unknown→替换为空字符串，不保留原始占位符 |

## 八、易错警示

> ⚠️ renderValidationMessage不要放在语言包文件(validation.ts)中，应放在工具层(utils/validation.ts)

> ⚠️ 占位符替换要处理undefined/null值，避免显示'undefined'字符串

> ⚠️ 多规则聚合时使用换行符('\n')分隔，不要用逗号（单条提示中可能包含逗号）

> ⚠️ 与Element Plus el-form集成时，validator回调的message参数须使用renderValidationMessage的返回值

> ⚠️ Key命名规范：validation.{ruleType}（如 validation.required），使用点号分隔
