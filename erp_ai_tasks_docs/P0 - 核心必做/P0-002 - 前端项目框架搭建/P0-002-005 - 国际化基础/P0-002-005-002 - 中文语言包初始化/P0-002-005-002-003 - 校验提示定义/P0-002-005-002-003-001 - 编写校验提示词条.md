### 5.1 词条结构设计
validation.ts 定义表单校验规则的提示消息模板：
```typescript
const validation = {
  // 必填校验
  required: '${label}不能为空',
  // 格式校验
  format: {
    phone: '请输入正确的${label}格式',
    email: '请输入正确的${label}格式',
    idCard: '请输入正确的${label}格式',
    url: '请输入正确的${label}格式'
  },
  // 长度校验
  length: {
    min: '${label}长度不能少于${min}个字符',
    max: '${label}长度不能超过${max}个字符',
    range: '${label}长度须在${min}-${max}个字符之间'
  },
  // 数值范围校验
  range: {
    min: '${label}不能小于${min}',
    max: '${label}不能大于${max}',
    between: '${label}须在${min}-${max}之间'
  },
  // 自定义规则
  custom: {
    duplicate: '${label}已存在，请勿重复添加',
    invalid: '${label}格式不正确'
  }
}
```

### 5.2 导出与聚合
- 使用`export default validation`导出整个校验提示对象
- 在`zh-CN/index.ts`中通过`import validation from './validation'`引入
- 聚合方式：`{ validation: { ...validation } }`，通过`$t('validation.required', { label: '用户名' })`访问
- 占位符替换由renderValidationMessage函数处理（见003-002任务）

### 5.3 特殊处理
- 占位符使用`${xxx}`语法：`${label}`为字段名、`${min}`/`${max}`为数值参数
- 占位符不要使用`{xxx}`（这是vue-i18n内置语法）或`{{xxx}}`（Vue模板语法），统一使用`${xxx}`由自定义render函数处理
- 格式校验类使用通用模板'请输入正确的${label}格式'，通过label参数区分手机号/邮箱等
- 所有规则必须有对应的提示模板，不能遗漏

## 八、易错警示

> ⚠️ 占位符语法统一使用`${xxx}`，不要使用`{xxx}`（vue-i18n内置）或`{{xxx}}`（Vue模板）

> ⚠️ 所有校验规则必须有对应的提示模板，遗漏的规则会导致运行时显示Key而非提示文本

> ⚠️ 数值范围类规则的${min}/${max}占位符不能遗漏，否则替换后显示'不能小于undefined'

> ⚠️ validation.ts只负责export default对象，不要引入i18n实例或调用$t()函数

> ⚠️ Key命名规范：validation.{ruleType}（如 validation.required），使用点号分隔
