### 5.1 词条结构设计
common.ts 定义跨模块复用的基础UI词条，按功能分类组织：
```typescript
const common = {
  // 操作类 - 基础按钮文本
  confirm: '确认',
  cancel: '取消',
  save: '保存',
  delete: '删除',
  edit: '编辑',
  add: '新增',
  search: '搜索',
  reset: '重置',
  submit: '提交',
  back: '返回',
  refresh: '刷新',
  // 状态类 - 布尔值/开关文本
  yes: '是',
  no: '否',
  enable: '启用',
  disable: '禁用',
  success: '成功',
  failed: '失败',
  // 标签类 - 通用功能文本
  export: '导出',
  import: '导入',
  upload: '上传',
  download: '下载',
  preview: '预览',
  // 表头类 - 表格通用列
  operation: '操作',
  serialNo: '序号',
  createTime: '创建时间',
  updateTime: '更新时间',
  remark: '备注'
}
```

### 5.2 导出与聚合
- 文件使用`export default common`导出整个词条对象
- 在`zh-CN/index.ts`中通过`import common from './common'`引入
- 聚合到语言包：`{ common: { ...common } }`，组件中通过`$t('common.confirm')`访问
- common.ts只定义词条，不做任何逻辑处理或i18n API调用

### 5.3 特殊处理
- 词条值中的占位符使用`${xxx}`语法（如`${label}不能为空`），由renderMessage函数在运行时替换
- 数字格式化不在词条中处理，使用vue-i18n的number formatter
- 空值/空列表等空状态文本：`noData: '暂无数据'`、`noResult: '暂无结果'`
- 操作类词条末尾不加标点符号，保持简洁

## 八、易错警示

> ⚠️ 语言包Key使用驼峰命名(confirm/cancelTime)，不要使用下划线(confirm_btn)或中文Key

> ⚠️ 操作类词条如"删除"、"导出"等需要二次确认的操作，词条末尾不加"..."，由组件决定是否追加

> ⚠️ common.ts只负责export default对象，不要引入i18n实例或调用$t()函数

> ⚠️ 词条值中不要包含HTML标签，如需富文本使用vue-i18n的v-html指令或组件插值

> ⚠️ Key命名规范：{module}.{function}.{field}（如 common.confirm），使用点号分隔
