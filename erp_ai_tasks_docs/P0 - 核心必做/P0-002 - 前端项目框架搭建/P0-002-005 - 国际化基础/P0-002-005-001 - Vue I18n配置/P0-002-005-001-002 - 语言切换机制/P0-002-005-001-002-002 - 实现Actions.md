### 5.1 配置结构
1. 实现`setLanguage(locale: string)` Action，处理语言切换的全部副作用：
```typescript
async function setLanguage(locale: string) {
  // 1. 动态加载语言包（如果尚未加载）
  if (!loadedLocales.value.includes(locale)) {
    await loadLocaleMessages(locale)
  }
  // 2. 切换i18n locale
  i18n.global.locale.value = locale
  // 3. 更新state
  language.value = locale
  // 4. 持久化到localStorage
  localStorage.setItem('app-language', locale)
}
```

### 5.2 关键配置项
1. `loadLocaleMessages(locale: string)` 动态加载语言包：
```typescript
const localeModules = import.meta.glob('../locales/*/index.ts')
async function loadLocaleMessages(locale: string) {
  const module = await localeModules[`../locales/${locale}/index.ts`]()
  i18n.global.setLocaleMessage(locale, module.default)
  loadedLocales.value.push(locale)
}
```
2. 使用Vite的`import.meta.glob`实现按需加载，不在初始化时import所有语言包

### 5.3 与Element Plus/dayjs集成
- setLanguage中同步更新Element Plus locale：导入`element-plus/dist/locale/zh-cn.mjs`和`en.mjs`，根据locale参数选择对应配置
- dayjs同步：`dayjs.locale(locale.toLowerCase())`，确保日期格式化跟随语言
- HTML属性：`document.documentElement.lang = locale`，用于浏览器无障碍和SEO
- 四处同步（i18n/Element Plus/dayjs/HTML lang）在setLanguage中统一完成

## 八、易错警示

> ⚠️ 切换语言时必须同步更新：i18n.locale + Element Plus locale + dayjs.locale + document.documentElement.lang

> ⚠️ 动态加载语言包使用vite的import.meta.glob，不要静态import所有语言包

> ⚠️ setLanguage必须标记为async，因为import.meta.glob返回Promise

> ⚠️ 切换语言后要更新HTML的lang属性（document.documentElement.lang），用于浏览器无障碍

> ⚠️ createI18n必须设置legacy: false，否则无法使用Composition API模式
