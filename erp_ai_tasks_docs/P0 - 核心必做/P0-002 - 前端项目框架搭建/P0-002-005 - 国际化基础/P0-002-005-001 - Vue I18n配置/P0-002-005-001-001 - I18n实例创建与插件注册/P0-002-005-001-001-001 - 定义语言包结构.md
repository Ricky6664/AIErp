### 5.1 配置结构
1. 创建`erp-web/src/i18n/index.ts`，使用`createI18n`工厂函数
2. 导入中文语言包`import zhCN from './locales/zh-CN'`和英文语言包`import enUS from './locales/en-US'`
3. messages配置为`{ 'zh-CN': zhCN, 'en-US': enUS }`
4. 导出i18n实例`export const i18n = createI18n({...})`供全局使用

### 5.2 关键配置项
```typescript
export const i18n = createI18n({
  legacy: false,                    // 必须false，启用Composition API模式
  locale: initialLocale,            // 从localStorage或浏览器语言检测
  fallbackLocale: 'zh-CN',          // 回退语言，缺失翻译时使用中文
  messages: { 'zh-CN': zhCN, 'en-US': enUS },
  missing(locale, key) {
    // 开发环境下输出警告，帮助发现未翻译词条
    console.warn(`[i18n] Missing translation: "${key}" in locale "${locale}"`)
  }
})
```

### 5.3 与Element Plus/dayjs集成
- 语言切换时需同步更新Element Plus的locale配置：`import zhCn from 'element-plus/dist/locale/zh-cn.mjs'`
- dayjs语言同步：`import 'dayjs/locale/zh-cn'` + `dayjs.locale('zh-cn')`
- HTML lang属性更新：`document.documentElement.lang = locale`
- 四处同步在一个setLanguage方法中统一处理，避免遗漏

## 八、易错警示

> ⚠️ createI18n必须设置legacy: false，否则无法使用Composition API模式（useI18n/t等将不可用）

> ⚠️ 切换语言时必须同步更新：i18n.locale + Element Plus locale + dayjs.locale + document.documentElement.lang

> ⚠️ 语言包Key使用点号分隔(sale.order.billNo)，不要使用下划线或驼峰

> ⚠️ 动态加载语言包使用vite的import.meta.glob，不要静态import所有语言包（影响首屏bundle体积）

> ⚠️ 初始语言优先级：用户设置 > localStorage > 浏览器语言 > 默认zh-CN
