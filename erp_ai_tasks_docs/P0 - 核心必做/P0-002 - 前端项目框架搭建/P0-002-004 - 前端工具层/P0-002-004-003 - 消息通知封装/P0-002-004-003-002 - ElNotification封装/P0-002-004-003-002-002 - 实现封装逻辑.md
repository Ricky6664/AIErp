### 5.1 函数签名与类型定义

```typescript
// erp-web/src/utils/notification.ts (逻辑实现)

import { ElNotification } from 'element-plus';

/** 活跃通知缓存（用于去重和批量关闭） */
const activeNotifications: Map<string, any>;

/**
 * 内部统一通知调用（去重+统一配置）
 */
function notifyImpl(options: NotifyOptions): void;

/**
 * 关闭所有活跃通知
 */
function clearAllImpl(): void;
```

### 5.2 实现逻辑

1. **通知去重**：使用Map缓存活跃通知实例，key为options.name；相同name的通知不重复弹出；通知关闭时自动从Map中删除
2. **统一配置**：
   - duration: 4500ms（默认自动关闭时间）
   - position: 'top-right'（右上角）
   - showClose: true
3. **统一图标**：与ElMessage封装一致，按type设置对应图标
4. **clearAllNotifications**：遍历activeNotifications Map，调用每个实例的close()方法，然后清空Map
5. **多通知堆叠**：多个通知同时显示时Element Plus自动计算offset避免重叠，但自定义offset时需注意

**快捷方法实现**：
- notifySuccess: `notifyImpl({ ...options, type: 'success' })`
- notifyError: `notifyImpl({ ...options, type: 'error' })`
- notifyWarning: `notifyImpl({ ...options, type: 'warning' })`

**边界处理**：
- title为空字符串时console.warn但仍弹出通知
- duration=0时通知不自动关闭，需要用户手动关闭
- name未设置时跳过去重检查（每次调用都弹出）

### 5.3 使用场景

1. **审批通知**：`notify({ title: '采购审批', message: '张三提交了采购单PO-2026-001', type: 'info', name: 'approval-PO-2026-001' })` 同一条采购单不重复通知
2. **系统公告**：`notify({ title: '系统维护', message: '今晚22:00-23:00系统维护', duration: 0 })` 不自动关闭
3. **退出登录清理**：`clearAllNotifications()` 退出时关闭所有未读通知
4. **批量导入结果**：`notifySuccess('导入完成', '成功导入100条，失败5条')`

## 八、易错警示

> ⚠️ name属性是去重关键，必须设置；未设置name的通知每次调用都会弹出

> ⚠️ 多个通知堆叠时Element Plus自动计算offset，但自定义offset时注意避免重叠

> ⚠️ 默认duration设为4500ms（比Message的3000ms长），适合需要用户阅读的通知内容

> ⚠️ clearAllNotifications要遍历Map调用每个实例的close()方法，不能只清空Map
