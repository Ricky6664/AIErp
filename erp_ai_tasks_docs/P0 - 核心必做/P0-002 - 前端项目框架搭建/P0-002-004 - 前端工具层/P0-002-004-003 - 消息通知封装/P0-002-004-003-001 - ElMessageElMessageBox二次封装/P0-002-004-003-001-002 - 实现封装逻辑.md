### 5.1 函数签名与类型定义

```typescript
// erp-web/src/utils/message.ts (逻辑实现)

import { ElMessage, ElMessageBox } from 'element-plus';
import { CircleCheck, CircleClose, Warning, InfoFilled } from '@element-plus/icons-vue';

/** 消息实例缓存Map（用于去重） */
const messageCache: Map<string, any>;

/**
 * 内部统一消息调用（去重+统一配置）
 */
function showMessage(options: MessageOptions): void;

/**
 * 确认弹窗实现
 */
function confirmImpl(message: MessageContent, title?: string, options?: ElMessageBoxOptions): Promise<boolean>;
```

### 5.2 实现逻辑

1. **消息去重**：使用Map缓存已弹出的消息实例，key为message内容的string形式；相同内容且grouping=true时不重复弹出；消息关闭时自动从Map中删除
2. **统一配置**：
   - duration: 3000ms（所有类型统一）
   - showClose: true（默认显示关闭按钮）
   - grouping: true（默认启用去重）
3. **统一图标**：
   - showSuccess → icon: CircleCheck
   - showError → icon: CircleClose
   - showWarning → icon: Warning
   - showInfo → icon: InfoFilled
4. **confirm实现**：
   - 调用`ElMessageBox.confirm(message, title, { confirmButtonText: '确定', cancelButtonText: '取消', type: 'warning' })`
   - 确认时resolve(true)
   - 取消时reject('cancel')，调用方用try-catch处理
5. **VNode支持**：message参数为VNode时直接传递给ElMessage的message属性

**边界处理**：
- message为null/undefined时不弹出消息，console.warn提示
- confirm弹窗不可关闭(allowEnterKeyConfirm)防止误操作

### 5.3 使用场景

1. **API拦截器错误提示**：在axios响应拦截器中`showError(response.data.message)`统一展示后端错误
2. **表单提交反馈**：`showSuccess('保存成功')` / `showError('保存失败，请重试')`
3. **批量操作确认**：`const ok = await confirm('确认批量删除选中的10条记录？'); if(ok) { batchDelete() }`
4. **去重场景**：快速连续点击提交按钮，相同错误消息只弹出一次

## 八、易错警示

> ⚠️ 消息去重用Map缓存message实例，关闭时从Map中删除，防止内存泄漏

> ⚠️ ElMessageBox的cancel按钮reject，不要catch吞掉，让调用方决定是否处理

> ⚠️ ElMessage的grouping属性设为true可自动合并相同内容消息，但VNode类型无法去重

> ⚠️ 图标组件需要从@element-plus/icons-vue按需导入，不要全量引入
