### 5.1 函数签名与类型定义

```typescript
// erp-web/src/utils/debounce.ts (追加导出)

import { ref, onUnmounted, type Ref } from 'vue';

/**
 * 函数只执行一次，后续调用返回首次结果
 * @param fn - 目标函数
 * @returns 包装后的只执行一次的函数
 */
export function once<T extends (...args: any[]) => any>(fn: T): T;

/**
 * 在目标函数执行前后注入钩子
 * @param fn - 目标函数
 * @param hooks - 前置和后置钩子
 * @returns 包装后的函数
 */
export function beforeAfter<T extends (...args: any[]) => any>(
  fn: T,
  hooks: { before?: (...args: Parameters<T>) => void; after?: (result: ReturnType<T>) => void }
): T;

/**
 * 带执行计数的函数包装器
 * @param fn - 目标函数
 * @returns { fn: 包装后函数, count: 执行次数ref }
 */
export function withCount<T extends (...args: any[]) => any>(
  fn: T
): { fn: T; count: Ref<number> };

/**
 * Vue Composable：响应式防抖
 * @param fn - 目标函数
 * @param delay - 延迟毫秒数
 * @returns { run: 防抖执行, cancel: 取消, isPending: 是否有pending调用 }
 */
export function useDebounce<T extends (...args: any[]) => any>(
  fn: T,
  delay?: number
): { run: (...args: Parameters<T>) => void; cancel: () => void; isPending: Ref<boolean> };

/**
 * Vue Composable：响应式节流
 * @param fn - 目标函数
 * @param interval - 间隔毫秒数
 */
export function useThrottle<T extends (...args: any[]) => any>(
  fn: T,
  interval?: number
): { run: (...args: Parameters<T>) => void; cancel: () => void; isThrottled: Ref<boolean> };
```

### 5.2 实现逻辑

1. **once**：使用闭包变量记录是否已执行和首次结果，后续调用直接返回缓存结果
2. **beforeAfter**：返回新函数，执行顺序为before → fn → after，after接收fn的返回值
3. **withCount**：使用Vue ref包装计数器，每次调用fn时count.value++，返回包装后函数和count ref
4. **useDebounce**：内部调用debounce()，在onUnmounted中自动调用cancel清理定时器，isPending用ref跟踪pending状态
5. **useThrottle**：内部调用throttle()，在onUnmounted中自动清理，isThrottled用ref跟踪节流状态

**边界处理**：
- Composable必须在setup()上下文中调用（需要onUnmounted生命周期）
- once函数执行出错时重置状态，允许下次重试
- useDebounce/useThrottle的cancel方法可在组件外安全调用

### 5.3 使用场景

1. **初始化只执行一次**：`const initOnce = once(initData)` 确保初始化逻辑不重复执行
2. **函数调用日志**：`beforeAfter(save, { before: () => showLoading(), after: () => hideLoading() })`
3. **Composable防抖搜索**：`const { run, cancel } = useDebounce(search, 300)` 在组件中使用，自动清理
4. **按钮点击计数**：`const { fn, count } = withCount(handleClick)` 跟踪按钮点击次数

## 八、易错警示

> ⚠️ useDebounce/useThrottle composable必须在onUnmounted中清理定时器，防止组件销毁后内存泄漏

> ⚠️ Composable的返回值用ref包装isPending/isThrottled状态，方便模板直接绑定

> ⚠️ Composable用于逻辑层（setup中），指令用于DOM层（模板中），二者使用场景不同

> ⚠️ 工具函数必须是纯函数，不要在其中读取localStorage或发起API调用
