### 5.1 函数签名与类型定义

```typescript
// erp-web/src/utils/number.ts

/** 数字格式化选项 */
interface FormatNumberOptions {
  /** 小数位数，默认2 */
  decimals?: number;
  /** 千分位分隔符，默认',' */
  thousandsSep?: string;
  /** 小数点符号，默认'.' */
  decimalSep?: string;
  /** 前缀（如货币符号），默认空 */
  prefix?: string;
  /** 后缀（如单位），默认空 */
  suffix?: string;
}

/**
 * 格式化金额（千分位+小数位）
 * @param value - 数值或可转换的字符串
 * @param decimals - 小数位数，默认2
 * @returns 格式化后的字符串，如 '1,234,567.89'
 */
export function formatMoney(value: number | string | null | undefined, decimals?: number): string;

/**
 * 格式化百分比
 * @param value - 小数值（0.1234表示12.34%）
 * @param decimals - 小数位数，默认2
 * @returns 百分比字符串，如 '12.34%'
 */
export function formatPercent(value: number | string | null | undefined, decimals?: number): string;

/**
 * 格式化数量（整数，无小数位）
 * @param value - 数量值
 * @returns 千分位整数格式字符串
 */
export function formatQty(value: number | string | null | undefined): string;

/**
 * 格式化文件大小（B/KB/MB/GB/TB）
 * @param bytes - 字节数
 * @returns 人类可读的文件大小字符串
 */
export function formatFileSize(bytes: number | null | undefined): string;
```

### 5.2 实现逻辑

1. **formatMoney**：使用Intl.NumberFormat('zh-CN', {minimumFractionDigits, maximumFractionDigits})实现千分位；金额保留2位小数（ERP场景）；NaN/Infinity返回'0.00'；null/undefined返回'0.00'
2. **formatPercent**：value * 100后拼接'%'，使用toFixed控制小数位；null/undefined返回'0.00%'
3. **formatQty**：使用Intl.NumberFormat('zh-CN', {maximumFractionDigits:0})输出整数千分位格式
4. **formatFileSize**：按1024进制逐级除以1024，保留2位小数，单位依次为B/KB/MB/GB/TB；bytes=0返回'0 B'

**边界处理**：
- 所有函数对null/undefined/NaN/Infinity统一返回'0.00'或对应零值格式
- 金额为0时显示'0.00'而非空字符串
- 数字格式化金额时保留2位小数（ERP标准），单价字段保留8位小数(decimal(18,8)对齐后端)

### 5.3 使用场景

1. **表格金额列**：`{{ formatMoney(row.amount) }}` 显示"1,234,567.89"
2. **报表百分比**：`{{ formatPercent(row.growthRate) }}` 显示"12.34%"
3. **库存数量**：`{{ formatQty(row.stockQty) }}` 显示"12,345"
4. **附件文件大小**：`{{ formatFileSize(file.size) }}` 显示"1.5 MB"

## 八、易错警示

> ⚠️ 数字格式化金额时保留2位小数（ERP标准），单价字段保留8位小数(decimal(18,8)对齐后端)

> ⚠️ 金额为0时显示'0.00'而非空字符串，NaN和Infinity要做兜底处理

> ⚠️ 优先使用Intl.NumberFormat而非正则替换，性能和国际化支持更好

> ⚠️ 工具函数必须是纯函数，不要在其中读取localStorage或发起API调用
