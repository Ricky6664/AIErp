### 5.1 函数签名与类型定义

```typescript
// erp-web/src/utils/number.ts (追加导出)

import Decimal from 'decimal.js';

/** 舍入模式 */
type RoundingMode = 'ROUND_HALF_UP' | 'ROUND_HALF_EVEN' | 'ROUND_DOWN' | 'ROUND_UP';

/**
 * 精确加法（解决0.1+0.2!==0.3问题）
 * @param a - 加数
 * @param b - 被加数
 * @returns 精确结果(Number)
 */
export function add(a: number | string, b: number | string): number;

/**
 * 精确减法
 */
export function subtract(a: number | string, b: number | string): number;

/**
 * 精确乘法
 */
export function multiply(a: number | string, b: number | string): number;

/**
 * 精确除法（含除零保护）
 * @param b - 除数，为0时返回0
 */
export function divide(a: number | string, b: number | string): number;

/**
 * 银行家舍入（四舍六入五成双）
 * @param value - 待舍入的值
 * @param decimals - 保留小数位数
 * @param mode - 舍入模式，默认ROUND_HALF_EVEN(银行家舍入)
 */
export function round(value: number | string, decimals: number, mode?: RoundingMode): number;
```

### 5.2 实现逻辑

1. **add/subtract/multiply/divide**：内部使用`new Decimal(a).plus(b).toNumber()`等decimal.js方法，避免JavaScript浮点数精度丢失
2. **divide除零保护**：除数为0时返回0而非Infinity，同时console.warn提示
3. **round银行家舍入**：使用Decimal的toDecimalPlaces方法配合Decimal.ROUND_HALF_EVEN模式；支持通过mode参数切换ROUND_HALF_UP(四舍五入)、ROUND_DOWN(截断)等模式
4. **全程使用Decimal**：金额计算链路中全程使用Decimal类型，只在最终展示时转Number或string，避免中途精度丢失

**边界处理**：
- 参数为string时先转Decimal验证是否合法数字
- NaN输入返回0并console.warn
- 除法结果为无限循环小数时，默认保留8位小数(decimal(18,8)对齐后端)

### 5.3 使用场景

1. **订单金额计算**：`multiply(row.price, row.qty)` 计算小计金额无精度丢失
2. **合计汇总**：列表合计使用`add(total, item.amount)`累加
3. **单价反算**：`divide(row.amount, row.qty)` 反算单价，保留8位小数
4. **金额舍入**：`round(calcResult, 2, 'ROUND_HALF_UP')` 四舍五入到分

## 八、易错警示

> ⚠️ JavaScript浮点数精度问题必须用decimal.js库解决，不要自行实现整数转换

> ⚠️ 除法必须做除零检查，除数为0时返回0并console.warn

> ⚠️ 金额计算全程使用Decimal，不要在中途转Number导致精度丢失

> ⚠️ 数字格式化金额时保留8位小数(decimal(18,8)对齐后端)适用于单价字段
