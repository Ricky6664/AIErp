### 5.1 函数签名与类型定义

```typescript
// erp-web/src/utils/object.ts

/**
 * 深拷贝对象（支持Date/RegExp/Map/Set/循环引用）
 * @param obj - 待拷贝的对象
 * @returns 深拷贝后的新对象
 */
export function deepClone<T>(obj: T): T;

/**
 * 深度合并多个对象（后面的覆盖前面的）
 * @param target - 目标对象
 * @param sources - 源对象（可变参数）
 * @returns 合并后的新对象（不修改原对象）
 */
export function deepMerge<T extends Record<string, any>>(target: T, ...sources: Partial<T>[]): T;

/**
 * 从对象中选择指定的键
 * @param obj - 源对象
 * @param keys - 要保留的键名数组
 * @returns 仅包含指定键的新对象
 */
export function pick<T extends Record<string, any>, K extends keyof T>(obj: T, keys: K[]): Pick<T, K>;

/**
 * 从对象中排除指定的键
 * @param obj - 源对象
 * @param keys - 要排除的键名数组
 * @returns 不包含指定键的新对象
 */
export function omit<T extends Record<string, any>, K extends keyof T>(obj: T, keys: K[]): Omit<T, K>;
```

### 5.2 实现逻辑

1. **deepClone**：使用WeakMap记录已拷贝对象处理循环引用；对Date返回new Date(obj.getTime())，对RegExp返回new RegExp(obj.source, obj.flags)，对Map/Set递归拷贝元素；null和原始类型直接返回
2. **deepMerge**：递归合并，使用WeakMap防止循环引用栈溢出；数组不合并直接替换（后端DTO场景）；源对象中值为undefined的键跳过不覆盖
3. **pick**：遍历keys数组，从obj中取值构建新对象，不存在的键跳过
4. **omit**：遍历obj所有键，排除keys中的键后构建新对象

**边界处理**：
- deepClone不使用JSON.parse(JSON.stringify())，会丢失函数、undefined、循环引用和特殊类型
- 所有函数不修改原对象，返回新对象（纯函数）
- 参数为null/undefined时deepClone返回null/undefined，其余返回空对象

### 5.3 使用场景

1. **表单数据备份**：`deepClone(formData)` 保存原始数据用于reset
2. **配置合并**：`deepMerge(defaultConfig, userConfig)` 合并默认配置和用户配置
3. **API参数过滤**：`pick(form, ['name','code'])` 只提交指定字段
4. **排除敏感字段**：`omit(user, ['password','salt'])` 排除密码等字段

## 八、易错警示

> ⚠️ deepClone不要用JSON.parse(JSON.stringify())，会丢失函数、undefined、循环引用和Date/RegExp等特殊类型

> ⚠️ deepMerge必须用WeakMap记录已处理对象，防止循环引用导致栈溢出

> ⚠️ pick/omit必须返回新对象，不能修改原对象（纯函数要求）

> ⚠️ 工具函数必须是纯函数，不要在其中读取localStorage或发起API调用
