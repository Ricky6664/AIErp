### 5.1 函数签名与类型定义

```typescript
// erp-web/src/utils/array.ts

/** 树节点基础结构 */
interface TreeNode {
  id: string | number;
  parentId: string | number | null;
  children?: TreeNode[];
  [key: string]: any;
}

/**
 * 扁平数组转树结构
 * @param list - 扁平数组（每项需包含id和parentId）
 * @param rootId - 根节点的parentId值，默认null或0
 * @returns 树结构数组
 */
export function arrayToTree<T extends TreeNode>(list: T[], rootId?: string | number | null): T[];

/**
 * 树结构转扁平数组
 * @param tree - 树结构数组
 * @param childrenKey - 子节点键名，默认'children'
 * @returns 扁平数组
 */
export function treeToArray<T extends Record<string, any>>(tree: T[], childrenKey?: string): T[];

/**
 * 数组去重（支持原始类型和对象数组按key去重）
 * @param arr - 源数组
 * @param keyOrFn - 去重依据：原始数组不传，对象数组传key名或取值函数
 * @returns 去重后的数组
 */
export function uniqueArray<T>(arr: T[], keyOrFn?: keyof T | ((item: T) => any)): T[];

/**
 * 数组扁平化（支持指定深度）
 * @param arr - 多维数组
 * @param depth - 展平深度，默认Infinity（完全展平）
 * @returns 扁平数组
 */
export function flatten<T>(arr: T[], depth?: number): T[];

/**
 * 按指定key对数组分组
 * @param arr - 源数组
 * @param keyOrFn - 分组依据字段名或取值函数
 * @returns 分组结果 Record<string, T[]>
 */
export function groupBy<T>(arr: T[], keyOrFn: keyof T | ((item: T) => string)): Record<string, T[]>;
```

### 5.2 实现逻辑

1. **arrayToTree**：使用Map一次遍历构建（O(n)复杂度），先以id为key建立映射，再遍历分配children；根节点parentId匹配rootId参数
2. **treeToArray**：递归遍历树，将每个节点(不含children)推入结果数组；使用迭代而非递归避免栈溢出
3. **uniqueArray**：原始类型用Set去重；对象数组用keyOrFn提取比较值，用Set记录已出现的值过滤
4. **flatten**：直接使用Array.prototype.flat(depth)实现
5. **groupBy**：遍历数组，用keyOrFn取分组值，将元素推入对应分组的数组中

**边界处理**：
- arrayToTree中空数组返回[]，无根节点时返回空数组并console.warn
- uniqueArray不传keyOrFn时对对象数组按JSON.stringify比较（性能差，仅兜底）
- groupBy返回类型标注为Record<string, T[]>

### 5.3 使用场景

1. **菜单/部门树**：`arrayToTree(menuList)` 将后端返回的扁平菜单转为树结构
2. **树搜索**：`treeToArray(tree)` 展平后filter搜索
3. **表格去重**：`uniqueArray(tableData, 'id')` 按ID去重
4. **数据分组**：`groupBy(orderList, 'status')` 按订单状态分组统计

## 八、易错警示

> ⚠️ 对象数组去重必须指定key函数，不能直接用Set（对象引用不同无法去重）

> ⚠️ arrayToTree使用Map一次遍历（O(n)），不要用嵌套循环查找（O(n²)）

> ⚠️ groupBy返回类型Record<string, T[]>要正确标注TypeScript泛型

> ⚠️ 工具函数必须是纯函数，不要在其中读取localStorage或发起API调用
