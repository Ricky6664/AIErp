### 5.1 函数签名与类型定义

```typescript
// erp-web/src/utils/date.ts

import dayjs from 'dayjs';
import 'dayjs/locale/zh-cn';

// 日期格式字符串类型
type DateFormat = 'YYYY-MM-DD' | 'YYYY-MM-DD HH:mm:ss' | 'YYYY/MM/DD' | string;

/**
 * 格式化日期为指定格式字符串
 * @param date - 日期输入，支持Date/string/number/dayjs
 * @param format - 格式字符串，默认'YYYY-MM-DD HH:mm:ss'
 * @returns 格式化后的日期字符串，无效输入返回空字符串
 */
export function formatDate(date: Date | string | number | null | undefined, format?: DateFormat): string;

/**
 * 解析字符串/时间戳为dayjs对象
 * @param value - 待解析的值
 * @returns dayjs实例，解析失败返回null
 */
export function parseDate(value: string | number | Date | null | undefined): dayjs.Dayjs | null;

/**
 * 根据起止日期生成日期范围数组
 * @param start - 起始日期
 * @param end - 结束日期
 * @param format - 格式字符串
 * @returns 日期字符串数组
 */
export function dateRange(start: Date | string, end: Date | string, format?: DateFormat): string[];

/**
 * 计算相对时间（如'3分钟前'、'2小时前'、'昨天'）
 * @param date - 目标日期
 * @returns 相对时间描述字符串
 */
export function relativeTime(date: Date | string | number): string;
```

### 5.2 实现逻辑

1. **formatDate**：统一使用dayjs格式化，对null/undefined/空字符串返回空串，对Invalid Date返回空串；默认format为`'YYYY-MM-DD HH:mm:ss'`
2. **parseDate**：使用dayjs解析，加入try-catch容错，解析失败返回null而非Invalid Date；支持ISO 8601字符串、Unix时间戳(毫秒)和Date对象
3. **dateRange**：基于dayjs逐日递增生成数组，start > end时返回空数组，边界包含start和end当天
4. **relativeTime**：使用dayjs的relativeTime插件，中文locale配置；小于1分钟显示"刚刚"，超过1年显示具体日期

**边界处理**：
- 所有函数第一个参数为null/undefined时安全返回空串或null
- 时区统一使用本地时区，不强制UTC
- dayjs初始化时注册zh-cn locale和relativeTime插件

### 5.3 使用场景

1. **表格列格式化**：`{{ formatDate(row.createTime) }}` 显示"2026-05-26 14:30:00"
2. **表单日期回显**：`parseDate(formData.dateStr)` 将后端返回的字符串转为dayjs对象供日期选择器使用
3. **报表日期范围**：`dateRange(startDate, endDate)` 生成日期列表用于图表X轴
4. **列表相对时间**：`relativeTime(item.updateTime)` 显示"3分钟前"

## 八、易错警示

> ⚠️ 日期工具函数必须处理时区问题，统一使用dayjs处理，禁止使用原生Date的getMonth()等方法自行拼接

> ⚠️ dayjs必须注册zh-cn locale和relativeTime插件后才能使用中文相对时间

> ⚠️ parseDate必须做容错处理，无效输入返回null而非Invalid Date对象

> ⚠️ 工具函数必须是纯函数，不要在其中读取localStorage或发起API调用
