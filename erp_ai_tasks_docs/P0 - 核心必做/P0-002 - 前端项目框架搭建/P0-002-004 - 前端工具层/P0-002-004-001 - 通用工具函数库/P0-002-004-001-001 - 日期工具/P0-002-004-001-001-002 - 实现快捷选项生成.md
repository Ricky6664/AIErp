### 5.1 函数签名与类型定义

```typescript
// erp-web/src/utils/date.ts (追加导出)

import dayjs from 'dayjs';

/** Element Plus日期选择器快捷选项结构 */
interface DateShortcut {
  text: string;
  value: () => [Date, Date];
}

/**
 * 生成日期范围选择器的快捷选项数组
 * 适配Element Plus el-date-picker的shortcuts属性
 * @returns DateShortcut[] 快捷选项数组
 */
export function getDateShortcuts(): DateShortcut[];

/**
 * 生成指定月份的第一天和最后一天
 * @param offset - 月份偏移量，0=本月，-1=上月
 * @returns [Date, Date] 月初和月末
 */
export function getMonthRange(offset: number): [Date, Date];

/**
 * 生成指定季度的第一天和最后一天
 * @param offset - 季度偏移量，0=本季度，-1=上季度
 * @returns [Date, Date] 季初和季末
 */
export function getQuarterRange(offset: number): [Date, Date];
```

### 5.2 实现逻辑

1. **getDateShortcuts**：返回包含"今天"、"本周"、"本月"、"本季度"、"本年"、"最近7天"、"最近30天"共7个快捷选项的数组
2. **value必须是函数**：每个选项的value是`() => [Date, Date]`函数形式，每次点击时实时计算日期范围，而非生成时写死
3. **本周起始日为周一**：国内习惯，使用dayjs().startOf('week').add(1,'day')处理（dayjs默认周日为起始，需+1天调整到周一）
4. **getMonthRange**：offset=0返回本月1日和月末，offset=-1返回上月1日和上月末，使用dayjs的startOf('month')和endOf('month')
5. **getQuarterRange**：根据当前月份计算所在季度(1-3月Q1,4-6月Q2...)，offset支持偏移

**边界处理**：
- "今天"返回 `[today 00:00:00, today 23:59:59]`
- "本年"返回 `[1月1日 00:00:00, 12月31日 23:59:59]`

### 5.3 使用场景

1. **Element Plus日期范围选择器**：`<el-date-picker :shortcuts="getDateShortcuts()" type="daterange" />` 直接使用
2. **报表查询面板**：快捷选项点击后自动填充日期范围并触发查询
3. **搜索表单**：为常用时间范围提供一键填充

## 八、易错警示

> ⚠️ 快捷选项的value必须是函数(返回Date数组)，不要直接写死日期，否则跨天时日期不会更新

> ⚠️ 本周起始日按周一计算(国内习惯)，dayjs默认周日为起始日，需要手动调整

> ⚠️ 工具函数必须是纯函数，不要在其中读取localStorage或发起API调用
