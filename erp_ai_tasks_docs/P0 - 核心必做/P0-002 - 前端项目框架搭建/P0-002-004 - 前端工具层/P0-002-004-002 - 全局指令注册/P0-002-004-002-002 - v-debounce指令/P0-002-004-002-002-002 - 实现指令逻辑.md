### 5.1 函数签名与类型定义

```typescript
// erp-web/src/directives/debounce.ts (逻辑实现)

import type { DebounceEl } from './debounce';

/**
 * 创建防抖点击处理函数
 * @param el - DOM元素
 * @param callback - 用户传入的回调函数
 * @param delay - 延迟毫秒数
 * @returns 防抖处理函数
 */
function createDebounceHandler(
  el: DebounceEl,
  callback: (...args: any[]) => void,
  delay: number
): () => void;

/**
 * 清理解抖状态
 * @param el - DOM元素
 */
function cleanupDebounce(el: DebounceEl): void;
```

### 5.2 实现逻辑

1. **防抖实现**：使用setTimeout+clearTimeout，每次点击时先clearTimeout(el._debounceTimer)再重新setTimeout，延迟delay毫秒后执行callback
2. **事件绑定**：在mounted中`el.addEventListener('click', handler)`，事件类型为click
3. **状态缓存**：将handler缓存在el._debounceHandler，timer ID缓存在el._debounceTimer，事件类型缓存在el._debounceEvent，便于updated和unmounted时使用
4. **清理逻辑**：unmounted时执行`clearTimeout(el._debounceTimer)`清除定时器，`el.removeEventListener('click', el._debounceHandler)`移除事件监听，`delete el._debounceHandler`删除缓存属性
5. **延迟解析**：binding.arg解析为parseInt，isNaN时使用默认值300ms

**关键实现细节**：
- 不使用lodash.debounce，自行实现减少依赖
- 防抖函数要缓存在el._debounceHandler上，unmounted时才能正确清除
- this指向通过闭包保持对el和callback的引用

### 5.3 使用场景

1. **表单提交防抖**：`<el-button v-debounce="submitForm">提交</el-button>` 快速多次点击只提交一次
2. **自定义延迟**：`<el-button v-debounce:1000="saveData">保存</el-button>` 1秒防抖
3. **列表操作防抖**：表格行操作按钮防止重复点击

## 八、易错警示

> ⚠️ 防抖函数必须缓存在el._debounceHandler上，unmounted时清除定时器和移除事件监听

> ⚠️ 不要用lodash.debounce，自行实现减少依赖（仅setTimeout+clearTimeout）

> ⚠️ el.addEventListener必须在mounted中绑定，unmounted中removeEventListener，事件类型和handler引用必须一致

> ⚠️ arg解析为number时要做parseInt和NaN检查，防止传入非数字导致setTimeout报错
