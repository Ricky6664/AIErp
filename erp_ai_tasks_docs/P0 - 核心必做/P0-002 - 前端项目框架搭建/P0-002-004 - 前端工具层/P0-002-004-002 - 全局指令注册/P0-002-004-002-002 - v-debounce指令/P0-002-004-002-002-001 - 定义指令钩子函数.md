### 5.1 函数签名与类型定义

```typescript
// erp-web/src/directives/debounce.ts

import type { Directive, DirectiveBinding } from 'vue';

/** v-debounce绑定值类型：回调函数 */
type DebounceCallback = (...args: any[]) => void;

/** 扩展HTMLElement以存储防抖状态 */
interface DebounceEl extends HTMLElement {
  /** 防抖处理函数 */
  _debounceHandler?: () => void;
  /** 防抖定时器ID */
  _debounceTimer?: ReturnType<typeof setTimeout>;
  /** 绑定的事件类型 */
  _debounceEvent?: string;
}

/**
 * v-debounce自定义指令定义
 * 用法：v-debounce="handleClick" 或 v-debounce:500="handleClick"（自定义延迟）
 */
export const debounceDirective: Directive<DebounceEl, DebounceCallback>;
```

### 5.2 实现逻辑

1. **mounted钩子**：
   - 从binding.arg解析延迟时间（如v-debounce:500解析为500ms），parseInt转数字，默认300ms
   - 创建防抖处理函数并缓存在el._debounceHandler上
   - 使用el.addEventListener('click', el._debounceHandler)绑定点击事件
2. **updated钩子**：
   - 如果binding.value(回调函数)变化，更新el._debounceHandler中的回调引用
   - 如果binding.arg(延迟时间)变化，重新创建防抖函数
3. **unmounted钩子**：
   - 清除el._debounceTimer定时器
   - el.removeEventListener(el._debounceEvent, el._debounceHandler)移除事件监听
   - 删除el上的_debounceHandler/_debounceTimer属性

**TypeScript类型约束**：
- 使用DebounceEl接口扩展HTMLElement，确保TypeScript能识别el上的自定义属性
- binding.value类型约束为函数类型

### 5.3 使用场景

1. **基础用法**：`<el-button v-debounce="handleSubmit">提交</el-button>` 默认300ms防抖
2. **自定义延迟**：`<el-button v-debounce:500="handleSubmit">提交</el-button>` 500ms防抖
3. **全局注册**：在main.ts中通过`app.directive('debounce', debounceDirective)`注册

## 八、易错警示

> ⚠️ unmounted中必须清除定时器并移除事件监听，否则组件销毁后仍会触发回调导致内存泄漏

> ⚠️ arg解析为number时必须做parseInt和NaN检查，解析失败则使用默认值300ms

> ⚠️ el.addEventListener必须在mounted中绑定，unmounted中removeEventListener，事件类型要一致
