### 5.1 函数签名与类型定义

```typescript
// erp-web/src/directives/permission.ts

import type { Directive, DirectiveBinding } from 'vue';

/** v-permission绑定值类型 */
type PermissionValue = string | string[];

/**
 * v-permission自定义指令定义
 * 用法：v-permission="'system:user:add'" 或 v-permission="['system:user:add','system:user:edit']"
 */
export const permissionDirective: Directive<HTMLElement, PermissionValue>;

/**
 * 检查当前用户是否拥有指定权限
 * @param value - 权限码或权限码数组
 * @returns 是否有权限（数组时满足任一即可）
 */
export function checkPermission(value: PermissionValue): boolean;
```

### 5.2 实现逻辑

1. **mounted钩子**：在元素挂载后读取binding.value（权限码），调用checkPermission检查权限，无权限时通过el.parentNode?.removeChild(el)移除DOM元素
2. **updated钩子**：在绑定值更新时重新执行权限检查，处理动态权限变更场景
3. **unmounted钩子**：清理工作（如有缓存的权限状态则清除）
4. **绑定值解析**：支持string（单个权限码）和string[]（多个权限码，满足任一即可），使用TypeScript的DirectiveBinding<PermissionValue>泛型约束

**TypeScript类型约束**：
- 指令使用`Directive<HTMLElement, PermissionValue>`确保el为HTMLElement、binding.value为PermissionValue类型
- checkPermission函数参数用联合类型`string | string[]`约束

### 5.3 使用场景

1. **按钮级权限控制**：`<el-button v-permission="'system:user:add'">新增</el-button>`
2. **多权限任一匹配**：`<el-button v-permission="['system:user:edit','system:user:audit']">操作</el-button>`
3. **全局注册**：在main.ts中通过`app.directive('permission', permissionDirective)`注册

## 八、易错警示

> ⚠️ 指令钩子必须使用TypeScript的DirectiveBinding<PermissionValue>泛型约束，避免binding.value为any

> ⚠️ mounted中获取权限值，updated中必须重新判断权限变化（支持动态权限切换）

> ⚠️ v-permission指令使用v-if方式(移除DOM)而非v-show，确保DOM中不存在无权限元素
