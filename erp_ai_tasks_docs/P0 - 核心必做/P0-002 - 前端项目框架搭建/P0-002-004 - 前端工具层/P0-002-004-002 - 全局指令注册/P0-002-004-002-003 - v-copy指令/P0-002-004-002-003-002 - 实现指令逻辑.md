### 5.1 函数签名与类型定义

```typescript
// erp-web/src/directives/copy.ts (逻辑实现)

import { ElMessage } from 'element-plus';
import type { CopyEl } from './copy';

/**
 * 复制文本到剪贴板
 * 优先使用navigator.clipboard API，降级使用document.execCommand('copy')
 * @param text - 待复制的文本
 * @returns Promise<boolean> 是否复制成功
 */
async function copyToClipboard(text: string): Promise<boolean>;

/**
 * 创建复制点击处理函数
 * @param el - DOM元素
 * @returns 点击处理函数
 */
function createCopyHandler(el: CopyEl): () => void;
```

### 5.2 实现逻辑

1. **copyToClipboard**：
   - 优先尝试`navigator.clipboard.writeText(text)`（现代浏览器，需HTTPS或localhost）
   - 降级方案：创建临时textarea元素，设置value，调用`document.execCommand('copy')`，然后移除textarea
   - 返回Promise<boolean>表示是否成功
2. **createCopyHandler**：
   - 读取el._copyValue获取待复制文本
   - 空字符串检查：为空时ElMessage.warning('复制内容为空')并return
   - 调用copyToClipboard，成功后ElMessage.success('复制成功')，失败后ElMessage.error('复制失败')
3. **事件绑定**：mounted中el.addEventListener('click', handler)
4. **清理逻辑**：unmounted中removeEventListener并删除el._copyValue/_copyHandler

**关键实现细节**：
- navigator.clipboard.writeText需要HTTPS或localhost环境，HTTP环境下会reject
- execCommand('copy')已废弃但作为降级方案保留，用try-catch包裹
- 复制空字符串时提示用户而非静默失败

### 5.3 使用场景

1. **订单详情复制**：`<span v-copy="order.orderNo" class="copyable">{{ order.orderNo }} <el-icon><DocumentCopy /></el-icon></span>`
2. **API地址复制**：开发文档中点击代码块复制API地址
3. **表格单元格复制**：表格中点击单元格复制内容到剪贴板

## 八、易错警示

> ⚠️ navigator.clipboard.writeText需要HTTPS或localhost环境，生产环境HTTP下会失败

> ⚠️ execCommand('copy')已废弃但必须作为降级方案保留，用try-catch包裹

> ⚠️ 复制空字符串时应该提示用户(ElMessage.warning)而不是静默失败

> ⚠️ 降级方案的临时textarea要设置position:fixed;left:-9999px避免页面闪烁
