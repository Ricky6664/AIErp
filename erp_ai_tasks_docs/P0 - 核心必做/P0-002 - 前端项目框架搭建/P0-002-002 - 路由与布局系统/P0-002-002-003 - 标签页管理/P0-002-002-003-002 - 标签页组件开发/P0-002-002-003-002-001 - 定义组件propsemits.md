### 5.1 文件结构与组件设计

文件路径：`erp-web/src/layouts/components/TabNav/types.ts`

```typescript
import type { TagView } from '@/stores/modules/tagsView'

/** TabNav组件Props */
export interface TabNavProps {
  /** 当前激活标签的路径 */
  activePath: string
  /** 标签列表(从tagsViewStore获取) */
  views: TagView[]
}

/** TabNav组件Emits */
export interface TabNavEmits {
  /** 选中标签 */
  (e: 'select', path: string): void
  /** 关闭标签 */
  (e: 'close', tag: TagView): void
  /** 刷新标签 */
  (e: 'refresh', path: string): void
  /** 右键菜单 */
  (e: 'contextmenu', event: MouseEvent, tag: TagView): void
}
```

文件路径：`erp-web/src/layouts/components/TabNav/index.vue`（Props/Emits声明部分）

```vue
<script setup lang="ts">
import type { TagView } from '@/stores/modules/tagsView'

defineOptions({ name: 'TabNav' })

const props = withDefaults(defineProps<{
  activePath: string
  views: readonly TagView[]
}>(), {
  activePath: '',
  views: () => []
})

const emit = defineEmits<{
  (e: 'select', path: string): void
  (e: 'close', tag: TagView): void
  (e: 'refresh', path: string): void
  (e: 'contextmenu', event: MouseEvent, tag: TagView): void
}>()
</script>
```

### 5.2 核心实现逻辑

1. **Props类型安全**：使用泛型defineProps + withDefaults设置默认值
2. **readonly views**：标签列表使用readonly修饰，子组件不直接修改props
3. **Emits类型声明**：使用defineEmits泛型声明所有事件及参数类型
4. **TagView类型复用**：从store中导出TagView接口，Props和Emits统一使用

### 5.3 交互逻辑

1. 点击标签 → emit('select', tag.fullPath) → 父组件调用router.push
2. 点击关闭按钮 → emit('close', tag) → 父组件调用tagsViewStore.closeSelectedTag
3. 右键标签 → emit('contextmenu', event, tag) → 父组件打开ContextMenu
4. activePath变化 → 对应标签高亮样式更新

## 八、易错警示

> ⚠️ Emits必须显式声明类型，Vue3不再支持隐式emit

> ⚠️ views使用readonly TagView[]修饰，子组件不要直接修改props

> ⚠️ defineEmits泛型中每个事件都要声明参数类型，避免运行时参数错误
