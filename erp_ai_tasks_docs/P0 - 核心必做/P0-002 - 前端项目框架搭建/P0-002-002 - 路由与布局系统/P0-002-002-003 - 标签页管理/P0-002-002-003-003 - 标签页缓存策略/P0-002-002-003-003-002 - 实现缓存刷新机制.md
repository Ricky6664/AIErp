### 5.1 文件结构与组件设计

**文件1：`erp-web/src/router/modules/redirect.ts` — Redirect中转路由**

```typescript
import type { RouteRecordRaw } from 'vue-router'

export const REDIRECT_ROUTE: RouteRecordRaw = {
  path: '/redirect/:path(.*)*',
  name: 'Redirect',
  component: () => import('@/views/redirect/index.vue'),
  meta: { title: '重定向', hideMenu: true, hideTab: true }
}
```

**文件2：`erp-web/src/views/redirect/index.vue` — Redirect中转组件**

```vue
<template>
  <div class="redirect-loading">
    <el-icon class="is-loading"><Loading /></el-icon>
  </div>
</template>

<script setup lang="ts">
import { onBeforeMount } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import { Loading } from '@element-plus/icons-vue'

defineOptions({ name: 'Redirect' })

const route = useRoute()
const router = useRouter()

onBeforeMount(() => {
  // 从路径中提取原始路由，replace回去触发组件重建
  const { params, query } = route
  const redirectPath = '/' + (params.path as string[])?.join('/') || '/home'
  router.replace({ path: redirectPath, query })
})
</script>
```

**文件3：`erp-web/src/stores/modules/tagsView.ts` — refreshSelectedPage方法**

```typescript
async function refreshSelectedPage(route: RouteLocationNormalized) {
  const name = route.name as string
  // 1. 从缓存列表移除(exclude)
  const index = cachedViews.value.indexOf(name)
  if (index > -1) cachedViews.value.splice(index, 1)

  // 2. 导航到redirect中转页
  await router.replace({
    path: '/redirect' + route.fullPath
  })
}
// redirect组件replace回原路径后，在路由守卫中重新addCachedView
```

### 5.2 核心实现逻辑

1. **exclude→导航→include流程**：先从cachedViews移除组件名(keep-alive不再缓存) → 导航到redirect页 → redirect页replace回原路径 → 组件重新创建(因为不在缓存中) → 路由watch中重新addCachedView
2. **redirect中转路由**：path='/redirect/:path(.*)*'捕获所有路径参数
3. **Loading状态**：redirect组件显示旋转loading图标
4. **保留query参数**：redirect组件replace时携带原query

### 5.3 交互逻辑

1. 右键标签"刷新" → refreshSelectedPage → exclude组件 → 导航到/redirect/xxx
2. Redirect组件显示loading → onBeforeMount → replace回原路径
3. 原路径组件重新创建(mounted重新执行) → 数据重新加载 → addCachedView重新缓存
4. 用户感知：短暂loading → 页面数据刷新

## 八、易错警示

> ⚠️ 不要使用location.reload()刷新页面，会丢失所有Pinia状态和keep-alive缓存

> ⚠️ redirect路由的path必须使用`:path(.*)*`通配符，否则多级路径无法正确捕获

> ⚠️ exclude后导航到redirect时，redirect组件replace回原路径会触发路由watch重新addCachedView

> ⚠️ redirect组件使用onBeforeMount而非onMounted，确保replace在组件挂载前执行
