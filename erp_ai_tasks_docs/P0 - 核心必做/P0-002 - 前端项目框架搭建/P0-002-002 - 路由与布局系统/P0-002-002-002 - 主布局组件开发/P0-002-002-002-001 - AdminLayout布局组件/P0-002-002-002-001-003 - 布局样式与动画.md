### 5.1 文件结构与组件设计

文件路径：`erp-web/src/layouts/styles/app-layout.scss`

```scss
// AppLayout 布局样式
.app-layout {
  width: 100%;
  height: 100vh;
  min-width: 1024px;  // 防止布局在小屏下崩溃
  overflow: hidden;

  &__aside {
    transition: width 0.3s ease;  // 侧边栏折叠过渡动画
    overflow-y: auto;
    overflow-x: hidden;
    background-color: var(--el-bg-color-overlay);
    border-right: 1px solid var(--el-border-color-light);
    // 隐藏滚动条但保持可滚动
    &::-webkit-scrollbar {
      width: 0;
      display: none;
    }
  }

  &__main-container {
    display: flex;
    flex-direction: column;
    overflow: hidden;
  }

  &__header {
    position: sticky;
    top: 0;
    z-index: 100;  // 确保header在内容区之上
    background-color: var(--el-bg-color);
    border-bottom: 1px solid var(--el-border-color-light);
    padding: 0 16px;
    display: flex;
    align-items: center;
    box-shadow: 0 1px 4px rgba(0, 0, 0, 0.08);
  }

  &__tabs {
    flex-shrink: 0;
    border-bottom: 1px solid var(--el-border-color-lighter);
    background-color: var(--el-bg-color);
  }

  &__content {
    flex: 1;
    overflow-y: auto;  // 内容超长时可滚动
    overflow-x: hidden;
    padding: 16px;
    background-color: var(--el-fill-color-lighter);
  }
}

// 路由切换过渡动画
.fade-transform-enter-active,
.fade-transform-leave-active {
  transition: all 0.25s ease;
}

.fade-transform-enter-from {
  opacity: 0;
  transform: translateX(-10px);
}

.fade-transform-leave-to {
  opacity: 0;
  transform: translateX(10px);
}
```

### 5.2 核心实现逻辑

1. **100vh高度**：布局容器占满视口，内部使用flex分配空间
2. **transition: width 0.3s**：侧边栏折叠时宽度平滑过渡
3. **sticky定位**：header跟随滚动但固定在顶部
4. **flex:1 on content**：内容区自动填充剩余空间
5. **CSS变量**：使用Element Plus的CSS变量(--el-*)保持主题一致性

### 5.3 交互逻辑

1. 侧边栏折叠 → width变化 → transition 0.3s ease → 平滑动画
2. 内容区超长 → overflow-y: auto → 出现滚动条
3. 路由切换 → transition name="fade-transform" → 淡入滑出效果

## 八、易错警示

> ⚠️ transition属性不要写在scoped style的深层嵌套中，可能不生效，建议放在独立scss文件

> ⚠️ z-index: 100要低于Element Plus的弹窗层级(2000+)，避免header遮挡Dialog

> ⚠️ overflow-y: auto在移动端可能触发橡皮筋效果，可加-webkit-overflow-scrolling: touch

> ⚠️ 100vh在移动端浏览器中可能被地址栏遮挡，必要时使用100dvh替代
