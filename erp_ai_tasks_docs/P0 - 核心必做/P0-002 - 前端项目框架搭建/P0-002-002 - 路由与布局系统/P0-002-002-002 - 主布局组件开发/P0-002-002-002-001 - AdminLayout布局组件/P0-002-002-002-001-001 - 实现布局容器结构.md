### 5.1 文件结构与组件设计

文件路径：`erp-web/src/layouts/AppLayout.vue`

```vue
<template>
  <el-container class="app-layout">
    <!-- 左侧边栏 -->
    <el-aside
      :width="isCollapsed ? '64px' : '220px'"
      class="app-layout__aside"
    >
      <Sidebar />
    </el-aside>

    <!-- 右侧主区域 -->
    <el-container class="app-layout__main-container">
      <!-- 顶部导航栏 -->
      <el-header class="app-layout__header" height="56px">
        <Navbar />
      </el-header>

      <!-- 标签页导航 -->
      <div class="app-layout__tabs">
        <TabNav />
      </div>

      <!-- 内容区域 -->
      <el-main class="app-layout__content">
        <router-view v-slot="{ Component, route }">
          <transition name="fade-transform" mode="out-in">
            <keep-alive :include="cachedViews">
              <component :is="Component" :key="route.fullPath" />
            </keep-alive>
          </transition>
        </router-view>
      </el-main>
    </el-container>
  </el-container>
</template>

<script setup lang="ts">
import { computed } from 'vue'
import Sidebar from './components/Sidebar/index.vue'
import Navbar from './components/Navbar.vue'
import TabNav from './components/TabNav/index.vue'
import { useLayoutStore } from '@/stores/modules/layout'
import { useTagsViewStore } from '@/stores/modules/tagsView'

defineOptions({ name: 'AppLayout' })

const layoutStore = useLayoutStore()
const tagsViewStore = useTagsViewStore()

const isCollapsed = computed(() => layoutStore.isCollapsed)
const cachedViews = computed(() => tagsViewStore.cachedViews)
</script>
```

### 5.2 核心实现逻辑

1. **el-container嵌套**：外层container包含aside和右侧container，右侧container包含header/tabs/main
2. **el-aside动态宽度**：通过computed绑定isCollapsed状态，折叠64px/展开220px
3. **keep-alive**：include绑定cachedViews(组件name数组)，仅缓存标记keepAlive的路由组件
4. **transition**：fade-transform动画，mode="out-in"确保旧组件先离开再渲染新组件
5. **router-view的key**：使用route.fullPath作为key，确保同路由不同参数时重新渲染

### 5.3 交互逻辑

1. 点击侧边栏折叠按钮 → layoutStore.toggleCollapse() → aside宽度变化 → 过渡动画
2. 路由切换 → keep-alive根据include决定缓存/销毁 → transition触发fade动画
3. 内容区滚动独立于侧边栏和顶部栏（overflow-y: auto在el-main上）

## 八、易错警示

> ⚠️ el-aside的width必须与collapsed状态联动，避免布局错位

> ⚠️ keep-alive的include必须匹配组件name属性，否则缓存不生效

> ⚠️ router-view的key使用route.fullPath而非route.path，避免query参数变化时不重新渲染

> ⚠️ defineOptions({ name: 'AppLayout' })必须设置，keep-alive的include依赖此name
