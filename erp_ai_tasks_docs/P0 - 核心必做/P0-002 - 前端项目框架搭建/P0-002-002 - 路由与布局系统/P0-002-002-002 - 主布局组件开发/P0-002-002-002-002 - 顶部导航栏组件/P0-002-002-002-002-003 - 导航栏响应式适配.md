### 5.1 文件结构与组件设计

**文件1：`erp-web/src/composables/useResponsive.ts` — 响应式断点composable**

```typescript
import { ref, onMounted, onUnmounted } from 'vue'

export type Breakpoint = 'mobile' | 'tablet' | 'desktop'

export function useResponsive() {
  const breakpoint = ref<Breakpoint>('desktop')
  const windowWidth = ref(window.innerWidth)

  const MOBILE_MAX = 768
  const TABLET_MAX = 1024

  function updateBreakpoint() {
    windowWidth.value = window.innerWidth
    if (windowWidth.value <= MOBILE_MAX) {
      breakpoint.value = 'mobile'
    } else if (windowWidth.value <= TABLET_MAX) {
      breakpoint.value = 'tablet'
    } else {
      breakpoint.value = 'desktop'
    }
  }

  const isMobile = computed(() => breakpoint.value === 'mobile')
  const isTablet = computed(() => breakpoint.value === 'tablet')

  onMounted(() => {
    updateBreakpoint()
    window.addEventListener('resize', updateBreakpoint)
  })
  onUnmounted(() => window.removeEventListener('resize', updateBreakpoint))

  return { breakpoint, windowWidth, isMobile, isTablet }
}
```

**文件2：Navbar响应式样式 — `erp-web/src/layouts/styles/navbar-responsive.scss`**

```scss
// 移动端适配 (≤768px)
@media (max-width: 768px) {
  .navbar {
    &__username { display: none; }     // 隐藏用户名，仅显示头像
    &__right { gap: 8px; }             // 缩小间距
  }

  .app-layout__aside {
    position: fixed;                    // overlay模式覆盖内容区
    z-index: 200;
    height: 100vh;
    box-shadow: 2px 0 8px rgba(0, 0, 0, 0.15);
  }

  // 遮罩层
  .app-layout__overlay {
    display: block;
    position: fixed;
    inset: 0;
    background: rgba(0, 0, 0, 0.3);
    z-index: 199;
  }
}

// 平板适配 (769px - 1024px)
@media (min-width: 769px) and (max-width: 1024px) {
  .navbar__username { display: none; }
}
```

### 5.2 核心实现逻辑

1. **useResponsive composable**：监听window resize事件，计算当前断点
2. **移动端自动折叠**：isMobile为true时自动设置layoutStore.isCollapsed = true
3. **overlay模式**：移动端侧边栏使用position: fixed覆盖内容区，添加遮罩层
4. **点击遮罩关闭**：遮罩层点击事件触发layoutStore.toggleCollapse()

### 5.3 交互逻辑

1. 窗口缩小到768px以下 → isMobile=true → 侧边栏自动折叠 → overlay模式
2. 移动端点击折叠按钮 → 侧边栏slide-in → 遮罩层显示
3. 点击遮罩层 → 侧边栏收起 → 遮罩层隐藏
4. 搜索框在小屏下收缩为搜索图标 → 点击展开搜索弹窗

## 八、易错警示

> ⚠️ CSS媒体查询断点要与useResponsive中的MOBILE_MAX/TABLET_MAX保持统一

> ⚠️ resize事件监听必须在onUnmounted时移除，避免内存泄漏

> ⚠️ 移动端侧边栏overlay模式z-index要高于遮罩层(aside:200 > overlay:199)

> ⚠️ 移动端touch事件与PC端click事件要兼容，el-dropdown的trigger="click"在移动端可正常触发
