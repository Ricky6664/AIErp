### 5.1 文件结构与组件设计

**面包屑交互** — 内嵌于Navbar.vue:
```typescript
import { useRoute, type RouteLocationMatched } from 'vue-router'

const route = useRoute()
const breadcrumbs = computed(() => {
  return route.matched
    .filter(item => item.meta?.title)
    .map(item => ({
      title: item.meta.title as string,
      titleI18n: item.meta.titleI18n as string | undefined,
      path: item.path
    }))
})
```

**全局搜索弹窗** — 独立组件`erp-web/src/layouts/components/SearchDialog.vue`:
```typescript
const visible = ref(false)
const searchKeyword = ref('')

// Ctrl+K 快捷键唤起
function handleKeydown(e: KeyboardEvent) {
  if ((e.ctrlKey || e.metaKey) && e.key === 'k') {
    e.preventDefault()
    visible.value = !visible.value
  }
}
onMounted(() => document.addEventListener('keydown', handleKeydown))
onUnmounted(() => document.removeEventListener('keydown', handleKeydown))
```

**退出登录逻辑**:
```typescript
async function handleUserCommand(command: string) {
  if (command === 'logout') {
    await ElMessageBox.confirm('确定要退出登录吗？', '提示', {
      confirmButtonText: '确定',
      cancelButtonText: '取消',
      type: 'warning'
    })
    await userStore.logout()       // 清除user/permission/tagsView状态
    await router.push('/login')    // 跳转登录页
  }
}
```

### 5.2 核心实现逻辑

1. **面包屑computed**：从route.matched派生，过滤有meta.title的路由记录，不手动维护
2. **全局搜索Teleport**：使用`<Teleport to="body">`挂载弹窗，避免被父元素overflow裁剪
3. **退出登录**：先ElMessageBox确认 → 调用userStore.logout() → 清除所有本地状态 → 跳转登录页
4. **快捷键监听**：onMounted注册keydown事件，onUnmounted移除，避免内存泄漏

### 5.3 交互逻辑

1. 路由切换 → route.matched变化 → breadcrumbs computed更新 → 面包屑重新渲染
2. Ctrl+K → searchDialog visible切换 → Teleport弹出/关闭
3. 点击消息铃铛 → el-popover展示消息列表 → 标记已读
4. 点击用户头像 → 选择"退出登录" → ElMessageBox确认 → 清除状态 → 跳转/login
