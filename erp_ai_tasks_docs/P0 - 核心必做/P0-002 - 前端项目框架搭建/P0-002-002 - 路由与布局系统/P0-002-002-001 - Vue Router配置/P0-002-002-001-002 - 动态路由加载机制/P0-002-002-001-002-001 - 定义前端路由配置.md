### 5.1 配置结构

**文件1：`erp-web/src/router/types.ts` — RouteMeta类型扩展**

```typescript
import 'vue-router'

declare module 'vue-router' {
  interface RouteMeta {
    title: string           // 页面标题(必填)
    titleI18n?: string      // i18n国际化key
    icon?: string           // 菜单图标(Element Plus图标名或SVG路径)
    keepAlive?: boolean     // 是否缓存组件(default: false)
    hideMenu?: boolean      // 隐藏菜单项(default: false)
    hideTab?: boolean       // 隐藏标签页(default: false)
    permissions?: string[]  // 权限标识数组(如['sale:order:list'])
    openType?: number       // 打开方式(0=tab, 1-3=dialog, 4=drawer, 5=new window)
    affix?: boolean         // 固定在标签栏(default: false)
  }
}
```

**文件2：`erp-web/src/router/modules/dynamic.ts` — 组件映射表**

```typescript
// 使用Vite的import.meta.glob批量导入views下所有vue组件
const viewModules = import.meta.glob('@/views/**/*.vue')

/**
 * 根据后端返回的componentPath获取前端懒加载组件
 * @param componentPath 后端返回的组件路径，如 'sale/order/index'
 * @returns 懒加载组件函数
 */
export function resolveComponent(componentPath: string) {
  const key = `/src/views/${componentPath}.vue`
  if (viewModules[key]) {
    return viewModules[key]
  }
  console.warn(`[Router] 未找到组件: ${key}`)
  return () => import('@/views/error/404.vue')  // 降级到404
}
```

### 5.2 关键配置项

| 配置项 | 类型 | 用途 |
|-------|------|------|
| RouteMeta.title | string | 面包屑/标签页/浏览器标题显示 |
| RouteMeta.permissions | string[] | 权限标识数组，守卫和菜单过滤使用 |
| RouteMeta.keepAlive | boolean | 控制keep-alive include列表 |
| RouteMeta.openType | number | 控制页面打开方式(tab/dialog/drawer/新窗口) |
| componentMap | Record<string, Function> | 后端componentPath到前端组件的映射 |

### 5.3 与路由守卫的集成

1. RouteMeta.permissions在`permissionStore.generateRoutes()`中用于过滤用户无权访问的路由
2. RouteMeta.keepAlive在`tagsView store`中用于维护cachedViews列表
3. resolveComponent函数在动态路由生成时将后端字符串路径转换为实际的Vue组件引用

## 八、易错警示

> ⚠️ RouteMeta的declare module 'vue-router'必须在项目入口文件中被import一次才能生效

> ⚠️ import.meta.glob返回的路径key包含`/src/`前缀，拼接时注意路径格式

> ⚠️ resolveComponent降级到404时不要throw错误，避免整个路由注册失败
