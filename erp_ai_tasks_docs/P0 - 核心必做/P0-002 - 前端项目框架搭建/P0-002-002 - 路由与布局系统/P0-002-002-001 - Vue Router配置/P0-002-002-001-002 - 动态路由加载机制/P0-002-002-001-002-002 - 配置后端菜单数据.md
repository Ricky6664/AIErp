### 5.1 配置结构

**文件：`erp-web/src/api/types/menu.ts` — 后端菜单数据接口**

```typescript
/** 后端菜单项数据结构 */
export interface MenuItem {
  id: number              // 菜单ID
  parentId: number        // 父级菜单ID(0=顶级)
  name: string            // 菜单名称
  path: string            // 路由路径
  component?: string      // 组件路径(如'sale/order/index')
  icon?: string           // 图标名称
  sort: number            // 排序号
  type: number            // 类型(0=目录, 1=菜单, 2=按钮)
  permissions?: string    // 权限标识(如'sale:order:list')
  visible: boolean        // 是否可见
  keepAlive: boolean      // 是否缓存
  openType?: number       // 打开方式
  children?: MenuItem[]   // 子菜单
}

/** getInfo接口响应中的菜单部分 */
export interface MenuResponse {
  menus: MenuItem[]       // 菜单树
  permissions: string[]   // 用户权限标识列表
}
```

**文件：`erp-web/src/utils/menuTransform.ts` — 菜单转换函数**

```typescript
import type { RouteRecordRaw } from 'vue-router'
import type { MenuItem } from '@/api/types/menu'
import { resolveComponent } from '@/router/modules/dynamic'
import AppLayout from '@/layouts/AppLayout.vue'

/**
 * 将后端菜单树转换为Vue Router路由配置
 */
export function transformMenuToRoutes(menus: MenuItem[]): RouteRecordRaw[] {
  return menus
    .filter(menu => menu.type !== 2)  // 过滤按钮类型
    .sort((a, b) => a.sort - b.sort)  // 按sort排序
    .map(menu => {
      const route: RouteRecordRaw = {
        path: menu.path,
        name: menu.path.replace(/\//g, '-').replace(/^-/, ''),
        meta: {
          title: menu.name,
          icon: menu.icon,
          keepAlive: menu.keepAlive ?? false,
          hideMenu: !menu.visible,
          permissions: menu.permissions ? [menu.permissions] : [],
          openType: menu.openType
        }
      }
      // 目录类型使用Layout组件
      if (menu.type === 0) {
        route.component = AppLayout
        if (menu.children?.length) {
          route.children = transformMenuToRoutes(menu.children)
          route.redirect = menu.children[0].path
        }
      }
      // 菜单类型使用动态组件
      if (menu.type === 1 && menu.component) {
        route.component = resolveComponent(menu.component)
      }
      return route
    })
}
```

### 5.2 关键配置项

| 字段 | 后端字段 | 前端映射 | 说明 |
|------|---------|---------|------|
| 路由path | path | route.path | 直接使用 |
| 路由name | path(生成) | route.name | 由path生成，去除前导/ |
| 组件引用 | component | resolveComponent() | 字符串→懒加载函数 |
| meta.title | name | route.meta.title | 菜单名称 |
| meta.permissions | permissions | string[] | 权限标识数组 |

### 5.3 与路由守卫的集成

1. `permissionStore.generateRoutes()`调用`getInfo()`获取MenuItem[]
2. 调用`transformMenuToRoutes()`转换为RouteRecordRaw[]
3. 遍历结果调用`router.addRoute()`逐条注册
4. 注册完成后调用`next({ ...to, replace: true })`重新触发导航

## 八、易错警示

> ⚠️ 路由name由path生成时必须去除前导斜杠并替换内部斜杠为连字符，避免name含/导致路由异常

> ⚠️ transformMenuToRoutes必须使用纯函数，不要修改原始MenuItem对象

> ⚠️ 后端返回的component字段可能为空或不存在对应前端组件，resolveComponent需做降级处理
