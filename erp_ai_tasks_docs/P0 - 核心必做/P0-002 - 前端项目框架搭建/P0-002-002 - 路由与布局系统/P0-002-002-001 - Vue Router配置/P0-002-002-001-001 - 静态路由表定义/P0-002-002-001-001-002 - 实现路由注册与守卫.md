### 5.1 文件结构与组件设计

文件路径：`erp-web/src/router/index.ts`

```typescript
import { createRouter, createWebHistory } from 'vue-router'
import type { RouteRecordRaw, RouterScrollBehavior } from 'vue-router'
import { staticRoutes } from './modules/static'

// 滚动行为：路由切换时滚动到顶部或保存的滚动位置
const scrollBehavior: RouterScrollBehavior = (to, from, savedPosition) => {
  if (savedPosition) return savedPosition
  if (to.hash) return { el: to.hash, behavior: 'smooth' }
  return { top: 0, behavior: 'smooth' }
}

// 创建Router实例，仅注册静态路由
const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes: staticRoutes as RouteRecordRaw[],
  scrollBehavior,
  strict: true  // 严格模式，尾部斜杠敏感
})

export default router
```

### 5.2 核心实现逻辑

1. **createWebHistory**：使用HTML5 History模式，需服务端配置fallback到index.html
2. **import.meta.env.BASE_URL**：从Vite环境变量读取基础路径，支持子目录部署
3. **scrollBehavior**：返回savedPosition支持浏览器前进/后退恢复滚动位置
4. **strict: true**：开启严格模式，`/home`和`/home/`视为不同路由
5. 动态路由不在此处注册，由`permissionStore.generateRoutes()`在守卫中通过`router.addRoute()`动态添加

### 5.3 与main.ts的集成

```typescript
// erp-web/src/main.ts
import router from './router'
import { setupRouterGuards } from './router/guards'

const app = createApp(App)
app.use(router)
setupRouterGuards(router)  // 注册路由守卫
app.mount('#app')
```

## 八、易错警示

> ⚠️ createWebHistory需服务端配置所有路由fallback到index.html，否则刷新404

> ⚠️ staticRoutes类型断言`as RouteRecordRaw[]`确保TypeScript类型兼容

> ⚠️ router实例必须在main.ts中app.use()注册后才能使用，不能在模块顶层调用router.push

> ⚠️ setupRouterGuards必须在app.use(router)之后调用，否则守卫无法绑定
