### 5.1 文件结构与组件设计

文件路径：`erp-web/src/router/guards.ts`

```typescript
import type { Router } from 'vue-router'
import { usePermissionStore } from '@/stores/modules/permission'
import { useUserStore } from '@/stores/modules/user'
import { WHITE_LIST, LOGIN_PATH, HOME_PATH, TOKEN_KEY } from './constants'

export function setupRouterGuards(router: Router) {
  router.beforeEach(async (to, from, next) => {
    const token = localStorage.getItem(TOKEN_KEY)

    // 1. 白名单路由直接放行
    if (WHITE_LIST.includes(to.path)) {
      // 已登录访问登录页，跳转首页
      if (to.path === LOGIN_PATH && token) {
        return next({ path: HOME_PATH, replace: true })
      }
      return next()
    }

    // 2. 无Token → 跳转登录页(携带redirect参数)
    if (!token) {
      return next({ path: LOGIN_PATH, query: { redirect: to.fullPath }, replace: true })
    }

    // 3. 动态路由未加载 → 加载后重新导航
    const permissionStore = usePermissionStore()
    if (!permissionStore.isRoutesLoaded) {
      try {
        const userStore = useUserStore()
        await userStore.getUserInfo()  // 获取用户信息和菜单
        await permissionStore.generateRoutes(userStore.menus)
        // 动态路由刚注册，需重新触发导航
        return next({ ...to, replace: true })
      } catch {
        // 获取信息失败(token过期等)，清除token跳登录
        localStorage.removeItem(TOKEN_KEY)
        return next({ path: LOGIN_PATH, replace: true })
      }
    }

    // 4. 权限校验
    const routePermissions = to.meta?.permissions as string[] | undefined
    if (routePermissions && !permissionStore.hasPermission(routePermissions)) {
      return next({ path: '/no-permission', replace: true })
    }

    // 5. 设置页面标题
    const title = to.meta?.title as string
    document.title = title ? `${title} - ERP管理系统` : 'ERP管理系统'

    // 6. 放行
    next()
  })
}
```

### 5.2 核心实现逻辑

1. **白名单优先**：WHITE_LIST中的路由不做任何校验直接next()
2. **已登录跳登录页**：避免已登录用户再次看到登录页
3. **动态路由加载**：isRoutesLoaded=false时加载，加载后用`next({...to, replace:true})`重新导航
4. **catch异常处理**：getUserInfo失败说明token无效，清除后跳登录
5. **权限校验**：仅对meta.permissions非空的路由做权限检查
6. **标题设置**：使用meta.title拼接系统名称设置document.title

### 5.3 交互逻辑

```
用户访问页面
  → 白名单? → 是 → 已登录+登录页? → 跳首页 / 放行
  → 否 → 有Token? → 否 → 跳登录页(携带redirect)
  → 是 → 路由已加载? → 否 → 加载动态路由 → next({...to, replace:true})
  → 是 → 有权限? → 否 → 跳无权限页
  → 是 → 设置标题 → next()
```

## 八、易错警示

> ⚠️ beforeEach中next()必须在每个分支都调用，遗漏会导致路由卡死白屏

> ⚠️ 动态路由addRoute后必须调用`next({ ...to, replace: true })`重新触发导航，否则首次访问404

> ⚠️ getUserInfo异常时必须清除localStorage中的token再跳登录，否则陷入死循环

> ⚠️ redirect参数使用to.fullPath而非to.path，保留query参数以便登录后恢复完整页面状态
