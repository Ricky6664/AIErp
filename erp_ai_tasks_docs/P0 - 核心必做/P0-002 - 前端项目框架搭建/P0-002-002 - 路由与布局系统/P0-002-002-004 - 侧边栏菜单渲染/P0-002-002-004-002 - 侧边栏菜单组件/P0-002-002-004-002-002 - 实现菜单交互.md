### 5.1 文件结构与组件设计

文件路径：`erp-web/src/layouts/components/Sidebar/index.vue`

```vue
<template>
  <div class="sidebar">
    <!-- Logo区域 -->
    <div class="sidebar__logo" @click="router.push('/home')">
      <img
        :src="layoutStore.isCollapsed ? SIDEBAR_LOGO.collapsed : SIDEBAR_LOGO.expanded"
        :alt="SIDEBAR_LOGO.title"
        class="sidebar__logo-img"
      />
      <span v-show="!layoutStore.isCollapsed" class="sidebar__logo-title">
        {{ SIDEBAR_LOGO.title }}
      </span>
    </div>

    <!-- 菜单区域 -->
    <el-scrollbar>
      <el-menu
        :default-active="activeMenu"
        :collapse="layoutStore.isCollapsed"
        :unique-opened="true"
        :collapse-transition="true"
        background-color="transparent"
        @select="handleMenuSelect"
      >
        <SidebarItem
          v-for="menu in filteredMenus"
          :key="menu.path"
          :item="menu"
        />
      </el-menu>
    </el-scrollbar>
  </div>
</template>

<script setup lang="ts">
import { computed } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import SidebarItem from './SidebarItem.vue'
import { useLayoutStore } from '@/stores/modules/layout'
import { usePermissionStore } from '@/stores/modules/permission'
import { filterRoutesByPermission } from '@/utils/permission'
import { SIDEBAR_LOGO } from './menuConfig'

defineOptions({ name: 'Sidebar' })

const route = useRoute()
const router = useRouter()
const layoutStore = useLayoutStore()
const permissionStore = usePermissionStore()

// 当前激活菜单 = 当前路由path
const activeMenu = computed(() => {
  const { meta, path } = route
  // 如果路由meta指定了activeMenu，使用指定值(用于详情页高亮列表页)
  if (meta?.activeMenu) return meta.activeMenu as string
  return path
})

// 权限过滤后的菜单列表
const filteredMenus = computed(() => {
  return filterRoutesByPermission(
    permissionStore.routes,
    permissionStore.permissions
  )
})

// 菜单选择事件
function handleMenuSelect(index: string) {
  // 外链不通过router导航
  if (/^(https?:\/\/|\/\/)/.test(index)) {
    window.open(index, '_blank')
    return
  }
  router.push(index)
}
</script>
```

### 5.2 核心实现逻辑

1. **default-active绑定route.path**：路由变化时菜单高亮自动跟随
2. **meta.activeMenu**：支持路由meta指定activeMenu值(如详情页高亮列表菜单)
3. **el-menu collapse属性**：绑定layoutStore.isCollapsed，折叠态下只显示图标
4. **unique-opened**：手风琴模式，同时只展开一个一级子菜单
5. **handleMenuSelect**：拦截外链使用window.open，普通路由使用router.push
6. **el-scrollbar**：菜单区域超长时可滚动

### 5.3 交互逻辑

1. 点击菜单项 → el-menu select事件 → handleMenuSelect → router.push导航
2. 路由变化 → activeMenu computed更新 → 菜单高亮自动切换
3. 点击折叠按钮 → layoutStore.isCollapsed变化 → el-menu collapse → 图标模式
4. Logo点击 → router.push('/home') → 返回首页

## 八、易错警示

> ⚠️ default-active要用route.path精确匹配，不要用route.name，否则嵌套路由高亮异常

> ⚠️ 折叠态下el-menu的collapse属性必须与layoutStore联动，不同步会导致布局错位

> ⚠️ handleMenuSelect中拦截外链，不要对http链接调用router.push否则会报错

> ⚠️ el-scrollbar包裹el-menu时注意折叠动画期间scrollbar高度可能需要重新计算
