### 5.1 文件结构与组件设计

**文件1：`erp-web/src/layouts/components/Sidebar/MenuItemIcon.vue`**

```vue
<template>
  <!-- Element Plus图标 -->
  <el-icon v-if="iconType === 'element'" class="menu-icon">
    <component :is="elementIcon" />
  </el-icon>

  <!-- SVG图标 -->
  <SvgIcon
    v-else-if="iconType === 'svg'"
    :name="icon"
    class="menu-icon"
  />

  <!-- 外部URL图标 -->
  <img
    v-else-if="iconType === 'external'"
    :src="icon"
    class="menu-icon menu-icon--external"
    alt=""
  />

  <!-- 无图标时的占位 -->
  <span v-else class="menu-icon menu-icon--placeholder" />
</template>

<script setup lang="ts">
import { computed } from 'vue'
import * as ElIcons from '@element-plus/icons-vue'
import SvgIcon from '@/components/SvgIcon/index.vue'

defineOptions({ name: 'MenuItemIcon' })

interface Props {
  icon?: string
  iconType?: 'element' | 'svg' | 'external'
}
const props = withDefaults(defineProps<Props>(), {
  iconType: 'element'
})

// 动态获取Element Plus图标组件
const elementIcon = computed(() => {
  if (!props.icon) return null
  return (ElIcons as Record<string, any>)[props.icon] || ElIcons.Menu
})
</script>

<style lang="scss" scoped>
.menu-icon {
  width: 20px;
  height: 20px;
  font-size: 18px;
  margin-right: 8px;
  flex-shrink: 0;

  &--external {
    object-fit: contain;
  }

  &--placeholder {
    display: inline-block;
  }
}
</style>
```

**文件2：外链菜单项处理 — 修改SidebarItem.vue**

```vue
<!-- 外链菜单使用a标签而非router-link -->
<template v-else>
  <a
    v-if="isExternal"
    :href="item.path"
    target="_blank"
    rel="noopener noreferrer"
    class="el-menu-item"
  >
    <MenuItemIcon :icon="item.icon" :icon-type="item.iconType" />
    <template #title><span>{{ item.title }}</span></template>
  </a>
  <el-menu-item v-else :index="item.path">
    <MenuItemIcon :icon="item.icon" :icon-type="item.iconType" />
    <template #title><span>{{ item.title }}</span></template>
  </el-menu-item>
</template>

<script setup lang="ts">
// 判断是否为外链
const isExternal = computed(() =>
  /^(https?:\/\/|\/\/)/.test(props.item.path)
)
</script>
```

### 5.2 核心实现逻辑

1. **三种图标类型**：element(Element Plus动态组件)、svg(SvgIcon组件)、external(img标签)
2. **动态图标组件**：通过`ElIcons[icon]`动态获取图标组件，未找到时降级到Menu图标
3. **外链判断**：path以http://或https://开头的视为外链
4. **安全属性**：外链a标签必须加`rel="noopener noreferrer"`防止安全漏洞
5. **图标尺寸**：统一20x20px，折叠态下去掉margin-right

### 5.3 交互逻辑

1. 菜单渲染 → MenuItemIcon根据iconType选择渲染方式
2. Element Plus图标 → 动态:is绑定 → 图标正常显示
3. SVG图标 → SvgIcon组件 → 读取src/assets/svg/目录下的SVG文件
4. 外链菜单 → 点击a标签 → 新窗口打开(target=_blank)
5. 侧边栏折叠 → 图标显示但文字隐藏 → 图标尺寸保持20px

## 八、易错警示

> ⚠️ 外链判断要同时支持http://和https://，正则使用`^(https?:\/\/|\/\/)`

> ⚠️ 外链a标签必须加rel="noopener noreferrer"，否则新窗口可通过window.opener访问原页面

> ⚠️ Element Plus图标动态引用使用`import * as ElIcons`全量导入，tree-shaking可能移除非使用图标

> ⚠️ SVG图标组件要设宽高(20x20)，避免在折叠态下图标尺寸失控
