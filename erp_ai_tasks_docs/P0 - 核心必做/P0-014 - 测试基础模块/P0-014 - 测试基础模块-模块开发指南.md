## 四、模块级专属约束

1. **后端测试依赖版本锁定**（pom.xml）：
   - `junit-jupiter` 5.10.x（测试核心框架）
   - `mockito-core` 5.x + `mockito-junit-jupiter` 5.x（Mock框架）
   - `assertj-core` 3.x（流式断言）
   - `h2database` 2.x（Mapper层内存数据库）
   - `testcontainers-postgresql` 1.19.x（集成测试容器）
   - `spring-boot-starter-test`（Spring测试集成）
   - `jacoco-maven-plugin` 0.8.x（覆盖率报告）

2. **后端测试分层模板**：
   - **Service层**：`@ExtendWith(MockitoExtension.class)` + `@Mock`依赖 + `@InjectMocks`被测类 + given/when/then三段式 + 覆盖率目标≥80%
   - **Controller层**：`@WebMvcTest` + MockMvc + `@MockBean` Service + JSON断言 + 异常场景覆盖 + 覆盖率目标≥70%
   - **Mapper层**：`@MybatisPlusTest` + `@Sql`初始化数据 + H2内存数据库 + SQL正确性验证 + 覆盖率目标≥60%
   - **集成测试**：`@SpringBootTest` + Testcontainers PostgreSQL + 真实数据库 + 全链路接口测试 + 事务隔离 + `@Transactional`自动回滚

3. **测试基类开发**：
   - **BaseServiceTest**：`@SpringBootTest` + Testcontainers PostgreSQL配置 + 通用Mock方法 + AssertJ断言工具 + `@Transactional`事务回滚
   - **TestDataFactory**：提供`buildEntity`、`buildDTO`、`buildPage`、`buildUser`等通用方法，各业务模块继承扩展专属工厂

4. **前端测试依赖版本锁定**（package.json）：
   - `vitest` 1.x（测试核心框架）
   - `@vue/test-utils` 2.x（Vue组件测试工具）
   - `happy-dom`（DOM环境）
   - `@vitest/coverage-v8`（覆盖率工具）
   - `msw` 2.x（API Mock服务）

5. **前端测试分层模板**：
   - **组件单元测试**：mount组件 + props传参 + 事件触发 + DOM断言 + 快照测试 + 覆盖率目标≥70%
   - **Composable测试**：renderComposable + 响应式状态验证 + 异步操作测试 + 边界条件
   - **API Mock策略**：MSW拦截HTTP请求 + 接口响应模拟 + 错误场景覆盖（401/403/500） + Loading状态测试

6. **测试覆盖率阈值**（CI门禁强制校验）：
   - **后端Service层**：行覆盖率≥80%，分支覆盖率≥70%
   - **后端Controller层**：行覆盖率≥70%
   - **后端Mapper层**：行覆盖率≥60%
   - **前端组件**：行覆盖率≥70%，分支覆盖率≥60%
   - **CI门禁**：覆盖率低于阈值时流水线强制失败，禁止合并

7. **测试命名规范**：
   - **测试类**：`<被测类名>Test`（如`UserServiceTest`、`UserControllerTest`、`UserMapperTest`）
   - **测试方法**：`should_<预期行为>_when_<条件>`（如`should_createUserSuccessfully_when_validInput`、`should_throwException_when_duplicateUsername`）
   - **测试结构**：所有测试方法必须使用given/when/then三段式注释，明确划分前置条件、执行动作、断言验证

8. **测试数据隔离策略**：
   - **单元测试**：使用`@ExtendWith(MockitoExtension.class)`，不依赖真实数据库
   - **集成测试**：使用Testcontainers启动独立PostgreSQL容器，每次测试前自动建表，测试后销毁容器
   - **数据前缀标记**：测试数据统一使用`TEST_`前缀（如`TEST_USER_001`、`TEST_DEPT_001`），便于排查数据泄漏
   - **并行测试安全**：集成测试使用`@TestInstance(PER_CLASS)` + 数据库事务回滚，避免并行测试数据冲突

9. **测试报告集成**：
   - **JaCoCo**：生成HTML/XML覆盖率报告，路径`target/site/jacoco/index.html`
   - **Vitest Coverage**：生成lcov/text-summary报告，路径`coverage/lcov-report/index.html`
   - **CI集成**：流水线上传覆盖率报告为artifact，并在PR评论中展示覆盖率变化
   - **覆盖率徽章**：README.md展示最新覆盖率徽章（Service/Controller/前端组件三项）

10. **测试规范文档**：需在项目根目录创建`docs/TESTING_GUIDE.md`，包含：
    - 测试框架安装与配置说明
    - 各层测试模板代码示例
    - 测试命名与结构规范
    - 测试数据准备指南
    - 覆盖率报告查看方法
    - 常见问题排查清单
