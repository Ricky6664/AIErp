### 5.1 接口定义
- 接口名：IRecruitmentService，继承 IServiceX<RecruitmentEntity>
- 包路径：com.erp.hrm.service

### 5.2 方法签名
```java
public interface IRecruitmentService extends IServiceX<RecruitmentEntity> {
    RecruitmentVO create(@Valid RecruitmentCreateDTO dto);
    RecruitmentVO update(Long id, @Valid RecruitmentUpdateDTO dto);
    void delete(Long id);
    RecruitmentVO getById(Long id);
    PageResult<RecruitmentVO> pageList(RecruitmentQueryDTO query);
}
```

### 5.3 入参DTO/返回VO
- CreateDTO字段：positionId(岗位ID), departmentId(部门ID), recruitCount(招聘人数-正整数), salaryRange(薪资范围), requirements(岗位要求-富文本), recruitStatus(招聘状态:招聘中/已完成/已取消), deadline(截止日期)
- UpdateDTO：与CreateDTO相同字段 + @NotNull Long id
- QueryDTO：pageNum, pageSize, 
- VO：positionId(岗位ID), departmentId(部门ID), recruitCount(招聘人数-正整数), salaryRange(薪资范围), requirements(岗位要求-富文本), recruitStatus(招聘状态:招聘中/已完成/已取消), deadline(截止日期) + id + createdTime + updatedTime

### 5.4 注解要求
- 写操作方法(create/update/delete)标注 @Transactional(rollbackFor = Exception.class)
- 接口方法JavaDoc注释完整(@param, @return)

## 八、易错警示

> ⚠️ 事务注解@Transactional仅加在写操作方法(create/update/delete)，读操作不加

> ⚠️ DTO字段校验注解(@NotNull/@NotBlank/@Size)与ServiceImpl校验保持一致

> ⚠️ 接口方法JavaDoc注释必须完整，包含@param和@return说明

> ⚠️ 方法返回类型统一使用VO对象，不直接返回Entity

> ⚠️ 异常统一抛出BusinessException，不要抛原生RuntimeException
