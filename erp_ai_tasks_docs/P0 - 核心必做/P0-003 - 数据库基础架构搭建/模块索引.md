# P0-003 数据库基础架构搭建 - 模块索引

> 本文档为 P0-003 的快速导航索引。详细开发规范请参阅 [模块开发指南](P0-003 - 数据库基础架构搭建-模块开发指南.md)。

## 模块概述

- **模块定位**：创建ERP系统PostgreSQL数据库及全部Schema，建立公共字段基座规范，通过Flyway迁移脚本创建全部业务领域的数据表（含组织架构、商品、CRM、SRM、仓库库存、财务、HRM、销售、采购、生产、委外、应收应付、凭证账簿、扩展业务、审批、消息、OA/运维/多语言/模板、期初管理等），并初始化系统预置数据（管理员账号、参数、字典、编码规则、菜单、数据视图） - **前置依赖**：P0-001（后端框架提供数据库连接与MyBatis-Plus基础设施）
