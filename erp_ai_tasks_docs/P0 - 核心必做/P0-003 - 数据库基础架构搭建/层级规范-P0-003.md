## 1. 模块架构约束

### 1.1 模块定位
P0-003负责创建ERP系统PostgreSQL数据库及全部Schema，建立公共字段基座规范，通过Flyway迁移脚本创建全部业务领域的数据表（约200张，涵盖组织架构、商品、CRM、SRM、仓库库存、财务、HRM、销售、采购、生产、委外、应收应付、凭证账簿、扩展业务、审批、消息、OA/运维/多语言/模板、期初管理等），并初始化系统预置数据（管理员账号、参数、字典、编码规则、菜单、数据视图）。本模块是整个ERP系统的数据层基石。

### 1.2 依赖关系
- 前置依赖：P0-001（后端框架提供数据库连接与MyBatis-Plus基础设施）
- 后续依赖：P0-004（认证与权限）以及全部后续业务模块（P0-005~P0-014、P1级、P2级）

### 1.3 技术约束
- **技术栈约束**：PostgreSQL 15+；Flyway迁移管理；MyBatis-Plus 3.5.5 ORM映射
- **性能约束**：单表查询响应 < 100ms（10万数据量）；联合查询响应 < 500ms；索引命中率 > 95%
- **安全约束**：所有业务表必须包含tenant_id字段实现多租户隔离；联合索引必须以tenant_id为首列；跨租户查询严格禁止；敏感字段（密码哈希）使用BCrypt加密存储

## 3. 业务流程

### 3.1 核心业务流程
1. **数据库与Schema创建**（P0-003-001）：创建PostgreSQL数据库 → 创建Schema → 配置数据库用户权限
2. **公共字段基座表创建**（P0-003-002）：创建系统核心表（sys_user/sys_role/sys_menu等）→ 创建认证相关表 → 创建系统管理表
3. **业务域表创建**（P0-003-003~P0-003-020）：按业务域分组创建表 → 组织架构表 → 商品管理表 → CRM表 → SRM表 → 仓库库存表 → 财务基础表 → HRM表 → 销售管理表 → 采购管理表 → 生产管理表 → 委外管理表 → 应收应付表 → 凭证账簿表 → 扩展业务表 → 审批流程表 → 消息管理表 → 辅助表 → 期初管理表
4. **系统初始化数据**（P0-003-021）：插入预置管理员/角色/菜单/参数/字典/编码规则
5. **Flyway迁移管理**（P0-003-022）：将所有DDL脚本纳入Flyway版本管理

### 3.2 业务规则
- **通用字段强制包含**：所有业务表必须包含10个通用字段（id/tenant_id/created_at/updated_at/created_by/updated_by/is_deleted/owner_dept_id/owner_id/version）
- **软删除部分唯一索引**：涉及业务唯一性校验的字段必须采用部分唯一索引 `CREATE UNIQUE INDEX uk_xxx ON table(code) WHERE is_deleted = false`
- **多租户隔离**：所有业务表必须包含tenant_id且不可为空；联合索引必须以tenant_id为首列
- **商品快照字段**：所有含商品的明细从表必须冗余存储商品快照字段（product_code/product_name/model/spec/brand/unit_id/unit等），快照字段保存后不可修改
- **base_qty计量基准**：所有涉及数量的计算必须统一使用base_qty字段（base_qty = qty × conversion_rate）
- **辅助属性独立分表**：库位/批次/序列号三种辅助属性各自独立建子表，三表独立管理、互不耦合
- **数值精度参数化**：数据库物理字段统一使用decimal(18,8)，实际显示精度由系统参数动态控制
- **数据权限取值链路**：数据权限过滤使用owner_id和owner_dept_id字段，禁止使用created_by做数据权限判定

### 3.3 状态流转
- **会计期间状态**：未开始 → 进行中 → 已结账
- **单据状态（通用模式）**：草稿 → 待审核 → 已审核 → 已关闭/已作废

## 5. 开发顺序约束

### 5.1 必须顺序执行的任务
1. **P0-003-001 数据库与Schema创建** → **P0-003-002 公共字段基座表创建**（所有业务表依赖公共字段基座）
2. **P0-003-002** → **P0-003-003 组织架构表建表**（商品/CRM/SRM等依赖组织架构表的外键引用）
3. **P0-003-003** → **P0-003-004 商品管理表建表**（仓库库存/销售/采购/生产等依赖商品表）
4. **全部表创建（P0-003-001~P0-003-020）** → **P0-003-021 系统初始化数据**（预置数据依赖所有表已创建）
5. **P0-003-021** → **P0-003-022 Flyway数据库迁移管理**（迁移脚本整合）

### 5.2 可并行执行的任务
以下建表子模块在满足前置依赖后可并行执行：
- P0-003-005（CRM表）和P0-003-006（SRM表）——均依赖P0-003-001~003，互不依赖
- P0-003-008（财务基础表）——仅依赖P0-003-001和P0-003-002，可与P0-003-003并行
- P0-003-017（审批流程表）、P0-003-018（消息管理表）、P0-003-019（辅助表）——均仅依赖公共字段基座和组织架构

依赖关系矩阵：
- P0-003-007（仓库库存表）需等待P0-003-004（商品表）完成
- P0-003-010（销售管理表）需等待P0-003-005（CRM表）+P0-003-007（仓库库存表）完成
- P0-003-011（采购管理表）需等待P0-003-006（SRM表）+P0-003-007（仓库库存表）完成
- P0-003-014（应收应付表）需等待P0-003-010（销售表）+P0-003-011（采购表）+P0-003-008（财务基础表）完成
