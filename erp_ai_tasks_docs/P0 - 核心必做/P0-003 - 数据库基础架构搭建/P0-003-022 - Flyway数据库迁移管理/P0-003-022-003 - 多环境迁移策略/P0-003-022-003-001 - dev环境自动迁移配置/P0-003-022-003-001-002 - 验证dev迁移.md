## 五、详细开发规格




> **本任务模块上下文**（来源：P0-003模块开发指南）
> - 本模块技术栈：PostgreSQL 15+ / Flyway迁移 / Schema多租户 / 公共字段基座规范
> - 通用字段强制约束：所有业务表必须包含10个通用字段(id(BIGINT PK), tenant_id(BIGINT NOT NULL), created_by(BIGINT), created_at(TIMESTAMP DEFAULT CURRENT_TIMESTAMP), updated_by(BIGINT), updated_at(TIMESTAMP DEFAULT CURRENT_TIMESTAMP), is_deleted(BOOLEAN DEFAULT false), owner_dept_id(BIGINT), owner_id(BIGINT), version(INT DEFAULT 1))
> - 数值精度约束：所有金额/单价/数量/转换率字段统一使用decimal(18,8)
> - 部分唯一索引约束：业务唯一性字段必须采用`CREATE UNIQUE INDEX ... WHERE is_deleted = false`
> - 多租户隔离：tenant_id字段不可为空，联合索引必须以tenant_id为首列
> - Flyway命名规范：V{yyyyMMdd}{seq}__{description}.sql

### 5.1 Maven依赖引入
- flyway-core + flyway-database-postgresql (Flyway 10+必需)

### 5.2 Spring Boot配置(application.yml)
- spring.flyway.enabled=true, baseline-on-migrate=true, baseline-version=0
- spring.flyway.locations=classpath:db/migration, validate-on-migrate=true
- spring.flyway.table=flyway_schema_history

### 5.3 迁移脚本目录与命名
- src/main/resources/db/migration/
- 命名规范：V{yyyyMMdd}{seq}__{description}.sql（双下划线）

### 5.4 环境差异
- dev自动迁移、test使用Testcontainers、staging/prod手动审核

## 八、易错警示


> ⚠️ flyway-database-postgresql依赖在Flyway 10+版本中为必需，缺少将导致No database found错误

> ⚠️ baseline-on-migrate必须设置为true，否则对已存在的数据库首次执行Flyway会报Found non-empty schema错误

> ⚠️ 迁移脚本文件名必须使用双下划线__分隔版本号和描述，单下划线将导致Flyway解析失败

> ⚠️ 生产环境建议设置spring.flyway.validate-on-migrate=true，防止脚本被篡改后误执行

> ⚠️ 脚本编码必须为UTF-8，中文COMMENT注释否则会出现乱码
