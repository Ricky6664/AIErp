### 5.1 核心功能
1. 创建OnlineDeviceList.vue列表页，采用P04单一列表页类型展示在线设备
2. 搜索栏：用户名搜索(el-input)、设备类型筛选(el-select:全部/PC/Mobile/Tablet)、状态筛选(el-select:全部/在线/已下线/已踢出)
3. el-table展示：用户名/设备类型/设备名称/操作系统/浏览器/IP地址/登录时间/最后活跃时间/状态/操作列
4. 操作列：强制下线按钮(v-permission="'system:onlineDevice:kick'")，仅在线状态设备可操作
5. 设备类型图标：PC显示电脑图标、Mobile显示手机图标、Tablet显示平板图标
6. 强制下线确认：弹出ElMessageBox确认("确定将该设备强制下线？")

### 5.2 数据交互
**在线设备查询**：`GET /api/system/online-device?pageNum=1&pageSize=20&username=xxx&deviceType=PC&status=online`
```json
{
  "code": 200,
  "data": {
    "records": [{ "tokenId": "xxx", "username": "admin", "deviceType": "PC", "deviceName": "Chrome on Windows", "os": "Windows 11", "browser": "Chrome 120", "ipAddress": "192.168.1.100", "loginTime": "2026-05-26 09:00:00", "lastActiveTime": "2026-05-26 10:30:00", "status": "online" }],
    "total": 38, "pageNum": 1, "pageSize": 20
  }
}
```
**强制下线**：`POST /api/system/online-device/{tokenId}/kick`
**涉及数据表**：auth_online_device

### 5.3 关键逻辑
- **状态标签颜色**：online→绿色(success)、offline→灰色(info)、kicked→红色(danger)
- **强制下线流程**：确认框 → 调用POST /api/system/online-device/{tokenId}/kick → 成功后刷新列表 → ElMessage提示"设备已强制下线"
- **最后活跃时间**：显示格式"YYYY-MM-DD HH:mm:ss"，超过10分钟未活跃的行使用黄色警告样式
- **自动刷新**：页面每30秒自动刷新设备列表(setInterval)，组件卸载时清除定时器
- **批量操作**：支持checkbox多选设备，提供"批量强制下线"按钮

### 5.4 验证
1. 列表正确展示在线设备数据，设备类型图标正确
2. 用户名/设备类型/状态筛选功能正常
3. 强制下线操作后设备状态变为"已踢出"，被踢用户下次请求跳转登录页
4. 已下线/已踢出设备的强制下线按钮禁用
5. 自动刷新功能正常，新登录设备实时出现在列表中
