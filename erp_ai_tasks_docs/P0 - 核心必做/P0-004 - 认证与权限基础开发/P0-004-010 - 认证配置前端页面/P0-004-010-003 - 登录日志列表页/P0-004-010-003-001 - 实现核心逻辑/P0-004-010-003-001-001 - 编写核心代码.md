## 五、详细开发规格


> **📦 本任务模块上下文**（来源：P0-004模块开发指南）
> - 本模块涉及数据表：sys_user, sys_dept, sys_user_dept, sys_user_role, sys_user_group, sys_user_group_member, sys_user_group_role, sys_user_password_history, sys_role, sys_role_menu
> - 本模块涉及API：/api/auth/login, /api/auth/logout, /api/auth/token/refresh, /api/auth/token/verify, /api/auth/user-info
> - 本模块业务规则：Sa-Token集成：所有登录认证必须通过Sa-Token框架实现，Token签发/注销/校验/续期均使用Sa-Token API，不允许自行实现Token机制。; 密码安全：用户密码必须使用BCrypt加密存储，不允许明文存储或可逆加密。密码策略配置（最小8位、大小写+数字+特殊字符四选三）由auth_password_policy表驱动。
>
> 💡 开发本任务时，请结合上述模块上下文理解业务场景和数据关系。
### 5.1 核心功能
1. 创建LoginLogList.vue列表页，采用P04单一列表页类型展示登录日志
2. 搜索栏：用户名搜索(el-input)、登录状态筛选(el-select:全部/成功/失败)、时间范围(el-date-picker range)、IP地址搜索、搜索/重置按钮
3. 操作栏：导出Excel按钮(v-permission="'system:loginLog:export'")、清空日志按钮(仅超管可见)
4. el-table展示：用户名/登录时间/登出时间/IP地址/登录方式/浏览器/操作系统/状态/在线时长
5. 在线时长计算：logoutTime - loginTime格式化为"X小时X分钟"，未登出显示"在线中"
6. el-pagination分页组件，默认按登录时间倒序

### 5.2 数据交互
**登录日志查询**：`GET /api/system/login-log?pageNum=1&pageSize=20&username=xxx&status=success&startTime=2026-05-01&endTime=2026-05-26&ip=192.168`
```json
{
  "code": 200,
  "data": {
    "records": [{ "id": 1, "username": "admin", "loginTime": "2026-05-26 10:00:00", "logoutTime": "2026-05-26 11:30:00", "ipAddress": "192.168.1.100", "loginMethod": "password", "browser": "Chrome 120", "os": "Windows 11", "status": "success", "onlineDuration": "1小时30分钟" }],
    "total": 1500, "pageNum": 1, "pageSize": 20
  }
}
```
**涉及数据表**：sys_login_log

### 5.3 关键逻辑
- **时间范围筛选**：el-date-picker的type="daterange"选择开始/结束日期，传递给后端的startTime/endTime格式为YYYY-MM-DD
- **在线时长格式化**：前端计算logoutTime-loginTime的毫秒差值，转换为"X小时X分钟"格式；logoutTime为null时显示"在线中"(绿色tag)
- **IP归属地展示**：如后端返回IP归属地信息则展示在IP地址后面(如"192.168.1.100 (内网)")
- **导出Excel**：使用xlsx库导出当前筛选条件下的登录日志，文件名格式"登录日志_YYYYMMDD.xlsx"
- **登录方式标签**：password→"密码登录"、sms→"短信登录"、oauth2→"OAuth2"、sso→"SSO"，使用不同颜色el-tag区分

### 5.4 验证
1. 列表正确展示登录日志数据，按登录时间倒序排列
2. 用户名/状态/时间范围/IP组合筛选功能正常
3. 在线时长正确计算，未登出记录显示"在线中"
4. 导出Excel文件内容与列表数据一致
5. 状态列成功显示绿色tag，失败显示红色tag
