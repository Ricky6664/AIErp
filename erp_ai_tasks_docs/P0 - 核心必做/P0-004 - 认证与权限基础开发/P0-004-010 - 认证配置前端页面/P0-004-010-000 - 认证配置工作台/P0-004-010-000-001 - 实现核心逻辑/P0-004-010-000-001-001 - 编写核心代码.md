## 五、详细开发规格


> **📦 本任务模块上下文**（来源：P0-004模块开发指南）
> - 本模块涉及数据表：sys_user, sys_dept, sys_user_dept, sys_user_role, sys_user_group, sys_user_group_member, sys_user_group_role, sys_user_password_history, sys_role, sys_role_menu
> - 本模块涉及API：/api/auth/login, /api/auth/logout, /api/auth/token/refresh, /api/auth/token/verify, /api/auth/user-info
> - 本模块业务规则：Sa-Token集成：所有登录认证必须通过Sa-Token框架实现，Token签发/注销/校验/续期均使用Sa-Token API，不允许自行实现Token机制。; 密码安全：用户密码必须使用BCrypt加密存储，不允许明文存储或可逆加密。密码策略配置（最小8位、大小写+数字+特殊字符四选三）由auth_password_policy表驱动。
>
> 💡 开发本任务时，请结合上述模块上下文理解业务场景和数据关系。
### 5.1 核心功能
1. 创建AuthWorkbench.vue工作台页面，采用P02工作台页面类型布局
2. 顶部统计卡片区：4个KPI卡片(在线设备数/今日登录次数/今日登录失败次数/SSO配置数量)，调用GET /api/system/auth-config/workbench
3. 图表区-登录趋势图：ECharts折线图展示近7天每日登录成功/失败次数对比(双折线)
4. 图表区-认证方式分布：ECharts环形图展示各认证方式(密码/短信/OAuth2等)的使用占比
5. 快捷操作区："密码策略配置"、"认证方式管理"、"SSO配置"、"在线设备"快捷入口
6. 最近登录日志：展示最近10条登录记录，异常登录(失败)使用红色标记

### 5.2 数据交互
**工作台聚合数据**：`GET /api/system/auth-config/workbench`
```json
{
  "code": 200,
  "data": {
    "onlineDeviceCount": 38, "todayLoginCount": 89, "todayFailCount": 5, "ssoConfigCount": 3,
    "loginTrend": [{ "date": "2026-05-20", "successCount": 78, "failCount": 3 }, ...],
    "authMethodDistribution": [{ "method": "密码登录", "count": 1200 }, { "method": "OAuth2", "count": 300 }],
    "recentLogins": [{ "username": "admin", "loginTime": "...", "ip": "...", "status": "success" }, ...]
  }
}
```

### 5.3 关键逻辑
- **ECharts按需引入**：使用echarts/core + LineChart + PieChart + GridComponent按需引入，减少打包体积
- **卡片数字动画**：统计数字使用CountUp动画从0渐变到目标值，动画时长1秒
- **登录趋势双折线**：successCount用绿色线条，failCount用红色线条，共享X轴(日期)；Tooltip同时展示两个数值
- **认证方式环形图**：展示各认证方式使用占比，中心显示总登录次数；点击图例可高亮对应扇区
- **异常登录标记**：最近登录日志表格中status=fail的行使用红色背景(el-tag type="danger")，成功使用绿色(el-tag type="success")
- **自动刷新**：工作台每60秒自动刷新统计数据(setInterval)，组件卸载时clearInterval

### 5.4 验证
1. 工作台正确展示4个KPI卡片，数字与后端聚合数据一致
2. 登录趋势折线图正确展示成功/失败双线对比
3. 认证方式环形图正确展示各方式占比
4. 快捷操作按钮正确跳转到对应配置页面
5. 最近登录日志中失败记录红色标记，成功记录绿色标记
