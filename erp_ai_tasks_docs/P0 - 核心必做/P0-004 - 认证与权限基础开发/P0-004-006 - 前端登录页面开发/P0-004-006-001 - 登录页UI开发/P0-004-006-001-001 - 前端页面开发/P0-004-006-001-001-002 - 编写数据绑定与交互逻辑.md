## 五、详细开发规格


> **📦 本任务模块上下文**（来源：P0-004模块开发指南）
> - 本模块涉及数据表：sys_user, sys_dept, sys_user_dept, sys_user_role, sys_user_group, sys_user_group_member, sys_user_group_role, sys_user_password_history, sys_role, sys_role_menu
> - 本模块涉及API：/api/auth/login, /api/auth/logout, /api/auth/token/refresh, /api/auth/token/verify, /api/auth/user-info
> - 本模块业务规则：Sa-Token集成：所有登录认证必须通过Sa-Token框架实现，Token签发/注销/校验/续期均使用Sa-Token API，不允许自行实现Token机制。; 密码安全：用户密码必须使用BCrypt加密存储，不允许明文存储或可逆加密。密码策略配置（最小8位、大小写+数字+特殊字符四选三）由auth_password_policy表驱动。
>
> 💡 开发本任务时，请结合上述模块上下文理解业务场景和数据关系。
### 5.1 核心功能
1. 使用Vue 3 setup语法创建LoginPage.vue，引入ElForm/ElInput/ElButton/ElImage等Element Plus组件
2. 创建登录表单数据绑定：reactive({ username, password, captchaCode, captchaKey, rememberMe })
3. 编写表单校验规则rules：username必填+3-20位、password必填+8-32位、captchaCode必填+4位
4. 实现图形验证码展示：页面加载时调用GET /api/auth/captcha获取base64图片和captchaKey，点击图片刷新验证码
5. 实现"记住我"功能：使用localStorage存储加密后的用户名，下次登录自动填充
6. 实现响应式布局：PC端居中卡片布局(width:420px)，移动端全宽适配(max-width:100%)

### 5.2 数据交互
**验证码请求**：`GET /api/auth/captcha`
```json
{ "code": 200, "data": { "captchaKey": "uuid-string", "captchaImage": "data:image/png;base64,..." } }
```
**组件Props/Events**：
- Props：无（顶级页面组件）
- Emits：无（通过router.push跳转）
- 路由跳转：登录成功 → router.push({ path: redirect || '/dashboard' })

### 5.3 关键逻辑
- **验证码生命周期**：页面onMounted时自动获取验证码；点击图片区域调用refreshCaptcha()重新获取；验证码captchaKey存储在表单数据中，登录时一并提交
- **表单校验触发时机**：输入框失焦(onBlur)触发单字段校验；点击登录按钮触发全表单校验(elFormRef.validate())，校验通过后才调用登录API
- **密码显示切换**：ElInput的show-password属性实现密码明文/密文切换图标
- **登录按钮防重复提交**：点击登录后设置loading=true禁用按钮，请求完成(成功或失败)后恢复loading=false
- **记住我实现**：使用localStorage存储用户名(不存储密码)，key为`remembered_username`；页面加载时检查并自动填充

### 5.4 验证
1. 登录页面正确渲染：用户名/密码输入框、验证码图片、登录按钮、记住我复选框
2. 表单校验：空用户名提交显示"请输入用户名"，密码不足8位显示"密码长度至少8位"
3. 点击验证码图片刷新获取新的验证码，captchaKey更新
4. 勾选"记住我"后关闭浏览器重新打开，用户名自动填充
5. 移动端访问时登录表单全宽显示，布局正常无溢出
