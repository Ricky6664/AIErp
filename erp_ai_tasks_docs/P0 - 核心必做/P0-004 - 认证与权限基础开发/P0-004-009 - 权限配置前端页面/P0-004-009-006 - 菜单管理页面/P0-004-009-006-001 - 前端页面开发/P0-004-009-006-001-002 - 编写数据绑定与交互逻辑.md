### 5.1 核心功能
1. 创建MenuManage.vue树形列表页，采用P05树形列表页类型，使用el-table的tree展示菜单树
2. 左侧菜单树：el-table设置row-key="id" + tree-props展示菜单的目录/菜单/按钮三级树形结构
3. 操作栏：新增顶级目录按钮、展开全部/折叠全部按钮、刷新按钮
4. 表格列：菜单名称/图标/类型(目录/菜单/按钮标签)/排序号/权限标识/路由路径/组件路径/可见性/状态/操作
5. 操作列：新增子菜单、编辑、删除按钮（按钮类型无"新增子菜单"操作）
6. 新增/编辑弹窗：el-dialog(中尺寸)，表单包含上级菜单(树形下拉)、菜单类型(radio)、菜单名称、图标选择、路由路径、组件路径、权限标识、排序号、可见性、启用状态

### 5.2 数据交互
**菜单树查询**：`GET /api/system/menu`返回完整菜单树
```json
[{ "id": 1, "parentId": 0, "name": "系统管理", "type": "directory", "icon": "setting", "path": "/system", "sortOrder": 1, "visible": true, "enabled": true, "children": [...] }]
```
**新增菜单请求**：`POST /api/system/menu`
```json
{ "parentId": 1, "name": "用户管理", "type": "menu", "icon": "user", "path": "/system/user", "component": "system/user/index", "permissionCode": "", "sortOrder": 1, "visible": true, "enabled": true }
```

### 5.3 关键逻辑
- **菜单类型联动**：选择"directory"时隐藏组件路径和权限标识字段；选择"button"时隐藏路由路径/组件路径/图标/可见性字段，仅显示权限标识
- **图标选择器**：提供Element Plus图标列表弹窗选择器，支持搜索过滤；选择后显示图标预览
- **上级菜单树形下拉**：使用el-tree-select展示菜单树，选择后parentId自动设置；按钮类型的上级只能是菜单，菜单的上级只能是目录
- **拖拽排序**：el-table支持行拖拽改变排序号(sortOrder)，拖拽后调用PUT接口更新排序
- **权限标识自动提示**：输入permissionCode时根据父菜单路径自动提示格式，如父菜单为"用户管理"则提示"system:user:add"

### 5.4 验证
1. 菜单树正确展示三级结构(目录→菜单→按钮)，展开/折叠功能正常
2. 新增子菜单时上级菜单自动设置为当前行
3. 菜单类型切换时表单字段联动显隐正确
4. 删除有子菜单的节点返回"存在子菜单，无法删除"错误
5. 修改菜单路由路径后前端侧边栏菜单实时更新
