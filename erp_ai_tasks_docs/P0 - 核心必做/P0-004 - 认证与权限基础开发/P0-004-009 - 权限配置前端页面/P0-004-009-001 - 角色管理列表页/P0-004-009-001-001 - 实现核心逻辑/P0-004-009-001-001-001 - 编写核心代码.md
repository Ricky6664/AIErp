## 五、详细开发规格


> **📦 本任务模块上下文**（来源：P0-004模块开发指南）
> - 本模块涉及数据表：sys_user, sys_dept, sys_user_dept, sys_user_role, sys_user_group, sys_user_group_member, sys_user_group_role, sys_user_password_history, sys_role, sys_role_menu
> - 本模块涉及API：/api/auth/login, /api/auth/logout, /api/auth/token/refresh, /api/auth/token/verify, /api/auth/user-info
> - 本模块业务规则：Sa-Token集成：所有登录认证必须通过Sa-Token框架实现，Token签发/注销/校验/续期均使用Sa-Token API，不允许自行实现Token机制。; 密码安全：用户密码必须使用BCrypt加密存储，不允许明文存储或可逆加密。密码策略配置（最小8位、大小写+数字+特殊字符四选三）由auth_password_policy表驱动。
>
> 💡 开发本任务时，请结合上述模块上下文理解业务场景和数据关系。
### 5.1 核心功能
1. 创建RoleList.vue列表页，采用P04单一列表页类型展示角色数据
2. 搜索栏：角色名称/角色编码关键字搜索(el-input)、启用状态筛选(el-select)、数据范围筛选(el-select)、搜索/重置按钮
3. 操作栏：新增角色按钮(v-permission="'system:role:add'")、批量删除按钮
4. el-table展示：角色名称/角色编码/数据范围/描述/用户数量/启用状态/创建时间/操作列
5. 操作列：编辑、权限配置(跳转菜单权限配置页)、数据权限、字段权限、删除按钮
6. el-pagination分页组件，支持页码和每页条数切换

### 5.2 数据交互
**角色列表查询**：`GET /api/system/role?pageNum=1&pageSize=20&keyword=xxx&enabled=true&dataScope=all`
```json
{
  "code": 200,
  "data": {
    "records": [{ "id": 1, "roleName": "管理员", "roleCode": "admin", "dataScope": "all", "dataScopeLabel": "全部数据", "description": "系统管理员", "userCount": 5, "enabled": true }],
    "total": 12, "pageNum": 1, "pageSize": 20
  }
}
```
**涉及数据表**：sys_role, sys_user_role(统计用户数量)

### 5.3 关键逻辑
- **数据范围标签**：dataScope字段映射显示标签：all→"全部数据"(蓝色)、dept→"本部门"(绿色)、dept_and_below→"本部门及下级"(橙色)、self→"仅本人"(灰色)、custom→"自定义"(紫色)
- **用户数量统计**：LEFT JOIN sys_user_role GROUP BY role_id统计每个角色的用户数量
- **superadmin保护**：超级管理员角色(superadmin)不可编辑/删除/修改权限，操作列对应按钮禁用并显示tooltip"系统内置角色不可操作"
- **权限配置跳转**：点击"权限配置"按钮跳转到菜单权限配置页(P13配置页类型)，传递roleId参数
- **删除前校验**：删除角色前检查是否有用户关联(sys_user_role)，有则提示"请先移除角色下的用户"

### 5.4 验证
1. 列表正确展示角色数据，数据范围标签颜色正确
2. 关键字搜索和状态/数据范围筛选功能正常
3. superadmin角色的编辑/删除/权限配置按钮禁用
4. 删除有用户关联的角色时提示先移除用户
5. 点击权限配置正确跳转到菜单权限配置页
