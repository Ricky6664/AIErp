>

### 5.1 核心功能
1. 创建RoleForm.vue表单弹窗页，使用el-dialog(大尺寸width:720px)展示角色表单
2. 表单字段：角色名称(必填)、角色编码(必填/编辑只读)、描述(textarea)、数据范围(el-select:全部/本部门/本部门及下级/仅本人/自定义)、启用状态(el-switch)
3. 自定义数据范围区域：当数据范围选择"自定义"时展开部门树选择器(el-tree checkbox)和人员选择器
4. 角色继承配置：el-select选择父角色(可选)，子角色自动继承父角色权限
5. 角色互斥配置：el-select多选互斥角色列表
6. 表单校验：角色名称2-50字符、角色编码2-30字符(字母数字下划线)

### 5.2 数据交互
**新增角色请求**：`POST /api/system/role`
```json
{
  "roleName": "string", "roleCode": "string", "description": "string",
  "dataScope": "all|dept|dept_and_below|self|custom",
  "customDeptIds": [1,2], "customUserIds": [10,20],
  "parentRoleId": null, "exclusionRoleIds": [3,4], "enabled": true
}
```
**编辑请求**：`PUT /api/system/role/{id}`

### 5.3 关键逻辑
- **数据范围联动**：选择"custom"时展开自定义区域(部门树+人员选择器)；选择其他范围时隐藏自定义区域并清空customDeptIds/customUserIds
- **角色编码规范**：角色编码使用小写字母+数字+下划线格式，如admin、hr_manager、purchase_operator
- **角色继承限制**：不可选择自身或自身的子角色作为父角色(防止循环继承)，编辑模式下加载继承树过滤不可选项
- **角色互斥配置**：互斥关系是双向的，A与B互斥后B与A自动互斥；写入sys_role_exclusion表
- **superadmin只读**：编辑superadmin角色时所有字段只读，仅可修改描述信息

### 5.4 验证
1. 新增角色表单校验正确，角色编码重复时返回错误
2. 数据范围选择"自定义"时展开部门树和人员选择器
3. 角色继承不可选择自身或子角色，防止循环继承
4. 互斥角色配置后，分配互斥角色给同一用户时被拒绝
5. 编辑模式正确回填角色数据，角色编码只读
