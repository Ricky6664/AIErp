## 五、详细开发规格


> **📦 本任务模块上下文**（来源：P0-004模块开发指南）
> - 本模块涉及数据表：sys_user, sys_dept, sys_user_dept, sys_user_role, sys_user_group, sys_user_group_member, sys_user_group_role, sys_user_password_history, sys_role, sys_role_menu
> - 本模块涉及API：/api/auth/login, /api/auth/logout, /api/auth/token/refresh, /api/auth/token/verify, /api/auth/user-info
> - 本模块业务规则：Sa-Token集成：所有登录认证必须通过Sa-Token框架实现，Token签发/注销/校验/续期均使用Sa-Token API，不允许自行实现Token机制。; 密码安全：用户密码必须使用BCrypt加密存储，不允许明文存储或可逆加密。密码策略配置（最小8位、大小写+数字+特殊字符四选三）由auth_password_policy表驱动。
>
> 💡 开发本任务时，请结合上述模块上下文理解业务场景和数据关系。
### 5.1 核心功能
1. 在App.vue的onMounted或路由守卫中调用系统参数加载API，获取全局配置信息
2. 创建Pinia appStore存储系统参数：系统名称、Logo URL、默认分页大小、日期格式、主题色等
3. 系统参数加载完成后设置全局默认值：ElConfigProvider的locale/size、Axios默认超时等
4. 提供useAppStore()获取系统参数，各业务组件通过store读取全局配置
5. 系统参数变更后(管理员修改)通过Pinia响应式自动更新所有引用组件

### 5.2 数据交互
**系统参数数据结构**（Pinia appStore state）：
```typescript
interface AppState {
  systemName: string;       // 系统名称
  logoUrl: string;          // Logo地址
  defaultPageSize: number;  // 默认分页大小(20)
  dateFormat: string;       // 日期格式(YYYY-MM-DD)
  dateTimeFormat: string;   // 日期时间格式(YYYY-MM-DD HH:mm:ss)
  themeColor: string;       // 主题色(#409EFF)
  sidebarCollapse: boolean; // 侧边栏折叠状态
  watermarkEnabled: boolean;// 水印开关
}
```
**加载时机**：应用初始化(App.vue onMounted) + 登录成功后刷新

### 5.3 关键逻辑
- **加载优先级**：本地默认值 → localStorage缓存 → 接口返回值，接口返回后更新localStorage缓存
- **Element Plus全局配置**：通过ElConfigProvider组件包裹App根组件，设置size(appStore.defaultSize)和locale(zhCn)
- **主题色动态切换**：appStore.themeColor变更时通过CSS变量(--el-color-primary)动态更新Element Plus主题色
- **水印渲染**：watermarkEnabled=true时在页面底层渲染水印层(当前用户名称+工号+时间)，使用Canvas绘制
- **离线缓存**：系统参数存入localStorage('app_config')，下次打开应用时先使用缓存渲染，接口返回后更新

### 5.4 验证
1. 应用启动后系统参数正确加载，系统名称/Logo显示正确
2. 默认分页大小配置生效，所有列表页使用配置的pageSize
3. 主题色修改后Element Plus组件颜色同步更新
4. 水印开关开启后页面底层显示水印
5. 刷新页面后系统参数从缓存恢复，不闪烁
