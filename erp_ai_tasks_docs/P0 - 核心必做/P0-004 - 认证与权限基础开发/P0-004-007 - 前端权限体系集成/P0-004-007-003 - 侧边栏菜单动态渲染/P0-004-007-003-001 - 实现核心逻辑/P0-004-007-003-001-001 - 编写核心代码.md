### 5.1 核心功能
1. 创建SidebarMenu.vue组件，从Pinia permissionStore获取菜单树数据
2. 使用Element Plus的el-menu + el-sub-menu + el-menu-item递归渲染多级菜单
3. 创建SidebarMenuItem.vue递归子组件，处理三种菜单类型：directory(渲染el-sub-menu)、menu(渲染el-menu-item)、button(不渲染)
4. 菜单图标使用Element Plus的Icon组件或自定义SVG图标，通过菜单数据的icon字段匹配
5. 实现菜单折叠功能：el-menu的collapse属性绑定sidebarStore.isCollapsed状态
6. 路由高亮联动：el-menu的default-active绑定当前路由path(route.path)

### 5.2 数据交互
**菜单数据源**：permissionStore.menuTree（来自GET /api/auth/user-info返回的菜单树，已过滤权限）
**组件Props**：
```typescript
interface MenuItem {
  id: number; parentId: number; name: string; type: 'directory'|'menu'|'button';
  icon: string; path: string; component: string; permissionCode: string;
  sortOrder: number; visible: boolean; children: MenuItem[];
}
```
**SidebarMenu组件**：
- Props: menuList(MenuItem[]), isCollapse(boolean)
- Events: 无（通过router.push导航）

### 5.3 关键逻辑
- **递归渲染**：SidebarMenuItem组件递归引用自身，directory类型渲染el-sub-menu包裹children，menu类型渲染el-menu-item，button类型跳过
- **visible过滤**：菜单数据中visible=false的节点不在侧边栏显示（但仍作为路由存在，用于详情页等隐藏页面）
- **菜单折叠**：折叠状态下仅显示图标+Tooltip提示菜单名称；使用sidebarStore.toggleCollapse()切换状态，状态存入localStorage持久化
- **路由高亮**：el-menu的default-active设置为当前路由path；子页面(如/user/123)高亮父菜单(/user)通过matched路由meta实现
- **外链菜单**：path以http开头的菜单项渲染为a标签外链，点击新窗口打开(window.open)

### 5.4 验证
1. 侧边栏正确渲染多级菜单树，目录可展开/折叠
2. 无权限的菜单项不显示（已通过后端权限过滤）
3. visible=false的菜单不在侧边栏显示
4. 折叠状态下仅显示图标，Tooltip显示菜单名称
5. 当前路由对应的菜单项高亮显示
