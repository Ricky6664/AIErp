## 五、详细开发规格


> **📦 本任务模块上下文**（来源：P0-004模块开发指南）
> - 本模块涉及数据表：sys_user, sys_dept, sys_user_dept, sys_user_role, sys_user_group, sys_user_group_member, sys_user_group_role, sys_user_password_history, sys_role, sys_role_menu
> - 本模块涉及API：/api/auth/login, /api/auth/logout, /api/auth/token/refresh, /api/auth/token/verify, /api/auth/user-info
> - 本模块业务规则：Sa-Token集成：所有登录认证必须通过Sa-Token框架实现，Token签发/注销/校验/续期均使用Sa-Token API，不允许自行实现Token机制。; 密码安全：用户密码必须使用BCrypt加密存储，不允许明文存储或可逆加密。密码策略配置（最小8位、大小写+数字+特殊字符四选三）由auth_password_policy表驱动。
>
> 💡 开发本任务时，请结合上述模块上下文理解业务场景和数据关系。
### 5.1 核心功能
1. 创建UserList.vue列表页，采用P04单一列表页类型，使用el-table展示用户数据
2. 搜索栏区域：el-form内联表单，包含用户名/昵称关键字搜索(el-input)、状态筛选(el-select:全部/正常/锁定/禁用)、部门筛选(el-tree-select)、搜索/重置按钮
3. 操作栏区域：新增用户按钮(v-permission="'system:user:add'")、批量删除按钮、导出按钮
4. 数据表格：el-table展示用户名/昵称/邮箱/手机号/部门/角色/状态/最后登录时间/操作列
5. 操作列：编辑(v-permission="'system:user:edit'")、删除(v-permission="'system:user:delete'")、重置密码(v-permission="'system:user:resetPwd'")按钮
6. 分页组件：el-pagination，支持页码/每页条数切换，绑定pageNum/pageSize

### 5.2 数据交互
**列表查询**：`GET /api/system/user?pageNum=1&pageSize=20&keyword=xxx&status=normal&deptId=1`
```json
{
  "code": 200,
  "data": {
    "records": [{ "id": 1, "username": "admin", "nickname": "管理员", "email": "admin@erp.com", "phone": "13800138000", "deptNames": ["技术部"], "roleNames": ["超级管理员"], "status": "normal", "lastLoginTime": "2026-05-26 10:00:00" }],
    "total": 256, "pageNum": 1, "pageSize": 20
  }
}
```

### 5.3 关键逻辑
- **搜索防抖**：关键字输入框使用lodash debounce(300ms)防抖，避免频繁请求
- **状态列渲染**：使用el-tag标记状态，normal=绿色success、locked=红色danger、disabled=灰色info
- **删除确认**：点击删除按钮弹出ElMessageBox.confirm("确定删除用户{username}？")，确认后调用DELETE接口
- **操作权限控制**：操作列按钮使用v-permission指令，无权限时按钮不渲染；操作栏的新增/导出按钮同理
- **部门树形筛选**：部门筛选使用el-tree-select组件，数据来自GET /api/system/menu获取权限部门树(sys_dept)
- **列宽自适应**：el-table使用stripe+border，操作列fixed="right"固定在右侧

### 5.4 验证
1. 列表页正确展示用户数据，分页功能正常(切换页码/每页条数)
2. 关键字搜索/状态筛选/部门筛选组合查询返回正确结果
3. 无"新增用户"权限时新增按钮不显示
4. 删除用户弹出确认框，确认后删除成功并刷新列表
5. 状态列正确显示不同颜色的tag标记
