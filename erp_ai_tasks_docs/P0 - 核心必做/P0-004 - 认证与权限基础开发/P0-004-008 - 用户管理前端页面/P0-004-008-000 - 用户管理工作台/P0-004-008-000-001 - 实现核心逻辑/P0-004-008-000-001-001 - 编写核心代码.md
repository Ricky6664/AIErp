## 五、详细开发规格


> **📦 本任务模块上下文**（来源：P0-004模块开发指南）
> - 本模块涉及数据表：sys_user, sys_dept, sys_user_dept, sys_user_role, sys_user_group, sys_user_group_member, sys_user_group_role, sys_user_password_history, sys_role, sys_role_menu
> - 本模块涉及API：/api/auth/login, /api/auth/logout, /api/auth/token/refresh, /api/auth/token/verify, /api/auth/user-info
> - 本模块业务规则：Sa-Token集成：所有登录认证必须通过Sa-Token框架实现，Token签发/注销/校验/续期均使用Sa-Token API，不允许自行实现Token机制。; 密码安全：用户密码必须使用BCrypt加密存储，不允许明文存储或可逆加密。密码策略配置（最小8位、大小写+数字+特殊字符四选三）由auth_password_policy表驱动。
>

### 5.1 核心功能
1. 创建UserWorkbench.vue工作台页面，采用P02工作台页面类型布局
2. 顶部统计卡片区：使用el-row + el-col展示4个KPI卡片(用户总数/角色总数/在线用户数/今日登录次数)，调用GET /api/system/user/workbench获取聚合数据
3. 图表区-用户活跃度趋势：使用ECharts折线图展示近7天每日登录次数趋势
4. 图表区-角色分布饼图：使用ECharts饼图展示各角色的用户数量占比
5. 快捷操作区：提供"新增用户"、"角色管理"、"权限配置"快捷入口按钮
6. 最近登录日志表格：展示最近10条登录记录(用户名/时间/IP/状态)

### 5.2 数据交互
**工作台聚合数据**：`GET /api/system/user/workbench`
```json
{
  "code": 200,
  "data": {
    "userTotal": 256, "roleTotal": 12, "onlineCount": 38, "todayLoginCount": 89,
    "loginTrend": [{ "date": "2026-05-20", "count": 78 }, ...],
    "roleDistribution": [{ "roleName": "管理员", "userCount": 5 }, ...],
    "recentLogins": [{ "username": "admin", "loginTime": "2026-05-26 10:30:00", "ip": "192.168.1.1", "status": "success" }, ...]
  }
}
```

### 5.3 关键逻辑
- **ECharts按需引入**：使用echarts/core + LineChart + PieChart + GridComponent + TooltipComponent按需引入，减少打包体积
- **卡片数字动画**：统计卡片数字使用CountUp.js或CSS transition从0渐变到目标值，动画时长1秒
- **响应式布局**：el-row使用:gutter="16"间距，el-col使用:xs="12" :sm="12" :md="6"实现移动端2列/PC端4列自适应
- **数据刷新**：工作台页面onMounted加载数据，提供手动刷新按钮(reload)，切换标签页回来时不重复加载(使用keep-alive缓存)
- **图表自适应**：监听window resize事件，调用chart.resize()更新图表尺寸；组件卸载时dispose释放ECharts实例

### 5.4 验证
1. 工作台页面正确展示4个KPI卡片，数字与后端聚合数据一致
2. 折线图正确展示近7天登录趋势，数据点可hover查看具体数值
3. 饼图正确展示角色用户分布，点击图例可筛选
4. 快捷操作按钮点击正确跳转到对应页面
5. 最近登录日志表格展示最近10条记录，状态列使用tag标记成功/失败
