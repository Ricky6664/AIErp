## 五、详细开发规格


> **📦 本任务模块上下文**（来源：P0-004模块开发指南）
> - 本模块涉及数据表：sys_user, sys_dept, sys_user_dept, sys_user_role, sys_user_group, sys_user_group_member, sys_user_group_role, sys_user_password_history, sys_role, sys_role_menu
> - 本模块涉及API：/api/auth/login, /api/auth/logout, /api/auth/token/refresh, /api/auth/token/verify, /api/auth/user-info
> - 本模块业务规则：Sa-Token集成：所有登录认证必须通过Sa-Token框架实现，Token签发/注销/校验/续期均使用Sa-Token API，不允许自行实现Token机制。; 密码安全：用户密码必须使用BCrypt加密存储，不允许明文存储或可逆加密。密码策略配置（最小8位、大小写+数字+特殊字符四选三）由auth_password_policy表驱动。
>
> 💡 开发本任务时，请结合上述模块上下文理解业务场景和数据关系。
### 5.1 核心功能
1. 创建UserGroupForm.vue表单弹窗页，使用el-dialog(大尺寸width:720px)展示用户组表单
2. 表单字段：组名称(必填)、组编码(必填/编辑只读)、描述(textarea)、启用状态(el-switch)
3. 成员管理区域：使用el-transfer穿梭框，左侧可选用户列表、右侧已选成员列表
4. 角色分配区域：el-checkbox-group展示可用角色列表，用户组继承的角色自动勾选
5. 表单校验：组名称2-50字符、组编码2-30字符(字母数字下划线)
6. 编辑模式：加载用户组详情回填表单+成员列表+角色列表

### 5.2 数据交互
**新增用户组请求**：`POST /api/system/user-group`
```json
{ "groupName": "string", "groupCode": "string", "description": "string", "enabled": true, "memberUserIds": [1,2,3], "roleIds": [1,2] }
```
**编辑请求**：`PUT /api/system/user-group/{id}`
**成员管理请求**：`POST /api/system/user-group/{id}/members`
```json
{ "memberUserIds": [1, 2, 3, 4, 5] }
```

### 5.3 关键逻辑
- **穿梭框数据加载**：左侧可选用户列表调用GET /api/system/user?pageSize=9999获取全部用户，过滤掉已选成员；右侧已选成员从用户组详情获取
- **穿梭框搜索**：el-transfer的filterable属性开启搜索过滤，支持按用户名/昵称筛选
- **组编码编辑限制**：编辑模式下组编码只读(系统标识不可更改)，仅允许修改名称/描述/成员/角色
- **角色继承说明**：用户组成员自动继承该组关联的所有角色权限(sys_user_group_role)，与用户直接分配的角色叠加
- **保存事务性**：保存操作事务内同时写入sys_user_group基本信息 + sys_user_group_member成员关联 + sys_user_group_role角色关联

### 5.4 验证
1. 新增用户组表单校验正确，组编码重复时返回错误
2. 编辑模式正确回填组信息和成员/角色列表
3. 穿梭框成员添加/移除操作正确，保存后sys_user_group_member更新
4. 角色分配保存后用户组成员自动获得对应角色权限
5. 禁用用户组后其成员不再继承该组的角色权限
