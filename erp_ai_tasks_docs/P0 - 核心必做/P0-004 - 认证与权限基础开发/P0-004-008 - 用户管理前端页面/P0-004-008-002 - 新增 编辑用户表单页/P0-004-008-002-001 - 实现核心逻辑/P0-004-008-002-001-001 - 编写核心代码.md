## 五、详细开发规格


> **📦 本任务模块上下文**（来源：P0-004模块开发指南）
> - 本模块涉及数据表：sys_user, sys_dept, sys_user_dept, sys_user_role, sys_user_group, sys_user_group_member, sys_user_group_role, sys_user_password_history, sys_role, sys_role_menu
> - 本模块涉及API：/api/auth/login, /api/auth/logout, /api/auth/token/refresh, /api/auth/token/verify, /api/auth/user-info
> - 本模块业务规则：Sa-Token集成：所有登录认证必须通过Sa-Token框架实现，Token签发/注销/校验/续期均使用Sa-Token API，不允许自行实现Token机制。; 密码安全：用户密码必须使用BCrypt加密存储，不允许明文存储或可逆加密。密码策略配置（最小8位、大小写+数字+特殊字符四选三）由auth_password_policy表驱动。
>
> 💡 开发本任务时，请结合上述模块上下文理解业务场景和数据关系。
### 5.1 核心功能
1. 创建UserForm.vue表单弹窗页，使用el-dialog(大尺寸width:720px) + el-form展示用户表单
2. 表单字段：用户名(新增可编辑/编辑只读)、昵称、密码(新增必填/编辑选填)、邮箱、手机号、头像上传(el-upload)、状态(el-radio:正常/禁用)
3. 部门选择：el-tree-select多选权限部门，标记主部门(radio选择)
4. 角色分配：el-select多选角色列表，数据来自GET /api/system/role?enabled=true
5. 表单校验规则：用户名3-20位字母数字、邮箱格式校验、手机号11位格式校验、密码8-32位+复杂度校验
6. 编辑模式：接收用户ID，调用GET /api/system/user/{id}回填表单数据

### 5.2 数据交互
**新增用户请求**：`POST /api/system/user`
```json
{ "username": "string", "password": "string", "nickname": "string", "email": "string", "phone": "string", "deptIds": [1,2], "primaryDeptId": 1, "roleIds": [1,2], "status": "normal" }
```
**编辑用户请求**：`PUT /api/system/user/{id}`（password字段选填，不传则不修改密码）
**组件Props/Events**：
- Props: visible(boolean), userId(number, 编辑模式传入)
- Emits: update:visible, success(保存成功后触发列表刷新)

### 5.3 关键逻辑
- **新增/编辑模式切换**：userId有值为编辑模式，加载用户详情回填表单；无值为新增模式，表单初始化为空
- **密码字段处理**：新增模式密码必填；编辑模式密码选填，不填则不修改密码，填写则校验复杂度后更新
- **头像上传**：使用el-upload组件，action="/api/common/upload"，限制jpg/png格式+2MB大小，上传成功后返回URL存入avatar字段
- **部门主部门标记**：多选部门后通过radio标记主部门(primaryDeptId)，主部门必须在已选部门列表中
- **角色互斥前端校验**：选择角色后实时校验互斥关系，选择互斥角色时el-select显示warning提示（后端也会二次校验）
- **保存防重复提交**：提交按钮添加loading状态，请求完成前禁用按钮

### 5.4 验证
1. 新增模式表单正确校验，必填项为空时提示错误
2. 编辑模式正确回填用户数据，用户名只读
3. 密码复杂度不足时显示"密码需包含大小写字母、数字和特殊字符中的至少三种"
4. 部门多选+主部门标记正确，提交数据格式正确
5. 保存成功后弹窗关闭，列表自动刷新显示新数据
