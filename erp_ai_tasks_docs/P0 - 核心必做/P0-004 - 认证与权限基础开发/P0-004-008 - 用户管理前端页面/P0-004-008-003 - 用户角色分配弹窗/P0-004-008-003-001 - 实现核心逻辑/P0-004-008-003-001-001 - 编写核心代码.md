> - 本模块业务规则：Sa-Token集成：所有登录认证必须通过Sa-Token框架实现，Token签发/注销/校验/续期均使用Sa-Token API，不允许自行实现Token机制。; 密码安全：用户密码必须使用BCrypt加密存储，不允许明文存储或可逆加密。密码策略配置（最小8位、大小写+数字+特殊字符四选三）由auth_password_policy表驱动。
>

### 5.1 核心功能
1. 创建UserRoleDialog.vue弹窗组件，使用el-dialog(中尺寸width:560px)展示角色分配界面
2. 弹窗打开时加载用户当前已分配角色(GET /api/system/user/{userId}获取roleIds)
3. 加载全部可用角色列表(GET /api/system/role?enabled=true)，使用el-checkbox-group展示
4. 每个角色checkbox旁展示角色名称+角色编码+描述信息
5. 保存时调用POST /api/system/user/role批量分配角色，传递userId+roleIds
6. 角色互斥校验：选择角色后实时检查互斥关系，互斥角色对显示红色warning标记

### 5.2 数据交互
**角色分配请求**：`POST /api/system/user/role`
```json
{ "userId": "Long", "roleIds": [1, 2, 3] }
```
**组件Props/Events**：
- Props: visible(boolean), userId(number), username(string)
- Emits: update:visible, success(分配成功后刷新列表)
**角色列表数据**：
```json
[{ "id": 1, "roleName": "超级管理员", "roleCode": "superadmin", "description": "系统最高权限角色" }]
```

### 5.3 关键逻辑
- **角色互斥实时校验**：监听roleIds变化，遍历sys_role_exclusion规则，若已选角色中存在互斥对则在对应checkbox下方显示ElAlert("角色互斥：{角色A}与{角色B}不可同时分配")
- **全选/反选功能**：提供全选checkbox和清空按钮，方便批量操作
- **超级管理员保护**：superadmin角色仅superadmin用户可操作分配，普通管理员无法修改超管角色
- **变更对比**：保存前对比初始角色列表和当前选择，提示"新增{N}个角色，移除{M}个角色"的变更摘要
- **保存确认**：角色变更时弹出二次确认("确定保存角色分配变更？")，无变更时保存按钮禁用

### 5.4 验证
1. 弹窗正确显示用户当前已分配的角色(已勾选)
2. 勾选互斥角色时显示红色互斥警告
3. 保存后用户角色关联表(sys_user_role)更新正确
4. 取消操作不修改角色分配
5. 无角色变更时保存按钮禁用
