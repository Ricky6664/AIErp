## 五、详细开发规格


> **📦 本任务模块上下文**（来源：P0-004模块开发指南）
> - 本模块涉及数据表：sys_user, sys_dept, sys_user_dept, sys_user_role, sys_user_group, sys_user_group_member, sys_user_group_role, sys_user_password_history, sys_role, sys_role_menu

> - 本模块业务规则：Sa-Token集成：所有登录认证必须通过Sa-Token框架实现，Token签发/注销/校验/续期均使用Sa-Token API，不允许自行实现Token机制。; 密码安全：用户密码必须使用BCrypt加密存储，不允许明文存储或可逆加密。密码策略配置（最小8位、大小写+数字+特殊字符四选三）由auth_password_policy表驱动。
>
> 💡 开发本任务时，请结合上述模块上下文理解业务场景和数据关系。
### 5.1 核心功能
1. 创建UserGroupList.vue列表页，采用P04单一列表页类型展示用户组数据
2. 搜索栏：组名称/组编码关键字搜索(el-input)、启用状态筛选(el-select)、搜索/重置按钮
3. 操作栏：新增用户组按钮(v-permission)、批量删除按钮
4. el-table展示：组名称/组编码/描述/成员数量/启用状态/创建时间/操作列
5. 操作列：编辑、成员管理(跳转组成员管理)、删除按钮
6. el-pagination分页组件，支持页码和每页条数切换

### 5.2 数据交互
**用户组列表查询**：`GET /api/system/user-group?pageNum=1&pageSize=20&keyword=xxx&enabled=true`
```json
{
  "code": 200,
  "data": {
    "records": [{ "id": 1, "groupName": "运维组", "groupCode": "ops", "description": "系统运维团队", "memberCount": 12, "enabled": true, "createTime": "2026-01-01" }],
    "total": 8, "pageNum": 1, "pageSize": 20
  }
}
```
**涉及数据表**：sys_user_group, sys_user_group_member, sys_user_group_role

### 5.3 关键逻辑
- **成员数量统计**：列表查询时LEFT JOIN sys_user_group_member GROUP BY group_id统计每个用户组的成员数量
- **组编码唯一性**：新增/编辑用户组时校验组编码唯一性(前后端双重校验)，后端返回"组编码已存在"错误
- **删除前校验**：删除用户组前检查是否有关联成员(sys_user_group_member)和关联角色(sys_user_group_role)，有则提示"请先移除组成员和角色关联"
- **成员管理跳转**：点击"成员管理"按钮跳转到用户组详情页面，展示组成员列表并提供添加/移除操作
- **状态切换**：启用/禁用用户组使用el-switch组件，切换时调用PUT接口更新enabled字段

### 5.4 验证
1. 列表页正确展示用户组数据，成员数量统计正确
2. 关键字搜索和状态筛选功能正常
3. 删除有成员的用户组时提示先移除成员
4. 组编码唯一性校验：新增重复编码时返回错误
5. 状态切换立即生效，禁用组的成员不继承该组角色权限
