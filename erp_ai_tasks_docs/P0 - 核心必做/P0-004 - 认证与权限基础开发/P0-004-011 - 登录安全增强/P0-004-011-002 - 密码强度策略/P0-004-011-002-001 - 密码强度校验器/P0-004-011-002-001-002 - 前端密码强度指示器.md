>
> 💡 开发本任务时，请结合上述模块上下文理解业务场景和数据关系。
### 5.1 核心功能
1. 创建PasswordStrength.vue组件，接收password prop，实时计算密码强度并展示进度条
2. 密码强度计算规则：检测大写(+1分)、小写(+1分)、数字(+1分)、特殊字符(+1分)、长度≥8(+1分)、长度≥12(+1分)
3. 强度等级映射：0-2分=弱(红色)、3-4分=中(橙色)、5-6分=强(绿色)
4. 使用el-progress组件展示强度条，percentage映射为强度百分比(弱=33%/中=66%/强=100%)
5. 在密码输入框下方显示强度指示器+密码要求提示(如"需包含大小写字母、数字和特殊字符中的至少三种")
6. 密码要求提示根据auth_password_policy配置动态显示

### 5.2 数据交互
**组件Props**：
```typescript
interface Props {
  password: string;  // 密码值(v-model绑定)
  policy?: {         // 密码策略(可选，不传使用默认策略)
    minLength: number; requireUppercase: boolean; requireLowercase: boolean;
    requireDigit: boolean; requireSpecialChar: boolean;
  }
}
```
**组件Emits**：
```typescript
{ "update:strength": (level: 'weak'|'medium'|'strong') => void }
```
**密码策略获取**：应用初始化时从后端GET /api/system/password-policy获取当前启用的策略，存入appStore

### 5.3 关键逻辑
- **实时计算**：使用computed属性监听password变化，实时重新计算强度分数；使用正则表达式检测各类字符
- **四选三规则**：大写/小写/数字/特殊字符四项中至少满足三项(由auth_password_policy表配置)；不满足时在指示器下方逐项显示✔/✘标记
- **特殊字符定义**：特殊字符集为`!@#$%^&*()_+-=[]{}|;':",./<>?`
- **防抖优化**：密码输入使用300ms debounce，避免每次按键都重新计算(虽然计算很快但减少DOM更新)
- **颜色主题**：弱=el-color-danger(#F56C6C)、中=el-color-warning(#E6A23C)、强=el-color-success(#67C23A)

### 5.4 验证
1. 输入纯数字密码显示"弱"(红色进度条33%)
2. 输入大小写+数字密码显示"中"(橙色进度条66%)
3. 输入大小写+数字+特殊字符+12位以上显示"强"(绿色进度条100%)
4. 逐项校验标记正确显示每项要求的通过/未通过状态
5. 密码清空后强度指示器重置为初始状态
