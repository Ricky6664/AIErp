### 5.1 核心功能
1. 在OAuth2配置表单底部添加"测试连接"按钮，仅编辑模式(已有配置ID)时显示
2. 点击按钮调用POST /api/system/oauth2-config/{id}/test接口，测试OAuth2配置的授权URL连通性
3. 按钮点击后显示loading状态(el-button loading)，禁用其他操作按钮，超时时间10秒
4. 测试结果展示：成功时ElMessage.success("连接成功：授权URL可访问")，失败时ElMessage.error显示具体错误信息
5. 测试结果区域展示详细日志：请求URL、HTTP状态码、响应时间(ms)

### 5.2 数据交互
**测试连接请求**：`POST /api/system/oauth2-config/{id}/test`
```json
// 请求体为空，从数据库读取配置
```
**测试成功响应**：
```json
{ "code": 200, "data": { "success": true, "statusCode": 200, "responseTime": 235, "message": "授权URL可访问", "testUrl": "https://open.work.weixin.qq.com/oauth2/authorize" } }
```
**测试失败响应**：
```json
{ "code": 200, "data": { "success": false, "statusCode": 0, "responseTime": 10000, "message": "连接超时(10秒)", "testUrl": "https://invalid-url.com" } }
```

### 5.3 关键逻辑
- **后端测试实现**：使用RestTemplate/WebClient向授权URL发送GET请求(设置connectTimeout=5s, readTimeout=10s)，检查响应状态码
- **状态码判定**：200/302/401视为连通(401表示服务器可达但需认证，OAuth2授权URL正常)，0/超时/DNS失败视为不可达
- **防重复点击**：按钮loading状态期间禁用点击，请求完成(成功或失败)后恢复
- **网络错误分类**：区分DNS解析失败、连接超时、HTTP错误码等不同错误类型，返回不同的错误提示
- **测试不暴露敏感信息**：测试连接的请求/响应日志中不包含ClientSecret，仅记录URL和状态码

### 5.4 验证
1. 有效OAuth2配置点击测试连接返回成功，显示响应时间
2. 无效URL返回连接失败，显示具体错误信息(超时/DNS失败等)
3. 按钮loading状态期间不可重复点击
4. 新增模式(无配置ID)时测试连接按钮不显示
5. 测试结果详细日志正确展示请求URL、状态码、响应时间

## 八、易错警示

> ⚠️ Sa-Token的StpUtil.login(userId)中userId必须是唯一标识，建议使用Long类型用户ID

> ⚠️ 密码比对使用BCrypt.checkpw()，不要使用MD5/SHA等可逆或弱哈希算法

> ⚠️ 多租户隔离(tenant_id)由MyBatis-Plus TenantLineInnerInterceptor自动注入，不要手动拼接
