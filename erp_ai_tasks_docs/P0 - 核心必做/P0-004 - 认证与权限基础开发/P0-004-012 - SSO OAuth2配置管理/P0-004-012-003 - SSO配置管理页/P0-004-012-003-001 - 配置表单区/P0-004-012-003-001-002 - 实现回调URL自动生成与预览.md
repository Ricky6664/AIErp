### 5.1 核心功能
1. 在OAuth2配置表单中创建回调URL自动生成组件，根据当前站点域名和供应商类型自动拼接redirect_uri
2. 回调URL格式：{window.location.origin}/api/auth/oauth2/callback/{providerType}，如https://erp.company.com/api/auth/oauth2/callback/wechat_work
3. 在表单中展示只读的回调URL文本框(el-input readonly) + 一键复制按钮(el-button + navigator.clipboard.writeText)
4. 供应商类型切换时自动更新回调URL中的providerType部分
5. 回调URL下方显示配置提示："请将以下回调URL添加到OAuth2供应商后台配置中"

### 5.2 数据交互
**回调URL生成规则**：
| 供应商类型 | providerType | 回调URL示例 |
|-----------|-------------|------------|
| 企业微信 | wechat_work | https://erp.com/api/auth/oauth2/callback/wechat_work |
| 钉钉 | dingtalk | https://erp.com/api/auth/oauth2/callback/dingtalk |
| 飞书 | feishu | https://erp.com/api/auth/oauth2/callback/feishu |
| GitHub | github | https://erp.com/api/auth/oauth2/callback/github |
| Google | google | https://erp.com/api/auth/oauth2/callback/google |

**组件Props**：providerType(string), baseUrl(string, 默认window.location.origin)
**组件Emits**：无(纯展示+复制)

### 5.3 关键逻辑
- **URL拼接逻辑**：使用computed属性监听providerType变化，自动计算redirect_uri = `${baseUrl}/api/auth/oauth2/callback/${providerType}`
- **一键复制实现**：使用navigator.clipboard.writeText(url)复制到剪贴板，成功后ElMessage.success("回调URL已复制到剪贴板")；兼容性降级使用document.execCommand('copy')
- **编辑模式预填充**：编辑已有OAuth2配置时，从配置数据中读取type自动设置providerType，回调URL自动计算
- **URL预览格式化**：回调URL使用等宽字体(font-family: monospace)展示，URL中的域名和providerType部分使用不同颜色高亮
- **HTTPS提示**：当前站点为HTTP协议时，在回调URL下方显示el-alert warning："当前站点使用HTTP协议，生产环境建议配置HTTPS"

### 5.4 验证
1. 选择不同供应商类型后回调URL自动更新对应的providerType
2. 点击复制按钮后剪贴板内容与显示的URL一致
3. 编辑模式下回调URL根据已有配置的type自动生成
4. 回调URL格式正确：{域名}/api/auth/oauth2/callback/{providerType}
5. HTTP环境下正确显示HTTPS建议提示

## 八、易错警示

> ⚠️ Sa-Token的StpUtil.login(userId)中userId必须是唯一标识，建议使用Long类型用户ID

> ⚠️ 密码比对使用BCrypt.checkpw()，不要使用MD5/SHA等可逆或弱哈希算法

> ⚠️ 多租户隔离(tenant_id)由MyBatis-Plus TenantLineInnerInterceptor自动注入，不要手动拼接
