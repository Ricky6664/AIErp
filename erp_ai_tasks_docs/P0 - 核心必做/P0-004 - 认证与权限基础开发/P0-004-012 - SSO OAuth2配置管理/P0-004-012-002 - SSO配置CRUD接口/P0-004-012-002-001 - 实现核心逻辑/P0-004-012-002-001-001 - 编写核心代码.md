## 五、详细开发规格


> **📦 本任务模块上下文**（来源：P0-004模块开发指南）
> - 本模块涉及数据表：sys_user, sys_dept, sys_user_dept, sys_user_role, sys_user_group, sys_user_group_member, sys_user_group_role, sys_user_password_history, sys_role, sys_role_menu
> - 本模块涉及API：/api/auth/login, /api/auth/logout, /api/auth/token/refresh, /api/auth/token/verify, /api/auth/user-info
> - 本模块业务规则：Sa-Token集成：所有登录认证必须通过Sa-Token框架实现，Token签发/注销/校验/续期均使用Sa-Token API，不允许自行实现Token机制。; 密码安全：用户密码必须使用BCrypt加密存储，不允许明文存储或可逆加密。密码策略配置（最小8位、大小写+数字+特殊字符四选三）由auth_password_policy表驱动。
>
> 💡 开发本任务时，请结合上述模块上下文理解业务场景和数据关系。
### 5.1 核心功能
1. 创建SsoConfigController类，添加@RestController + @RequestMapping("/api/system/sso-config")注解
2. 编写SSO配置CRUD：GET分页查询、GET /{id}详情、POST新增(名称/类型[SAML/OAuth2/CAS]/IdP地址/SP实体ID/SSO登录URL/SSO登出URL/证书/启用状态)、PUT修改、DELETE删除
3. 创建OAuth2ConfigController类，添加@RestController + @RequestMapping("/api/system/oauth2-config")注解
4. 编写OAuth2配置CRUD：GET分页查询、GET /{id}详情、POST新增(供应商名称/类型[微信/钉钉/飞书/GitHub/Google]/ClientID/ClientSecret/授权URL/TokenURL/用户信息URL/Scope/启用状态)、PUT修改、DELETE删除
5. 编写POST /api/system/oauth2-config/{id}/test测试连接接口：验证授权URL和TokenURL的连通性
6. ClientSecret加密存储：使用AES-256加密后存入数据库，读取时解密返回(前端显示脱敏为****)

### 5.2 数据交互
**SSO配置请求**：`POST /api/system/sso-config`
```json
{ "ssoName": "企业SSO", "type": "SAML", "idpUrl": "https://idp.company.com", "spEntityId": "erp-system", "ssoLoginUrl": "https://idp.company.com/sso/login", "ssoLogoutUrl": "https://idp.company.com/sso/logout", "certificate": "MIIC...", "enabled": true }
```
**OAuth2配置请求**：`POST /api/system/oauth2-config`
```json
{ "supplierName": "企业微信", "type": "wechat_work", "clientId": "wx123456", "clientSecret": "加密存储", "authUrl": "https://open.work.weixin.qq.com/oauth2/authorize", "tokenUrl": "https://qyapi.weixin.qq.com/cgi-bin/gettoken", "userInfoUrl": "https://qyapi.weixin.qq.com/cgi-bin/user/getuserinfo", "scope": "snsapi_base", "enabled": true }
```

### 5.3 关键逻辑
- **ClientSecret加密存储**：使用AES-256-GCM加密ClientSecret，密钥从环境变量(AES_SECRET_KEY)读取，不硬编码；数据库存储格式为`AES:{base64(iv)}:{base64(ciphertext)}`
- **前端脱敏展示**：GET详情接口返回的clientSecret字段脱敏为"********"，仅保存时传递明文
- **测试连接实现**：使用RestTemplate向授权URL发送HEAD请求(超时10秒)，检查HTTP状态码；200/302视为连通，其他状态码或超时视为失败
- **SSO证书校验**：新增/修改SSO配置时校验证书格式(X.509 PEM格式)，使用CertificateFactory解析证书验证有效性
- **P0阶段范围**：P0仅完成配置CRUD管理和前端配置页面，具体的SAML/OAuth2/CAS授权流程(重定向→授权→回调→用户匹配)在P2阶段扩展

### 5.4 验证
1. SSO配置CRUD操作正常，证书格式校验正确(非法PEM格式返回错误)
2. OAuth2配置CRUD操作正常，ClientSecret数据库存储为加密格式
3. 测试连接正确返回连通/失败结果，超时时返回"连接超时"
4. GET详情接口ClientSecret字段脱敏显示
5. 删除SSO/OAuth2配置后前端列表更新，关联数据清理正确

## 八、易错警示

> ⚠️ Sa-Token的StpUtil.login(userId)中userId必须是唯一标识，建议使用Long类型用户ID

> ⚠️ 密码比对使用BCrypt.checkpw()，不要使用MD5/SHA等可逆或弱哈希算法

> ⚠️ 多租户隔离(tenant_id)由MyBatis-Plus TenantLineInnerInterceptor自动注入，不要手动拼接
