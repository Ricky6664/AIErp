## 五、详细开发规格


> **📦 本任务模块上下文**（来源：P0-004模块开发指南）
> - 本模块涉及数据表：sys_user, sys_dept, sys_user_dept, sys_user_role, sys_user_group, sys_user_group_member, sys_user_group_role, sys_user_password_history, sys_role, sys_role_menu
> - 本模块涉及API：/api/auth/login, /api/auth/logout, /api/auth/token/refresh, /api/auth/token/verify, /api/auth/user-info
> - 本模块业务规则：Sa-Token集成：所有登录认证必须通过Sa-Token框架实现，Token签发/注销/校验/续期均使用Sa-Token API，不允许自行实现Token机制。; 密码安全：用户密码必须使用BCrypt加密存储，不允许明文存储或可逆加密。密码策略配置（最小8位、大小写+数字+特殊字符四选三）由auth_password_policy表驱动。
>
> 💡 开发本任务时，请结合上述模块上下文理解业务场景和数据关系。
### 5.1 核心功能
1. 创建LoginRequest DTO，包含username、password、captchaCode、captchaKey字段，添加@NotBlank校验注解
2. 在AuthController中编写login方法，接收LoginRequest并调用BindingResult校验参数合法性
3. 调用CaptchaService.verifyCaptcha(captchaKey, captchaCode)校验图形验证码，验证失败抛出CaptchaException
4. 通过sys_user表查询用户，使用BCrypt.checkpw校验密码；密码错误时递增Redis登录失败计数器
5. 调用StpUtil.login(userId)签发Sa-Token，将用户权限标识列表(permissionCodeList)写入Session
6. 构造LoginResponse返回token、用户基本信息(id/username/nickname/avatar)、菜单权限树与按钮权限标识列表
7. 通过@Async异步方法写入sys_login_log登录日志，记录用户ID、IP、浏览器、操作系统、登录状态

### 5.2 数据交互
**请求**：`POST /api/auth/login`
```json
{ "username": "string", "password": "string", "captchaCode": "string", "captchaKey": "string" }
```
**响应**：
```json
{
  "code": 200,
  "data": {
    "token": "string (Sa-Token值)",
    "userId": "Long",
    "username": "string",
    "nickname": "string",
    "avatar": "string",
    "menuTree": [{ "id": "Long", "name": "string", "path": "string", "children": [] }],
    "permissions": ["system:user:add", "system:user:edit", "..."]
  }
}
```
**Redis缓存**：`login:fail:{username}` → 失败次数(Integer)，TTL=15min；`captcha:{captchaKey}` → 验证码文本(String)，TTL=5min

### 5.3 关键逻辑
- **验证码一次性消费**：验证码校验通过后立即从Redis删除captchaKey，防止重放攻击
- **BCrypt密码比对**：使用BCrypt.checkpw(plainPassword, hashedPassword)进行不可逆校验，不使用可逆加密
- **登录失败计数**：每次密码错误递增Redis Key `login:fail:{username}`，达到auth_password_policy.max_login_attempts(默认5次)时设置锁定标记 `login:lock:{username}`，TTL=lock_duration(默认15分钟)
- **锁定状态前置校验**：登录前先检查 `login:lock:{username}` 是否存在，存在则直接返回锁定中错误，不执行密码校验
- **异步日志写入**：使用Spring @Async注解+ThreadPoolTaskExecutor异步写入sys_login_log，确保日志不阻塞登录主流程
- **租户隔离**：所有查询均附加tenant_id条件，通过MyBatis-Plus TenantLineInnerInterceptor自动注入

### 5.4 验证
1. 正确用户名+密码+验证码登录成功，返回有效token和完整权限数据
2. 错误密码连续输入5次后账户被锁定，第6次登录返回"账户已锁定，请15分钟后再试"
3. 图形验证码过期(超过5分钟)后提交返回"验证码已过期"错误
4. 验证码校验一次后立即失效，重复使用同一验证码返回"验证码错误"
5. 登录成功/失败均在sys_login_log中有对应记录，且写入不影响登录响应时间

## 八、易错警示

> ⚠️ Sa-Token的StpUtil.login(userId)中userId必须是唯一标识，建议使用Long类型用户ID

> ⚠️ 密码比对使用BCrypt.checkpw()，不要使用MD5/SHA等可逆或弱哈希算法

> ⚠️ 多租户隔离(tenant_id)由MyBatis-Plus TenantLineInnerInterceptor自动注入，不要手动拼接
