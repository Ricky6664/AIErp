# P0-001 后端项目框架搭建 - 模块开发指南

## 1. 模块概述

**模块编号**: P0-001  
**模块名称**: 后端项目框架搭建  
**优先级**: P0（最高）  
**阶段**: 第一阶段（基础架构层）

### 1.1 模块定位
搭建Spring Boot 3.x + MyBatis-Plus 3.5.5后端项目骨架，配置全局基础设施，为后续所有业务模块提供统一的技术底座。本模块是整个ERP系统的后端基石，所有业务模块都将基于此框架进行开发。

### 1.2 核心价值
- **统一技术标准**: 锁定JDK17 + Spring Boot 3.4.x + MyBatis-Plus 3.5.5技术栈
- **规范开发流程**: 提供统一的项目结构、异常处理、响应格式、日志规范
- **降低开发成本**: 预置通用能力（编码引擎、数据视图引擎、系统参数服务）
- **保障代码质量**: 内置参数校验、权限控制、审计日志等基础能力

### 1.3 前置依赖
**无**（本模块是后端开发的起点）

### 1.4 被依赖方
- P0-003（数据库基础架构搭建）
- P0-004 及后续所有业务模块

## 5. 关键技术决策

### 5.1 主键策略：雪花算法
- **决策**: 使用`IdType.ASSIGN_ID`（雪花算法）而非自增ID
- **原因**: 
  - 支持分布式部署，不依赖数据库自增
  - 避免ID冲突，便于数据合并
  - 性能优于UUID
- **实现**: MyBatis-Plus内置支持，BaseEntity统一配置

### 5.2 软删除机制
- **决策**: 使用`is_deleted`字段（0=未删除，1=已删除）
- **原因**:
  - 保留历史数据，支持数据恢复
  - 避免外键约束导致的级联删除问题
  - 符合审计要求
- **实现**: MyBatis-Plus `@TableLogic`注解，自动拦截DELETE语句

### 5.3 乐观锁控制
- **决策**: 使用`version`字段实现乐观锁
- **原因**:
  - 避免悲观锁的性能开销
  - 防止并发更新导致的数据不一致
- **实现**: MyBatis-Plus `@Version`注解，自动递增版本号

### 5.4 自动填充策略
- **决策**: 自动填充`created_by`/`updated_by`/`created_at`/`updated_at`
- **原因**:
  - 减少重复代码
  - 确保审计字段完整性
- **实现**: MyBatis-Plus `MetaObjectHandler`接口

### 5.5 权限框架选型：Sa-Token
- **决策**: 使用Sa-Token而非Spring Security
- **原因**:
  - 学习曲线更平缓，API更友好
  - 功能足够（认证、授权、SSO、OAuth2）
  - 社区活跃，文档完善
- **配置**: Token有效期30天，临时有效期30分钟（无操作自动登出）

### 5.6 编码引擎设计
- **决策**: 基于Redis的分布式序列号生成器
- **原因**:
  - 高性能（Redis原子操作）
  - 支持多实例部署
  - 灵活的编码规则（前缀+日期+序列号）
- **实现**: `code:generate`配置节点，支持缓存和分布式锁

### 5.7 数据视图引擎设计
- **决策**: 动态SQL构建器 + 视图配置表
- **原因**:
  - 支持复杂查询场景（多表JOIN、聚合统计）
  - 可配置的查询条件，减少硬编码
  - 性能优化（预编译SQL、索引优化）
- **实现**: `sys_data_view`配置表 + `DataViewQueryBuilder`动态构建器

## 6. 风险点与应对策略

### 6.1 长路径文件问题（Windows环境）
**风险**: Windows MAX_PATH限制（260字符）导致深层嵌套目录文件创建失败  
**影响**: P0-001-001-003-003-001下的3个叶子任务文档内容不完整  
**应对**:
- ✅ 已手动修复3个长路径文件，补充完整内容
- 建议: 启用Windows长路径支持（注册表/组策略）
- 建议: 使用相对较短的项目根目录路径

### 6.2 DDL字段定义占位符
**风险**: 部分DDL文档中字段定义使用"根据设计文档确定"占位  
**影响**: 开发者需要额外查阅设计文档才能获取完整字段信息  
**应对**:
- 在Phase 5全量验证阶段检查并补充完整字段定义
- 建议: DDL任务文档应直接包含完整的字段名、类型、约束、默认值

### 6.3 配置属性类注入失败
**风险**: `@ConfigurationProperties`配置类未正确注入  
**影响**: 文件上传、编码生成、分页等功能使用默认值而非配置值  
**应对**:
- 确保配置类添加`@Component`注解
- 启动日志检查配置绑定是否成功
- 编写配置验证测试用例

### 6.4 Sa-Token权限数据加载
**风险**: `StpInterfaceImpl`未正确实现权限数据加载  
**影响**: 权限验证失败，所有接口返回403  
**应对**:
- 确保`getPermissionList`和`getRoleList`方法正确查询数据库
- 添加权限缓存机制（Redis）
- 编写权限验证集成测试

### 6.5 多租户数据隔离
**风险**: 多租户拦截器未正确配置，导致数据泄露  
**影响**: 租户A访问到租户B的数据  
**应对**:
- 确保`TenantInterceptor`正确拦截所有SQL
- BaseEntity必须包含`tenantId`字段
- 编写多租户数据隔离测试用例

### 6.6 文件上传安全
**风险**: 文件上传未正确校验文件类型和大小  
**影响**: 恶意文件上传、磁盘空间耗尽  
**应对**:
- 配置白名单（MIME类型）和黑名单（扩展名）
- 限制单文件大小（10MB）和请求总大小（100MB）
- 图片自动压缩（超过1920x1080）

## 8. 关键配置参考

### 8.1 application.yml核心配置节点

```yaml
# 数据库配置
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/erp_dev
    username: ${DB_USERNAME:postgres}
    password: ${DB_PASSWORD:postgres}
  
  # Redis配置
  data:
    redis:
      host: localhost
      port: 6379
      database: 0

# MyBatis-Plus配置
mybatis-plus:
  global-config:
    db-config:
      logic-delete-field: isDeleted
      logic-delete-value: 1
      logic-not-delete-value: 0
      id-type: ASSIGN_ID

# Sa-Token配置
sa-token:
  token-name: Authorization
  timeout: 2592000        # 30天
  active-timeout: 1800    # 30分钟
  is-concurrent: false
  is-share: false
  token-style: uuid

# 文件上传配置
file:
  upload:
    local-path: /data/erp/files
    allowed-types: [image/jpeg, image/png, application/pdf, ...]
    blocked-extensions: [exe, bat, cmd, sh, php, jsp, asp]

# 编码生成配置
code:
  generate:
    cache-key-prefix: "erp:code:seq:"
    cache-ttl: 86400
    enable-cache: true
    seq-format: "%06d"

# 分页配置
page:
  default-page: 1
  default-size: 20
  max-size: 500
```
