## 1. 模块架构约束

### 1.1 模块定位
P0-001是整个ERP系统的后端基石，负责搭建Spring Boot 3.x + MyBatis-Plus 3.5.5后端项目骨架，配置全局基础设施。本模块为后续所有业务模块提供统一的技术底座，包括项目结构规范、全局异常处理、统一响应格式、数据库连接、认证框架集成、编码引擎、数据视图引擎、系统参数服务等核心能力。所有后端业务模块都将基于此框架进行开发。

### 1.2 依赖关系
- 前置依赖：无（本模块是后端开发的起点）
- 后续依赖：
  - P0-003（数据库基础架构搭建）——依赖P0-001-003数据库连接与基础DAO层
  - P0-004（认证与权限基础开发）——依赖P0-001-004 Sa-Token认证框架集成
  - P0-005 及后续所有业务模块——依赖本模块全部基础能力

### 1.3 技术约束
- **技术栈约束**：JDK 17（LTS）+ Spring Boot 3.4.x + MyBatis-Plus 3.5.5 + PostgreSQL 15+ + Redis 7.x + Sa-Token 1.39.0 + Hutool 5.8.x + Knife4j 4.x + Logback 1.4.x
- **性能约束**：项目启动时间 < 10秒；编码生成性能 > 1000次/秒（Redis缓存）；数据视图查询性能 < 500ms（10万数据量）；文件上传性能 > 10MB/s（本地存储）
- **安全约束**：所有敏感配置（密码、密钥）使用环境变量注入，禁止硬编码；Sa-Token Token有效期30天、临时有效期30分钟；文件上传白名单（MIME类型）+黑名单（扩展名）限制，单文件10MB/请求100MB上限；多租户数据隔离（tenant_id字段+MyBatis-Plus拦截器）；SQL注入防护（MyBatis-Plus参数化查询）

## 2. 数据模型关系

### 2.1 核心数据表
| 表名 | 说明 | 关键字段 |
|------|------|---------|
| sys_code_rule | 编码规则配置表 | rule_code, target_table, target_field, reset_cycle, is_enabled |
| sys_code_rule_segment | 编码规则段配置表 | rule_id, segment_type, segment_order, fixed_value, date_format, seq_digits, step |
| sys_data_view | 数据视图配置表 | view_code, main_table, query_sql_template |
| sys_data_view_field | 数据视图字段配置表 | view_id, field_name, field_label, query_type, sort_order, is_visible |
| sys_param | 系统参数表 | param_group, param_code, param_name, param_value, value_type |
| doc_detail_location | 库位辅助属性子表 | detail_id, location_id, qty |
| doc_detail_batch | 批次辅助属性子表 | detail_id, batch_no, qty |
| doc_detail_serial | 序列号辅助属性子表 | detail_id, serial_no |

### 2.2 表关系图
- `sys_code_rule` 1:N `sys_code_rule_segment`：一个编码规则包含多个段配置，按segment_order排序拼接
- `sys_data_view` 1:N `sys_data_view_field`：一个数据视图包含多个字段配置
- `doc_detail_location`/`doc_detail_batch`/`doc_detail_serial`：三张通用单据从表独立存在，被所有业务单据明细行共享引用，通过detail_id关联到各业务明细表

### 2.3 数据流转
1. 编码引擎：业务模块调用编码生成API → 查询sys_code_rule获取规则 → 查询sys_code_rule_segment获取段配置 → Redis INCR生成序列号 → 拼接返回完整编码
2. 数据视图引擎：前端传入视图编号+查询参数 → 查询sys_data_view获取SQL模板 → 查询sys_data_view_field获取字段配置 → DataViewQueryBuilder动态构建SQL → 执行查询返回结果
3. 系统参数服务：业务模块通过param_code查询参数 → Redis缓存命中则直接返回 → 未命中则查库并写入缓存

## 3. 业务流程

### 3.1 核心业务流程
1. **项目初始化**：创建Spring Boot项目骨架 → 配置pom.xml依赖 → 配置多环境application.yml → 配置Logback日志框架
2. **全局异常处理**：定义业务异常类 → 实现GlobalExceptionHandler → 定义R<T>统一响应格式 → 实现参数校验框架
3. **数据库连接**：配置数据源 → 配置MyBatis-Plus（分页插件+乐观锁插件+自动填充+软删除+多租户拦截器）→ 实现BaseEntity基类 → 实现通用Mapper/Service
4. **Sa-Token集成**：配置Sa-Token → 实现StpInterfaceImpl权限数据加载 → 配置路由拦截器 → 实现SecurityUtils工具类
5. **编码引擎**：配置编码生成属性 → 实现Redis序列号生成器 → 提供编码自动生成API
6. **数据视图引擎**：实现DataViewQueryBuilder → 实现动态SQL构建 → 提供查询API
7. **系统参数服务**：实现参数读取服务 → 配置Redis缓存 → 提供参数查询API
8. **公共基础服务**：实现文件上传下载 → 实现短信/邮件发送 → 实现操作日志AOP切面
9. **通用单据从表**：创建doc_detail_location/batch/serial三张公共从表

### 3.2 业务规则
- 主键策略统一使用雪花算法（IdType.ASSIGN_ID），不使用自增ID
- 软删除使用is_deleted字段（0=未删除，1=已删除），MyBatis-Plus @TableLogic自动拦截DELETE
- 乐观锁使用version字段，MyBatis-Plus @Version自动递增
- 自动填充created_by/updated_by/created_at/updated_at，通过MetaObjectHandler实现
- 分页插件必须在乐观锁插件之前注册（MybatisPlusConfig插件顺序）
- 编码生成基于Redis原子操作，支持分布式部署和并发安全

### 3.3 状态流转
本模块不涉及业务状态流转，主要提供基础框架能力。

## 4. 接口契约

### 4.1 对外接口
| 接口路径 | 方法 | 说明 |
|---------|------|------|
| /api/code/generate | POST | 编码自动生成（根据规则编码生成唯一业务编码） |
| /api/code/preview | GET | 编码预览（预览下一个编码值，不消耗序列号） |
| /api/dataview/{viewCode} | GET | 数据视图查询（根据视图编号+查询参数执行动态查询） |
| /api/dataview/{viewCode}/fields | GET | 获取数据视图字段配置 |
| /api/system/param/by-code/{paramCode} | GET | 按编码查询系统参数值 |
| /api/system/param/by-group/{group} | GET | 按分组查询参数列表 |
| /api/file/upload | POST | 文件上传（MultipartFile，返回文件路径） |
| /api/file/download | GET | 文件下载（根据文件路径下载） |

### 4.2 依赖接口
本模块为基础框架模块，不依赖其他业务模块接口，仅依赖外部中间件：
- PostgreSQL数据库连接
- Redis缓存服务
- MinIO对象存储（可选，可切换本地存储）

## 5. 开发顺序约束

### 5.1 必须顺序执行的任务
1. **P0-001-001 项目初始化与基础配置** → **P0-001-002 全局异常处理与统一响应** → **P0-001-003 数据库连接与基础DAO层**
   - 这三步构成基础依赖链，后续所有子模块都依赖此链路
   - 项目骨架必须先于异常处理，异常处理必须先于数据库连接配置

### 5.2 可并行执行的任务
以下6个子模块均仅依赖P0-001-003（数据库连接与基础DAO层），可完全并行开发：
- P0-001-004 Sa-Token认证框架集成
- P0-001-005 编码引擎基础服务
- P0-001-006 数据视图引擎基础服务
- P0-001-007 系统参数服务基础
- P0-001-008 公共基础服务
- P0-001-009 通用单据公共从表服务
