# 全局规范 - 页面类型定义 - 展示类 P01 至 P05

> 本文档定义系统页面类型 P01~P05（首页/仪表盘、工作台、主从列表、单一列表、树形列表），为前端页面开发提供完整布局与交互规范。
> 本文档为独立规范文档，内容自包含，无需参照外部设计文档。

---

## 页面整体主布局（通用框架）

系统采用**左侧边栏 + 右侧内容区**的经典ERP双栏主布局结构，所有业务页面统一运行在此主布局框架内：

```
┌──────────────────────────────────────────────────────────────┐
│                       系统顶栏（可选）                         │
├────────────┬─────────────────────────────────────────────────┤
│            │  标签页栏  [首页] [客户中心] [销售订单] ...      │
│  🔍 搜索   │  ─────────────────────────────────────────────  │
│  ┌──────┐  │  头部扩展工具栏 [最大化] [主题] [语言] [用户]   │
│  │搜索框│  │  ─────────────────────────────────────────────  │
│  └──────┘  │                                                 │
│  侧边栏     │           右侧内容区                             │
│  导航       │      （各页面类型P01~P15的                      │
│            │       具体布局在此区域内渲染）                   │
│  ┌────────┐│                                                 │
│  │一级菜单││                                                 │
│  │🔧 首页 ││                                                 │
│  │👥 CRM  ││                                                 │
│  │🏭 SRM  ││                                                 │
│  │📦 商品 ││                                                 │
│  │...     ││                                                 │
│  ├────────┤│                                                 │
│  │二级菜单││                                                 │
│  │客户中心││                                                 │
│  │客户分类││                                                 │
│  │...     ││                                                 │
│  └────────┘│                                                 │
│            │                                                 │
├────────────┴─────────────────────────────────────────────────┤
│                       （无底部栏）                             │
└──────────────────────────────────────────────────────────────┘
```

**主布局规则：**

- **左侧边栏**：固定宽度（展开240px/收起64px），承载**两级菜单**导航结构；一级菜单（模块级）强制配备图标，点击一级菜单展开其下的二级菜单（功能点级）；侧边栏顶部集成**菜单搜索框**，支持按功能点名称/拼音首字母模糊搜索并快速定位到目标菜单项，搜索结果实时过滤二级菜单列表，点击搜索结果直接跳转并激活对应功能点标签页
- **右侧内容区**：占据全部剩余宽度，由上至下依次为标签页栏→头部扩展工具栏→内容区主体
- **标签页栏**：支持多标签页并存切换，标签页栏右侧集成头部扩展工具栏（窗口最大化、主题切换、语言设置、用户中心等）
- **内容区主体**：根据当前激活标签页对应的页面类型（P01~P15），渲染各页面类型的专属布局
- **全局无浏览器滚动条**：所有业务区块内容溢出时严格使用局部滚动条，不产生全局页面级滚动

## P01 首页/仪表盘布局

右侧内容区整体划分为**可自由拖拽排列的网格布局**，支持用户自定义布局与组件位置调整；区块间保留16px间距、12px圆角，区块白底适配全局背景。

### 内容区结构

- **顶部欢迎栏**：展示当前用户问候语、日期、快捷搜索入口
- **KPI指标卡片区**：横排展示核心经营指标卡片（如今日订单、本月销售额、库存预警数等），每个卡片支持点击下钻至对应工作台
- **快捷入口区**：常用功能快捷图标矩阵，支持用户自定义配置
- **图表看板区**：可配置的图表组件网格，支持折线图、柱状图、饼图、数字看板等，图表数据支持时间维度切换
- **待办/消息区**：审批待办、业务预警、未读消息的快捷汇总列表
- **最近访问区**：最近操作的菜单与单据快捷回访列表

### 布局规则

- 所有区块组件支持拖拽调整位置与尺寸
- 支持管理员配置默认首页布局模板，普通用户可自定义覆盖
- 内容溢出时右侧内容区整体内部产生局部滚动

## P02 工作台布局

每个模块均配备独立工作台，布局与首页类似但聚焦当前模块，右侧内容区采用**网格+列表混合布局**；区块间保留16px间距、12px圆角，区块白底适配全局背景。

### 内容区结构

- **模块KPI指标卡片区**：展示当前模块核心指标（如销售管理：今日订单数、本月销售额、待发货数、逾期应收等）
- **快捷操作区**：模块内高频操作按钮（如销售管理：新建报价单、新建销售订单、新建发货通知单等）
- **模块图表区**：模块维度统计图表（趋势图、排名图等）
- **待处理业务列表**：当前模块待审批/待处理/预警单据列表，支持点击直接跳转
- **最近操作区**：当前模块最近操作记录

### 布局规则

- 各模块工作台KPI指标与快捷操作可通过后台配置调整
- 内容溢出时右侧内容区内部产生局部滚动

## P03 主从列表类业务页面（含关联信息区）

右侧内容区自上而下划分三大功能区域，区域间保留16px间距、12px圆角，区块白底适配全局背景；首块查询区域高度自适应按需占位，剩余可视高度由第二、第三区域按比例自动分配。

### 常用查询区

页面顶部，整体分为上下双结构，支持后台配置多字段模糊查询项与常用字段查询项；两类查询结果为**且的关系**，同时与表格自身列筛选搜索条件也为**且的关联关系**。

- **上部分**：多字段模糊查询，支持配置名称、编码、型号等多个字符串类字段，输入单个关键词后，以**或关系**匹配所选全部字段，实现一键多字段模糊检索
- **下部分**：常用字段查询，预设名称、编码、规格等常用业务字段，每个字段独立输入关键词检索，字段之间以**且关系**组合筛选条件

### 主数据列表区

中部占剩余高度比例空间，内部采用**上下结构**布局，上部为列表功能操作区，下部为数据表格展示核心业务数据；内置分页、字段排序、行级操作能力；内容溢出时**复用表格自身滚动条**，固定表头不随内容滚动偏移。

- **上部功能操作区**：采用左右分排按钮布局，所有按钮统一配备图标+文字样式
  - 左侧按钮：新增、导出、下推（需先选中行，未选中时置灰）、更多（沟通、分享）
  - 右侧按钮：格式设置、表格刷新数据、行高调整、铺满，后三项仅展示图标无文字
- **下部数据表格**：集成列表数据表格统一标配功能规范（详见第六章6.2节）

### 关联信息区

底部按比例分配剩余高度，默认采用**左右分排布局**；左侧为分组导航栏、右侧为标签页容器，选中左侧分组自动切换右侧对应标签页内容；**标签页栏右侧增设头部扩展工具栏**，承载区域铺满等快捷功能操作；区域内容溢出时在容器内部生成局部滚动条。

- **标签页配置规则**：支持标签页显隐权限配置，管理员可配置全局最大可见范围，普通用户可在管理员限定范围内自定义个人标签页显隐
- **数据刷新机制**：单击主数据列表行时，仅刷新关联信息区当前激活标签页的数据；切换关联区标签页时，自动刷新新选中标签页的数据
- **头部扩展工具栏快捷按钮**：新增、放大查看表格；新增按钮可根据当前选中标签页业务类型，跳转至对应业务新增页面，放大查看表格仅展示图标样式

### 区域铺满切换能力

第二、第三区域均配备快捷铺满按钮，支持一键单独铺满第二区域并隐藏第三区域，或铺满第三区域并隐藏第二区域；铺满按钮统一集成在各自对应区域头部扩展工具栏中。

## P04 单一列表类业务页面（仅两区域）

适配无需关联子数据、只做单列表查询展示的业务场景，**去掉第三关联信息区**，右侧内容区仅保留两大功能区域，区域间保留16px间距、12px圆角，区块白底适配全局背景；常用查询区高度自适应按需占位，剩余全部可视高度归主数据列表区独占。

### 常用查询区

同P03常用查询区规范。

### 主数据列表区

独占查询区以外全部剩余可视高度，内部采用**上下结构**布局，上部为列表功能操作区，下部为数据表格展示核心业务数据；内置分页、字段排序、行级操作能力；内容溢出时**复用表格自身滚动条**，固定表头不随内容滚动偏移。

- **上部功能操作区**：采用左右分排按钮布局，所有按钮统一配备图标+文字样式
  - 左侧按钮：新增、导出、下推（需先选中行，未选中时置灰）、更多（沟通、分享）
  - 右侧按钮：格式设置、表格刷新数据、行高调整、铺满，后三项仅展示图标无文字
- **下部数据表格**：集成列表数据表格统一标配功能规范（详见第六章6.2节）

## P05 树形列表类业务页面

适配具有层级树形结构的数据管理场景（如分类、科目树），右侧内容区采用**左侧树+右侧列表**双栏布局；区域间保留16px间距、12px圆角，区块白底适配全局背景。

### 树形导航区（左侧）

- 占据左侧固定宽度（默认280px，支持拖拽调整宽度），展示树形层级结构
- 支持树节点的展开/收起、搜索过滤、新增/编辑/删除节点
- 单击树节点时，右侧列表自动过滤显示当前节点及其子节点下的数据
- 树节点支持右键菜单操作（新增子级、编辑、删除、刷新）
- 树区域底部显示当前选中节点路径

### 数据列表区（右侧）

- 占据剩余宽度空间，采用上下结构：上部为查询+操作区，下部为数据表格
- 查询区与操作按钮区规范同P03常用查询区与主数据列表区
- 数据表格自动按当前选中树节点过滤数据
- 支持在列表中直接维护树形分类字段

### 树形区与列表区联动

- 选中树节点 → 列表自动筛选该节点下数据
- 列表中新增数据 → 自动归属当前选中树节点分类
- 树节点删除 → 校验该节点下是否存在关联数据，存在则阻止删除
