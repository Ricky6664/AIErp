## 0.8 系统参数配置规范

### 0.8.1 参数读取优先级规则
```
模块级总开关(如inv.batch_manage) → 商品控制策略(商品级开关) → 单据级参数
```

**完整优先级链（从高到低）**：

```
1. 单据级参数（单据表字段值，如 sale_order.stock_deduct_mode）
   ↓ 为空时
2. 商品控制策略（商品表字段值，如 sku.stock_manage_mode）
   ↓ 为空时
3. 模块级参数（sys_config表，如 inv.batch_manage）
   ↓ 为空时
4. 全局默认参数（sys_config表，category=system，如 system.decimal_places_price）
   ↓ 为空时
5. 代码硬编码默认值（SysParamService方法参数中的defaultValue）
```

**使用示例**：

```java
// 读取库存扣减时机参数（完整优先级链）
String deductMode = sysParamService.getStringParam(
    "sale.stock_deduct_mode",      // 模块级参数
    "on_stock_out"                  // 硬编码兜底默认值
);

// 读取商品级覆盖策略
String skuDeductMode = sku.getStockDeductMode();
if (StringUtils.isNotBlank(skuDeductMode)) {
    deductMode = skuDeductMode;     // 商品级优先
}

// 读取单据级覆盖策略
if (StringUtils.isNotBlank(order.getStockDeductMode())) {
    deductMode = order.getStockDeductMode(); // 单据级最高优先
}
```

### 0.8.2 数值精度参数优先级规则
```
模块级参数(sale.decimal_places_price) → 全局默认参数(system.decimal_places_price)
```
- 若模块级参数未配置（为空），则使用全局默认参数
- 所有精度参数值上限为8，超过8时自动截断为8
- 数据库物理字段统一使用decimal(18,8)

## 9.11 sys_config表结构

| 字段名 | 数据类型 | 非空 | 说明 |
|--------|---------|:----:|------|
| id | BIGINT | 是 | 雪花ID主键 |
| config_category | VARCHAR(32) | 是 | 参数分类（inventory/crm/sale/finance/purchase/produce/approval/system） |
| config_key | VARCHAR(128) | 是 | 参数键（如inv.batch_manage） |
| config_value | VARCHAR(512) | 否 | 参数值 |
| config_name | VARCHAR(128) | 是 | 参数名称 |
| config_type | SMALLINT | 是 | 参数类型：0=系统预置 1=用户自定义 |
| value_type | VARCHAR(16) | 是 | 值类型：boolean/string/number/enum |
| enum_options | VARCHAR(512) | 否 | 枚举可选项（JSON数组，value_type=enum时使用） |
| remark | VARCHAR(512) | 否 | 参数说明 |
| tenant_id | BIGINT | 是 | 租户ID |
| creator_id / create_time / updater_id / update_time / is_deleted | — | — | 公共字段 |

**索引**：UK_tenant_key (tenant_id, config_key, is_deleted) 唯一索引

## 9.13 参数缓存策略

| 规范项 | 要求 |
|--------|------|
| 缓存Key | `erp:sys:config:{tenantId}`（Hash类型，field=config_key，value=config_value） |
| TTL | 12小时 |
| 更新策略 | 修改参数→更新DB→事务提交后删除缓存Key→下次读取时重新加载 |
| 预热 | 应用启动时通过ApplicationRunner加载全部系统预置参数 |
| 读取优先级 | 租户级参数 → 全局参数(tenant_id=0) → 代码硬编码默认值 |

### 缓存变更通知机制

```
参数修改后缓存刷新流程：

1. 管理员修改参数 → API请求到达后端
2. 更新数据库 sys_config 表（事务内）
3. 事务提交后（@TransactionalEventListener phase=AFTER_COMMIT）：
   a. 删除 Redis Hash 缓存 Key: erp:sys:config:{tenantId}
   b. 发布 Redis Pub/Sub 消息: channel=erp:sys:config:change
      payload={"tenantId":1001, "configKey":"sale.decimal_places_price"}
4. 所有后端实例监听该频道，收到消息后：
   a. 清除本地 JVM 缓存（Caffeine）中该租户的全部参数缓存
   b. 下次读取时从 Redis 重新加载
5. 管理员点击"手动刷新缓存"按钮时，强制清除该租户全部参数缓存
```

**Redis缓存数据结构**：

```
Key: erp:sys:config:1001  (Hash类型)
Field                     Value
─────────────────────────────────────────
inv.batch_manage          "true"
inv.negative_stock        "false"
sale.decimal_places_price "4"
sale.decimal_places_qty   "6"
finance.auto_voucher      "false"
...（该租户所有参数）
```

**读取流程**：

```java
// SysParamService 参数读取流程
public String getStringParam(String key, String defaultValue) {
    Long tenantId = SecurityUtils.getCurrentTenantId();

    // 1. 查本地JVM缓存（Caffeine，过期5分钟）
    String value = localCache.get(tenantId + ":" + key);
    if (value != null) return value;

    // 2. 查Redis Hash缓存
    String redisKey = "erp:sys:config:" + tenantId;
    value = (String) redisTemplate.opsForHash().get(redisKey, key);
    if (value != null) {
        localCache.put(tenantId + ":" + key, value);
        return value;
    }

    // 3. 缓存未命中，从数据库加载该租户全部参数到Redis
    loadTenantConfigToRedis(tenantId);
    value = (String) redisTemplate.opsForHash().get(redisKey, key);

    // 4. 租户级未配置，尝试全局参数（tenant_id=0）
    if (value == null) {
        String globalKey = "erp:sys:config:0";
        if (!Boolean.TRUE.equals(redisTemplate.hasKey(globalKey))) {
            loadTenantConfigToRedis(0L);
        }
        value = (String) redisTemplate.opsForHash().get(globalKey, key);
    }

    if (value != null) {
        localCache.put(tenantId + ":" + key, value);
        return value;
    }

    // 5. 全部未命中，返回硬编码默认值
    return defaultValue;
}
```

## 9.14 参数使用规范

```java
// 通过SysParamService统一读取，禁止直接查表
@Service
public class SysParamService {
    // 获取布尔参数
    public boolean getBooleanParam(String key, boolean defaultValue);
    // 获取数值参数
    public int getIntParam(String key, int defaultValue);
    // 获取字符串参数
    public String getStringParam(String key, String defaultValue);
    // 获取精度参数（小数位数）
    public int getDecimalPlaces(String module, String field, int defaultPlaces);
}

// 使用示例
boolean batchManage = sysParamService.getBooleanParam("inv.batch_manage", true);
int pricePlaces = sysParamService.getDecimalPlaces("sale", "price", 4);
```
