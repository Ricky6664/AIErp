# 全局规范-报表生成与导出规范

> 本文档定义报表架构、数据组装流程、Excel/PDF导出标准、定时调度、权限控制及性能优化规范，所有涉及报表查询、数据导出、打印输出的开发任务必须严格遵守。

---

## 1. 报表架构总览

### 1.1 分层架构

```
前端展示层
├── ReportViewer          # 报表展示组件（表格/图表）
├── ReportFilter          # 筛选条件组件
├── ExportButton          # 导出按钮（Excel/PDF）
└── ReportScheduler       # 定时报表配置界面
        │
        ▼
API接口层
├── ReportController      # REST API
├── ExportController      # 导出API
└── ScheduleController    # 调度配置API
        │
        ▼
报表服务层
├── ReportDataService     # 报表数据服务（核心入口）
├── ReportQueryBuilder     # 查询构建器（流式API）
├── ReportCacheManager    # 报表缓存管理
├── ReportExportService   # 导出服务
└── ReportScheduleService # 调度服务
        │
        ▼
数据访问层
├── MyBatis-Plus Mapper   # 标准查询
├── 动态SQL               # 复杂报表查询

```

### 1.2 核心类职责

| 类 | 职责 | 说明 |
|----|------|------|
| ReportDataService | 报表数据服务入口 | 协调查询、缓存、权限 |

| ReportExportService | 导出服务 | Excel/PDF生成与文件管理 |
| ReportScheduleService | 调度管理 | 与XXL-JOB集成，定时生成与分发 |

## 2. 报表类型定义

### 2.1 类型总览

| 报表类型 | 类型编码 | 说明 | 输出形式 |
|---------|---------|------|---------|
| 标准列表报表 | LIST | 筛选+排序+分页的明细数据 | 表格 → Excel |
| 汇总统计报表 | SUMMARY | 分组聚合的统计数据 | 表格+汇总行 → Excel/PDF |
| 交叉透视报表 | PIVOT | 动态列的交叉分析 | 表格（动态列）→ Excel |
| 图表数据报表 | CHART | 提供给前端图表的数据集 | JSON（series数据） |
| 打印文档报表 | DOCUMENT | 格式化的打印文档 | PDF |

### 2.2 各类型详细规范

#### 标准列表报表（LIST）

| 规范项 | 要求 |
|--------|------|
| 分页 | 默认每页20条，最大200条 |
| 排序 | 支持多字段排序，默认按创建时间倒序 |
| 筛选 | 支持精确匹配、模糊匹配、范围查询 |
| 导出 | 支持全量导出（不受分页限制） |

#### 汇总统计报表（SUMMARY）

| 规范项 | 要求 |
|--------|------|
| 分组 | 支持多维度分组（最多3层） |
| 聚合 | SUM、COUNT、AVG、MAX、MIN |
| 汇总行 | 底部显示合计行 |
| 小计 | 每个分组层级显示小计 |

#### 交叉透视报表（PIVOT）

| 规范项 | 要求 |
|--------|------|
| 行维度 | 固定列，最多3个字段 |
| 列维度 | 动态列，1个字段（值自动展开为列头） |
| 值 | 交叉单元格的聚合值 |
| 列数限制 | 动态列最多50列，超出提示"维度过多" |

#### 图表数据报表（CHART）

| 规范项 | 要求 |
|--------|------|
| 数据格式 | ECharts series格式 |
| 数据量 | 单系列最多1000个数据点 |
| 类型 | 折线图、柱状图、饼图、散点图 |
| 刷新 | 支持手动刷新，缓存5分钟 |

#### 打印文档报表（DOCUMENT）

| 规范项 | 要求 |
|--------|------|
| 纸张 | A4纵向/横向 |
| 格式 | PDF输出 |
| 水印 | 机密/内部文件水印 |
| 页码 | 底部居中显示"第X页/共Y页" |

## 3. 后端报表数据组装

### 3.1 ReportQueryBuilder流式API

```java
public class ReportQueryBuilder {

    private String tableName;
    private List<String> selectFields = new ArrayList<>();
    private List<String> groupByFields = new ArrayList<>();
    private List<String> orderByFields = new ArrayList<>();
    private List<Condition> conditions = new ArrayList<>();
    private String havingClause;
    private Integer limit;
    private Integer offset;

    // 基础查询
    public ReportQueryBuilder from(String tableName) {
        this.tableName = tableName;
        return this;
    }

    public ReportQueryBuilder select(String... fields) {
        this.selectFields.addAll(Arrays.asList(fields));
        return this;
    }

    // 筛选条件
    public ReportQueryBuilder where(String field, String operator, Object value) {
        this.conditions.add(new Condition(field, operator, value));
        return this;
    }

    public ReportQueryBuilder whereBetween(String field, Object start, Object end) {
        this.conditions.add(new Condition(field, "BETWEEN", List.of(start, end)));
        return this;
    }

    public ReportQueryBuilder whereIn(String field, Collection<?> values) {
        this.conditions.add(new Condition(field, "IN", values));
        return this;
    }

    // 分组聚合
    public ReportQueryBuilder groupBy(String... fields) {
        this.groupByFields.addAll(Arrays.asList(fields));
        return this;
    }

    public ReportQueryBuilder having(String clause) {
        this.havingClause = clause;
        return this;
    }

    // 排序分页
    public ReportQueryBuilder orderBy(String field, String direction) {
        this.orderByFields.add(field + " " + direction);
        return this;
    }

    public ReportQueryBuilder limit(int limit, int offset) {
        this.limit = limit;
        this.offset = offset;
        return this;
    }

    // 构建SQL（内部使用）
    public String buildSql() {
        // 使用MyBatis-Plus的Wrapper或自定义SQL拼接
        // 返回参数化SQL，禁止字符串拼接
    }

    // 构建参数
    public Map<String, Object> buildParams() {
        // 返回参数Map，与SQL占位符对应
    }
}
```

### 3.2 查询复杂度限制

| 限制项 | 最大值 | 说明 |
|--------|--------|------|
| JOIN数量 | 5 | 超过5个JOIN必须拆分或优化 |
| 子查询数量 | 3 | 嵌套子查询不超过3层 |
| WHERE条件数 | 20 | 单个查询筛选条件不超过20个 |
| GROUP BY字段数 | 5 | 分组字段不超过5个 |
| ORDER BY字段数 | 3 | 排序字段不超过3个 |
| 查询超时 | 30秒 | 超过30秒强制终止 |

### 3.3 大数据量报表处理

| 数据量 | 处理方式 | 说明 |
|--------|---------|------|
| ≤ 1,000行 | 同步查询，直接返回 | 前端实时展示 |
| 1,001 ~ 10,000行 | 同步查询+分页 | 前端分页或虚拟滚动 |
| 10,001 ~ 100,000行 | 异步生成+缓存 | 生成结果缓存到Redis，前端轮询 |
| > 100,000行 | 异步生成+下载通知 | 后台生成文件→MinIO存储→站内信通知下载 |

**异步生成流程**：

```
用户点击导出
    │
    ▼
ReportExportService.createAsyncTask()
    │
    ├── 1. 生成任务ID
    ├── 2. 记录任务到 sys_report_execution（status=PENDING）
    ├── 3. 发送RabbitMQ消息到队列 erp.report.export
    └── 4. 返回任务ID给前端
            │
            ▼
前端轮询 GET /api/report/export/status/{taskId}
    │
    ▼
ReportExportConsumer（异步消费）
    │
    ├── 1. 查询数据（分批查询，每批5000行）
    ├── 2. 生成Excel/PDF文件
    ├── 3. 上传文件到MinIO
    ├── 4. 更新 sys_report_execution（status=COMPLETED, result_file_url=...）
    └── 5. 发送站内信通知用户
```

## 4. 缓存策略

### 4.1 缓存Key设计

```
erp:report:{reportCode}:{tenantId}:{paramHash}
```

- `paramHash`：筛选参数的SHA-256摘要前16位

**示例**：
```
erp:report:sale_monthly:1001:a3f8b2c1d4e5f6a7
```

### 4.2 TTL策略

| 报表类型 | 默认TTL | 说明 |
|---------|---------|------|
| 实时报表 | 1分钟 | 需要近实时数据的报表 |
| 日报 | 5分钟 | 日维度的汇总报表 |
| 月报 | 30分钟 | 月维度的汇总报表 |
| 年报 | 2小时 | 年维度的汇总报表 |
| 静态报表 | 24小时 | 数据不常变化的配置类报表 |

### 4.3 缓存失效规则

| 触发条件 | 处理方式 |
|---------|---------|
| TTL过期 | 自动失效，下次查询重新生成 |
| 数据变更通知 | 相关报表缓存主动清除（通过RabbitMQ消息） |
| 手动刷新 | 前端"刷新"按钮触发缓存清除 |
| 报表配置变更 | 该报表所有缓存清除 |

### 4.4 缓存实现

```java
@Service
public class ReportCacheManager {

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    /**
     * 获取缓存的报表数据
     */
    @SuppressWarnings("unchecked")
    public ReportResult getCached(String reportCode, Long tenantId, Map<String, Object> params) {
        String key = buildCacheKey(reportCode, tenantId, params);
        return (ReportResult) redisTemplate.opsForValue().get(key);
    }

    /**
     * 缓存报表数据
     */
    public void cache(String reportCode, Long tenantId, Map<String, Object> params,
                      ReportResult result, Duration ttl) {
        String key = buildCacheKey(reportCode, tenantId, params);
        result.setDataTimestamp(System.currentTimeMillis());
        redisTemplate.opsForValue().set(key, result, ttl);
    }

    /**
     * 清除报表缓存
     */
    public void evict(String reportCode, Long tenantId) {
        String pattern = "erp:report:" + reportCode + ":" + tenantId + ":*";
        Set<String> keys = redisTemplate.keys(pattern);
        if (keys != null && !keys.isEmpty()) {
            redisTemplate.delete(keys);
        }
    }

    private String buildCacheKey(String reportCode, Long tenantId, Map<String, Object> params) {
        String paramStr = JSON.toJSONString(new TreeMap<>(params));
        String paramHash = DigestUtils.sha256Hex(paramStr).substring(0, 16);
        return "erp:report:" + reportCode + ":" + tenantId + ":" + paramHash;
    }
}
```

```java
@Service
public class PivotReportExportService {

    /**
     * 导出交叉透视报表（动态列）
     */
    public void exportPivotReport(HttpServletResponse response,
            List<String> dynamicHeaders,
            List<List<Object>> data) throws IOException {

        response.setContentType("application/vnd.openxmlformats-officedocument.spreadsheetml.sheet");
        response.setHeader("Content-Disposition", "attachment;filename=pivot_report.xlsx");

        // 构建动态表头
        List<List<String>> head = new ArrayList<>();

        // 固定列
        head.add(List.of("行维度"));

        // 动态列
        for (String header : dynamicHeaders) {
            head.add(List.of(header));
        }

        try (ExcelWriter writer = EasyExcel.write(response.getOutputStream())
                .head(head)
                .registerWriteHandler(new DefaultStyleHandler())
                .build()) {

            WriteSheet sheet = EasyExcel.writerSheet("透视分析").build();
            writer.write(data, sheet);
        }
    }
}
```

```java
/**
 * 在最后一行添加合计公式
 */
public void addSummaryRow(WriteSheetHolder writeSheetHolder, int totalRows, int startCol, int endCol) {
    Sheet sheet = writeSheetHolder.getSheet();
    Row summaryRow = sheet.createRow(totalRows + 1);

    // 合计标签
    Cell labelCell = summaryRow.createCell(0);
    labelCell.setCellValue("合计");

    // 求和公式
    for (int col = startCol; col <= endCol; col++) {
        Cell cell = summaryRow.createCell(col);
        String colLetter = CellReference.convertNumToColString(col);
        String formula = String.format("SUM(%s2:%s%d)", colLetter, colLetter, totalRows + 1);
        cell.setCellFormula(formula);
    }
}
```

```java
@Service
public class PdfReportGenerator {

    /**
     * 生成PDF报表

    public byte[] generatePdfReport(ReportResult reportResult, ReportPdfConfig config) {
        ByteArrayOutputStream outputStream = new ByteArrayOutputStream();

        PdfWriter writer = new PdfWriter(outputStream);
        PdfDocument pdfDoc = new PdfDocument(writer);

        // 页面设置
        PageSize pageSize = config.isLandscape()
            ? PageSize.A4.rotate()
            : PageSize.A4;
        Document document = new Document(pdfDoc, pageSize);
        document.setMargins(20, 15, 20, 15);

        // 注册中文字体
        PdfFont simsunFont = PdfFontFactory.createFont("STSong-Light", "UniGB-UCS2-H");
        PdfFont simheiFont = PdfFontFactory.createFont("STHeiti-Light", "UniGB-UCS2-H");

        // 1. 页眉
        addHeader(document, config, simheiFont);

        // 2. 标题
        Paragraph title = new Paragraph(config.getTitle())
            .setFont(simheiFont)
            .setFontSize(14)
            .setTextAlignment(TextAlignment.CENTER)
            .setMarginBottom(10);
        document.add(title);

        // 3. 日期范围
        Paragraph dateRange = new Paragraph(config.getDateRangeText())
            .setFont(simsunFont)
            .setFontSize(10)
            .setTextAlignment(TextAlignment.CENTER)
            .setMarginBottom(15);
        document.add(dateRange);

        // 4. 数据表格
        Table table = createDataTable(reportResult, simsunFont, simheiFont, config);
        document.add(table);

        // 5. 页脚
        addFooter(document, config, simsunFont);

        // 6. 水印
        if (config.isWatermark()) {
            addWatermark(pdfDoc, config.getWatermarkText(), simheiFont);
        }

        document.close();
        return outputStream.toByteArray();
    }

    private Table createDataTable(ReportResult reportResult, PdfFont bodyFont,
            PdfFont headerFont, ReportPdfConfig config) {

        int colCount = reportResult.getColumns().size();
        float[] columnWidths = config.getColumnWidthRatios();
        Table table = new Table(UnitValue.createPercentArray(columnWidths));
        table.setWidth(UnitValue.createPercentValue(100));

        // 表头
        for (ReportResult.ReportColumn col : reportResult.getColumns()) {
            Cell headerCell = new Cell()
                .add(new Paragraph(col.getTitle()).setFont(headerFont).setFontSize(10))
                .setBackgroundColor(ColorConstants.LIGHT_GRAY)
                .setTextAlignment(TextAlignment.CENTER)
                .setPadding(5);
            table.addHeaderCell(headerCell);
        }

        // 数据行
        for (Map<String, Object> row : reportResult.getRows()) {
            for (ReportResult.ReportColumn col : reportResult.getColumns()) {
                Object value = row.get(col.getField());
                String displayValue = formatValue(value, col.getFormat());

                TextAlignment alignment = "right".equals(col.getAlignment())
                    ? TextAlignment.RIGHT
                    : TextAlignment.LEFT;

                Cell cell = new Cell()
                    .add(new Paragraph(displayValue).setFont(bodyFont).setFontSize(9))
                    .setTextAlignment(alignment)
                    .setPadding(4);
                table.addCell(cell);
            }
        }

        return table;
    }

    /**
     * 添加水印
     */
    private void addWatermark(PdfDocument pdfDoc, String text, PdfFont font) {
        PdfCanvas canvas;
        for (int i = 1; i <= pdfDoc.getNumberOfPages(); i++) {
            canvas = new PdfCanvas(pdfDoc.getPage(i));
            canvas.saveState();
            canvas.setFillColor(new DeviceRgb(200, 200, 200));
            canvas.setFontAndSize(font, 40);

            for (float x = 0; x < 600; x += 200) {
                for (float y = 0; y < 800; y += 200) {
                    canvas.beginText();
                    canvas.setTextMatrix(
                        com.itextpdf.kernel.geom.AffineTransform.getRotateInstance(
                            Math.PI / 4, x, y));
                    canvas.showText(text);
                    canvas.endText();
                }
            }
            canvas.restoreState();
        }
    }
}
```

## 7. 报表定时调度

### 7.1 与XXL-JOB集成

```java
@Component
public class ReportScheduleJobHandler {

    @Autowired
    private ReportScheduleService scheduleService;

    @Autowired
    private ReportExportService exportService;

    @Autowired
    private NotificationService notificationService;

    /**
     * 定时报表生成任务
     */
    @XxlJob("reportScheduleGenerate")
    public void execute() {
        String param = XxlJobHelper.getJobParam();
        Long scheduleId = Long.parseLong(param);

        ReportSchedule schedule = scheduleService.getById(scheduleId);
        if (schedule == null || !schedule.getIsEnabled()) {
            XxlJobHelper.log("调度任务不存在或已禁用，scheduleId={}", scheduleId);
            return;
        }

        try {
            // 1. 构建查询参数（根据调度周期计算日期范围）
            Map<String, Object> params = buildScheduleParams(schedule);

            // 2. 异步生成报表
            ReportExecution execution = exportService.createAsyncExport(
                schedule.getReportCode(), params, schedule.getExportFormat());

            // 3. 等待生成完成（轮询，最长等待10分钟）
            ReportExecution completed = waitForCompletion(execution.getId(), Duration.ofMinutes(10));

            // 4. 分发报表
            distributeReport(schedule, completed);

            XxlJobHelper.handleSuccess("报表生成成功: " + completed.getResultFileUrl());
        } catch (Exception e) {
            XxlJobHelper.handleFail("报表生成失败: " + e.getMessage());
        }
    }

    /**
     * 分发报表到指定渠道
     */
    private void distributeReport(ReportSchedule schedule, ReportExecution execution) {
        String[] channels = schedule.getDistributeChannels().split(",");

        for (String channel : channels) {
            switch (channel.trim()) {
                case "email" -> sendEmailReport(schedule, execution);
                case "notification" -> sendNotificationReport(schedule, execution);
                case "download" -> { /* 文件已生成到MinIO，用户自行下载 */ }
                default -> log.warn("未知的分发渠道: {}", channel);
            }
        }
    }
}
```

```vue
<script setup lang="ts">

  try {
```

```vue
    })

    if (result.async) {
      // 异步导出：轮询状态

const pollExportStatus = (taskId: string) => {
  const interval = setInterval(async () => {
    const status = await getExportStatus(taskId)

      clearInterval(interval)
      ElMessage.success('报表生成完成')
      downloadFile(status.fileUrl, `report.${status.format}`)
    } else if (status.status === 'FAILED') {
      clearInterval(interval)
      ElMessage.error('报表生成失败: ' + status.errorMsg)
    }
  }, 3000)

  // 最长轮询10分钟
  setTimeout(() => clearInterval(interval), 600000)
}
```

### 10.2 数据权限过滤

```java
@Service
public class ReportDataPermissionFilter {

    /**
     * 根据当前用户的数据权限过滤报表查询
     */
    public void applyDataPermission(ReportQueryBuilder builder, String reportCode) {
        Long userId = StpUtil.getLoginIdAsLong();
        DataScope dataScope = dataPermissionService.getUserDataScope(userId, reportCode);

        switch (dataScope.getType()) {
            case ALL -> {
                // 全部数据，不添加过滤条件
            }
            case DEPT -> {
                // 本部门数据
                builder.where("dept_id", "=", dataScope.getDeptId());
            }
            case DEPT_AND_CHILDREN -> {
                // 本部门及下级部门数据
                builder.where("dept_id", "IN", dataScope.getDeptIds());
            }
            case SELF -> {
                // 仅本人数据
                builder.where("creator_id", "=", userId);
            }
            case CUSTOM -> {
                // 自定义SQL条件
                builder.appendRawCondition(dataScope.getCustomSql());
            }
        }

        // 租户隔离（必须）
        builder.where("tenant_id", "=", StpUtil.getSession().get("tenantId"));
    }
}
```

### 11.3 大报表分批查询

```java
@Service
public class LargeReportExportService {

    private static final int BATCH_SIZE = 5000;

    /**
     * 分批查询并写入Excel（适用于>10万行的大报表）
     */
    public void exportLargeReport(String reportCode, Map<String, Object> params,
            OutputStream outputStream) {

        ReportResult reportResult = reportDataService.queryMetaData(reportCode, params);

        try (ExcelWriter writer = EasyExcel.write(outputStream)
                .head(buildHead(reportResult.getColumns()))
                .build()) {

            WriteSheet sheet = EasyExcel.writerSheet(reportResult.getReportName()).build();

            long totalCount = reportResult.getTotalCount();
            int totalPages = (int) Math.ceil((double) totalCount / BATCH_SIZE);

            for (int page = 0; page < totalPages; page++) {
                // 分批查询
                List<Map<String, Object>> batchData = reportDataService.queryData(
                    reportCode, params, page * BATCH_SIZE, BATCH_SIZE);

                // 转换为DTO
                List<List<Object>> rows = convertToRows(batchData, reportResult.getColumns());

                // 写入当前批次
                writer.write(rows, sheet);

                // 释放内存
                batchData.clear();
            }
        }
    }
}
```

### 11.4 物化视图（高频报表预计算）

```sql
-- 销售月度汇总物化视图
CREATE MATERIALIZED VIEW mv_sale_monthly_summary AS
SELECT
    DATE_TRUNC('month', o.order_date) AS report_month,
    o.dept_id,
    c.industry,
    COUNT(DISTINCT o.id) AS order_count,
    SUM(od.quantity) AS total_quantity,
    SUM(od.amount) AS total_amount,
    AVG(od.amount) AS avg_order_amount
FROM sale_order o
JOIN sale_order_detail od ON o.id = od.order_id
LEFT JOIN bas_customer c ON o.customer_id = c.id
WHERE o.audit_status = 3
  AND o.deleted = 0
GROUP BY DATE_TRUNC('month', o.order_date), o.dept_id, c.industry;

-- 创建索引
CREATE INDEX idx_mv_sale_monthly_month ON mv_sale_monthly_summary(report_month);
CREATE INDEX idx_mv_sale_monthly_dept ON mv_sale_monthly_summary(dept_id);

-- 定时刷新（每天凌晨2:00通过XXL-JOB执行）
REFRESH MATERIALIZED VIEW CONCURRENTLY mv_sale_monthly_summary;
```
