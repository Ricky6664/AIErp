# P2-011 报表中心模块开发 - 模块开发指南

## 一、模块概述
- **模块定位**：完成分业务报表（采购/销售/库存/财务/生产）、自定义报表及报表设计器，提供统一的报表管理与数据可视化能力
- **前置依赖**：P0-005（P10报表页组件）、各业务模块
- **被依赖方**：无
- **开发阶段**：阶段十

## 四、模块级专属约束

本模块无模块级专属约束，遵循全局规范。财务报表（资产负债表/利润表/现金流量表）取数逻辑已由P1-014完整实现，本科目余额表/辅助核算报表已由P1-013覆盖，本模块仅提供报表中心视角的统一聚合查看入口，不重复实现取数逻辑。数据大屏基于report_screen_config配置表，支持1920x1080/2K/4K自适应缩放与定时刷新。

### 5.1 rpt_catalog（报表目录表）— 主表

**通用必含字段（通过继承BaseEntity获取）**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 |
|--------|---------|------|--------|---------|

| tenant_id | bigint | NOT NULL | - | 租户ID |

| updated_at | timestamp | NOT NULL | CURRENT_TIMESTAMP | 更新时间 |
| created_by | bigint | NOT NULL | 当前登录用户ID | 创建人ID |
| updated_by | bigint | NOT NULL | 当前登录用户ID | 修改人ID |
| is_deleted | boolean | NOT NULL | false | 是否删除 |
| owner_dept_id | bigint | - | 创建人所属部门ID | 所属部门ID |
| owner_id | bigint | - | created_by值 | 数据负责人ID |
| version | int | NOT NULL | 1 | 版本号(乐观锁) |

**业务字段**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 | 说明 |
|--------|---------|------|--------|---------|------|
| catalog_name | varchar(50) | NOT NULL | - | 目录名称 | 必填，同一上级下不重复 |
| parent_id | bigint | - | 0 | 上级目录ID | 0或null表示顶级目录，树形结构 |
| catalog_level | int | NOT NULL | 1 | 级次 | 树形层级，1为一级 |

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |

| 循环引用检查 | 新增/修改 | parent_id不能指向自身或子孙目录 | "不能将目录设为自身或其下属目录的子目录" |
| 删除前关联检查 | 删除 | 检查子目录+报表是否引用 | "该目录下存在子目录或报表，无法删除" |
