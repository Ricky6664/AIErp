### 5.1 按钮配置

```vue
<el-button type="primary" v-permission="'report:add'" @click="handleAdd">新增</el-button>
<el-button type="danger" :disabled="!selectedRows.length" v-permission="'report:delete'" @click="handleBatchDelete">批量删除</el-button>
```

### 5.2 权限控制

- v-permission指令根据当前用户权限控制按钮显示
- 批量操作按钮在selectedRows.length===0时disabled

### 5.3 删除二次确认

```ts
ElMessageBox.confirm('确定删除选中记录？', '提示', { type: 'warning' })
  .then(() => deleteApi(selectedIds.value))
  .then(() => { ElMessage.success('删除成功'); refresh() })
```

### 5.4 验证

1. 权限指令v-permission正确
2. 批量操作disabled逻辑正确
3. 删除二次确认弹窗正常

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 权限控制必须使用v-permission指令，禁止手动判断角色

> ⚠️ 删除/批量操作必须二次确认（ElMessageBox.confirm）

> ⚠️ 表格操作列fixed="right"防止横向滚动被遮挡

> ⚠️ 表单离开未保存提示——beforeRouteLeave守卫拦截

> ⚠️ 接口请求必须携带loading状态，防止重复提交

> ⚠️ [报表中心模块] SQL查询必须经过白名单校验，禁止INSERT/UPDATE/DELETE/DROP/ALTER/TRUNCATE等写操作

> ⚠️ [报表中心模块] 所有动态SQL必须自动注入tenant_id和is_deleted条件，确保多租户隔离和逻辑删除

> ⚠️ [报表中心模块] 报表查询必须设置30秒超时限制，超时自动终止并返回友好提示
