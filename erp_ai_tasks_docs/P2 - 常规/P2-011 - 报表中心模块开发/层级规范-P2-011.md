## 1. 模块架构约束

### 1.1 模块定位
报表中心模块是ERP系统中的数据展示核心模块，负责完成分业务报表（采购/销售/库存/财务/生产）、自定义报表及报表设计器功能。该模块提供统一的报表管理与数据可视化能力，汇总各业务模块数据，为管理决策提供数据支撑。

### 1.2 依赖关系
- 前置依赖：
  - P0-005（P10报表页组件）：提供前端报表展示组件基础（表格/图表/导出）
  - 各业务模块：提供采购/销售/库存/财务/生产的业务数据源
- 后续依赖：无（本模块为终端消费模块，不被其他模块直接依赖）

### 1.3 技术约束
- 技术栈约束：后端基于Spring Boot + MyBatis-Plus，前端基于Vue3 + Element Plus + ECharts；自定义报表引擎基于动态SQL构建；数据大屏使用CSS Grid/Flex自适应布局
- 性能约束：报表数据查询响应时间不超过5秒（复杂报表可放宽到10秒）；报表设计器渲染帧率不低于30fps
- 安全约束：自定义报表SQL仅允许SELECT语句，禁止DML/DDL操作；报表数据按用户权限过滤

## 2. 数据模型关系

### 2.1 核心数据表
| 表名 | 说明 | 关键字段 |
|------|------|---------|
| report | 报表主表 | id, report_code, report_name, report_type, category_id, data_source, status |
| report_category | 报表分类表 | id, category_name, parent_id, sort_order, status |
| report_catalog | 报表目录表 | id, catalog_name, parent_id, report_ids, sort_order |
| report_favorite | 报表收藏表 | id, user_id, report_id, create_time |
| report_screen_config | 数据大屏配置表 | id, screen_name, layout_json, refresh_interval, resolution, status |

### 2.2 表关系图
- report_category：树形结构自关联表，通过 parent_id 实现多级分类
- report_category → report：一对多关系，通过 category_id 关联
- report_catalog：树形结构，组织报表的展示目录
- report_favorite → report：多对一关系，通过 report_id 关联（用户收藏的报表）
- report_screen_config：独立配置表，存储大屏布局JSON

### 2.3 数据流转
1. 预置报表流程：选择业务模块 → 配置数据源SQL → 设置报表参数 → 发布报表 → 用户查看
2. 自定义报表流程：打开报表设计器 → 配置数据源 → 拖拽字段/图表 → 预览 → 保存发布
3. 数据大屏流程：创建大屏配置 → 编排图表组件 → 设置刷新间隔 → 全屏展示

## 3. 业务流程

### 3.1 核心业务流程
1. **报表管理**：预置报表的CRUD管理与分类
2. **报表分类**：树形结构的报表分类管理
3. **报表数据动态查询**：通用的报表数据查询引擎
4. **分业务报表**：采购报表、销售报表、库存报表、财务报表、生产报表
5. **自定义报表设计器**：可视化拖拽式报表设计工具
6. **报表目录管理**：组织报表展示结构
7. **报表收藏**：用户个人报表收藏功能
8. **数据大屏**：大屏数据可视化展示

### 3.2 业务规则
- 财务报表（资产负债表/利润表/现金流量表）取数逻辑由P1-014实现，本模块仅提供聚合查看入口
- 本科目余额表/辅助核算报表由P1-013覆盖，不重复实现取数逻辑
- 自定义报表SQL仅允许SELECT，禁止DROP/DELETE/UPDATE
- 数据大屏支持1920x1080/2K/4K自适应缩放与定时刷新
- 报表收藏按用户维度管理，每人最多收藏50个报表

### 3.3 状态流转
报表状态流转：
- 草稿(0) → 已发布(1) → 已停用(2)

数据大屏状态流转：
- 草稿(0) → 已发布(1) → 已停用(2)

## 5. 开发顺序约束

### 5.1 必须顺序执行的任务
1. 报表CRUD接口 → 报表数据动态查询接口（查询引擎依赖报表定义）
2. 报表数据动态查询接口 → 采购/销售/库存/财务/生产报表数据接口（业务报表依赖通用查询引擎）
3. 报表CRUD接口 → 自定义报表引擎接口（设计器依赖报表定义）
4. 后端接口全部完成 → 前端页面开发

### 5.2 可并行执行的任务
- 报表CRUD接口与报表分类CRUD接口可并行开发
- 采购报表、销售报表、库存报表、财务报表、生产报表数据接口可并行开发（均依赖通用查询引擎）
- 报表目录管理、报表收藏、数据大屏接口可并行开发
- 前端页面中，各业务报表页面（采购/销售/库存/财务/生产）可并行开发
- 自定义报表设计器页面与报表查看页面可并行开发
