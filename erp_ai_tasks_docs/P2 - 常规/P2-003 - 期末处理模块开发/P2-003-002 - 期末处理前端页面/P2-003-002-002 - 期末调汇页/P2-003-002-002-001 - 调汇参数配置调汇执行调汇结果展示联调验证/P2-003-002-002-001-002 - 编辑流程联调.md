### 5.1 编辑流程
1. 父页面[编辑]→打开弹窗(mode='edit', id)
2. api.detail(id)回填(含明细)
3. 修改→校验+联动
4. [保存]→validate()→api.update(form+version)
5. 成功→close()+emit('refresh')
6. 乐观锁冲突→提示刷新
