### 5.1 校验规则清单

| 校验项 | 规则 | 错误码 |
|--------|------|--------|
| 编号唯一 | 同租户下code不重复(含逻辑删除) | DUPLICATE_CODE |
| 名称必填 | name不为空且≤100字符 | NAME_REQUIRED |
| 状态流转 | 草稿(0)→已提交(1)→已审核(2) | INVALID_STATUS |
| 明细非空 | details至少1条 | DETAILS_EMPTY |
| 金额校验 | 明细合计 = 主表amount | AMOUNT_MISMATCH |

### 5.2 校验实现

```java
private void validateCreate(PeriodCreateDTO dto) {
    if (lambdaQuery().eq(PeriodEntity::getCode, dto.getCode()).exists()) {
        throw new BusinessException(ErrorCode.DUPLICATE_CODE);
    }
    if (CollectionUtils.isEmpty(dto.getDetails())) {
        throw new BusinessException(ErrorCode.DETAILS_EMPTY);
    }
    BigDecimal detailSum = dto.getDetails().stream().map(PeriodDetailDTO::getAmount).reduce(BigDecimal.ZERO, BigDecimal::add);
    if (detailSum.compareTo(dto.getAmount()) != 0) {
        throw new BusinessException(ErrorCode.AMOUNT_MISMATCH);
    }
}
```
