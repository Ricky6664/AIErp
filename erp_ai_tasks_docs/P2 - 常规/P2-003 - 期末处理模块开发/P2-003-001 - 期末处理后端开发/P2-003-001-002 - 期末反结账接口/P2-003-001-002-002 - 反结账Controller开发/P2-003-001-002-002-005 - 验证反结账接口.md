### 5.2 测试代码

```java
@SpringBootTest
@AutoConfigureMockMvc
class PeriodControllerTest {
    @Autowired MockMvc mockMvc;

    @Test
    void test_create_success() throws Exception {
        PeriodCreateDTO dto = new PeriodCreateDTO();
        dto.setCode("TEST001");
        dto.setName("测试");
        mockMvc.perform(post("/api/period/period/create")
            .contentType(MediaType.APPLICATION_JSON)
            .content(toJson(dto)))
            .andExpect(status().isOk())
            .andExpect(jsonPath("$.code").value(200));
    }
}
```
