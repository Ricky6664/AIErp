# P2-003 期末处理模块开发 - 模块开发指南

## 一、模块概述
- **模块定位**：完成期末结账/反结账、期末调汇、期末结转等财务期末处理功能，确保会计期间的正确关闭与结转
- **前置依赖**：P1-012（凭证）、P1-013（账簿）、P1-014（报表）
- **被依赖方**：无
- **开发阶段**：阶段九

## 四、数据表完整字段定义

> 以下字段定义为开发时的唯一权威来源。所有DDL/Entity/Mapper任务必须严格遵照此定义。
> 通用必含字段（10个）不再在每张表中重复列出，通过继承BaseEntity获取。
> 所有数值字段物理DDL统一使用decimal(18,8)，显示精度由系统参数控制。

### 4.1 fin_accounting_period（会计期间表）— 主表

**通用必含字段（通过继承BaseEntity获取）**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 |
|--------|---------|------|--------|---------|
| id | bigint | PRIMARY KEY | 雪花算法(ASSIGN_ID) | 主键ID |
| tenant_id | bigint | NOT NULL | - | 租户ID |
| created_at | timestamp | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | timestamp | NOT NULL | CURRENT_TIMESTAMP | 更新时间 |
| created_by | bigint | NOT NULL | 当前登录用户ID | 创建人ID |
| updated_by | bigint | NOT NULL | 当前登录用户ID | 修改人ID |
| is_deleted | boolean | NOT NULL | false | 是否删除 |
| owner_dept_id | bigint | - | 创建人所属部门ID | 所属部门ID |
| owner_id | bigint | - | created_by值 | 数据负责人ID |
| version | int | NOT NULL | 1 | 版本号(乐观锁) |

**业务字段**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 | 说明 |
|--------|---------|------|--------|---------|------|
| period_name | varchar(50) | NOT NULL | - | 期间名称 | 如"2026年1月" |
| fiscal_year | int | NOT NULL | - | 会计年度 | 如2026 |
| period_number | int | NOT NULL | - | 期间号 | 1~12月份号 |
| start_date | date | NOT NULL | - | 开始日期 | 期间起始日期 |
| end_date | date | NOT NULL | - | 结束日期 | 期间截止日期 |
| is_closed | boolean | NOT NULL | false | 是否已结账 | 结账状态标志 |
| closed_by | bigint | - | - | 结账人ID | 执行结账操作的用户 |
| closed_at | timestamp | - | - | 结账时间 | 结账操作的时间戳 |

**扩展字段（所有业务表统一预留）**：

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| pk_fin_accounting_period | 主键 | id | 主键索引 |
| uk_fin_accounting_period_yp | 部分唯一 | tenant_id, fiscal_year, period_number WHERE is_deleted=false | 同租户年度期间唯一 |

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |
|--------|---------|------|---------|
| 期间唯一性 | 新增/修改 | 同tenant_id下fiscal_year+period_number不能重复 | "该会计期间已存在" |
| 日期连续性 | 新增 | start_date必须紧接上一期间的end_date次日 | "期间日期不连续" |
| 期间号范围 | 新增/修改 | period_number >= 1 AND period_number <= 12 | "期间号需在1~12之间" |
| 日期逻辑 | 新增/修改 | end_date >= start_date | "结束日期不能早于开始日期" |
| 结账操作权限 | 结账 | 当前用户需有财务主管权限 | "无结账操作权限" |
| 结账顺序检查 | 结账 | 上一期间必须已结账(除第一期外) | "上一期间尚未结账，请先结上一期间" |

### 4.2 fin_period_revaluation（期末调汇记录表）— 主表

**通用必含字段**：同fin_accounting_period（10个，通过继承BaseEntity获取）

**业务字段**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 | 说明 |
|--------|---------|------|--------|---------|------|
| period_id | bigint | NOT NULL | - | 会计期间ID | 关联fin_accounting_period.id |
| currency | varchar(10) | NOT NULL | - | 币种 | 如USD/EUR/GBP等外币代码 |
| original_rate | decimal(18,8) | NOT NULL | - | 原汇率 | 调汇前的记账汇率 |
| new_rate | decimal(18,8) | NOT NULL | - | 新汇率 | 期末调整汇率 |
| adjustment_amount | decimal(18,8) | NOT NULL | 0 | 调整金额 | 汇兑损益调整金额 |
| status | varchar(30) | NOT NULL | 'draft' | 状态 | 枚举：draft(草稿)/approved(已审核) |

**扩展字段**：同fin_accounting_period

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| pk_fin_period_revaluation | 主键 | id | 主键索引 |
| uk_fin_period_revaluation_pc | 部分唯一 | tenant_id, period_id, currency WHERE is_deleted=false | 同期间同币种唯一 |
| idx_fin_period_revaluation_period | 普通 | period_id | 按期间查调汇记录 |

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |
|--------|---------|------|---------|
| 会计期间存在性 | 新增/修改 | period_id必须在fin_accounting_period中存在 | "会计期间不存在" |
| 期间未结账 | 新增/修改 | 会计期间is_closed=false | "该期间已结账，不可调汇" |
| 币种必填 | 新增/修改 | currency非空 | "币种不能为空" |
| 汇率正数 | 新增/修改 | original_rate > 0 AND new_rate > 0 | "汇率必须大于零" |
| 删除前状态检查 | 删除 | status必须为draft | "已审核的调汇记录不可删除" |

## 六、Service层业务逻辑规格

### 6.1 FinAccountingPeriodService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(FinAccountingPeriodQueryDTO) | 无(只读) | 支持fiscalYear + isClosed筛选，按fiscalYear DESC, periodNumber DESC排序 |
| getById(Long) | 无(只读) | 返回FinAccountingPeriodDetailVO |
| create(FinAccountingPeriodCreateDTO) | @Transactional | 期间唯一性校验 → 日期连续性校验 → 日期逻辑校验 → save |
| update(id, FinAccountingPeriodUpdateDTO) | @Transactional | 存在性校验 → 结账状态校验(已结账不可改) → 乐观锁更新 |
| close(Long periodId) | @Transactional | 权限校验(财务主管) → 存在性校验 → 未结账校验 → 上一期间已结账校验 → 检查本期凭证全部审核 → 更新is_closed=true + closed_by + closed_at → 操作日志 |
| reverse(Long periodId) | @Transactional | 权限校验(财务主管) → 已结账校验 → 下一期间未结账校验 → 回退is_closed=false → 清除closed_by/closed_at → 操作日志 |

### 6.2 FinPeriodRevaluationService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(FinPeriodRevaluationQueryDTO) | 无(只读) | 支持periodId + currency + status筛选 |
| getById(Long) | 无(只读) | 返回FinPeriodRevaluationDetailVO |
| create(FinPeriodRevaluationCreateDTO) | @Transactional | 期间存在性+未结账校验 → 币种唯一性校验 → 自动计算adjustmentAmount(遍历外币账户余额*(newRate-originalRate)) → save |
| update(id, FinPeriodRevaluationUpdateDTO) | @Transactional | 存在性校验 → 状态校验(仅draft可改) → 重新计算adjustmentAmount → 乐观锁更新 |
| delete(Long) | @Transactional | 状态校验(仅draft可删) → 逻辑删除 |
| approve(Long) | @Transactional | 状态流转draft→approved → 生成汇兑损益凭证 → 操作日志 |

### 6.3 FinPeriodCarryForwardService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| execute(Long periodId, String carryType) | @Transactional | 期间存在性+已结账校验 → 根据carryType(损益结转/成本结转/增值税结转/所得税结转/利润分配结转)执行对应结转逻辑 → 生成结转凭证 → 操作日志 |
| queryHistory(Long periodId) | 无(只读) | 查询指定期间的结转历史记录 |
