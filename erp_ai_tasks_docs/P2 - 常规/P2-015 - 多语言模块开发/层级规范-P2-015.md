## 1. 模块架构约束

### 1.1 模块定位
多语言模块是ERP系统中的国际化基础模块，负责完成多语言翻译管理、语言切换、菜单/表格/字典/文案多语言配置。该模块为系统提供完整的国际化（i18n）能力，支持多语言界面的动态切换和管理。

### 1.2 依赖关系
- 前置依赖：
  - P0-002（前端框架含i18n基础）：提供前端i18n框架基础（vue-i18n集成、语言包加载机制）
- 后续依赖：无（本模块为终端消费模块，但其多语言配置能力影响全系统所有页面的国际化展示）

### 1.3 技术约束
- 技术栈约束：后端基于Spring Boot + MyBatis-Plus，前端基于Vue3 + vue-i18n + Element Plus；翻译数据缓存使用Redis
- 性能约束：翻译数据加载响应时间不超过1秒（缓存命中时不超过100ms）；语言切换响应时间不超过500ms
- 安全约束：翻译数据修改后需清除对应语言编码的Redis缓存；翻译导入需防止XSS注入

## 2. 数据模型关系

### 2.1 核心数据表
| 表名 | 说明 | 关键字段 |
|------|------|---------|
| i18n_language | 语言定义表 | id, language_code, language_name, is_default, status, sort_order |
| i18n_translation | 翻译键值表 | id, language_code, translation_key, translation_value, category, module_code |

### 2.2 表关系图
- i18n_language：独立表，定义系统支持的语言列表
- i18n_translation → i18n_language：多对一关系，通过 language_code 关联（每条翻译属于一种语言）
- i18n_translation 按 category 分类：menu（菜单）、table（表格列）、dict（字典）、system（系统文案）、custom（自定义）

### 2.3 数据流转
1. 语言管理流程：添加语言 → 设置是否默认语言 → 启用/禁用
2. 翻译管理流程：选择语言 → 录入/导入翻译键值对 → 缓存至Redis → 前端加载
3. 语言切换流程：用户切换语言 → 更新Accept-Language请求头 → 后端返回对应语言翻译 → 前端重新渲染
4. 翻译导入导出流程：导出翻译模板（Excel/JSON）→ 线下翻译 → 导入翻译 → 增量更新/覆盖率统计

## 3. 业务流程

### 3.1 核心业务流程
1. **语言定义管理**：配置系统支持的语言列表
2. **翻译键值管理**：管理各语言的翻译键值对
3. **全局语言切换**：前端顶部导航栏语言切换组件
4. **菜单多语言配置**：配置系统菜单的多语言翻译
5. **表格列多语言配置**：配置表格列头的多语言翻译
6. **字典多语言配置**：配置数据字典的多语言翻译
7. **系统文案配置**：配置系统提示文案的多语言翻译
8. **翻译导入导出**：批量导入/导出翻译数据

### 3.2 业务规则
- 菜单/表格列/字典多语言数据按语言编码缓存至Redis（TTL 24h）
- 翻译变更时自动清除对应语言编码的缓存
- 前端菜单与字典加载时根据请求头Accept-Language返回对应语言翻译
- 缺失翻译时自动回退默认语言（is_default=1的语言）
- 翻译导入支持增量更新与覆盖率统计
- 表格多语言配置复用i18n_translation表（category=table）

### 3.3 状态流转
语言状态流转：
- 启用(1) / 禁用(0)

翻译覆盖率状态：
- 完整(100%) / 部分完成(<100%)

## 4. 接口契约

### 4.1 对外接口
| 接口路径 | 方法 | 说明 |
|---------|------|------|
| /api/i18n/language/* | POST/PUT/DELETE/GET | 语言定义CRUD操作 |
| /api/i18n/translation/* | POST/PUT/DELETE/GET | 翻译键值CRUD操作 |
| /api/i18n/export/* | GET | 翻译数据导出（Excel/JSON） |
| /api/i18n/import/* | POST | 翻译数据导入 |
| /api/i18n/menu/* | GET/PUT | 菜单多语言查询与更新 |
| /api/i18n/table-column/* | GET/PUT | 表格列多语言查询与更新 |
| /api/i18n/dict/* | GET/PUT | 字典多语言查询与更新 |
| /api/i18n/system-text/* | POST/PUT/DELETE/GET | 系统文案配置CRUD操作 |
| /api/i18n/table/* | GET/PUT | 表格多语言配置 |

### 4.2 依赖接口
- P0-002 前端框架接口：获取i18n基础配置、语言包加载机制

## 5. 开发顺序约束

### 5.1 必须顺序执行的任务
1. 语言定义CRUD接口 → 翻译键值CRUD接口（翻译依赖语言定义）
2. 翻译键值CRUD接口 → 翻译数据导出/导入接口（导入导出依赖翻译数据）
3. 翻译键值CRUD接口 → 菜单/表格列/字典/系统文案多语言接口（各分类翻译依赖基础翻译）
4. 后端接口全部完成 → 前端页面开发

### 5.2 可并行执行的任务
- 翻译数据导出接口与翻译数据导入接口可并行开发
- 菜单多语言接口、表格列多语言接口、字典多语言接口、系统文案配置接口可并行开发（各分类相互独立）
- 前端页面中，语言定义列表页、翻译管理列表页、菜单多语言配置页、表格列多语言配置页、字典多语言配置页可并行开发
- 全局语言切换组件可与其他前端页面并行开发
