# P2-015 多语言模块开发 - 模块开发指南

## 一、模块概述
- **模块定位**：完成多语言翻译管理、语言切换、菜单/表格/字典/文案多语言配置，为系统提供完整的国际化（i18n）能力
- **前置依赖**：P0-002（前端框架含i18n基础）
- **被依赖方**：无
- **开发阶段**：阶段十

## 四、模块级专属约束

本模块无模块级专属约束，遵循全局国际化开发规范。菜单/表格列/字典多语言数据按语言编码缓存至Redis（TTL 24h），翻译变更时自动清除缓存；前端菜单与字典加载时根据请求头Accept-Language返回对应语言翻译；缺失翻译时自动回退默认语言；翻译导入支持增量更新与覆盖率统计；表格多语言配置复用i18n_translation_key表（module=table）。

## 五、数据表完整字段定义

> 以下字段定义为开发时的唯一权威来源。所有DDL/Entity/Mapper任务必须严格遵照此定义。
> 通用必含字段（10个）不再在每张表中重复列出，通过继承BaseEntity获取。

### 5.1 i18n_language（语言定义表）— 主表

**通用必含字段（通过继承BaseEntity获取）**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 |
|--------|---------|------|--------|---------|
| id | bigint | PRIMARY KEY | 雪花算法(ASSIGN_ID) | 主键ID |
| tenant_id | bigint | NOT NULL | - | 租户ID |
| created_at | timestamp | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | timestamp | NOT NULL | CURRENT_TIMESTAMP | 更新时间 |
| created_by | bigint | NOT NULL | 当前登录用户ID | 创建人ID |
| updated_by | bigint | NOT NULL | 当前登录用户ID | 修改人ID |
| is_deleted | boolean | NOT NULL | false | 是否删除 |
| owner_dept_id | bigint | - | 创建人所属部门ID | 所属部门ID |
| owner_id | bigint | - | created_by值 | 数据负责人ID |
| version | int | NOT NULL | 1 | 版本号(乐观锁) |

**业务字段**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 | 说明 |
|--------|---------|------|--------|---------|------|
| language_code | varchar(10) | NOT NULL | - | 语言编码 | ISO 639-1编码，如zh-CN/en-US/ja-JP |
| language_name | varchar(50) | NOT NULL | - | 语言名称 | 中文显示名称，如"中文简体" |
| native_name | varchar(50) | - | - | 本地名称 | 该语言的本地化名称，如"简体中文" |
| icon | varchar(100) | - | - | 图标 | 国旗或语言图标标识 |
| sort_no | int | NOT NULL | 0 | 排序号 | 语言切换列表排序 |
| enable_flag | boolean | NOT NULL | true | 是否启用 | 启用/禁用状态 |

**扩展字段（所有业务表统一预留）**：

| 字段名 | 数据类型 | 说明 |
|--------|---------|------|
| ext_str1~ext_str10 | varchar(200) | 扩展字符串字段 |
| ext_num1~ext_num5 | decimal(18,8) | 扩展数值字段 |
| ext_date1~ext_date3 | date | 扩展日期字段 |
| ext_bool1~ext_bool3 | boolean | 扩展布尔字段 |

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| pk_i18n_language | 主键 | id | 主键索引 |
| uk_i18n_language_code | 部分唯一 | tenant_id, language_code WHERE is_deleted=false | 同租户语言编码唯一 |
| idx_i18n_language_enable | 普通 | tenant_id, enable_flag | 按启用状态查询 |

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |
|--------|---------|------|---------|
| 语言编码唯一 | 新增/修改 | 同tenant_id下language_code不可重复 | "语言编码已存在" |
| 语言编码格式 | 新增 | 符合ISO 639-1标准格式(如xx或xx-XX) | "语言编码格式不正确" |
| 删除前关联检查 | 删除 | 检查i18n_translation_value是否有引用 | "该语言下存在翻译数据，无法删除" |

**通用必含字段**：同i18n_language（10个，通过继承BaseEntity获取）

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |

### 5.3 i18n_translation_value（翻译值表）— 从表

**通用必含字段**：同i18n_language（10个，通过继承BaseEntity获取）

**业务字段**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 | 说明 |
|--------|---------|------|--------|---------|------|
| key_id | bigint | NOT NULL | - | 翻译键ID | 关联i18n_translation_key.id |
| language_code | varchar(10) | NOT NULL | - | 语言编码 | 关联i18n_language.language_code |
| translation_value | varchar(500) | NOT NULL | - | 翻译值 | 该语言下的翻译文本 |

**扩展字段**：同i18n_language

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| pk_i18n_translation_value | 主键 | id | 主键索引 |

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |
|--------|---------|------|---------|
| 键+语言唯一 | 新增/修改 | 同key_id+language_code不可重复 | "该语言下已有翻译" |
| 翻译键存在性 | 新增 | key_id必须在i18n_translation_key中存在 | "翻译键不存在" |
| 语言编码存在性 | 新增 | language_code必须在i18n_language中存在 | "语言编码不存在" |

## 七、Service层业务逻辑规格

### 7.1 I18nLanguageService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(LanguageQueryDTO) | 无(只读) | 按enableFlag筛选 + keyword模糊搜索 |

### 7.2 I18nTranslationService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(TranslationKeyQueryDTO) | 无(只读) | 按module筛选 + keyword模糊搜索translationKey/description |

| getByModule(String module, String langCode) | 无(只读) | 按模块+语言返回翻译Map，优先读Redis缓存 |

### 7.3 I18nImportExportService

| 方法 | 事务 | 业务逻辑要点 |

| getCoverageStats() | 无(只读) | 统计各语言翻译完成率 = 已翻译数 / (翻译键总数 × 语言数) |

### 7.4 I18nWorkbenchService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| getWorkbenchData() | 无(只读) | 聚合查询：语言总数 + 翻译键总数 + 各语言翻译完成率 + 最近修改翻译 |
