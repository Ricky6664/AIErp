### 5.1 接口定义

| 属性 | 值 |
|------|-----|
| 路径 | /api/i18n/language |
| 权限标识 | i18n:xxx |
| 请求体 | I18nDTO（@Valid校验） |
| 响应体 | Result<T> |

### 5.2 Controller代码结构

```java
@RestController
@RequestMapping("/api/i18n/language")
@Tag(name = "多语言管理")
public class I18nController {
    @PostMapping("/create")
    @Operation(summary = "新增")
    @SaCheckPermission("i18n:add")
    public Result<Long> create(@RequestBody @Valid I18nCreateDTO dto) {
        return R.ok(i18nService.create(dto));
    }
}
```

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id条件

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE而非DELETE

> ⚠️ 接口路径必须符合 `/api/{module}/{resource}` 规范，复数形式

> ⚠️ @RequestBody必须配合@Valid使用，否则DTO校验不生效

> ⚠️ GET请求复杂查询参数使用@ModelAttribute而非@RequestParam

> ⚠️ [多语言模块] i18n key命名规范：{module}.{page}.{component}.{field}，例如sys.user.list.title

> ⚠️ [多语言模块] 翻译加载使用懒加载策略，首次请求某语言翻译时才加载并缓存

> ⚠️ [多语言模块] 翻译Key全局唯一性校验，新增时检查是否已存在相同key+language_code的记录
