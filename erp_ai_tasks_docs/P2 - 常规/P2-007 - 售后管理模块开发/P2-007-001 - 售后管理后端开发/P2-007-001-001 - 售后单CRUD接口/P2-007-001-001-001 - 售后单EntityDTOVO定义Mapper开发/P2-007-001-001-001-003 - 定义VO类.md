### 5.1 核心功能
1. 定义XxxVO用于列表展示，XxxDetailVO用于详情返回
2. 字段命名与前端约定一致(驼峰)，金额保留2位小数
3. 枚举字段同时返回code+name(如status/statusName)
4. 关联数据通过VO嵌套展示(如明细List<XxxDetailVO>)
5. 使用@Schema注解补充Knife4j字段描述

### 5.2 数据交互
1. Service查询Entity后转换为VO返回前端
2. 枚举code通过EnumUtils转为中文name填充到VO
3. 关联数据通过子查询/JOIN获取并嵌套到VO
4. 分页查询返回IPage<XxxVO>含total/pages/records
5. 敏感字段(手机号/身份证)脱敏后写入VO

### 5.3 关键逻辑
1. 金额字段BigDecimal保留2位，RoundingMode.HALF_UP
2. 枚举双字段输出(code+name)，前端下拉框直接使用
3. 日期字段@JsonFormat格式化输出
4. 脱敏注解@Desensitize处理手机号/身份证/银行卡
5. 嵌套VO处理主子表数据，避免N+1查询

### 5.4 验证
1. VO类编译通过，字段命名符合前端约定
2. 枚举code→name转换正确
3. 金额精度2位小数正确
4. 脱敏字段输出格式正确
5. 嵌套VO数据结构与前端匹配
