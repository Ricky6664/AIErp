# P2-007 售后管理模块开发 - 模块开发指南

## 一、模块概述
- **模块定位**：完成售后全链路管理，包含售后单、远程/上门服务、退货/换货/维修、送修/接修及客户回访等功能
- **前置依赖**：P0-007（商品）、P0-008（客户）、P0-010（仓库）、P1-001（审核引擎）
- **被依赖方**：无
- **开发阶段**：阶段九

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |

## 六、Service层业务逻辑规格

### 6.1 AftersaleOrderService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(AftersaleOrderQueryDTO) | 无(只读) | 支持customerId + aftersaleType + status筛选 + keyword模糊搜索 |
| getById(Long) | 无(只读) | 返回AftersaleOrderDetailVO含明细行 |
| create(AftersaleOrderCreateDTO) | @Transactional | 客户校验 → 销售订单有效性校验 → 编码引擎生成orderNo → 主表save → 明细行batchSave → 操作日志 |
| update(id, AftersaleOrderUpdateDTO) | @Transactional | 存在性+状态校验(仅draft可改) → 乐观锁更新 → 明细行替换 |
| delete(Long) | @Transactional | 状态校验(仅draft可删) → 关联退货/换货/维修检查 → 删除明细 → 逻辑删除 |
| approve(Long) | @Transactional | 状态流转draft→approved → 操作日志 |

### 6.2 AftersaleReturnService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page/getById | 无(只读) | 常规查询 |

| approve(Long) | @Transactional | 状态流转draft→approved → 库存自动增加(退货入库) → 退款金额联动应收 → 操作日志 |

### 6.3 AftersaleExchangeService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
