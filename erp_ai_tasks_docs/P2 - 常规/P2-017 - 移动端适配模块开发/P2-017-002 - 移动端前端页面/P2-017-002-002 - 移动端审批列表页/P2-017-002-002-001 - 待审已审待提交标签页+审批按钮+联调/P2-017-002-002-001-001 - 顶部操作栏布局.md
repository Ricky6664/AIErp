### 5.1 按钮配置

```vue
<el-button type="primary" v-permission="'mobile:add'" @click="handleAdd">新增</el-button>
<el-button type="danger" :disabled="!selectedRows.length" v-permission="'mobile:delete'" @click="handleBatchDelete">批量删除</el-button>
```

### 5.2 权限控制

- v-permission指令根据当前用户权限控制按钮显示
- 批量操作按钮在selectedRows.length===0时disabled

### 5.3 删除二次确认

```ts
ElMessageBox.confirm('确定删除选中记录？', '提示', { type: 'warning' })
  .then(() => deleteApi(selectedIds.value))
  .then(() => { ElMessage.success('删除成功'); refresh() })
```

### 5.4 验证

1. 权限指令v-permission正确
2. 批量操作disabled逻辑正确
3. 删除二次确认弹窗正常

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 权限控制必须使用v-permission指令，禁止手动判断角色

> ⚠️ 删除/批量操作必须二次确认（ElMessageBox.confirm）

> ⚠️ 表格操作列fixed="right"防止横向滚动被遮挡

> ⚠️ 表单离开未保存提示——beforeRouteLeave守卫拦截

> ⚠️ 接口请求必须携带loading状态，防止重复提交

> ⚠️ [移动端模块] 响应式设计断点：320px(手机)/768px(平板)/1024px(桌面)，使用CSS媒体查询适配

> ⚠️ [移动端模块] 离线数据同步时需处理冲突（乐观锁version校验），冲突时提示用户选择保留版本

> ⚠️ [移动端模块] 推送通知发送需记录推送日志（成功/失败/点击），失败时需重试机制（最多3次）
