## 四、模块级专属约束

本模块包含移动端专属约束，基于UniApp跨平台框架（iOS/Android/H5）开发：

1. **跨平台适配**：移动端页面基于UniApp开发，需同时适配iOS、Android与H5三种平台；移动端首页采用H5适配方案，包含快捷功能入口、待办提醒与KPI卡片。
2. **消息推送**：集成APNs（iOS）与FCM（Android）推送通道，支持即时/定时/批量推送策略；消息模板支持变量占位符。
3. **离线模式**：移动端单据操作支持离线暂存，网络恢复后自动同步数据至服务端；离线策略可在移动端配置管理中配置。
4. **版本管理**：支持版本号管理与强制更新机制，客户端启动时检查版本并按配置决定是否强制升级。
5. **移动端审批**：支持待审/已审/待提交标签页切换、审批意见输入、签名附件、催办通知与审批委托功能。
6. **移动端安全**：AppID/AppSecret等敏感配置加密存储；移动端接口独立鉴权，与PC端Token体系隔离。

**PushLogQueryDTO**：userId(Long) + pushType(String) + isRead(Boolean) + startTime(LocalDateTime) + endTime(LocalDateTime) + PageQuery
**PushLogListVO**：id + userName + title + pushType + pushTime + isRead
