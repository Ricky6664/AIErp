## 五、详细开发规格

> **本任务模块上下文**
> - 涉及数据表：borrow_application(借用申请单), borrow_apply(借用出库单), borrow_return(借用归还单), borrow_in(借入单), borrow_in_return(借入归还单)

### 5.1 字段组件
- 文本：el-input(max length)
- 数值：el-input-number(precision精度)
- 下拉：el-select(远程搜索可选)
- 日期：el-date-picker(value-format统一)
- 业务选择器：自定义弹窗
- 附件：el-upload(限制类型/大小)

### 5.2 示例
```vue
<el-form-item label="金额" prop="amount">
  <el-input-number v-model="form.amount" :min="0" :precision="2"/>
</el-form-item>
<el-form-item label="部门" prop="deptId">
  <DeptSelector v-model="form.deptId" @change="handleDeptChange"/>
</el-form-item>
```
