## 五、详细开发规格

> **本任务模块上下文**
> - 涉及数据表：borrow_application(借用申请单), borrow_apply(借用出库单), borrow_return(借用归还单), borrow_in(借入单), borrow_in_return(借入归还单)
> - 涉及API：/api/borrow/application/*, /api/borrow/outbound/*, /api/borrow/return/*, /api/borrow/in/*

### 5.1 核心功能
1. @PostMapping/@PutMapping/@DeleteMapping/@GetMapping映射具体路径
2. @SaCheckPermission进行接口权限校验
3. @RequestBody + @Valid触发DTO参数校验，路径参数用@PathVariable
4. 统一返回Result<T>包装响应，分页用IPage<XxxVO>
5. @Operation(summary="...")补充Knife4j文档注解

### 5.2 数据交互
1. 前端请求通过RESTful API进入Controller
2. Controller调用Service处理业务，不直接操作Mapper
3. DTO参数校验通过后传入Service，VO由Service返回
4. 统一Result<T>包装：code=200成功，code!=200失败含message
5. 分页接口接收PageQuery，返回IPage<XxxVO>

### 5.3 关键逻辑
1. @SaCheckPermission权限注解，匹配权限编码
2. @Valid参数校验，MethodArgumentNotValidException全局处理
3. 路径参数@PathVariable，查询参数@RequestParam
4. 分页参数默认值：pageNum=1, pageSize=20, maxSize=100
5. 接口幂等性：新增防重复提交，修改删除用乐观锁

### 5.4 验证
1. Controller编译通过，接口可访问
2. @SaCheckPermission权限校验生效
3. @Valid参数校验返回明确错误信息
4. Result<T>包装格式统一，code/message/data完整
5. Knife4j文档注解完整，doc.html可查
