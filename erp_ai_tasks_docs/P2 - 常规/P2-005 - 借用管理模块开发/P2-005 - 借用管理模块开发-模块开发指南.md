# P2-005 借用管理模块开发 - 模块开发指南

## 一、模块概述
- **模块定位**：完成借用申请→出库→归还及借入→归还全链路管理，包含借用申请单、借用出库单、借用归还单、借入单、借入归还单
- **前置依赖**：P0-007（商品）、P0-010（仓库）
- **被依赖方**：无
- **开发阶段**：阶段九

## 四、数据表完整字段定义

> 以下字段定义为开发时的唯一权威来源。所有DDL/Entity/Mapper任务必须严格遵照此定义。
> 通用必含字段（10个）不再在每张表中重复列出，通过继承BaseEntity获取。
> 所有数值字段物理DDL统一使用decimal(18,8)，显示精度由系统参数控制。

| 申请人存在性 | 新增/修改 | applicant_id必须在hrm_employee中存在 | "申请人不存在" |
| 部门存在性 | 新增/修改 | department_id必须在org_department中存在 | "所属部门不存在" |

### 6.1 BorrowApplicationService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(BorrowApplicationQueryDTO) | 无(只读) | 支持applicantId + departmentId + status筛选 + keyword模糊搜索 |
| getById(Long) | 无(只读) | 返回BorrowApplicationDetailVO含明细行 |

| update(id, BorrowApplicationUpdateDTO) | @Transactional | 存在性+状态校验(仅draft可改) → 乐观锁更新 → 明细行替换 |
| delete(Long) | @Transactional | 状态校验(仅draft可删) → 出库/归还记录检查 → 删除明细 → 逻辑删除主表 |
| approve(Long) | @Transactional | 状态流转draft→approved → 操作日志 |
