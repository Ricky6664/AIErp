### 5.1 注解规范

```java
@RestController
@Tag(name = "样品管理-Sample管理", description = "Sample相关接口")
public class SampleController {

    @PostMapping("/create")
    @Operation(summary = "创建Sample", description = "创建新的Sample记录")
    public Result<SampleVO> create(
        @RequestBody @Valid @Parameter(description = "创建参数") SampleCreateDTO dto) {
        ...
    }
}

@Data
public class SampleCreateDTO {
    @Schema(description = "编号", example = "EXP202605260001", required = true)
    @NotBlank private String code;
}
```

### 5.2 必加注解
- 类@Tag(name, description)
- 方法@Operation(summary, description)
- 参数@Parameter
- 字段@Schema(description, example, required)
