# P2-004 样品管理模块开发 - 模块开发指南

## 一、模块概述
- **模块定位**：完成样品申请→发货→归还全链路管理，包含样品申请、样品发货、样品采购、样品入库、样品归还及样品库存查询
- **前置依赖**：P0-007（商品）、P0-008（客户）、P0-010（仓库）
- **被依赖方**：无
- **开发阶段**：阶段九

## 四、数据表完整字段定义

> 以下字段定义为开发时的唯一权威来源。所有DDL/Entity/Mapper任务必须严格遵照此定义。
> 通用必含字段（10个）不再在每张表中重复列出，通过继承BaseEntity获取。
> 所有数值字段物理DDL统一使用decimal(18,8)，显示精度由系统参数控制。

### 4.1 sample_application（样品申请单主表）— 主表

**通用必含字段（通过继承BaseEntity获取）**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 |
|--------|---------|------|--------|---------|
| id | bigint | PRIMARY KEY | 雪花算法(ASSIGN_ID) | 主键ID |
| tenant_id | bigint | NOT NULL | - | 租户ID |
| created_at | timestamp | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | timestamp | NOT NULL | CURRENT_TIMESTAMP | 更新时间 |
| created_by | bigint | NOT NULL | 当前登录用户ID | 创建人ID |
| updated_by | bigint | NOT NULL | 当前登录用户ID | 修改人ID |
| is_deleted | boolean | NOT NULL | false | 是否删除 |
| owner_dept_id | bigint | - | 创建人所属部门ID | 所属部门ID |
| owner_id | bigint | - | created_by值 | 数据负责人ID |
| version | int | NOT NULL | 1 | 版本号(乐观锁) |

**业务字段**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 | 说明 |
|--------|---------|------|--------|---------|------|
| order_no | varchar(50) | NOT NULL | 编码引擎自动生成 | 申请单号 | 唯一编号 |
| order_date | date | NOT NULL | 当前日期 | 单据日期 | 申请单日期 |
| customer_id | bigint | NOT NULL | - | 客户ID | 关联crm_customer.id |
| application_date | date | NOT NULL | 当前日期 | 申请日期 | 样品申请日期 |
| applicant_id | bigint | NOT NULL | 当前登录用户ID | 申请人ID | 关联hrm_employee.id |
| department_id | bigint | NOT NULL | - | 部门ID | 关联org_department.id |
| purpose | varchar(300) | - | - | 申请目的 | 样品用途说明 |
| status | varchar(30) | NOT NULL | 'draft' | 状态 | 枚举：draft(草稿)/approved(已审核)/shipped(已发货)/returned(已归还) |

**扩展字段（所有业务表统一预留）**：

| 字段名 | 数据类型 | 说明 |
|--------|---------|------|
| ext_str1~ext_str10 | varchar(200) | 扩展字符串字段 |
| ext_num1~ext_num5 | decimal(18,8) | 扩展数值字段 |
| ext_date1~ext_date3 | date | 扩展日期字段 |
| ext_bool1~ext_bool3 | boolean | 扩展布尔字段 |
| ext_json | jsonb | 扩展JSON字段 |

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| pk_sample_application | 主键 | id | 主键索引 |
| uk_sample_application_order_no | 部分唯一 | tenant_id, order_no WHERE is_deleted=false | 同租户单号唯一 |
| idx_sample_application_customer | 普通 | customer_id | 按客户查申请 |
| idx_sample_application_applicant | 普通 | applicant_id, status | 按申请人+状态查询 |

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |
|--------|---------|------|---------|
| 单号唯一 | 新增/修改 | 同tenant_id下is_deleted=false不能同单号 | "申请单号已存在" |
| 客户存在性 | 新增/修改 | customer_id必须在crm_customer中存在 | "客户不存在" |
| 申请人存在性 | 新增/修改 | applicant_id必须在hrm_employee中存在 | "申请人不存在" |
| 删除前状态检查 | 删除 | status必须为draft | "已审核的申请单不可删除" |
