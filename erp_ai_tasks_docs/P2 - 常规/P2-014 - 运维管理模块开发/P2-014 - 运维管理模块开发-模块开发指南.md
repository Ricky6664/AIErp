- **开发阶段**：阶段十

## 四、模块级专属约束

本模块包含运维级专属约束，覆盖监控、备份、恢复、告警四大运维领域：

1. **定时任务管理**：集成XXL-JOB调度框架，支持Cron表达式配置与手动触发，任务执行日志自动记录。
2. **数据备份与恢复**：备份文件需MD5校验完整性；恢复操作需@RequiresPermissions("ops:recovery:execute")权限控制与二次确认；恢复过程需记录完整日志并支持回滚。
3. **运维告警**：告警规则支持阈值配置，超阈值自动触发告警通知推送（站内信/邮件/短信）。
4. **服务器监控**：CPU/内存/磁盘/JVM/数据库连接池实时采集并存储历史趋势数据；集成Spring Boot Actuator暴露/health、/metrics、/info端点并配置安全访问。
5. **在线用户管理**：基于Sa-Token会话列表实现，支持强制下线（踢出指定用户会话）与会话信息查看（登录IP/设备/浏览器/时间）。

**JobLogListVO**：id + jobName + startTime + endTime + status + result(截取前100字符) + errorMsg(截取前100字符)

### 6.3 数据备份

**BackupCreateDTO**：backupName(String,@NotBlank) + backupType(String,@Pattern(regexp="full|incremental"))
**BackupListVO**：id + backupName + backupType + backupTime + fileSize + status

### 6.4 运维告警

**AlertQueryDTO**：alertType(String) + alertLevel(String) + isResolved(Boolean) + startTime(LocalDateTime) + endTime(LocalDateTime) + PageQuery
**AlertListVO**：id + alertType + alertLevel + alertContent(截取前100字符) + alertTime + isResolved + resolveBy + resolveTime
**AlertResolveDTO**：resolveRemark(String,@NotBlank,@Size(max=500))

### 6.5 服务器监控

**ServerMonitorQueryDTO**：serverIp(String) + startTime(LocalDateTime) + endTime(LocalDateTime) + PageQuery
**ServerMonitorListVO**：id + serverName + serverIp + cpuUsage + memoryUsage + diskUsage + networkIn + networkOut + status + checkTime

### 6.6 在线用户

**UserSessionQueryDTO**：isOnline(Boolean) + keyword(String模糊搜索userName) + PageQuery
**UserSessionListVO**：id + userId + userName + loginTime + lastActiveTime + loginIp + deviceInfo + isOnline

## 七、Service层业务逻辑规格
