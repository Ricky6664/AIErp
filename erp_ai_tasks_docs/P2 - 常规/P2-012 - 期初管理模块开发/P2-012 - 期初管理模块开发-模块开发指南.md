# P2-012 期初管理模块开发 - 模块开发指南

## 一、模块概述
- **模块定位**：完成系统初始化数据管理，包含期初库存、期初应收、期初应付、期初应开票、期初应收票、期初固定资产、期初科目余额的录入与审核写入
- **前置依赖**：P0-007（商品）、P0-010（仓库）、P1-010（应收）、P1-011（应付）、P1-012（凭证）
- **被依赖方**：无
- **开发阶段**：阶段十

## 四、模块级专属约束

本模块无模块级专属约束，遵循全局规范。期初数据审核通过后自动写入对应业务表（库存表/应收表/应付表/资产卡片表/科目余额表）；已启用（已存在业务单据）的仓库/客户/供应商/科目不可修改期初数据；期初科目余额必须通过试算平衡校验（全部借方合计=全部贷方合计）方可提交；期初固定资产支持四种折旧方法公式自动计算月折旧额。

### 7.1 InitStockService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|

| getById(Long) | 无(只读) | 返回InitStockDetailVO，含明细列表 |
| create(InitStockCreateDTO) | @Transactional | 仓库存在性校验 → 仓库未启用检查 → 明细行号自动编排 → 计算total_cost → save主表+明细 |
