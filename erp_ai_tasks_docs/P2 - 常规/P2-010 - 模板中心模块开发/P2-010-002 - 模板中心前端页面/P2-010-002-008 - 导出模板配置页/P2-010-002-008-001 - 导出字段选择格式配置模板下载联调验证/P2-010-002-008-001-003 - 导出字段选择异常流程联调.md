### 5.1 字段组件映射

| 字段类型 | 组件 | 默认值 | 说明 |
|---------|------|--------|------|
| 文本 | el-input | "" | 支持placeholder |
| 字典 | DictSelect | null | 自动加载字典项 |
| 日期 | el-date-picker | null | type="daterange" |
| 级联 | el-cascader | [] | 多级选择 |

### 5.2 字典加载

- DictSelect组件通过dict_type属性自动调用/api/sys/dict/items/{dict_type}
- 选项缓存到Pinia store，避免重复请求

### 5.3 验证

1. 各字段组件渲染正确
2. 字典选项加载正确
3. 默认值生效

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 权限控制必须使用v-permission指令，禁止手动判断角色

> ⚠️ 删除/批量操作必须二次确认（ElMessageBox.confirm）

> ⚠️ 表格操作列fixed="right"防止横向滚动被遮挡

> ⚠️ 表单离开未保存提示——beforeRouteLeave守卫拦截

> ⚠️ 接口请求必须携带loading状态，防止重复提交

> ⚠️ [模板中心模块] 模板分类树形结构递归查询时注意防止无限循环（parent_id校验）

> ⚠️ [模板中心模块] 模板内容JSON存储需做JSON格式合法性校验

> ⚠️ [模板中心模块] 打印模板设计器拖拽组件坐标使用JSON数组存储，注意序列化/反序列化性能
