# P2-010 模板中心模块开发 - 模块开发指南

## 一、模块概述
- **模块定位**：完成模板管理、模板分类、打印模板、导入/导出模板及模板设计器功能，为全系统提供统一的模板管理能力
- **前置依赖**：P0-005（公共组件含打印组件）
- **被依赖方**：无
- **开发阶段**：阶段十

## 四、模块级专属约束

本模块无模块级专属约束，遵循全局规范。模板分类支持树形结构；模板内容以JSON格式存储；打印模板设计器支持拖拽式组件编排与数据绑定；导入模板需配置字段映射与校验规则；导出模板需配置导出字段与格式。

## 七、Service层业务逻辑规格

### 7.1 TemplateService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(TemplateQueryDTO) | 无(只读) | 按categoryId/templateType筛选 + keyword模糊搜索 + enableFlag筛选 |
| getById(Long) | 无(只读) | 返回TemplateDetailVO，含categoryName |
| create(TemplateCreateDTO) | @Transactional | 分类存在性校验 → 名称唯一性校验 → 编码引擎生成templateCode → save |
| update(id, TemplateUpdateDTO) | @Transactional | 存在性校验 → 名称唯一性校验(排除自身) → 乐观锁更新 |
| delete(Long) | @Transactional | 单据配置引用检查 → 逻辑删除 |

### 7.2 TemplateCategoryService

|------|------|------------|

| create(CategoryCreateDTO) | @Transactional | 名称唯一性校验 → 循环引用检查 → save |
| update(id, CategoryUpdateDTO) | @Transactional | 存在性校验 → 名称唯一性校验(排除自身) → 循环引用检查 → 乐观锁更新 |
