# P2-006 租赁管理模块开发 - 模块开发指南

## 一、模块概述
- **模块定位**：完成租赁合同→出库→计费→收款→归还及租入→归还全链路管理，包含租赁合同、租赁出库、租赁计费、租赁收款、租赁归还、租入单、租入归还单
- **前置依赖**：P0-008（客户）、P0-007（商品）
- **被依赖方**：无
- **开发阶段**：阶段九
