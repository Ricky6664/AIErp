## 1. 模块架构约束

### 1.1 模块定位
租赁管理模块是ERP系统中的业务辅助模块，负责完成租赁合同→出库→计费→收款→归还及租入→归还全链路管理。模块包含租赁合同、租赁出库、租赁计费、租赁收款、租赁归还、租入单、租入归还单，实现对外出租和对内租入的双向租赁业务管理。

### 1.2 依赖关系
- 前置依赖：
  - P0-008（客户）：提供客户基础数据，租赁合同关联承租客户
  - P0-007（商品）：提供商品/物品基础数据，租赁关联具体租赁物品
- 后续依赖：无（本模块为终端消费模块，不被其他模块直接依赖）

### 1.3 技术约束
- 技术栈约束：后端基于Spring Boot + MyBatis-Plus，前端基于Vue3 + Element Plus；计费引擎使用定时任务自动生成计费单
- 性能约束：计费单自动生成（批量100份合同）响应时间不超过30秒；库存操作响应时间不超过3秒
- 安全约束：租赁出库/归还操作需审核通过后执行库存变更；收款操作需@RequiresPermissions("lease:receipt:confirm")权限

| lease_contract_detail | 租赁合同明细表 | id, contract_id, product_id, qty, unit_price, billing_method |

| lease_receipt | 租赁收款单主表 | id, receipt_no, billing_id, receipt_amount, receipt_date, status |
| lease_return | 租赁归还单主表 | id, return_no, outbound_id, return_date, warehouse_id, status |

### 2.2 表关系图
- lease_contract（主表）→ lease_contract_detail（从表）：一对多关系，通过 contract_id 关联
- lease_contract → lease_outbound：一对多关系，通过 contract_id 关联
- lease_outbound（主表）→ lease_outbound_detail（从表）：一对多关系，通过 outbound_id 关联
- lease_contract → lease_billing：一对多关系，通过 contract_id 关联（按期计费）
- lease_billing → lease_receipt：一对多关系，通过 billing_id 关联（收款核销计费）
- lease_outbound → lease_return：一对一/多关系，通过 outbound_id 关联
- lease_inbound（主表）→ lease_inbound_detail（从表）：一对多关系，通过 inbound_id 关联
- lease_inbound → lease_in_return：一对一/多关系，通过 inbound_id 关联

### 2.3 数据流转
1. 出租流程：签订租赁合同 → 合同审核通过 → 出库发货 → 按期计费 → 收款确认 → 到期归还
2. 租入流程：创建租入单 → 审核通过后入库 → 到期归还出库

## 3. 业务流程

### 3.1 核心业务流程
1. **租赁合同管理**：签订租赁合同，约定租赁物品、租期、计费方式
2. **租赁出库**：合同生效后从仓库发出租赁物品
3. **租赁计费**：按计费周期（日/周/月）自动生成计费单
4. **租赁收款**：对计费单进行收款确认与核销
5. **租赁归还**：租赁到期后客户归还物品，验收入库
6. **租入管理**：向供应商租入物品，入库登记
7. **租入归还**：租期到期后归还供应商物品

### 3.2 业务规则
- 租赁出库单审核后自动扣减库存并关联合同
- 租赁计费单到期自动生成并联动应收款
- 租赁收款单支持收款确认与核销
- 租赁归还单审核后自动增加库存并更新合同状态
- 出库数量不得超过合同未出库数量
- 超期归还需自动计算超期费用

### 3.3 状态流转
租赁合同状态流转：
- 草稿(0) → 待审核(1) → 执行中(3) / 已驳回(4) → 已完成(5) / 已终止(6)

租赁计费单状态流转：
- 待计费(0) → 已计费(1) → 部分收款(2) → 已收款(3)

## 5. 开发顺序约束

### 5.1 必须顺序执行的任务
1. 租赁合同CRUD接口 → 租赁出库单CRUD接口（出库依赖合同）
2. 租赁合同CRUD接口 → 租赁计费CRUD接口（计费依赖合同）
3. 租赁计费CRUD接口 → 租赁收款单CRUD接口（收款依赖计费单）
4. 租赁出库单CRUD接口 → 租赁归还单CRUD接口（归还依赖出库单）
5. 租入单CRUD接口 → 租入归还单CRUD接口（归还依赖租入单）
6. 后端接口全部完成 → 前端页面开发

### 5.2 可并行执行的任务
- 租赁合同CRUD接口与租入单CRUD接口可并行开发（两者相互独立）
- 租赁出库单CRUD接口与租赁计费CRUD接口可并行开发（均仅依赖合同接口）
- 前端页面中，租赁合同列表页、租赁出库列表页、租赁计费列表页、租赁收款列表页、租赁归还列表页可并行开发
