### 5.1 注解规范

```java
@RestController
@Tag(name = "租赁管理-Lease管理", description = "Lease相关接口")
public class LeaseController {

    @PostMapping("/create")
    @Operation(summary = "创建Lease", description = "创建新的Lease记录")
    public Result<LeaseVO> create(
        @RequestBody @Valid @Parameter(description = "创建参数") LeaseCreateDTO dto) {
        ...
    }
}

@Data
public class LeaseCreateDTO {
    @Schema(description = "编号", example = "EXP202605260001", required = true)
    @NotBlank private String code;
}
```

- 类@Tag(name, description)
- 方法@Operation(summary, description)
- 参数@Parameter
- 字段@Schema(description, example, required)
