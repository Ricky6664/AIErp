### 5.1 核心功能
1. 使用@TableName注解映射数据库表名
2. 使用@TableId(type=IdType.ASSIGN_ID)配置雪花算法主键
3. 使用@TableField注解映射所有业务字段(驼峰→下划线)
4. 继承BaseEntity获取10个通用字段(id/tenant_id/created_at/updated_at/created_by/updated_by/is_deleted/owner_dept_id/owner_id/version)
5. 使用@TableLogic标注is_deleted，@Version标注version

### 5.2 数据交互
1. Entity映射数据库表，字段驼峰自动转下划线
2. 继承BaseEntity获取通用字段，MetaObjectHandler自动填充
3. @TableLogic逻辑删除，查询自动追加is_deleted=false
4. @Version乐观锁，更新时自动version+1
5. 通过MyBatis-Plus BaseMapper进行CRUD操作

### 5.3 关键逻辑
1. @TableName精确匹配数据库表名，Schema正确
2. 所有字段@TableField映射，驼峰→下划线转换
3. BigDecimal金额字段precision=18/scale=8
4. 枚举字段使用IEnum接口实现序列化
5. BaseEntity通用字段不重复定义

### 5.4 验证
1. Entity类编译通过，@TableName映射正确
2. 所有字段@TableField完整，无遗漏
3. BaseEntity通用字段继承正确
4. @TableLogic/@Version注解生效
5. MyBatis-Plus代码生成器验证CRUD可用
