# P2-002 固定资产模块开发 - 模块开发指南

## 一、模块概述
- **模块定位**：完成固定资产全生命周期管理，包含资产卡片录入、资产折旧计提、资产变动管理、资产清理处置及资产统计报表
- **前置依赖**：P0-011（财务基础含会计科目）
- **被依赖方**：无
- **开发阶段**：阶段九

## 四、数据表完整字段定义

> 以下字段定义为开发时的唯一权威来源。所有DDL/Entity/Mapper任务必须严格遵照此定义。
> 通用必含字段（10个）不再在每张表中重复列出，通过继承BaseEntity获取。
> 所有数值字段物理DDL统一使用decimal(18,8)，显示精度由系统参数控制。

**通用必含字段（通过继承BaseEntity获取）**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 |

| id | bigint | PRIMARY KEY | 雪花算法(ASSIGN_ID) | 主键ID |
| tenant_id | bigint | NOT NULL | - | 租户ID |
| created_at | timestamp | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | timestamp | NOT NULL | CURRENT_TIMESTAMP | 更新时间 |
| created_by | bigint | NOT NULL | 当前登录用户ID | 创建人ID |
| updated_by | bigint | NOT NULL | 当前登录用户ID | 修改人ID |
| is_deleted | boolean | NOT NULL | false | 是否删除 |
| owner_dept_id | bigint | - | 创建人所属部门ID | 所属部门ID |
| owner_id | bigint | - | created_by值 | 数据负责人ID |
| version | int | NOT NULL | 1 | 版本号(乐观锁) |

**业务字段**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 | 说明 |
|--------|---------|------|--------|---------|------|
| category_code | varchar(50) | NOT NULL | 编码引擎自动生成 | 分类编码 | 唯一编码 |

| parent_id | bigint | - | 0 | 上级分类ID | 0或null表示顶级，树形层级结构 |
| depreciation_method | varchar(30) | - | 'straight_line' | 折旧方法 | 枚举：straight_line(直线法)/accelerated(加速折旧)/double_declining(双倍余额递减)/sum_of_years(年数总和) |
| useful_life_months | int | - | - | 使用年限(月) | 该类资产的标准使用年限 |
| residual_rate | decimal(18,8) | - | 0.05 | 残值率 | 预计残值占原值的比率(如0.05表示5%) |
| sort_no | int | NOT NULL | 0 | 排序号 | 显示排序 |
| enable_flag | boolean | NOT NULL | true | 是否启用 | 启用状态 |

**扩展字段（所有业务表统一预留）**：

| 字段名 | 数据类型 | 说明 |
|--------|---------|------|

| ext_num1~ext_num5 | decimal(18,8) | 扩展数值字段 |
| ext_date1~ext_date3 | date | 扩展日期字段 |
| ext_bool1~ext_bool3 | boolean | 扩展布尔字段 |
| ext_json | jsonb | 扩展JSON字段 |

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| pk_fa_category | 主键 | id | 主键索引 |
| uk_fa_category_code | 部分唯一 | tenant_id, category_code WHERE is_deleted=false | 同租户分类编码唯一 |
| idx_fa_category_parent | 普通 | parent_id | 按上级查下级(树形查询) |

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |
|--------|---------|------|---------|
| 分类编码唯一 | 新增/修改 | 同tenant_id下is_deleted=false不能同编码 | "资产分类编码已存在" |
| 分类名称必填 | 新增/修改 | category_name非空 | "分类名称不能为空" |
| 循环引用检查 | 新增/修改 | parent_id不能指向自身或子孙分类 | "不能将分类设为自身或其子分类的下级" |
| 残值率范围 | 新增/修改 | residual_rate >= 0 AND residual_rate < 1 | "残值率需在0~1之间" |
| 删除前引用检查 | 删除 | fa_card.category_id无引用 | "该分类下存在资产卡片，无法删除" |

| original_value | decimal(18,8) | NOT NULL | 0 | 原值 | 处置时的资产原值 |
| accumulated_depreciation | decimal(18,8) | NOT NULL | 0 | 累计折旧 | 处置时的累计折旧 |
| net_value | decimal(18,8) | NOT NULL | 0 | 净值 | 处置时的净值 |
| proceeds | decimal(18,8) | - | 0 | 处置收入 | 处置获得的收入 |
| disposal_expense | decimal(18,8) | - | 0 | 处置费用 | 拆卸费、运输费、中介费等 |
| gain_loss | decimal(18,8) | - | 0 | 处置损益 | 计算公式：proceeds - disposal_expense - net_value |
| status | varchar(30) | NOT NULL | 'draft' | 状态 | 枚举：draft(草稿)/approved(已审核) |

**扩展字段**：同fa_category

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| pk_fa_disposal | 主键 | id | 主键索引 |
| idx_fa_disposal_card | 普通 | card_id | 按资产查处置记录 |
| idx_fa_disposal_status | 普通 | tenant_id, status | 按状态查询 |

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |
|--------|---------|------|---------|
| 资产卡片存在性 | 新增/修改 | card_id必须在fa_card中存在 | "资产卡片不存在" |
| 资产状态检查 | 新增 | 资产状态不能为disposed或scrapped | "该资产已处置" |
| 处置类型必填 | 新增/修改 | disposal_type非空 | "处置类型不能为空" |
| 删除前状态检查 | 删除 | status必须为draft | "已审核的处置单不可删除" |
| 审核后回写卡片 | 审核 | 审核通过后更新fa_card.status为disposed | - |

## 六、Service层业务逻辑规格

### 6.1 FaCategoryService

| getById(Long) | 无(只读) | 返回FaCategoryDetailVO |
| create(FaCategoryCreateDTO) | @Transactional | 编码引擎生成categoryCode → 循环引用检查 → save |

### 6.2 FaCardService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(FaCardQueryDTO) | 无(只读) | 支持categoryId + departmentId + status + keyword筛选 |
| getById(Long) | 无(只读) | 返回FaCardDetailVO，含categoryName/departmentName/custodianName |
| create(FaCardCreateDTO) | @Transactional | 分类/部门存在性校验 → 编码引擎生成assetCode → 自动计算depreciationStartDate(取得次月) → 初始化netValue=originalValue → save |
| update(id, FaCardUpdateDTO) | @Transactional | 存在性校验 → 状态校验(已处置不可改) → 乐观锁更新 |
| delete(Long) | @Transactional | 存在性校验 → 状态校验(仅in_use/draft可删) → 折旧/变动/处置记录检查 → 逻辑删除 |

### 6.3 FaDepreciationService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(FaDepreciationQueryDTO) | 无(只读) | 支持periodId + status筛选 |
| getById(Long) | 无(只读) | 返回FaDepreciationDetailVO含明细行 |
| calculate(periodId) | @Transactional | 检查期间唯一性 → 遍历所有in_use状态资产 → 按折旧方法计算本期折旧额 → 生成明细行 → 汇总totalDepreciation → save主表+明细 → 生成折旧凭证 |
| delete(Long) | @Transactional | 状态校验(仅draft可删) → 删除明细 → 逻辑删除主表 |
