### 5.1 新增流程
1. 父页面[新增]→打开弹窗(mode='create')
2. 表单初始化空+默认值
3. 填写→校验+联动
4. [保存]→formRef.validate()→api.create(form)
5. 成功→ElMessage.success+close()+emit('refresh')
6. 失败→定位错误字段

### 5.2 错误处理
- 字段校验：滚动到第一个错误
- 400：字段错误
- 409：编号已存在
- 500：系统异常
