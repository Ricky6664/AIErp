### 5.1 注解规范

```java
@RestController
@Tag(name = "固定资产-Asset管理", description = "Asset相关接口")
public class AssetController {

    @PostMapping("/create")
    @Operation(summary = "创建Asset", description = "创建新的Asset记录")
    public Result<AssetVO> create(
        @RequestBody @Valid @Parameter(description = "创建参数") AssetCreateDTO dto) {
        ...
    }
}

@Data
public class AssetCreateDTO {
    @Schema(description = "编号", example = "EXP202605260001", required = true)
    @NotBlank private String code;
}
```

### 5.2 必加注解
- 类@Tag(name, description)
- 方法@Operation(summary, description)
- 参数@Parameter
- 字段@Schema(description, example, required)
