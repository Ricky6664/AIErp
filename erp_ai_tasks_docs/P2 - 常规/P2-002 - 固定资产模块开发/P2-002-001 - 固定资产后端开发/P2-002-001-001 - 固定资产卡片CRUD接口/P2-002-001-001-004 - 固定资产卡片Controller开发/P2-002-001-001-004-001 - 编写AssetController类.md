### 5.1 Controller类

```java
@Slf4j
@RestController
@RequestMapping("/api/asset/asset")
@Tag(name = "固定资产-Asset管理")
public class AssetController {

    @Autowired private AssetService assetService;

    @PostMapping("/create")
    @Operation(summary = "创建Asset")
    public Result<AssetVO> create(@RequestBody @Valid AssetCreateDTO dto) {
        return Result.success(assetService.create(dto));
    }

    @PutMapping("/update")
    @Operation(summary = "修改Asset")
    public Result<Boolean> update(@RequestBody @Valid AssetUpdateDTO dto) {
        return Result.success(assetService.update(dto));
    }

    @DeleteMapping("/delete/{id}")
    @Operation(summary = "删除Asset")
    public Result<Boolean> delete(@PathVariable Long id) {
        return Result.success(assetService.delete(id));
    }

    @GetMapping("/page")
    @Operation(summary = "分页查询Asset")
    public Result<Page<AssetListVO>> page(AssetQueryDTO query) {
        return Result.success(assetService.getPage(query));
    }

    @GetMapping("/detail/{id}")
    @Operation(summary = "Asset详情")
    public Result<AssetVO> detail(@PathVariable Long id) {
        return Result.success(assetService.getDetail(id));
    }
}
```

### 5.2 规范
- 路径/asset/{resource}全小写-分隔
- 统一Result<T>
- @Tag/@Operation完整
- @Valid触发校验
