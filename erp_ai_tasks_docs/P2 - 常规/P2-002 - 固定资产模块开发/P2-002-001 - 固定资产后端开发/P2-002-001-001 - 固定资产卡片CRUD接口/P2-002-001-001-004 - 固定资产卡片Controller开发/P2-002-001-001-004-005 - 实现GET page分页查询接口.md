## 五、详细开发规格

> **本任务模块上下文**
> - 涉及数据表：fa_card(资产卡片表), fa_depreciation(折旧计提表), fa_depreciation_detail(折旧明细), fa_change(资产变动表), fa_disposal(资产处置表), fa_asset_disposal_detail(处置明细)
> - 涉及API：/api/fa/card/*, /api/fa/depreciation/*, /api/fa/change/*, /api/fa/disposal/*, /api/fa/report/*
### 5.1 接口
- URL: GET /api/asset/asset/page
- Query: pageNum/pageSize/code/name/status/startDate/endDate/sortField/sortOrder
- 响应: Result<Page<AssetListVO>>

### 5.2 响应示例
```json
{"code": 200, "data": {"records": [{"id": 1, "code": "EXP001", "status": 0, "statusName": "草稿"}], "total": 100, "pageNum": 1, "pageSize": 20}}
```

### 5.3 处理流程
1. QueryWrapperX动态条件
2. LIKE '%xxx%'
3. between日期范围
4. 默认createTime DESC
5. page()分页
6. 批量翻译字典/关联
