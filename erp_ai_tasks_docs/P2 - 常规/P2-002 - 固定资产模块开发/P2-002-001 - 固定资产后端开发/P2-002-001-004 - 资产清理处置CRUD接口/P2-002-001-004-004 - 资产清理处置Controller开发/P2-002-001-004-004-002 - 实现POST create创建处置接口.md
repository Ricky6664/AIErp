## 五、详细开发规格

> **本任务模块上下文**
> - 涉及数据表：fa_card(资产卡片表), fa_depreciation(折旧计提表), fa_depreciation_detail(折旧明细), fa_change(资产变动表), fa_disposal(资产处置表), fa_asset_disposal_detail(处置明细)
> - 涉及API：/api/fa/card/*, /api/fa/depreciation/*, /api/fa/change/*, /api/fa/disposal/*, /api/fa/report/*
### 5.1 接口
- URL: POST /api/asset/asset/create
- Content-Type: application/json
- 请求体: AssetCreateDTO(@Valid)
- 响应: Result<AssetVO>

### 5.2 请求示例
```json
{"code": "EXP202605260001", "name": "示例", "deptId": 1001, "bizDate": "2026-05-26", "amount": 1500.00, "details": [{"materialId": 1, "quantity": 2, "unitPrice": 750.00}]}
```

### 5.3 响应示例
```json
{"code": 200, "message": "success", "data": {"id": 1234567890, "code": "EXP202605260001", "status": 0, "statusName": "草稿"}}
```

### 5.4 处理流程
1. @Valid触发校验(缺必填返400)
2. 编号唯一性校验(重复返409)
3. DTO→Entity(MapStruct)
4. 编号生成(CodeGeneratorService)
5. 公共字段填充(createBy/tenantId/isDeleted=0)
6. save()获取主键
7. 保存明细(mainId=主表.id)
8. 返回新建VO
