## 五、详细开发规格

> **本任务模块上下文**
> - 涉及数据表：fa_card(资产卡片表), fa_depreciation(折旧计提表), fa_depreciation_detail(折旧明细), fa_change(资产变动表), fa_disposal(资产处置表), fa_asset_disposal_detail(处置明细)
> - 涉及API：/api/fa/card/*, /api/fa/depreciation/*, /api/fa/change/*, /api/fa/disposal/*, /api/fa/report/*
### 5.1 接口
- URL: GET /api/asset/asset/detail/{id}
- 响应: Result<AssetVO>(含明细)

### 5.2 处理流程
1. getById(id)主表
2. 校验存在
3. selectByMainId明细
4. 翻译字典+关联
5. 组装完整VO返回
