### 5.1 SQL示例

```sql
SELECT
    d.name AS dept_name,
    ei.name AS expense_item_name,
    SUM(r.amount) AS total_amount,
    COUNT(r.id) AS record_count
FROM expense_expense r
JOIN sys_dept d ON r.dept_id = d.id
WHERE r.is_deleted = 0
  AND r.status = 2
  AND r.biz_date BETWEEN :startDate AND :endDate
  AND r.tenant_id = :tenantId
GROUP BY d.id, ei.id
ORDER BY total_amount DESC
```

### 5.2 性能优化
- 确保biz_date/dept_id/status有索引
- 大数据量分页或限制时间范围
- EXPLAIN查看执行计划
