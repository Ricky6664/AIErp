## 五、详细开发规格

> **本任务模块上下文**
> - 涉及数据表：expense_budget(费用预算单), expense_budget_detail(预算明细), expense_application(费用申请单), expense_application_detail(申请明细), expense_reimbursement(费用报销单), expense_reimbursement_detail(报销明细)
> - 涉及API：/api/expense/claim/*, /api/expense/application/*, /api/expense/budget/*, /api/expense/budget/execution/*
### 5.1 接口
- URL: GET /api/expense/expense/page
- Query: pageNum/pageSize/code/name/status/startDate/endDate/sortField/sortOrder
- 响应: Result<Page<ExpenseListVO>>

### 5.2 响应示例
```json
{"code": 200, "data": {"records": [{"id": 1, "code": "EXP001", "status": 0, "statusName": "草稿"}], "total": 100, "pageNum": 1, "pageSize": 20}}
```

### 5.3 处理流程
1. QueryWrapperX动态条件
2. LIKE '%xxx%'
3. between日期范围
4. 默认createTime DESC
5. page()分页
6. 批量翻译字典/关联
