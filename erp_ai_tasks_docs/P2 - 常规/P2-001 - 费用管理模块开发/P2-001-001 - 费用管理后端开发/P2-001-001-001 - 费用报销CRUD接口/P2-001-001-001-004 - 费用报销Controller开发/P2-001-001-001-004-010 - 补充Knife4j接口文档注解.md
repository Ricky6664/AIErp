### 5.1 注解规范

```java
@RestController
@Tag(name = "费用管理-Expense管理", description = "Expense相关接口")
public class ExpenseController {

    @PostMapping("/create")
    @Operation(summary = "创建Expense", description = "创建新的Expense记录")
    public Result<ExpenseVO> create(
        @RequestBody @Valid @Parameter(description = "创建参数") ExpenseCreateDTO dto) {
        ...
    }
}

@Data
public class ExpenseCreateDTO {
    @Schema(description = "编号", example = "EXP202605260001", required = true)
    @NotBlank private String code;
}
```

### 5.2 必加注解
- 类@Tag(name, description)
- 方法@Operation(summary, description)
- 参数@Parameter
- 字段@Schema(description, example, required)
