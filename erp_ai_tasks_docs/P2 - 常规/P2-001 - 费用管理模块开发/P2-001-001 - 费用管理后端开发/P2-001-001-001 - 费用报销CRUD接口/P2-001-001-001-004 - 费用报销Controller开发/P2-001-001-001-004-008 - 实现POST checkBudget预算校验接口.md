### 5.1 接口
- URL: POST /api/expense/expense/checkBudget
- 请求:
```json
{"deptId": 1001, "period": "2026-05", "expenseItemId": 2001, "amount": 5000.00}
```
- 响应:
```json
{"code": 200, "data": {"budgetAmount": 100000, "usedAmount": 85000, "availableAmount": 15000, "executionRate": 90.0, "exceed": false, "warning": "执行率已达90%"}}
```

### 5.2 计算
1. 预算表查预算总额
2. 已审核报销+审核中申请合计
3. 可用 = 预算 - 已发生
4. 执行率 = 已发生/预算 ×100%
5. >80%黄/>100%红
