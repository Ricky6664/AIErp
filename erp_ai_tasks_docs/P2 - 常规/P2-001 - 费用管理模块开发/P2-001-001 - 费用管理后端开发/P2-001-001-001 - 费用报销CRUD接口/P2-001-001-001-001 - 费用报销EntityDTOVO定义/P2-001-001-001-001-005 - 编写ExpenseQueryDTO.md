### 5.1 QueryDTO定义

```java
@Data
public class ExpenseQueryDTO extends PageDTO {
    @Schema(description = "编号(模糊)") private String code;
    @Schema(description = "名称(模糊)") private String name;
    @Schema(description = "状态") private Integer status;
    @Schema(description = "开始日期") @DateTimeFormat(pattern = "yyyy-MM-dd") private LocalDate startDate;
    @Schema(description = "结束日期") @DateTimeFormat(pattern = "yyyy-MM-dd") private LocalDate endDate;
    @Schema(description = "部门ID") private Long deptId;
    @Schema(description = "排序字段") private String sortField;
    @Schema(description = "排序方式") private String sortOrder;
}
```

### 5.2 查询条件
- 编号/名称LIKE '%xxx%'
- 日期between
- 多字段排序
- PageDTO默认pageNum=1, pageSize=20, 最大100
