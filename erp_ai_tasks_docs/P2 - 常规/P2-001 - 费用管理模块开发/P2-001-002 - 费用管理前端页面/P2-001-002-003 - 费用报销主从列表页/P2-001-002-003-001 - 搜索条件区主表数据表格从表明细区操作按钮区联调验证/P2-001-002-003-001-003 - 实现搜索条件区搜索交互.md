### 5.1 交互逻辑
```typescript
const searchForm = reactive({ code: '', status: null, dateRange: [] })
let searchTimer: any = null

const handleSearch = () => {
  clearTimeout(searchTimer)
  searchTimer = setTimeout(() => {
    emit('search', { ...searchForm, pageNum: 1 })
  }, 300)
}

const handleReset = () => {
  Object.assign(searchForm, { code: '', status: null, dateRange: [] })
  handleSearch()
}
```

### 5.2 要点
- 防抖300ms
- 搜索时pageNum=1
- 重置清空并触发搜索
- URL参数同步
