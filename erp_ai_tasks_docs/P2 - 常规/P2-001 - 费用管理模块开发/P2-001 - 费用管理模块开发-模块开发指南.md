# P2-001 费用管理模块开发 - 模块开发指南

## 一、模块概述
- **模块定位**：完成费用报销与费用预算管理，包含费用预算单、费用申请单、费用报销单的全流程CRUD，以及费用预算执行率查询与费用统计报表
- **前置依赖**：P0-011（财务基础）、P1-001（审核引擎）
- **被依赖方**：无
- **开发阶段**：阶段九

## 六、Service层业务逻辑规格

### 6.1 ExpenseBudgetService

| 方法 | 事务 | 业务逻辑要点 |
|------|------|------------|
| page(ExpenseBudgetQueryDTO) | 无(只读) | 支持departmentId + budgetYear + status筛选 + keyword模糊搜索 |
| getById(Long) | 无(只读) | 返回ExpenseBudgetDetailVO，含明细行及departmentName |
| create(ExpenseBudgetCreateDTO) | @Transactional | 部门存在性校验 → 编码引擎生成orderNo → 计算totalAmount → 主表save → 明细行batchSave(自动编排lineNo) → 操作日志 |
| update(id, ExpenseBudgetUpdateDTO) | @Transactional | 存在性校验 → 状态校验(仅draft可改) → 重新计算totalAmount → 乐观锁更新主表 → 删除旧明细 → 重新插入新明细 → 操作日志 |
| delete(Long) | @Transactional | 存在性校验 → 状态校验(仅draft可删) → 删除明细 → 逻辑删除主表 → 操作日志 |

### 6.2 ExpenseApplicationService
