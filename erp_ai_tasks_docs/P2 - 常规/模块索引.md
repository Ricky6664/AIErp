# P2 常规 - 模块索引

> 本文档为P2级模块的入口索引。具体开发细节请进入各模块目录查阅模块开发指南。

## 本优先级定位

P2为常规模块，包含扩展业务（费用/资产/期末/样品/借用/租赁/售后）、系统完善（OA/AI/模板/报表/期初/运维/多语言/仪表盘/移动端）等17个模块。依赖P1核心业务链路。共17个模块、1,107个叶子任务。
