## 五、详细开发规格

> **本任务模块上下文**
> - 数据表：oa_announcement（公告表）
> - 专属字段：title, content(TEXT), publish_date, expire_date, is_top, status(0草稿/1已发布/2已过期)
> - 公共字段：id, created_by, created_at, updated_by, updated_at, is_deleted, tenant_id, version
> - API基础路径：/api/oa/announcement

### 5.1 create 方法
- 接收 `OaAnnouncementCreateDTO`，字段：title(NotBlank), content(NotBlank,TEXT), expire_date, is_top
- 创建时 status 默认为 0(draft)，publish_date 为 null
- DTO -> Entity 转换，设置 created_by=StpUtil.getLoginIdAsLong()
- 调用 `oaAnnouncementMapper.insert(entity)` 返回 VO

### 5.2 update 方法
- 仅 status=0(draft) 的公告允许修改，否则抛 BusinessException(422, "已发布公告不可修改")
- 乐观锁：WHERE id=? AND version=?
- 校验记录存在且 is_deleted=false

### 5.3 delete 方法
- 软删除：UPDATE oa_announcement SET is_deleted=1 WHERE id=?
- 已发布公告建议先撤回再删除

### 5.4 getPage 方法
- 查询字段：title(模糊), status, is_top, publish_date(范围)
- 排序规则：is_top DESC, publish_date DESC（置顶公告优先）
- 定时任务扫描 expire_date < now() 的记录自动设置 status=2(expired)

### 5.5 getDetail 方法
- 查询完整 Entity -> VO 转换
- 包含创建人姓名（关联 sys_user 表）

### 5.6 publish/withdraw 方法（专属）
- publish：校验 status==0 -> SET status=1, publish_date=NOW()
- withdraw：校验 status==1 -> SET status=0, publish_date=NULL
- 状态流转：draft(0) -> published(1) -> expired(2)

### 5.7 错误码规范
- 400: 参数错误（@Valid 校验失败）
- 404: 记录不存在
- 409: 资源冲突（如时间冲突、唯一性冲突）
- 422: 业务规则不允许（如状态不允许操作、余额不足）
- 500: 服务端异常

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ @TableField 注解勿遗漏，特别是 created_at/updated_at 自动填充

> ⚠️ 事务边界准确避免大事务，仅在写操作加 @Transactional

> ⚠️ 异常统一使用 BusinessException，禁止抛出 RuntimeException

> ⚠️ [公告] 已发布(status=1)公告不可修改/删除，需先撤回

> ⚠️ [公告] expire_date 过期自动处理需定时任务配合
