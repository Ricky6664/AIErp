### 5.5 必加注解清单
- 类 `@Tag(name, description)` -- name 格式：`OA办公-公告管理`
- 方法 `@Operation(summary, description)` -- summary 简明，description 含业务规则
- 参数 `@Parameter(description)` -- 路径参数和查询参数
- 字段 `@Schema(description, example, required)` -- example 使用业务真实样例值，禁止中文

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ @Schema example 禁止使用中文，使用英文/数字/拼音

> ⚠️ @Tag name 格式必须为 `OA办公-公告管理`，禁止使用泛型名称

> ⚠️ example 值需符合字段类型（日期用 ISO 格式、数字用数字字符串）

> ⚠️ [公告] publish/withdraw 的 @Operation description 需说明状态流转规则

> ⚠️ [公告] content 字段为 TEXT 类型，@Schema 需注明
