## 五、详细开发规格

> **本任务模块上下文**
> - 数据表：oa_meeting_room（会议室表）
> - 专属字段：room_name, room_code, floor, capacity, equipment(JSON), enable_flag
> - 公共字段：id, created_by, created_at, updated_by, updated_at, is_deleted, tenant_id, version
> - API基础路径：/api/oa/meeting-room

### 5.1 create 方法
- 接收 `OaMeetingRoomCreateDTO`，字段：roomName(NotBlank), floor, capacity(NotNull,Min=1), equipment(JSON List), enableFlag
- **唯一性校验**：查询同 tenant_id 下 room_name 是否重复，重复抛 BusinessException(409, "会议室名称已存在")
- room_code 由编码引擎自动生成，格式：MR-{floor}-{seq}，如 MR-3-001
- 调用 `oaMeetingRoomMapper.insert(entity)` 返回 VO

### 5.2 update 方法
- room_name 修改需重新校验唯一性（排除自身 ID）
- room_code 不可修改
- 乐观锁：WHERE id=? AND version=?

### 5.3 delete 方法
- **关联约束**：查询 oa_meeting WHERE meeting_room_id=? AND status NOT IN (2,3)（非已完成/已取消），存在记录抛 BusinessException(422, "该会议室存在未结束的会议，不可删除")
- 软删除：UPDATE oa_meeting_room SET is_deleted=1

### 5.4 getPage 方法
- 查询字段：roomName(模糊), floor, capacity(>=), enableFlag
- 默认按 floor ASC, room_code ASC 排序

### 5.5 getDetail 方法
- 查询完整 Entity -> VO
- equipment 字段从 JSON 解析为 List<String>

### 5.6 getAvailableSlots 方法（专属）
- 参数：date（yyyy-MM-dd）
- 查询指定日期所有会议室的已预订时段
- 生成 08:00-20:00 的半小时时间槽，标记已被占用的时段
- 返回每个会议室的可用时段列表

### 5.7 错误码规范
- 400: 参数错误（@Valid 校验失败）
- 404: 记录不存在
- 409: 资源冲突（如时间冲突、唯一性冲突）
- 422: 业务规则不允许（如状态不允许操作、余额不足）
- 500: 服务端异常

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ @TableField 注解勿遗漏，特别是 created_at/updated_at 自动填充

> ⚠️ 事务边界准确避免大事务，仅在写操作加 @Transactional

> ⚠️ 异常统一使用 BusinessException，禁止抛出 RuntimeException

> ⚠️ [会议室] room_name 在 tenant_id 下必须唯一

> ⚠️ [会议室] 删除前检查是否有关联的未完成会议
