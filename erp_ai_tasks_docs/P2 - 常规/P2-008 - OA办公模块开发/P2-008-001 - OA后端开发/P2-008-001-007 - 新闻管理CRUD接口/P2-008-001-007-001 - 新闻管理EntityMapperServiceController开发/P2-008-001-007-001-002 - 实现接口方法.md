## 五、详细开发规格

> **本任务模块上下文**
> - 数据表：oa_news（新闻表）
> - 专属字段：title, category, content(富文本), cover_image, is_top, publish_date, status
> - 公共字段：id, created_by, created_at, updated_by, updated_at, is_deleted, tenant_id, version
> - API基础路径：/api/oa/news

### 5.1 create 方法
- 接收 `OaNewsCreateDTO`，字段：title(NotBlank), category(NotBlank,枚举:company/industry/notice), content(NotBlank,富文本HTML), coverImage(URL), isTop
- **XSS 过滤**：content 字段使用 Jsoup.clean() 过滤危险 HTML 标签/script
- cover_image 由前端上传至 MinIO，此处存储返回的 URL
- status 默认 0(draft)，publish_date 为 null

### 5.2 update 方法
- 仅 status=0(draft) 允许修改，已发布新闻需先下线
- content 同样执行 XSS 过滤
- 乐观锁：WHERE id=? AND version=?

### 5.3 delete 方法
- 软删除：UPDATE oa_news SET is_deleted=1 WHERE id=?
- 已发布新闻建议先下线再删除

### 5.4 getPage 方法
- 查询字段：title(模糊), category, status, isTop, publishDate(范围)
- 排序：is_top DESC, publish_date DESC
- category 含义：company(公司动态), industry(行业资讯), notice(通知公告)

### 5.5 getDetail 方法
- 查询完整 Entity -> VO
- 包含创建人姓名、cover_image 完整 URL
- content 字段返回过滤后的安全 HTML

### 5.6 publish/offline 方法（专属）
- publish：校验 status==0 -> SET status=1, publish_date=NOW()
- offline：校验 status==1 -> SET status=2
- 状态流转：draft(0) -> published(1) -> offline(2)

### 5.7 错误码规范
- 400: 参数错误（@Valid 校验失败）
- 404: 记录不存在
- 409: 资源冲突（如时间冲突、唯一性冲突）
- 422: 业务规则不允许（如状态不允许操作、余额不足）
- 500: 服务端异常

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ @TableField 注解勿遗漏，特别是 created_at/updated_at 自动填充

> ⚠️ 事务边界准确避免大事务，仅在写操作加 @Transactional

> ⚠️ 异常统一使用 BusinessException，禁止抛出 RuntimeException

> ⚠️ [新闻] content 富文本必须 XSS 过滤（Jsoup.clean）

> ⚠️ [新闻] cover_image URL 来自 MinIO 上传，不可直接接收文件
