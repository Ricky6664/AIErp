### 5.4 CreateDTO @Schema 注解示例

```java
@Data
public class OaNewsCreateDTO {
    @Schema(description = "新闻标题", example = "公司荣获2026年度创新企业奖", required = true)
    @NotBlank private String title;

    @Schema(description = "分类：company公司动态/industry行业资讯/notice通知公告", example = "company", required = true)
    @NotBlank private String category;

    @Schema(description = "新闻内容(富文本HTML,需XSS过滤)", example = "<p>2026年5月25日，我司在...</p>", required = true)
    @NotBlank private String content;

    @Schema(description = "封面图URL(MinIO上传返回)", example = "https://minio.example.com/news/cover-001.jpg")
    private String coverImage;

    @Schema(description = "是否置顶：0否/1是", example = "0")
    private Integer isTop;
}
```

### 5.5 必加注解清单
- 类 `@Tag(name, description)` -- name 格式：`OA办公-新闻管理`
- 方法 `@Operation(summary, description)` -- summary 简明，description 含业务规则
- 参数 `@Parameter(description)` -- 路径参数和查询参数
- 字段 `@Schema(description, example, required)` -- example 使用业务真实样例值，禁止中文

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ @Schema example 禁止使用中文，使用英文/数字/拼音

> ⚠️ @Tag name 格式必须为 `OA办公-新闻管理`，禁止使用泛型名称

> ⚠️ example 值需符合字段类型（日期用 ISO 格式、数字用数字字符串）

> ⚠️ [新闻] content 字段需注明 XSS 过滤要求

> ⚠️ [新闻] coverImage 为 MinIO URL，非文件上传字段
