# P2-008 OA办公模块开发 - 模块开发指南

## 一、模块概述
- **模块定位**：完成日程、公告、会议、用车、请假、新闻等OA办公功能，提供日常办公协同能力
- **前置依赖**：P0-004（用户/权限）、P1-002（审批流程）
- **被依赖方**：无
- **开发阶段**：阶段十

## 四、数据表完整字段定义

> 以下字段定义为开发时的唯一权威来源。所有DDL/Entity/Mapper任务必须严格遵照此定义。

**通用必含字段**：同oa_car（10个，通过继承BaseEntity获取）

**业务字段**：

| 字段名 | 数据类型 | 约束 | 默认值 | 中文标题 | 说明 |

**业务校验规则**：

| 校验项 | 校验时机 | 规则 | 错误提示 |
|--------|---------|------|---------|

| 总天数非负 | 新增/修改 | total_days >= 0 | "总天数不能为负" |
| 更新机制 | 请假审核/反审 | 审核时扣减used_days、更新remaining_days；反审时回补 | - |
