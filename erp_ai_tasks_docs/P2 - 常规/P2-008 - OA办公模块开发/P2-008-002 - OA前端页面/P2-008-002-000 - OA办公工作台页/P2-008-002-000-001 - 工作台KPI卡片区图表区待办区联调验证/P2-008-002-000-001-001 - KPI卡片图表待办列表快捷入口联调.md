## 五、详细开发规格

> **本任务模块上下文**
> - 涉及数据表：oa_schedule(日程表), oa_announcement(公告表), oa_meeting(会议表), oa_meeting_room(会议室表), oa_vehicle(用车申请表), oa_leave(请假申请表), oa_news(新闻表)
> - 涉及API：GET /api/oa/dashboard/kpi

### 5.1 KPI卡片区（4张卡片）

| 卡片名称 | 数据来源字段 | 图标 | 颜色 |
|---------|------------|------|------|
| 待审批数 | kpiData.pendingApprovalCount | el-icon-document-checked | #E6A23C(橙) |
| 本月日程数 | kpiData.monthScheduleCount | el-icon-calendar | #409EFF(蓝) |
| 未读公告数 | kpiData.unreadAnnouncementCount | el-icon-bell | #F56C6C(红) |
| 待处理请假数 | kpiData.pendingLeaveCount | el-icon-suitcase | #67C23A(绿) |

每张卡片结构：图标 + 数值 + 标签名 + 点击跳转对应列表页

### 5.2 图表区（ECharts）

| 图表名称 | 图表类型 | 数据来源 | 说明 |
|---------|---------|---------|------|
| 月度日程统计 | 柱状图(bar) | kpiData.monthlyScheduleChart | X轴=日期, Y轴=日程数量, 显示当月每日日程数 |
| 请假类型分布 | 饼图(pie) | kpiData.leaveTypePieChart | 按leaveType分组统计占比(年假/事假/病假/婚假/产假/丧假) |

- ECharts实例需要在onMounted后初始化
- 窗口resize时调用chart.resize()
- 组件卸载时dispose图表实例

### 5.3 待办列表（前5条）

| 待办类型 | 展示内容 | 点击行为 |
|---------|---------|---------|
| 即将开始的会议 | 会议主题+开始时间+会议室 | 跳转会议详情 |
| 待处理的用车申请 | 申请人+目的地+状态 | 跳转用车审批 |
| 即将到期的日程 | 日程标题+截止时间 | 跳转日程编辑 |

API: GET /api/oa/dashboard/todo?limit=5

### 5.4 快捷入口

| 入口名称 | 图标 | 路由跳转 |
|---------|------|---------|
| 新建日程 | el-icon-plus | /oa/schedule?action=create |
| 新建公告 | el-icon-document-add | /oa/announcement?action=create |
| 新建请假 | el-icon-edit | /oa/leave?action=create |

### 5.5 API接口

```typescript
// GET /api/oa/dashboard/kpi 响应结构
interface DashboardKpiVO {
  pendingApprovalCount: number    // 待审批数
  monthScheduleCount: number      // 本月日程数
  unreadAnnouncementCount: number // 未读公告数
  pendingLeaveCount: number       // 待处理请假数
  monthlyScheduleChart: Array<{ date: string; count: number }>
  leaveTypePieChart: Array<{ type: string; count: number }>
}

// GET /api/oa/dashboard/todo 响应结构
interface TodoItemVO {
  id: number
  type: 'meeting' | 'vehicle' | 'schedule'
  title: string
  subtitle: string
  link: string
  createTime: string
}
```

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ KPI接口使用缓存策略(5分钟内不重复请求)，避免频繁刷新导致后端压力

> ⚠️ ECharts实例必须在组件卸载时dispose，避免内存泄漏

> ⚠️ 待办列表数据按需加载，不要一次拉取全部待办事项

> ⚠️ 快捷入口路由路径必须与router配置完全一致，避免404

> ⚠️ 窗口resize监听需要在onUnmounted中移除，防止事件泄漏

> ⚠️ [OA模块] 请假天数计算排除周末和节假日

> ⚠️ [OA模块] 会议室预订校验时间冲突(同会议室同时段)

> ⚠️ [OA模块] 假期余额校验(已用+本次≤总额)
