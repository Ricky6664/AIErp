### 5.1 字段组件映射

| 字段名 | 组件 | 关键属性 | 说明 |
|--------|------|---------|------|
| title | el-input | placeholder="请输入公告标题关键字", clearable, maxlength=100 | 公告标题关键字搜索 |
| status | el-select | placeholder="全部状态", clearable, 字典:announcement_status | 发布状态筛选 |
| publishDateRange | el-date-picker | type="daterange", value-format="YYYY-MM-DD", range-separator="至" | 发布日期范围 |

### 5.2 字典加载

```typescript
import { useDictStore } from '@/store/dict'

const dictStore = useDictStore()
const statusOptions = ref<DictItem[]>([])

onMounted(async () => {
  // 公告状态字典: announcement_status
  // 值: draft(草稿), published(已发布), expired(已过期)
  statusOptions.value = await dictStore.getDictItems('announcement_status')
})
```

### 5.3 各字段渲染细节

**title (el-input)**
- 类型：文本输入框
- 输入防抖：通过@input事件配合lodash.debounce实现300ms防抖
- 回车搜索：@keyup.enter绑定handleSearch
- 清空：clearable属性，点击清空图标自动触发搜索

**status (el-select)**
- 选项来源：dictApi.getDictItems('announcement_status')
- 选项列表：
  - { label: '草稿', value: 'draft' }
  - { label: '已发布', value: 'published' }
  - { label: '已过期', value: 'expired' }
- clearable: 清空选中后自动触发搜索

**publishDateRange (el-date-picker)**
- type="daterange"
- value-format="YYYY-MM-DD"
- range-separator="至"
- start-placeholder="开始日期"
- end-placeholder="结束日期"
- 选择日期范围后自动触发搜索(@change)
- shortcuts快捷选项：最近一周、最近一个月、最近三个月

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ 字典使用dictStore/dictApi统一接口获取，不要硬编码选项

> ⚠️ el-select务必设置clearable，否则选中后无法清空

> ⚠️ el-date-picker的value-format必须与后端接口期望格式一致(YYYY-MM-DD)

> ⚠️ [OA模块] 公告状态值draft/published/expired需与后端枚举严格匹配
