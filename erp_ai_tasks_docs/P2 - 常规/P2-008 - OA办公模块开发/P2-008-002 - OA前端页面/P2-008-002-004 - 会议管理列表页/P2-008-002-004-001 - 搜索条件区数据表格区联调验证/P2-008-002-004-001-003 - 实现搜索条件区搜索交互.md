### 5.1 交互逻辑

```typescript
import { debounce } from 'lodash-es'

const searchForm = reactive({
  title: '',
  meetingRoomId: null as number | null,
  organizerId: null as number | null,
  meetingDateRange: [] as string[],
  status: null as string | null
})

// title字段防抖搜索
const handleTitleInput = debounce(() => {
  handleSearch()
}, 300)

// 搜索：重置pageNum=1
const handleSearch = () => {
  const params = {
    title: searchForm.title || undefined,
    meetingRoomId: searchForm.meetingRoomId || undefined,
    organizerId: searchForm.organizerId || undefined,
    startDate: searchForm.meetingDateRange?.[0] || undefined,
    endDate: searchForm.meetingDateRange?.[1] || undefined,
    status: searchForm.status || undefined,
    pageNum: 1
  }
  emit('search', params)
  syncUrlParams(params)
}

// 重置
const handleReset = () => {
  Object.assign(searchForm, {
    title: '',
    meetingRoomId: null,
    organizerId: null,
    meetingDateRange: [],
    status: null
  })
  handleSearch()
}

// URL参数同步
const syncUrlParams = (params: Record<string, any>) => {
  const query: Record<string, string> = {}
  if (params.title) query.title = params.title
  if (params.meetingRoomId) query.meetingRoomId = String(params.meetingRoomId)
  if (params.organizerId) query.organizerId = String(params.organizerId)
  if (params.startDate) query.startDate = params.startDate
  if (params.endDate) query.endDate = params.endDate
  if (params.status) query.status = params.status
  router.replace({ query })
}
```

### 5.2 各字段触发方式

| 字段 | 触发方式 | 说明 |
|------|---------|------|
| title | 输入防抖300ms + 回车键 | 文本输入，防抖避免频繁请求 |
| meetingRoomId | @change即触发 | 下拉选择变化即搜索 |
| organizerId | @change即触发 | UserSelector选中即搜索 |
| meetingDateRange | @change即触发 | 日期范围选择后自动搜索 |
| status | @change即触发 | 下拉选择变化即搜索 |

### 5.3 URL参数同步字段

| URL参数 | 对应表单字段 | 类型 |
|---------|------------|------|
| title | searchForm.title | string |
| meetingRoomId | searchForm.meetingRoomId | number |
| organizerId | searchForm.organizerId | number |
| startDate | meetingDateRange[0] | string |
| endDate | meetingDateRange[1] | string |
| status | searchForm.status | string |

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ 防抖300ms使用lodash-es的debounce，组件卸载时cancel

> ⚠️ 搜索时务必重置pageNum=1

> ⚠️ meetingRoomId和organizerId在URL中存储ID值(字符串)，页面加载时需要Number()转换

> ⚠️ meetingDateRange重置时清空为[]而非null

> ⚠️ [OA模块] 会议搜索title为模糊匹配(like)
