### 5.2 会议室选项加载

```typescript
const roomOptions = ref<MeetingRoomOption[]>([])

onMounted(async () => {
  // 从会议室API获取可选会议室列表
  const res = await meetingRoomApi.getOptions()
  roomOptions.value = res.data.map((room: any) => ({
    id: room.id,
    roomName: room.roomName,
    capacity: room.capacity
  }))
})

interface MeetingRoomOption {
  id: number
  roomName: string
  capacity: number
}
```

### 5.3 状态字典加载

```typescript
const dictStore = useDictStore()
const statusOptions = ref<DictItem[]>([])

onMounted(async () => {
  // 会议状态字典: meeting_status
  // 值: pending(待开始), ongoing(进行中), completed(已结束), cancelled(已取消)
  statusOptions.value = await dictStore.getDictItems('meeting_status')
})
```

### 5.4 UserSelector配置

```vue
<UserSelector
  v-model="searchForm.organizerId"
  placeholder="请选择组织者"
  clearable
  :multiple="false"
  :show-dept="true"
/>
```

- UserSelector为全局注册的业务选择器组件
- 支持按姓名/工号模糊搜索
- 选中后显示用户姓名，存储用户ID
- clearable: 清空选中后自动触发搜索

### 5.5 el-date-picker配置

- type="daterange"
- value-format="YYYY-MM-DD"
- range-separator="至"
- start-placeholder="开始日期"
- end-placeholder="结束日期"
- shortcuts: 最近一周、最近一个月、最近三个月

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ 会议室选项使用meeting-room/options API，不使用字典接口

> ⚠️ UserSelector组件需要在项目中全局注册或通过auto-import引入

> ⚠️ el-select务必设置clearable和filterable(会议室可能较多)

> ⚠️ [OA模块] 会议状态值pending/ongoing/completed/cancelled需与后端枚举严格匹配
