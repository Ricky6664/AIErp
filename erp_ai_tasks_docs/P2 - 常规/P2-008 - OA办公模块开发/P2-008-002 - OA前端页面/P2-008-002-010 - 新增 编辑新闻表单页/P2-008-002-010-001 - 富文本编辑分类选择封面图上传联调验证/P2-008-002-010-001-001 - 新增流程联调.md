### 5.1 表单字段定义

| 字段名 | 组件类型 | 是否必填 | 校验规则 | 说明 |
|--------|---------|---------|---------|------|
| title | el-input | 是 | required, max 200字符 | 新闻标题 |
| category | el-select | 是 | required | 新闻分类(company/industry/notice) |
| content | TinyMCE(Editor) | 是 | required, HTML sanitize | 新闻正文(富文本编辑器) |
| coverImage | ImageUpload | 否 | — | 封面图(URL), 建议尺寸800x450 |

| publishDate | el-date-picker | 否 | — | 发布日期, 默认今天 |

### 5.2 新增流程

1. 新闻列表页点击[新增新闻]→路由跳转到/oa/news/create
2. 表单初始化：publishDate默认今天, isTop默认false, content为空(初始化TinyMCE)
3. 填写表单→实时校验
4. [发布]→formRef.validate()→调用newsApi.create(form)
5. 成功→ElMessage.success('新闻创建成功')+router.push('/oa/news')
6. [保存草稿]→设置status='draft'→调用同一API

### 5.5 内容校验(HTML sanitize)

```typescript
const validateContent = (rule: any, value: string, callback: any) => {
  if (!value || value === '<p><br></p>' || value.trim() === '') {
    callback(new Error('请输入新闻正文'))
    return
  }
  // 去除HTML标签后检查纯文本长度
  const plainText = value.replace(/<[^>]+>/g, '').trim()
  if (plainText.length < 10) {
    callback(new Error('新闻正文内容不能少于10个字符'))
  } else {
    callback()
  }
}
```

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ TinyMCE需要正确配置API Key或使用自托管版本

> ⚠️ TinyMCE图片上传需要配置images_upload_handler，默认不允许粘贴图片

> ⚠️ ImageUpload组件限制文件大小(5MB)和类型(jpeg/png/gif)

> ⚠️ content HTML内容需要后端sanitize防XSS，前端不做过滤

> ⚠️ 按钮loading防重复提交

> ⚠️ [OA模块] 新闻富文本中不允许嵌入外部链接(script/iframe标签)
