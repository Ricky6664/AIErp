## 五、详细开发规格

> **本任务模块上下文**
> - 涉及数据表：oa_news(新闻表)
> - 涉及API：GET /api/oa/news/detail/{id}, PUT /api/oa/news/update

### 5.1 编辑流程

1. 新闻列表页点击[编辑]→路由跳转到/oa/news/edit/{id}
2. 调用newsApi.detail(id)获取NewsDetailVO
3. 回填表单字段：
   - title ← detail.title
   - category ← detail.category
   - content ← detail.content (HTML字符串，需等TinyMCE初始化完成后setContent)
   - coverImage ← detail.coverImage (图片URL)
   - isTop ← detail.isTop (boolean)
   - publishDate ← detail.publishDate (YYYY-MM-DD)
   - version ← detail.version (隐藏域)

### 5.2 TinyMCE回填HTML内容

```typescript
// TinyMCE编辑器初始化后设置内容
const editorRef = ref<any>(null)

const loadDetail = async () => {
  const res = await newsApi.detail(newsId)
  const detail = res.data
  Object.assign(form, {
    title: detail.title,
    category: detail.category,
    content: detail.content,
    coverImage: detail.coverImage,
    isTop: detail.isTop,
    publishDate: detail.publishDate,
    version: detail.version
  })
  // TinyMCE异步初始化，需要等待就绪后setContent
  nextTick(() => {
    if (editorRef.value?.editor) {
      editorRef.value.editor.setContent(detail.content || '')
    }
  })
}
```

### 5.3 只读字段

| 字段 | 只读条件 | 说明 |
|------|---------|------|
| publishDate | status='published'时只读 | 已发布新闻不允许修改发布日期 |

### 5.4 封面图编辑

- 编辑模式下显示当前封面图预览
- 支持点击替换新图片
- 支持删除当前封面图(设置为null)

### 5.5 乐观锁处理

```typescript
const handleSave = async () => {
  await formRef.validate()
  // 从TinyMCE获取最新HTML内容
  form.content = editorRef.value?.editor?.getContent() || ''
  try {
    await newsApi.update({
      ...form,
      id: newsId,
      version: form.version
    })
    ElMessage.success('新闻更新成功')
    router.push('/oa/news')
  } catch (e: any) {
    if (e.status === 409) {
      ElMessage.warning('该新闻已被其他用户修改，请刷新后重试')
    }
  }
}
```

### 5.6 回填注意事项

- TinyMCE异步初始化：需要确保编辑器ready后再setContent，否则内容丢失
- content为HTML字符串，可能包含img标签(图片URL需确保可访问)
- coverImage为图片URL，ImageUpload组件通过URL回显预览
- version字段必须在隐藏域中携带
