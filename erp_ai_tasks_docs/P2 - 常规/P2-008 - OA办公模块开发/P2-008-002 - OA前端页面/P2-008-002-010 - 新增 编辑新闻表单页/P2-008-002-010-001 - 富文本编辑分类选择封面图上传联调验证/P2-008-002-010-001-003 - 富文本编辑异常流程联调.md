### 5.1 新闻特有异常场景

| 场景 | 处理方式 | 提示信息 |
|------|---------|---------|
| TinyMCE编辑器加载失败 | 降级为textarea，ElMessage.warning | "富文本编辑器加载失败，已切换为纯文本模式" |
| 图片上传失败 | 文件上传组件错误回调，ElMessage.error | "图片上传失败，请重试" |
| 图片大小超限(>5MB) | 上传前校验拦截 | "图片大小不能超过5MB" |
| 富文本内容过大(>100KB HTML) | 提交前校验 | "新闻正文内容过大，请精简或减少图片" |
| 封面图上传失败 | ImageUpload错误回调 | "封面图上传失败，请重试" |

### 5.2 通用异常场景

| 场景 | 处理方式 | 提示信息 |
|------|---------|---------|
| 网络断开 | axios拦截器捕获 | "网络连接异常，请检查网络" |
| 接口超时(>30s) | axios timeout配置 | "请求超时，请重试" |
| 服务端500 | 展示traceId | "系统异常(traceId:xxx)，请联系管理员" |
| 乐观锁冲突(409) | ElMessage.warning | "该新闻已被其他用户修改，请刷新后重试" |
| 未保存离开 | beforeRouteLeave+confirm | "新闻内容尚未保存，确定离开吗？" |
| 重复提交 | 按钮loading | 保存按钮disabled |

### 5.3 TinyMCE加载失败降级

```typescript
const editorFailed = ref(false)

const handleEditorError = (error: any) => {
  console.error('TinyMCE load error:', error)
  editorFailed.value = true
  ElMessage.warning('富文本编辑器加载失败，已切换为纯文本模式')
}
```

```vue
<!-- 降级方案 -->
<template>
  <div v-if="!editorFailed">
    <Editor v-model="form.content" :init="tinymceConfig" @error="handleEditorError"/>
  </div>
  <div v-else>
    <el-input v-model="form.content" type="textarea" :rows="20"
              placeholder="富文本编辑器不可用，请输入纯文本"/>
  </div>
</template>
```

### 5.4 图片上传异常处理

```typescript
const handleImageUploadError = (error: Error) => {
  ElMessage.error('图片上传失败，请重试')
  console.error('Image upload error:', error)
}

const beforeImageUpload = (file: File) => {
  const isLt5M = file.size / 1024 / 1024 < 5
  if (!isLt5M) {
    ElMessage.error('图片大小不能超过5MB')
    return false
  }
  const isValidType = ['image/jpeg', 'image/png', 'image/gif'].includes(file.type)
  if (!isValidType) {
    ElMessage.error('仅支持JPEG/PNG/GIF格式图片')
    return false
  }
  return true
}
```

### 5.5 未保存离开拦截(新闻特有)

```typescript
const isDirty = ref(false)

// TinyMCE内容变化追踪
watch(() => form.content, () => { isDirty.value = true })
watch(() => form.title, () => { isDirty.value = true })

onBeforeRouteLeave((to, from, next) => {
  if (isDirty.value) {
    ElMessageBox.confirm('新闻内容尚未保存，确定离开吗？', '提示', {
      confirmButtonText: '确定离开',
      cancelButtonText: '继续编辑',
      type: 'warning'
    }).then(() => next()).catch(() => next(false))
  } else {
    next()
  }
})
```

| 序号 | 检查项 | 验证方法 |

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ TinyMCE编辑器初始化是异步的，必须确保editor ready后再setContent

> ⚠️ 图片上传失败的提示需要与表单提交失败区分开

> ⚠️ 富文本HTML内容可能包含XSS风险(script/iframe标签)，由后端统一sanitize

> ⚠️ dirty状态追踪在TinyMCE内容变化时需要监听，而不仅是el-input

> ⚠️ [OA模块] 新闻正文不允许嵌入外部script/iframe标签，后端会过滤
