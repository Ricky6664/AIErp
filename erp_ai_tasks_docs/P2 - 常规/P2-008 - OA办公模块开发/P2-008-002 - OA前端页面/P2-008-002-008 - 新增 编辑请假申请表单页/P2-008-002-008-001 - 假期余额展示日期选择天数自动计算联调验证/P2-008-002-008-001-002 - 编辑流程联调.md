## 五、详细开发规格

> **本任务模块上下文**
> - 涉及数据表：oa_leave(请假申请表)
> - 涉及API：GET /api/oa/leave/detail/{id}, PUT /api/oa/leave/update

### 5.1 编辑流程

1. 请假列表页点击[编辑]→打开LeaveFormDialog(mode='edit', leaveId)
2. 调用leaveApi.detail(leaveId)获取LeaveDetailVO
3. 回填表单字段：
   - leaveType ← detail.leaveType
   - startDate ← detail.startDate (YYYY-MM-DD)
   - endDate ← detail.endDate (YYYY-MM-DD)
   - duration ← detail.duration (number, readonly)
   - reason ← detail.reason
   - version ← detail.version (隐藏域)

### 5.2 只读字段

| 字段 | 只读条件 | 说明 |
|------|---------|------|
| duration | 始终只读 | 天数由日期自动计算，不可手动修改 |
| leaveType | status='approved'时只读 | 已审批的请假不允许修改类型 |
| startDate | status='approved'时只读 | 已审批的请假不允许修改开始日期 |
| endDate | status='approved'时只读 | 已审批的请假不允许修改结束日期 |

### 5.3 乐观锁处理

```typescript
const handleSave = async () => {
  await formRef.validate()
  try {
    await leaveApi.update({
      ...form,
      id: leaveId,
      version: form.version
    })
    ElMessage.success('请假申请已更新')
    dialogVisible.value = false
    emit('refresh')
  } catch (e: any) {
    if (e.status === 409) {
      ElMessage.warning('该请假申请已被其他用户修改，请刷新后重试')
    }
  }
}
```

### 5.4 回填注意事项

- startDate/endDate：后端返回"YYYY-MM-DD"字符串，直接绑定el-date-picker
- duration：number类型，直接绑定el-input-number(readonly)
- leaveType：字符串枚举值，el-select通过value匹配
- version：number类型，存于隐藏域
- 回填后自动触发一次calculateDuration验证天数一致性

### 5.5 编辑权限控制

- 仅status='pending'(待审批)的请假申请允许编辑
- status='approved'(已审批)和status='rejected'(已驳回)的请假不允许编辑

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）
