### 5.2 新增流程

1. 请假列表页点击[新增请假]→打开LeaveFormDialog(mode='create')
2. 初始化：调用leaveApi.getBalance()获取当前用户各假期类型余额并展示
3. 选择leaveType→显示该类型剩余天数
4. 选择startDate和endDate→自动调用leaveApi.calculateDuration(startDate, endDate)计算天数
5. duration自动回填(readonly)
6. 填写reason(事假时必填)
7. [提交]→formRef.validate()→leaveApi.create(form)
8. 成功→ElMessage.success('请假申请已提交')+关闭弹窗+emit('refresh')

### 5.4 天数自动计算

```typescript
const calculateDuration = async () => {
  if (form.startDate && form.endDate) {
    if (form.endDate < form.startDate) {
      ElMessage.warning('结束日期不能早于开始日期')
      return
    }
    const res = await leaveApi.calculateDuration({
      startDate: form.startDate,
      endDate: form.endDate
    })
    form.duration = res.data // 后端计算，排除周末和节假日
  }
}

watch([() => form.startDate, () => form.endDate], calculateDuration)
```

### 5.5 条件校验：事假必填reason

```typescript
const rules = {

        } else {

        }

    }
  ]
}
```
