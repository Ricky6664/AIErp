### 5.1 请假特有异常场景

| 场景 | 处理方式 | 提示信息 |
|------|---------|---------|
| 假期余额不足 | 后端返回400，前端ElMessage.error | "假期余额不足，剩余{X}天，本次需{Y}天" |
| 日期范围非法(endDate<startDate) | 表单校验拦截 | "结束日期不能早于开始日期" |
| 跨节假日天数计算 | 调用后端calculateDuration API | 显示"实际请假天数: X天(含Y个节假日)" |
| 已审批请假编辑 | 前端拦截，不发起请求 | "已审批的请假申请不可编辑" |
| 请假日期为过去日期(新增时) | el-date-picker禁用过去日期 | 日期选择器灰色不可选 |

### 5.2 通用异常场景

| 场景 | 处理方式 | 提示信息 |
|------|---------|---------|
| 网络断开 | axios拦截器捕获 | "网络连接异常，请检查网络" |
| 接口超时(>30s) | axios timeout配置 | "请求超时，请重试" |
| 服务端500 | 展示traceId | "系统异常(traceId:xxx)，请联系管理员" |
| 乐观锁冲突(409) | ElMessage.warning | "该请假申请已被其他用户修改，请刷新后重试" |
| 未保存离开 | beforeRouteLeave+confirm | "请假申请尚未保存，确定离开吗？" |
| 重复提交 | 按钮loading | 提交按钮disabled |

### 5.3 假期余额不足处理

```typescript
const handleSubmit = async () => {
  await formRef.validate()
  try {
    await leaveApi.create(form)
    ElMessage.success('请假申请已提交')
    dialogVisible.value = false
    emit('refresh')
  } catch (e: any) {
    if (e.response?.status === 400 && e.response?.data?.code === 'BALANCE_INSUFFICIENT') {
      const { remaining, required } = e.response.data.data
      ElMessage.error(`假期余额不足，剩余${remaining}天，本次需${required}天`)
    }
  }
}
```

### 5.4 天数计算异常

```typescript
const calculateDuration = async () => {
  if (!form.startDate || !form.endDate) return
  if (form.endDate < form.startDate) {
    ElMessage.warning('结束日期不能早于开始日期')
    form.duration = null
    return
  }
  try {
    loading.duration = true
    const res = await leaveApi.calculateDuration({
      startDate: form.startDate,
      endDate: form.endDate
    })
    form.duration = res.data.duration
    if (res.data.holidayCount > 0) {
      ElMessage.info(`包含${res.data.holidayCount}个节假日，实际请假${res.data.duration}天`)
    }
  } catch (e) {
    ElMessage.error('天数计算失败，请重试')
  } finally {
    loading.duration = false
  }
}
```

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ 假期余额不足由后端校验(前端余额展示仅为参考)，前端需处理400响应

> ⚠️ 天数计算API可能因节假日数据未配置而返回错误，需要兜底处理

> ⚠️ 跨节假日常见场景：春节、国庆、清明、端午、中秋等

> ⚠️ dirty状态追踪在保存成功后重置为false

> ⚠️ [OA模块] 请假天数计算排除周末和节假日

> ⚠️ [OA模块] 假期余额校验(已用+本次<=总额)
