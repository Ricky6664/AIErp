### 5.1 交互逻辑

```typescript
import { debounce } from 'lodash-es'

const searchForm = reactive({
  title: '',
  category: null as string | null,
  status: null as string | null,
  publishDateRange: [] as string[]
})

// title字段防抖搜索
const handleTitleInput = debounce(() => {
  handleSearch()
}, 300)

// 搜索：重置pageNum=1
const handleSearch = () => {
  const params = {
    title: searchForm.title || undefined,
    category: searchForm.category || undefined,
    status: searchForm.status || undefined,
    startDate: searchForm.publishDateRange?.[0] || undefined,
    endDate: searchForm.publishDateRange?.[1] || undefined,
    pageNum: 1
  }
  emit('search', params)
  syncUrlParams(params)
}

// 重置
const handleReset = () => {
  Object.assign(searchForm, {
    title: '',
    category: null,
    status: null,
    publishDateRange: []
  })
  handleSearch()
}

// URL参数同步
const syncUrlParams = (params: Record<string, any>) => {
  const query: Record<string, string> = {}
  if (params.title) query.title = params.title
  if (params.category) query.category = params.category
  if (params.status) query.status = params.status
  if (params.startDate) query.startDate = params.startDate
  if (params.endDate) query.endDate = params.endDate
  router.replace({ query })
}

// 页面加载时从URL恢复搜索条件
onMounted(() => {
  const { title, category, status, startDate, endDate } = route.query
  if (title) searchForm.title = title as string
  if (category) searchForm.category = category as string
  if (status) searchForm.status = status as string
  if (startDate && endDate) searchForm.publishDateRange = [startDate as string, endDate as string]
  handleSearch()
})
```

### 5.2 各字段触发方式

| 字段 | 触发方式 | 说明 |
|------|---------|------|
| title | 输入防抖300ms + 回车键 | 文本输入，防抖避免频繁请求 |
| category | @change即触发 | 分类选择变化即搜索 |
| status | @change即触发 | 状态选择变化即搜索 |
| publishDateRange | @change即触发 | 日期范围选择后自动搜索 |

### 5.3 URL参数同步

| URL参数 | 对应表单字段 | 类型 |
|---------|------------|------|
| title | searchForm.title | string |
| category | searchForm.category | string |
| status | searchForm.status | string |
| startDate | publishDateRange[0] | string |
| endDate | publishDateRange[1] | string |

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ 防抖300ms使用lodash-es的debounce，组件卸载时cancel

> ⚠️ 搜索时务必重置pageNum=1

> ⚠️ publishDateRange重置时清空为[]而非null

> ⚠️ [OA模块] 新闻搜索title为模糊匹配(like)，category和status为精确匹配
