### 5.1 字段组件映射

| 字段名 | 组件 | 关键属性 | 数据来源 |
|--------|------|---------|---------|
| title | el-input | placeholder="请输入新闻标题关键字", clearable, maxlength=200 | 用户输入 |
| category | el-select | placeholder="全部分类", clearable | 字典:news_category |
| status | el-select | placeholder="全部状态", clearable | 字典:news_status |
| publishDateRange | el-date-picker | type="daterange", value-format="YYYY-MM-DD" | 用户选择 |

### 5.2 分类字典加载

```typescript
const dictStore = useDictStore()
const categoryOptions = ref<DictItem[]>([])
const statusOptions = ref<DictItem[]>([])

onMounted(async () => {
  // 新闻分类字典: news_category
  // 值: company(公司新闻), industry(行业动态), notice(通知公告)
  categoryOptions.value = await dictStore.getDictItems('news_category')

  // 新闻状态字典: news_status
  // 值: draft(草稿), published(已发布), offline(已下线)
  statusOptions.value = await dictStore.getDictItems('news_status')
})
```

### 5.3 分类选项列表

| 值 | 标签 | 说明 |
|---|------|------|
| company | 公司新闻 | 公司内部新闻 |
| industry | 行业动态 | 行业新闻 |
| notice | 通知公告 | 通知类信息 |

### 5.4 状态选项列表

| 值 | 标签 | 说明 |
|---|------|------|
| draft | 草稿 | 编辑中未发布 |
| published | 已发布 | 已对外展示 |
| offline | 已下线 | 已撤回不再展示 |

### 5.5 el-date-picker配置

- type="daterange"
- value-format="YYYY-MM-DD"
- range-separator="至"
- shortcuts: 最近一周、最近一个月、最近三个月、本年

### 5.6 title el-input

- 新闻标题关键字搜索，支持模糊匹配
- 输入防抖300ms通过@input + debounce实现
- 回车键触发搜索@keyup.enter

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ news_category和news_status是两个不同的字典，不要混淆

> ⚠️ 新闻状态(draft/published/offline)与公告状态(draft/published/expired)不完全相同

> ⚠️ 所有el-select务必设置clearable

> ⚠️ [OA模块] 新闻分类值company/industry/notice需与后端枚举严格匹配
