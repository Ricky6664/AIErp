### 5.1 通用异常场景

| 场景 | 处理方式 | 提示信息 |
|------|---------|---------|
| 网络断开 | axios拦截器捕获，ElMessage.error | "网络连接异常，请检查网络" |
| 接口超时(>30s) | axios timeout配置，取消请求 | "请求超时，请重试" |
| 服务端500 | 拦截器统一处理，展示traceId | "系统异常(traceId:xxx)，请联系管理员" |
| 乐观锁冲突(409) | ElMessage.warning+建议刷新 | "该公告已被其他用户修改，请刷新后重试" |
| 未保存离开 | beforeRouteLeave+ElMessageBox.confirm | "公告内容尚未保存，确定离开吗？" |
| 重复提交 | 按钮loading状态 | 保存按钮disabled直到请求返回 |

### 5.2 公告特有异常场景

| 场景 | 处理方式 | 提示信息 |
|------|---------|---------|
| expireDate早于publishDate | 表单校验拦截 | "过期日期必须晚于发布日期" |
| 附件上传失败 | 文件上传组件错误回调，ElMessage.error | "附件上传失败，请重试" |
| 附件大小超限(>20MB) | 上传前校验 | "附件大小不能超过20MB" |
| 内容字数不足10字 | 表单校验拦截 | "公告内容不能少于10个字符" |

### 5.3 实现要点

```typescript
// 脏状态追踪
const isDirty = ref(false)
watch(() => form, () => { isDirty.value = true }, { deep: true })

// 未保存离开拦截
onBeforeRouteLeave((to, from, next) => {
  if (isDirty.value) {
    ElMessageBox.confirm('公告内容尚未保存，确定离开吗？', '提示', {
      confirmButtonText: '确定离开',
      cancelButtonText: '继续编辑',
      type: 'warning'
    }).then(() => next()).catch(() => next(false))
  } else {
    next()
  }
})

// 附件上传异常处理
const handleUploadError = (error: Error) => {
  ElMessage.error('附件上传失败，请重试')
  console.error('Upload error:', error)
}

// 附件大小校验
const beforeUpload = (file: File) => {
  const isLt20M = file.size / 1024 / 1024 < 20
  if (!isLt20M) {
    ElMessage.error('附件大小不能超过20MB')
  }
  return isLt20M
}
```

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ axios拦截器统一处理异常，避免在组件中重复try-catch

> ⚠️ 附件上传失败不应阻断表单编辑，用户仍可继续修改其他字段

> ⚠️ dirty状态追踪需要在保存成功后重置为false

> ⚠️ [OA模块] 公告内容可能包含敏感信息，前端不做XSS过滤由后端统一处理
