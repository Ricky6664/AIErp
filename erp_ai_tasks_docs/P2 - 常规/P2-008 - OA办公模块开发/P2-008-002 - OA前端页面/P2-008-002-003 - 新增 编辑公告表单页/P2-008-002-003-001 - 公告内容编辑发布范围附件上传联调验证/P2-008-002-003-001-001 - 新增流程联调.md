### 5.1 表单字段定义

| 字段名 | 组件类型 | 是否必填 | 校验规则 | 说明 |
|--------|---------|---------|---------|------|
| title | el-input | 是 | required, max 100字符 | 公告标题 |
| content | el-input(type=textarea) | 是 | required, min 10字符 | 公告内容(textarea, rows=10) |
| publishDate | el-date-picker | 否 | — | 发布日期, 默认今天, value-format="YYYY-MM-DD" |
| expireDate | el-date-picker | 否 | 若填写则必须>publishDate | 过期日期 |
| isTop | el-switch | 否 | — | 是否置顶, 默认false |

### 5.2 新增流程

1. 公告列表页点击[新增公告]按钮→路由跳转到/oa/announcement/create
2. 表单初始化：publishDate默认今天, isTop默认false, content为空
3. 填写表单→实时校验
4. [发布]→formRef.validate()→调用announcementApi.create(form)
5. 成功→ElMessage.success('公告创建成功')+router.push('/oa/announcement')
6. [保存草稿]→设置status='draft'→调用同一API
7. 失败→定位第一个错误字段scrollIntoView

### 5.3 关键校验规则

```typescript
const rules = {
  title: [
    { required: true, message: '请输入公告标题', trigger: 'blur' },
    { max: 100, message: '标题不能超过100个字符', trigger: 'blur' }
  ],
  content: [
    { required: true, message: '请输入公告内容', trigger: 'blur' },
    { min: 10, message: '公告内容不能少于10个字符', trigger: 'blur' }
  ]
}

// expireDate > publishDate 自定义校验
const validateExpireDate = (rule: any, value: any, callback: any) => {
  if (value && form.publishDate && value <= form.publishDate) {
    callback(new Error('过期日期必须晚于发布日期'))
  } else {
    callback()
  }
}
```

### 5.4 错误处理

- 字段校验失败：滚动到第一个错误字段
- 400：后端返回字段级错误，映射到对应el-form-item
- 500：ElMessage.error('系统异常，请稍后重试')

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ title字段maxlength=100需要在el-input上设置show-word-limit

> ⚠️ content textarea设置rows=10，确保足够的编辑空间

> ⚠️ publishDate和expireDate的el-date-picker需要禁用过去日期(past日期不可选)

> ⚠️ 按钮loading防重复提交

> ⚠️ [OA模块] 公告发布后不可编辑标题，需通过新增版本方式修改
