## 五、详细开发规格

> **本任务模块上下文**

> - 涉及API：GET /api/oa/announcement/detail/{id}, PUT /api/oa/announcement/update

### 5.1 编辑流程

1. 公告列表页点击[编辑]→路由跳转到/oa/announcement/edit/{id}
2. 调用announcementApi.detail(id)获取AnnouncementDetailVO
3. 回填表单字段：
   - title ← detail.title
   - content ← detail.content
   - publishDate ← detail.publishDate (YYYY-MM-DD)
   - expireDate ← detail.expireDate (YYYY-MM-DD, 可能为null)
   - isTop ← detail.isTop (boolean)
   - version ← detail.version (隐藏域)

### 5.2 只读字段

| 字段 | 只读条件 | 说明 |
|------|---------|------|
| publishDate | 编辑模式下始终只读 | 发布日期一旦设定不可修改 |
| title | status='published'时只读 | 已发布公告不允许修改标题 |

```vue
<el-form-item label="公告标题">
  <el-input v-model="form.title" :disabled="form.status === 'published'"
            placeholder="请输入公告标题" maxlength="100" show-word-limit/>
</el-form-item>

<el-form-item label="发布日期">
  <el-date-picker v-model="form.publishDate" disabled
                  value-format="YYYY-MM-DD" type="date"/>
</el-form-item>
```

### 5.3 乐观锁处理

```typescript
const handleSave = async () => {
  await formRef.validate()
  try {
    await announcementApi.update({
      ...form,
      id: announcementId,
      version: form.version
    })
    ElMessage.success('公告更新成功')
    router.push('/oa/announcement')
  } catch (e: any) {
    if (e.status === 409) {
      ElMessage.warning('该公告已被其他用户修改，请刷新后重试')
    }
  }
}
```

### 5.4 回填注意事项

- publishDate/expireDate：后端返回"YYYY-MM-DD"字符串，直接绑定el-date-picker
- isTop：后端返回boolean，直接绑定el-switch
- content：长文本内容直接赋值给textarea
- version：数字类型，存于隐藏域
