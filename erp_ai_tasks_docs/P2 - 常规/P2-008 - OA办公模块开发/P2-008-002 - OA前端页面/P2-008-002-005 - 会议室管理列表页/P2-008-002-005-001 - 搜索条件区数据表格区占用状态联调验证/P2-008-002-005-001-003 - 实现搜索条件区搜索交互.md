### 5.1 交互逻辑

```typescript
import { debounce } from 'lodash-es'

const searchForm = reactive({
  roomName: '',
  enableFlag: null as boolean | null,
  capacityMin: null as number | null,
  capacityMax: null as number | null
})

// roomName字段防抖搜索
const handleRoomNameInput = debounce(() => {
  handleSearch()
}, 300)

// 搜索：重置pageNum=1
const handleSearch = () => {
  const params = {
    roomName: searchForm.roomName || undefined,
    enableFlag: searchForm.enableFlag ?? undefined,
    minCapacity: searchForm.capacityMin ?? undefined,
    maxCapacity: searchForm.capacityMax ?? undefined,
    pageNum: 1
  }
  emit('search', params)
  syncUrlParams(params)
}

// 重置
const handleReset = () => {
  Object.assign(searchForm, {
    roomName: '',
    enableFlag: null,
    capacityMin: null,
    capacityMax: null
  })
  handleSearch()
}

// URL参数同步
const syncUrlParams = (params: Record<string, any>) => {
  const query: Record<string, string> = {}
  if (params.roomName) query.roomName = params.roomName
  if (params.enableFlag !== undefined) query.enableFlag = String(params.enableFlag)
  if (params.minCapacity !== undefined) query.minCapacity = String(params.minCapacity)
  if (params.maxCapacity !== undefined) query.maxCapacity = String(params.maxCapacity)
  router.replace({ query })
}
```

### 5.2 各字段触发方式

| 字段 | 触发方式 | 说明 |
|------|---------|------|
| roomName | 输入防抖300ms + 回车键 | 文本输入，防抖避免频繁请求 |
| enableFlag | @change即触发 | 下拉选择变化即搜索 |
| capacityMin | @change即触发 | 数字变化即搜索 |
| capacityMax | @change即触发 | 数字变化即搜索 |

### 5.3 URL参数同步

| URL参数 | 对应表单字段 | 类型转换 |
|---------|------------|---------|
| roomName | searchForm.roomName | string |
| enableFlag | searchForm.enableFlag | boolean(string→boolean) |
| minCapacity | searchForm.capacityMin | number |
| maxCapacity | searchForm.capacityMax | number |

### 5.4 URL恢复时类型转换

```typescript
onMounted(() => {
  const { roomName, enableFlag, minCapacity, maxCapacity } = route.query
  if (roomName) searchForm.roomName = roomName as string
  if (enableFlag !== undefined) searchForm.enableFlag = enableFlag === 'true'
  if (minCapacity) searchForm.capacityMin = Number(minCapacity)
  if (maxCapacity) searchForm.capacityMax = Number(maxCapacity)
  handleSearch()
})
```

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ enableFlag是布尔类型，URL中存储为字符串"true"/"false"，恢复时需要正确转换

> ⚠️ capacityMin和capacityMax重置时清空为null而非0

> ⚠️ 防抖300ms的debounce实例需要在onUnmounted时cancel

> ⚠️ [OA模块] 容纳人数范围minCapacity/maxCapacity传给后端时为两个独立参数
