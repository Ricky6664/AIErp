### 5.1 字段组件映射

| 字段名 | 组件 | 关键属性 | 说明 |
|--------|------|---------|------|
| roomName | el-input | placeholder="请输入会议室名称", clearable, maxlength=50 | 会议室名称关键字搜索 |
| enableFlag | el-select | placeholder="全部", clearable | 启用状态筛选(布尔类型) |
| capacityMin | el-input-number | :min="0", :step="1", controls-position="right" | 最小容纳人数 |
| capacityMax | el-input-number | :min="0", :step="1", controls-position="right" | 最大容纳人数 |

### 5.2 enableFlag选项

```typescript
// 注意：enableFlag使用布尔类型，不使用字典
const enableOptions = [
  { label: '全部', value: null },
  { label: '启用', value: true },
  { label: '停用', value: false }
]
```

- 与字典驱动不同，enableFlag是布尔字段，选项硬编码
- "全部"选项value为null，搜索时不传该参数

### 5.3 el-input-number配置

```vue
<el-input-number
  v-model="searchForm.capacityMin"
  :min="0"
  :max="9999"
  :step="1"
  :precision="0"
  controls-position="right"
  placeholder="最少人数"
  @change="handleCapacityChange"
/>
```

- min=0：不允许负数
- max=9999：合理上限
- step=1：步长为1
- precision=0：正整数
- controls-position="right"：加减按钮在右侧

### 5.4 人数范围校验

```typescript
const handleCapacityChange = () => {
  if (searchForm.capacityMin != null && searchForm.capacityMax != null
      && searchForm.capacityMin > searchForm.capacityMax) {
    ElMessage.warning('最少人数不能大于最多人数')
  }
}
```

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id
