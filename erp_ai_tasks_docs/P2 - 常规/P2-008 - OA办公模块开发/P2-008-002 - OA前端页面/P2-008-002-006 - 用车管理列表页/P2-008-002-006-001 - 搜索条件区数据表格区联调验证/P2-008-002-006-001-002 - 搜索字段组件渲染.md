### 5.1 字段组件映射

| 字段名 | 组件 | 关键属性 | 数据来源 |
|--------|------|---------|---------|
| applicantId | UserSelector | placeholder="请选择申请人", clearable | UserSelector组件内置 |
| purpose | el-input | placeholder="请输入用车事由关键字", clearable, maxlength=200 | 用户输入 |
| dateRange | el-date-picker | type="daterange", value-format="YYYY-MM-DD" | 用户选择 |
| status | el-select | placeholder="全部状态", clearable | 字典:vehicle_status |

### 5.2 UserSelector配置

```vue
<UserSelector
  v-model="searchForm.applicantId"
  placeholder="请选择申请人"
  clearable
  :multiple="false"
  :show-dept="true"
/>
```

- 支持按姓名/工号模糊搜索
- 选中后显示用户姓名，存储用户ID(number)
- clearable: 清空选中后自动触发搜索

### 5.3 状态字典加载

```typescript
const dictStore = useDictStore()
const statusOptions = ref<DictItem[]>([])

onMounted(async () => {
  // 用车状态字典: vehicle_status
  // 值: pending(待审批), approved(已审批), dispatched(已派车), completed(已完成)
  statusOptions.value = await dictStore.getDictItems('vehicle_status')
})
```

### 5.4 el-date-picker配置

- type="daterange"
- value-format="YYYY-MM-DD"
- range-separator="至"
- shortcuts: 最近一周、最近一个月、最近三个月、本年

### 5.5 purpose el-input

- 用车事由关键字搜索，支持模糊匹配
- 输入防抖300ms通过@input + debounce实现
- 回车键触发搜索@keyup.enter

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ UserSelector存储的是用户ID(number)，不是姓名

> ⚠️ vehicle_status字典必须覆盖完整流程状态(4种)

> ⚠️ el-date-picker的value-format必须与后端接口格式一致(YYYY-MM-DD)

> ⚠️ [OA模块] 用车状态流转: pending→approved→dispatched→completed
