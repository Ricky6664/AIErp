## 五、详细开发规格

> **本任务模块上下文**
> - 涉及数据表：oa_schedule(日程表)
> - 涉及API：GET /api/oa/schedule/detail/{id}, PUT /api/oa/schedule/update

### 5.1 编辑流程

1. 用户点击FullCalendar日程卡片→打开ScheduleFormDialog(mode='edit', scheduleId)
2. 调用scheduleApi.detail(scheduleId)获取ScheduleDetailVO
3. 回填表单字段：
   - title ← detail.title
   - scheduleDate ← detail.scheduleDate (字符串"YYYY-MM-DD")
   - startTime ← detail.startTime (字符串"HH:mm")
   - endTime ← detail.endTime (字符串"HH:mm")
   - location ← detail.location
   - remindFlag ← detail.remindFlag
   - color ← detail.color (默认"#409EFF")
   - version ← detail.version (隐藏字段)

### 5.2 只读字段

| 字段 | 只读条件 | 说明 |
|------|---------|------|
| scheduleDate | 如果日程日期已过(早于今天) | 已过去的日程不允许改日期 |
| startTime | 如果日程日期已过 | 同上 |

### 5.3 乐观锁处理

```typescript
// 隐藏字段
<input type="hidden" v-model="form.version" />

// 提交
const handleSave = async () => {
  await formRef.validate()
  try {
    await scheduleApi.update({ ...form, id: scheduleId, version: form.version })
    ElMessage.success('日程更新成功')
    dialogVisible.value = false
    emit('refresh')
  } catch (e: any) {
    if (e.status === 409) {
      ElMessage.warning('该日程已被其他用户修改，请刷新后重试')
    }
  }
}
```

### 5.4 回填注意事项

- 日期格式：后端返回"YYYY-MM-DD"字符串，el-date-picker需要正确识别
- 时间格式：后端返回"HH:mm"字符串，el-time-picker需要format匹配
- 颜色值：后端返回hex格式"#409EFF"，el-color-picker直接绑定

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ 回填时日期和时间字段需要确保格式与组件期望格式一致，避免显示异常

> ⚠️ version字段必须在表单中作为隐藏域存在，不能遗漏

> ⚠️ 乐观锁冲突返回409状态码，需要前端拦截并显示友好提示

> ⚠️ [OA模块] 已过去的日程仅允许修改location/remindFlag/color，不允许修改日期和时间
