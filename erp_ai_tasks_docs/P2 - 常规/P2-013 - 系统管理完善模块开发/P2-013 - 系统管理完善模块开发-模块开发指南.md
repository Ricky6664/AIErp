# P2-013 系统管理完善模块开发 - 模块开发指南

## 一、模块概述
- **模块定位**：完善系统管理功能，包含系统管理工作台、编码规则管理、数据视图管理、单据配置、操作日志查询、登录日志、缓存管理及系统公告等功能（数据字典管理与系统参数管理已在V10.0迁移至P0-005-016/017）
- **前置依赖**：P0-004（认证权限基础）
- **被依赖方**：无
- **开发阶段**：阶段十

## 四、模块级专属约束

本模块部分功能已在V10.0版本中迁移至P0阶段：
- **数据字典管理**：后端CRUD已迁移至P0-005-016-001，前端页面已迁移至P0-005-016-002。P2阶段仅保留数据字典增强功能（字典导入模板管理、字典数据批量导入导出增强、字典引用查询）。
- **系统参数管理**：后端CRUD已迁移至P0-005-017-001，前端页面已迁移至P0-005-017-002。P2阶段仅保留系统参数增强功能（参数变更审计日志、参数分组层级嵌套、参数版本管理）。
- **登录认证增强**：验证码生成、密码强度校验、登录失败锁定等功能已迁移至P0-004-011（登录安全增强）和P0-004-012（SSO/OAuth2配置管理）。P2阶段仅保留系统管理配置页面的联调验证。

本模块剩余核心功能为：系统管理工作台、编码规则管理、数据视图管理、单据配置、操作日志/登录日志查询、缓存管理、系统公告。缓存管理需Redis SCAN按前缀搜索，操作需@RequiresPermissions("system:cache:manage")权限控制；系统公告支持定时发布（XXL-JOB调度）与发布范围控制。
