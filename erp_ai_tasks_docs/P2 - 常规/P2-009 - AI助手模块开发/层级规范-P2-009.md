## 1. 模块架构约束

### 1.1 模块定位
AI助手模块是ERP系统中的智能化核心模块，负责完成AI对话、智能问答、数据智能分析、对话式录入/查询/分析/审核等AI能力集成。该模块支持LLM流式对话与RAG检索增强，为系统各业务模块提供智能化赋能，提升用户操作效率和决策质量。

### 1.2 依赖关系
- 前置依赖：
  - P0-005（P14 AI对话页组件）：提供前端AI对话UI组件基础（流式消息展示、对话历史）
- 后续依赖：无（本模块为终端消费模块，不被其他模块直接依赖，但其能力可被各模块嵌入调用）

### 1.3 技术约束
- 技术栈约束：后端基于Spring Boot + Spring AI/WebFlux实现流式响应；前端基于Vue3 + SSE客户端；向量存储使用pgvector或Milvus
- 性能约束：流式对话首字节响应时间不超过2秒；RAG检索响应时间不超过1秒；单次对话上下文窗口最大4096 tokens
- 安全约束：AI对话采用流式SSE响应，需处理上下文窗口裁剪与Token计数；数据智能分析需严格SQL安全校验（仅允许SELECT，禁止DROP/DELETE/UPDATE）；API Key等敏感配置需加密存储并支持运行时热更新

## 2. 数据模型关系

### 2.1 核心数据表
| 表名 | 说明 | 关键字段 |
|------|------|---------|
| ai_config | AI配置表 | id, config_key, config_value(encrypted), config_type, status, update_time |
| ai_prompt_template | AI提示词模板表 | id, template_code, template_name, prompt_content, variables, category |
| ai_knowledge_base | AI知识库表 | id, kb_name, description, document_count, embedding_model, status |
| ai_knowledge_document | AI知识库文档表 | id, kb_id, doc_name, doc_type, doc_content, chunk_count, vector_status |
| ai_conversation_session | AI对话会话表 | id, user_id, session_title, session_type, message_count, create_time |
| ai_conversation_message | AI对话消息表 | id, session_id, role, content, token_count, create_time |

### 2.2 表关系图
- ai_config：独立配置表，存储AI服务商配置（API Key/Endpoint/Model等）
- ai_prompt_template：独立模板表，存储各场景的提示词模板
- ai_knowledge_base（主表）→ ai_knowledge_document（从表）：一对多关系，通过 kb_id 关联
- ai_conversation_session（主表）→ ai_conversation_message（从表）：一对多关系，通过 session_id 关联
- ai_conversation_session → 用户表：通过 user_id 关联

### 2.3 数据流转
1. AI对话流程：用户输入消息 → 构造上下文（加载历史消息）→ 调用LLM流式接口 → SSE推送到前端 → 保存对话记录
2. 智能问答流程：用户提问 → RAG检索知识库（文档向量化+语义检索）→ 构造增强Prompt → 调用LLM → 返回答案+引用来源
3. 数据智能分析流程：用户描述分析需求 → 生成安全SQL（仅SELECT）→ 执行查询 → 分析结果 → 生成可视化图表
4. 对话式智能录入流程：用户描述录入内容 → NLP提取结构化数据 → 回填表单字段 → 用户确认提交
5. 对话式单据审核流程：加载单据数据 → AI分析合规性 → 生成审核意见 → 用户确认审核结果

## 3. 业务流程

### 3.1 核心业务流程
1. **AI对话**：基于LLM的智能对话，支持多轮上下文对话
2. **智能问答**：基于RAG的企业知识库问答，提供精准答案和来源引用
3. **数据智能分析**：自然语言转SQL查询，自动生成数据分析结果和图表
4. **对话式智能录入**：通过对话方式智能填充表单数据
5. **对话式智能查询**：通过对话方式查询业务数据
6. **对话式智能分析汇总**：多维度数据汇总分析
7. **对话式单据审核**：AI辅助单据合规性审核
8. **AI配置管理**：管理AI服务商配置、提示词模板、知识库

### 3.2 业务规则
- 智能问答基于RAG检索增强生成，需文档向量化与语义检索
- 数据智能分析SQL安全校验：仅允许SELECT语句，禁止DROP/DELETE/UPDATE/INSERT
- API Key等敏感配置需AES加密存储，运行时解密使用
- 对话上下文窗口超过限制时自动裁剪早期消息
- 知识库文档变更后需重新执行向量化索引
- 单次对话最大Token数量限制为4096

### 3.3 状态流转
知识库文档状态流转：
- 待处理(0) → 向量化中(1) → 已完成(2) / 失败(3)
- 失败(3) → 待处理(0)（可重新处理）

AI配置状态流转：
- 启用(1) / 禁用(0)

## 5. 开发顺序约束

### 5.1 必须顺序执行的任务
1. AI对话接口 → 智能问答/数据智能分析/智能录入/智能查询/智能分析/单据审核接口（均依赖基础对话能力）
2. AI配置管理 → AI对话接口（对话依赖AI服务商配置）
3. 知识库管理 → 智能问答接口（问答依赖知识库数据）
4. 后端接口全部完成 → 前端页面开发

### 5.2 可并行执行的任务
- 智能问答接口、数据智能分析接口、智能录入接口、智能查询接口、智能分析汇总接口、单据审核接口可并行开发（均依赖基础对话接口）
- AI配置管理、提示词模板管理、知识库管理可并行开发
- 前端页面中，AI对话页、智能问答入口、数据智能分析页可并行开发
- 对话式智能录入页、智能查询页、智能分析汇总页、单据审核页可并行开发
