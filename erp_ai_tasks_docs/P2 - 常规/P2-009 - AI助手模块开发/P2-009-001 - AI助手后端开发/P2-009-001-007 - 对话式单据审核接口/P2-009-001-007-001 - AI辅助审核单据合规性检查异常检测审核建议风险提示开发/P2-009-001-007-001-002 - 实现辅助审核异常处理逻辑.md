### 5.1 异常处理

```java
@RestControllerAdvice
public class AiExceptionHandler {

    @ExceptionHandler(AiServiceException.class)
    public Result<?> handleAiException(AiServiceException e) {
        log.error("AI服务异常: {}", e.getMessage(), e);
        if (e instanceof ModelUnavailableException) {
            return Result.fail(e.getErrorCode(), "AI服务繁忙，请稍后重试");
        }
        return Result.fail(e.getErrorCode(), e.getMessage());
    }

    @ExceptionHandler(TimeoutException.class)
    public Result<?> handleTimeout(TimeoutException e) {
        return Result.fail("AI_001", "AI响应超时，请稍后重试");
    }
}
```
