### 5.1 异常类

```java
public class AiServiceException extends BusinessException {
    public AiServiceException(String message) {
        super(ErrorCode.AI_SERVICE_ERROR, message);
    }
}

public class TokenLimitException extends AiServiceException {
    public TokenLimitException(int limit, int actual) {
        super("Token超限: 限额" + limit + ", 实际" + actual);
    }
}

public class ModelUnavailableException extends AiServiceException {
    public ModelUnavailableException(String model) {
        super("模型不可用: " + model);
    }
}
```

### 5.2 错误码
