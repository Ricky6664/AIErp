### 5.1 HTTP客户端

```java
@Component
public class LlmHttpClient {
    private final WebClient webClient;

    @Value("${ai.llm.base-url}") private String baseUrl;
    @Value("${ai.llm.timeout:60000}") private int timeout;

    public LlmHttpClient() {
        this.webClient = WebClient.builder()
            .baseUrl(baseUrl)
            .defaultHeader(HttpHeaders.CONTENT_TYPE, MediaType.APPLICATION_JSON_VALUE)
            .codecs(c -> c.defaultCodecs().maxInMemorySize(16 * 1024 * 1024))
            .build();
    }

    public Flux<String> chat(String apiKey, List<Message> messages, String model) {
        return webClient.post()
            .uri("/v1/chat/completions")
            .header(HttpHeaders.AUTHORIZATION, "Bearer " + apiKey)
            .bodyValue(Map.of("model", model, "messages", messages, "stream", true))
            .retrieve()
            .bodyToFlux(String.class)
            .timeout(Duration.ofMillis(timeout));
    }
}
```

### 5.2 要点
- API Key从ai_config读取+AES解密
- 超时60秒
- 内存缓冲16MB
