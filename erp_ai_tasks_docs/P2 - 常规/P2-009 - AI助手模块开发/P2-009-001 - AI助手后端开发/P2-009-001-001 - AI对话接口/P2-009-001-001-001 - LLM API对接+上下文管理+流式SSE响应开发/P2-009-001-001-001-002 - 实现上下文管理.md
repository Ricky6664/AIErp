### 5.1 上下文管理

```java
@Service
public class ConversationContextService {
    @Autowired private AiConversationMessageMapper messageMapper;

    public List<Message> buildContext(Long sessionId, String userMessage, int maxTokens) {
        saveMessage(sessionId, "user", userMessage);
        List<AiConversationMessageEntity> history = messageMapper.selectList(
            new LambdaQueryWrapper<AiConversationMessageEntity>()
                .eq(AiConversationMessageEntity::getSessionId, sessionId)
                .orderByDesc(AiConversationMessageEntity::getCreateTime)
                .last("LIMIT 20")
        );
        Collections.reverse(history);
        List<Message> messages = new ArrayList<>();
        messages.add(Message.system("你是ERP智能助手..."));
        history.forEach(m -> messages.add(Message.of(m.getRole(), m.getContent())));
        messages.add(Message.user(userMessage));
        return tokenService.trimContext(messages, maxTokens);
    }
}
```
