### 5.2 测试代码

```java
@SpringBootTest
@AutoConfigureMockMvc
class AiControllerTest {
    @Autowired MockMvc mockMvc;

    @Test
    void test_create_success() throws Exception {
        AiCreateDTO dto = new AiCreateDTO();
        dto.setCode("TEST001");
        dto.setName("测试");
        mockMvc.perform(post("/api/ai/ai/create")
            .contentType(MediaType.APPLICATION_JSON)
            .content(toJson(dto)))
            .andExpect(status().isOk())
            .andExpect(jsonPath("$.code").value(200));
    }
}
```

## 八、易错警示

> ⚠️ 代码提交前确保无敏感信息硬编码（密码/密钥/token）

> ⚠️ 多租户隔离(tenant_id)必须正确——所有SQL查询需自动注入tenant_id

> ⚠️ 逻辑删除字段(is_deleted)正确处理——查询追加is_deleted=false，删除使用UPDATE

> ⚠️ @TableField勿遗漏

> ⚠️ 事务边界准确避免大事务

> ⚠️ 异常统一BusinessException

> ⚠️ [AI模块] API Key AES加密存储

> ⚠️ [AI模块] Token计数精确避免超限

> ⚠️ [AI模块] AI服务降级策略

> ⚠️ [AI模块] 流式响应中断优雅处理

> ⚠️ [AI模块] SQL安全仅允许SELECT
