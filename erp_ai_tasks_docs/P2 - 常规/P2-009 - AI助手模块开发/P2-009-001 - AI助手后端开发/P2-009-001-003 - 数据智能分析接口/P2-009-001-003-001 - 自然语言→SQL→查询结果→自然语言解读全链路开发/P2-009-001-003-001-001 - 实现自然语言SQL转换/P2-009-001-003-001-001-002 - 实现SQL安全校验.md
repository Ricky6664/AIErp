### 5.1 SQL安全校验

```java
public void validateSql(String sql) {
    String upper = sql.trim().toUpperCase();
    if (!upper.startsWith("SELECT")) {
        throw new BusinessException("仅允许查询语句");
    }
    String[] blacklist = {"DROP", "DELETE", "UPDATE", "INSERT", "ALTER", "TRUNCATE", "CREATE", "--", ";--"};
    for (String bad : blacklist) {
        if (upper.contains(bad)) {
            throw new BusinessException("非法关键词: " + bad);
        }
    }
    // 表名白名单
    Set<String> allowedTables = Set.of("sales_order", "product");
    // 强制LIMIT
    if (!upper.contains("LIMIT")) {
        sql = sql + " LIMIT 1000";
    }
}
```
