## 五、详细开发规格

> **本任务模块上下文**
> - 涉及数据表：ai_config(AI配置表), ai_prompt_template(提示词模板表), ai_knowledge_base(知识库表), ai_knowledge_document(知识库文档表), ai_conversation_session(会话表), ai_conversation_message(消息表)
> - 涉及API：/api/ai/chat/*, /api/ai/config/*, /api/ai/knowledge/*, /api/ai/prompt/*, /api/ai/analysis/*

### 5.1 核心功能
1. 构建自然语言→SQL的Prompt模板，包含表结构+字段说明上下文
2. 调用LLM API生成SQL，限制仅允许SELECT语句
3. SQL安全校验：禁止DROP/DELETE/UPDATE/INSERT，限制JOIN数量
4. 结果集转Markdown/JSON，使用LLM生成自然语言解读
5. @Cacheable缓存高频查询SQL，减少LLM调用成本

### 5.2 数据交互
1. Controller接收用户自然语言/对话请求，封装为AiChatDTO
2. Service调用外部AI API(LLM)，使用WebClient异步请求
3. AI响应解析为结构化数据，写入ai_conversation_message表
4. 会话上下文通过Redis缓存(session_id→messages列表)
5. 流式SSE响应通过Flux<String>逐token推送到前端

### 5.3 关键逻辑
1. 重试策略：指数退避(maxAttempts=3, backoff=2s/4s/8s)
2. 超时控制：连接超时5s，读取超时60s(LLM推理慢)
3. Token计数精确：prompt_tokens+completion_tokens=total_tokens
4. SQL安全白名单：仅允许SELECT+指定表，禁止子查询写操作
5. 降级策略：AI不可用时返回预设回复，不阻塞用户操作

### 5.4 验证
1. AI服务调用链路编译通过
2. 重试/超时机制正确触发
3. Token计数不超模型限制
4. SQL安全校验拦截非法语句
5. AI服务不可用时降级正常
