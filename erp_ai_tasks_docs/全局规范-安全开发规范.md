# 全局规范 - 安全开发规范

> 本文档定义ERP系统安全开发的完整规范，涵盖Sa-Token鉴权模式、密码策略、SSO/OAuth2集成、敏感数据处理、SQL注入防护、XSS防护及CSRF防护。系统采用Sa-Token（1.38+）作为权限框架，五层权限体系（菜单/数据/字段/按钮/接口），所有安全规范必须在开发中严格执行。

## 1. Sa-Token鉴权模式

### 1.1 五层权限体系

| 权限层级 | 说明 | 配置入口 |
|---------|------|---------|
| 菜单权限 | 控制用户可见菜单与页面 | 菜单权限配置页 |
| 数据权限 | 控制用户可操作的数据范围 | 数据权限配置页 |
| 字段权限 | 控制用户可见/可编辑的字段 | 字段权限配置页 |
| 按钮权限 | 控制用户可操作的按钮 | 菜单权限配置页（按钮级） |
| 接口权限 | 控制后端API接口的访问权限，按钮权限在后端映射为接口权限，每个按钮对应一个或多个API接口，后端接口独立校验权限，前端按钮隐藏不替代后端鉴权 | 由按钮权限自动关联，后端拦截器统一校验 |

```java
// 登录接口
@PostMapping("/auth/login")
public R<LoginVO> login(@RequestBody LoginDTO dto) {
    // 1. 验证码校验
    captchaService.verify(dto.getCaptchaId(), dto.getCaptchaCode());

    // 2. 密码校验
    SysUser user = userService.findByUsername(dto.getUsername());
    if (user == null || !passwordEncoder.matches(dto.getPassword(), user.getPassword())) {
        loginFailService.recordFail(dto.getUsername()); // 记录登录失败
        throw new AuthException("用户名或密码错误");
    }

    // 3. 账户状态检查
    if (!user.getEnableFlag()) {
        throw new AuthException("账户已被禁用");
    }

    // 4. Sa-Token登录
    StpUtil.login(user.getId());

    // 5. 存储额外信息到Session
    StpUtil.getSession().set("user", user);
    StpUtil.getSession().set("permissions", permissionService.getUserPermissions(user.getId()));
    StpUtil.getSession().set("roles", roleService.getUserRoles(user.getId()));

    // 6. 返回Token和用户信息
    return R.ok(LoginVO.builder()
        .token(StpUtil.getTokenValue())
        .userId(user.getId())
        .username(user.getUsername())
        .realName(user.getRealName())
        .permissions(StpUtil.getSession().get("permissions"))
        .build());
}
```

### 1.5 数据权限实现

```java
// 数据权限拦截器 — 基于owner_dept_id和owner_id字段
@Component
public class DataPermissionInterceptor implements InnerInterceptor {

    @Override
    public void beforeQuery(Executor executor, MappedStatement ms,
                            Object parameter, RowBounds rowBounds,
                            ResultHandler resultHandler, BoundSql boundSql) {
        // 获取当前用户数据权限范围
        DataPermissionScope scope = DataPermissionContext.getScope();
        if (scope == null || scope.isAll()) {
            return; // 全部权限，不追加条件
        }

        // 根据数据权限维度追加SQL条件
        String dataFilter = buildDataFilter(scope);
        // 注入到SQL WHERE条件中
    }

    private String buildDataFilter(DataPermissionScope scope) {
        return switch (scope.getType()) {
            case SELF -> "owner_id = " + StpUtil.getLoginIdAsLong();
            case DEPT -> "owner_dept_id = " + getCurrentDeptId();
            case DEPT_AND_CHILDREN -> "owner_dept_id IN (" + getDeptAndChildIds() + ")";
            case CUSTOM -> "owner_dept_id IN (" + scope.getDeptIds() +
                           ") OR owner_id IN (" + scope.getUserIds() + ")";
            case ALL -> "";
        };
    }
}
```

- **数据权限维度**：本人、本部门、本部门及下级部门、全部、**自定义**（支持自定义选择部门/人员列表）
- **权限部门与组织架构部门分离**：权限部门用于数据权限控制，组织部门用于员工归属管理
- **数据权限取值链路**：`WHERE owner_dept_id IN (用户可见部门) AND/OR owner_id IN (用户可见人员)`

## 2. 密码策略

### 2.1 密码复杂度要求

| 策略项 | 默认值 | 说明 |
|--------|--------|------|
| min_length | 8 | 最小长度 |
| max_length | 32 | 最大长度 |
| require_uppercase | true | 需含大写字母 |
| require_lowercase | true | 需含小写字母 |
| require_digit | true | 需含数字 |
| require_special | true | 需含特殊字符 |

**四选三规则**：最小8位 + 大小写字母 + 数字 + 特殊字符四选三 + 禁止连续3位相同字符 + 禁止与用户名相同

### 2.2 密码强度校验器

```java
@Component
public class PasswordValidator {

    public PasswordValidationResult validate(String password, String username) {
        List<String> errors = new ArrayList<>();

        // 长度校验
        if (password.length() < 8) errors.add("密码长度不能少于8位");
        if (password.length() > 32) errors.add("密码长度不能超过32位");

        // 复杂度校验（四选三）
        int complexity = 0;
        if (password.matches(".*[A-Z].*")) complexity++;
        if (password.matches(".*[a-z].*")) complexity++;
        if (password.matches(".*\\d.*")) complexity++;
        if (password.matches(".*[!@#$%^&*()_+\\-=\\[\\]{}|;:,.<>?].*")) complexity++;
        if (complexity < 3) errors.add("密码必须包含大写字母、小写字母、数字、特殊字符中的至少三种");

        // 连续字符校验
        if (password.matches(".*(.)\\1{2,}.*")) errors.add("密码不能包含连续3位相同字符");

        // 用户名校验
        if (password.equalsIgnoreCase(username)) errors.add("密码不能与用户名相同");

        return new PasswordValidationResult(errors.isEmpty(), errors, complexity);
    }
}
```

### 2.3 密码过期提醒

| 策略项 | 默认值 | 说明 |
|--------|--------|------|
| expire_days | 90 | 过期天数（0=不过期） |
| reminder_before_days | 7 | 过期前提醒天数 |

- **过期检测**：登录时检查`last_password_update`字段，计算距过期剩余天数
- **过期提醒**：过期前7天在登录后弹窗提醒用户修改密码
- **强制修改**：密码过期后，登录成功但强制跳转到修改密码页面
- **首次登录**：首次登录强制修改密码

```java
// 登录时密码过期检查
public LoginResult checkPasswordExpiry(SysUser user) {
    if (user.getPasswordExpireDate() == null) return LoginResult.ok();

    long daysRemaining = ChronoUnit.DAYS.between(
        LocalDate.now(), user.getPasswordExpireDate());

    if (daysRemaining < 0) {
        return LoginResult.forcePasswordChange("密码已过期，请修改密码");
    }
    if (daysRemaining <= 7) {
        return LoginResult.passwordExpiringSoon(daysRemaining);
    }
    return LoginResult.ok();
}
```

### 2.4 历史密码检查

| 策略项 | 默认值 | 说明 |
|--------|--------|------|
| history_count | 5 | 历史密码校验数 |

- **密码历史记录**：每次修改密码时，将旧密码（加密后）存入`sys_user_password_history`表
- **重复检查**：修改密码时检查最近5次历史密码，旧密码不可重复使用
- **存储格式**：历史密码使用与当前密码相同的加密算法（BCrypt）

```java
// 历史密码校验
public boolean isPasswordInHistory(Long userId, String newPassword) {
    List<PasswordHistory> histories = passwordHistoryMapper.selectList(
        new LambdaQueryWrapper<PasswordHistory>()
            .eq(PasswordHistory::getUserId, userId)
            .orderByDesc(PasswordHistory::getCreatedAt)
            .last("LIMIT 5")
    );

    return histories.stream()
        .anyMatch(h -> passwordEncoder.matches(newPassword, h.getPasswordHash()));
}
```

### 2.5 登录失败锁定

- **redirect_uri白名单**：仅允许配置的redirect_uri，防止开放重定向攻击
- **Token有效期**：SSO会话有效期与Sa-Token配置联动

### 4.3 传输加密

- **HTTPS强制**：生产环境所有API通信必须使用HTTPS（TLS 1.2+）
- **敏感字段加密**：前端提交密码、手机号、身份证号等敏感字段时，使用RSA公钥加密传输
- **响应加密**：后端返回敏感数据时，根据场景决定是否需要加密传输
- **API签名**：外部系统调用API时，使用HMAC-SHA256签名防篡改

### 4.4 日志脱敏

- **审计日志**：敏感数据操作记录到审计日志（谁在什么时间查看/修改了什么敏感数据）

## 5. SQL注入防护

### 5.1 MyBatis-Plus参数化查询

- **内置方法安全**：MyBatis-Plus内置CRUD方法（selectById/selectList/insert/update/delete）使用PreparedStatement参数化查询，天然防SQL注入
- **LambdaQueryWrapper**：优先使用LambdaQueryWrapper构造查询条件，避免手写SQL字符串

```java
// 正确：使用LambdaQueryWrapper（参数化）
List<SaleOrder> orders = baseMapper.selectList(
    new LambdaQueryWrapper<SaleOrder>()
        .eq(SaleOrder::getStatus, status)
        .like(SaleOrder::getOrderNo, orderNo)
        .between(SaleOrder::getOrderDate, startDate, endDate)
);
```

### 5.2 禁止拼接SQL

```xml
<!-- 错误：直接拼接用户输入（SQL注入风险！）-->
```

### 5.3 动态SQL安全

## 6. XSS防护

### 6.1 前端输入过滤

- **输入过滤**：表单输入时对HTML标签进行转义，防止恶意脚本注入
- **富文本白名单**：富文本编辑器使用DOMPurify等库进行HTML白名单过滤
- **URL校验**：对用户输入的URL进行协议校验，仅允许http/https

```typescript
// 前端XSS过滤工具
import DOMPurify from 'dompurify'

// 富文本内容净化
export function sanitizeHtml(html: string): string {
  return DOMPurify.sanitize(html, {
    ALLOWED_TAGS: ['p', 'br', 'b', 'i', 'u', 'strong', 'em', 'a', 'ul', 'ol', 'li'],
    ALLOWED_ATTR: ['href', 'target', 'rel'],
  })
}

// 普通文本转义
export function escapeHtml(text: string): string {
  const map: Record<string, string> = {
    '&': '&amp;', '<': '&lt;', '>': '&gt;',
    '"': '&quot;', "'": '&#039;',
  }
  return text.replace(/[&<>"']/g, (m) => map[m])
}
```

### 6.2 后端输出编码

- **Content-Type**：API响应设置正确的`Content-Type: application/json;charset=UTF-8`
- **HTML转义**：返回给前端的数据在必要时进行HTML转义
- **CSP头**：设置Content-Security-Policy响应头，限制可执行的脚本来源

```java
// 全局XSS过滤器
@Component
@Order(1)
public class XssFilter implements Filter {

    @Override
    public void doFilter(ServletRequest request, ServletResponse response,
                         FilterChain chain) throws IOException, ServletException {
        HttpServletRequest httpRequest = (HttpServletRequest) request;
        // 包装request，对参数进行XSS过滤
        chain.doFilter(new XssHttpServletRequestWrapper(httpRequest), response);
    }
}

// XSS过滤包装类
public class XssHttpServletRequestWrapper extends HttpServletRequestWrapper {

    @Override
    public String getParameter(String name) {
        String value = super.getParameter(name);
        return value != null ? HtmlUtils.htmlEscape(value) : null;
    }

    @Override
    public String[] getParameterValues(String name) {
        String[] values = super.getParameterValues(name);
        if (values == null) return null;
        return Arrays.stream(values)
            .map(HtmlUtils::htmlEscape)
            .toArray(String[]::new);
    }
}
```

### 6.3 Vue模板自动转义

- **{{ }}双花括号**：Vue模板中`{{ }}`插值自动转义HTML，无需额外处理
- **v-html风险**：使用`v-html`指令时必须确保内容已经过DOMPurify净化
- **禁止v-html**：除非富文本场景且已净化，禁止使用`v-html`渲染用户输入内容

### 8.2 自定义限流注解

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface RateLimit {
    /** 时间窗口内最大请求数 */
    int maxRequests() default 100;

    /** 时间窗口（秒） */
    int windowSeconds() default 60;

    /** 限流Key前缀，为空时使用方法签名 */
    String keyPrefix() default "";

    /** 限流维度 */
    LimitDimension dimension() default LimitDimension.IP;
}

public enum LimitDimension {
    IP,         // 按客户端IP
    USER,       // 按登录用户ID
    IP_USER,    // 按IP+用户ID
    PHONE       // 按手机号（用于短信接口）
}
```

### 8.3 Redis滑动窗口限流实现

```java
@Aspect
@Component
public class RateLimitAspect {

    @Autowired
    private StringRedisTemplate redisTemplate;

    @Autowired
    private HttpServletRequest request;

    @Around("@annotation(rateLimit)")
    public Object around(ProceedingJoinPoint point, RateLimit rateLimit) throws Throwable {
        String key = buildKey(rateLimit, point);
        String redisKey = "rate_limit:" + key;

        long now = System.currentTimeMillis();
        long windowStart = now - rateLimit.windowSeconds() * 1000L;

        // 使用Redis ZSET实现滑动窗口
        redisTemplate.opsForZSet().removeRangeByScore(redisKey, 0, windowStart);
        redisTemplate.opsForZSet().add(redisKey, String.valueOf(now), now);
        Long count = redisTemplate.opsForZSet().zCard(redisKey);
        redisTemplate.expire(redisKey, Duration.ofSeconds(rateLimit.windowSeconds));

        if (count != null && count > rateLimit.maxRequests()) {
            throw new BusinessException(
                ErrorCode.RATE_LIMIT_EXCEEDED,
                "请求过于频繁，请稍后重试"
            );
        }

        return point.proceed();
    }

    private String buildKey(RateLimit rateLimit, ProceedingJoinPoint point) {
        String prefix = rateLimit.keyPrefix().isEmpty()
            ? point.getSignature().toShortString()
            : rateLimit.keyPrefix();

        String dimensionValue = switch (rateLimit.dimension()) {
            case IP -> getClientIp();
            case USER -> String.valueOf(StpUtil.getLoginIdAsLong());
            case IP_USER -> getClientIp() + ":" + StpUtil.getLoginIdAsLong();
            case PHONE -> extractPhoneFromArgs(point.getArgs());
        };

        return prefix + ":" + dimensionValue;
    }

    private String getClientIp() {
        String ip = request.getHeader("X-Forwarded-For");
        if (ip == null || ip.isEmpty() || "unknown".equalsIgnoreCase(ip)) {
            ip = request.getHeader("X-Real-IP");
        }
        if (ip == null || ip.isEmpty() || "unknown".equalsIgnoreCase(ip)) {
            ip = request.getRemoteAddr();
        }
        // 多级代理取第一个IP
        if (ip != null && ip.contains(",")) {
            ip = ip.split(",")[0].trim();
        }
        return ip;
    }

    private String extractPhoneFromArgs(Object[] args) {
        for (Object arg : args) {
            if (arg instanceof SmsCodeDTO dto) {
                return dto.getPhone();
            }
        }
        return "unknown";
    }
}
```

### 8.5 登录失败锁定

连续登录失败超过阈值时锁定账号，使用Redis计数器实现：

```java
@Component
public class LoginAttemptService {

    @Autowired
    private StringRedisTemplate redisTemplate;

    private static final int MAX_ATTEMPTS = 5;
    private static final int LOCK_DURATION_MINUTES = 15;

    /**
     * 记录登录失败
     */
    public void recordFailure(String username) {
        String key = "login:fail:" + username;
        Long count = redisTemplate.opsForValue().increment(key);
        if (count != null && count == 1) {
            redisTemplate.expire(key, Duration.ofMinutes(LOCK_DURATION_MINUTES));
        }
    }

    /**
     * 判断账号是否被锁定
     */
    public boolean isLocked(String username) {
        String key = "login:fail:" + username;
        String count = redisTemplate.opsForValue().get(key);
        return count != null && Integer.parseInt(count) >= MAX_ATTEMPTS;
    }

    /**
     * 登录成功后重置失败计数
     */
    public void resetAttempts(String username) {
        String key = "login:fail:" + username;
        redisTemplate.delete(key);
    }

    /**
     * 获取剩余锁定时间（分钟）
     */
    public int getRemainingLockTime(String username) {
        String key = "login:fail:" + username;
        Long ttl = redisTemplate.getExpire(key, TimeUnit.MINUTES);
        return ttl != null ? ttl.intValue() : 0;
    }
}
```
