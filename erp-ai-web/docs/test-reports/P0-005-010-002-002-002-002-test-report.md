## 组件覆盖范围

当前 ErpFieldRenderer 支持 2 种 fieldType 映射（可扩展至20种）:

- `text` → ErpInput (单行文本)
- `textarea` → ErpTextarea (多行文本)

两种组件均实现了完整的功能接口:

- v-model 双向绑定 (modelValue + update:modelValue)
- disabled 只读模式
- fieldConfig 字段配置集成 (title/label/rules/linkages/readonly)
- validate() / reset() 暴露方法
- 校验规则: required, min, max, pattern, custom validator
- 联动规则监听 (linkage事件 + evaluateCondition)
- 错误信息展示
- 插槽支持
